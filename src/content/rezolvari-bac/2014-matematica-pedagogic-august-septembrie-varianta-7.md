## Subiectul I (30 de puncte)

### 1. Ordonați crescător $2014^0$, $\sqrt9$ și $2$

$2014^0 = 1$, $\sqrt9 = 3$, deci ordinea este $2014^0 < 2 < \sqrt9$.

**Răspuns:** $2014^0,\ 2,\ \sqrt9$. *Barem: 2p valorile, 3p ordonarea.*

### 2. Intersecția graficului $f(x) = 2x - 4$ cu axa $Ox$

$f(x) = 0 \iff 2x - 4 = 0 \iff x = 2$.

**Răspuns:** $(2, 0)$. *Barem: 2p ecuația, 3p coordonatele.*

### 3. Ecuația $2^{2x+1} = 2^{-1}$

$$2x + 1 = -1 \iff x = -1.$$

**Răspuns:** $x = -1$. *Barem: 3p egalarea exponenților, 2p soluția.*

### 4. Numere de trei cifre distincte formate cu cifrele $1, 3, 5, 7, 9$

Cifra unităților: 5 moduri; cifra zecilor: 4 moduri; cifra sutelor: 3 moduri.

$$5\cdot4\cdot3 = 60.$$

**Răspuns:** $60$ de numere. *Barem: 1p, 2p, 2p.*

### 5. $A(2,2)$, $B(5,2)$, $C(2,5)$: triunghiul $ABC$ este isoscel

$$AB = \sqrt{(5-2)^2 + 0^2} = 3, \qquad AC = \sqrt{0^2 + (5-2)^2} = 3.$$

$AB = AC$, deci triunghiul este isoscel. *Barem: 2p $AB$, 3p $AC$ și concluzia.*

### 6. Aria triunghiului $ABC$ dreptunghic în $A$ cu $AB = 5$, $BC = 13$

Pitagora: $AC = \sqrt{169 - 25} = 12$.

$$\mathcal A = \frac{AB\cdot AC}{2} = \frac{5\cdot 12}{2} = 30.$$

**Răspuns:** $30$. *Barem: 2p $AC$, 3p aria.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = xy - x - y + 5$.

### 1. $0 * 1$

$$0 * 1 = 0 - 0 - 1 + 5 = 4.$$

*Barem: 3p înlocuirea, 2p rezultatul.*

### 2. Legea este comutativă

$$y * x = yx - y - x + 5 = xy - x - y + 5 = x * y.$$

*Barem: 2p scrierea, 3p verificarea.*

### 3. $x * y = (x-1)(y-1) + 4$

$$xy - x - y + 1 + 4 = x(y - 1) - (y - 1) + 4 = (x-1)(y-1) + 4.$$

*Barem: 2p rescrierea, 3p factorizarea.*

### 4. $x * 1 = 4$ pentru orice $x$

$$x * 1 = (x - 1)\cdot 0 + 4 = 4.$$

**Răspuns:** da. *Barem: 3p înlocuirea, 2p concluzia.*

### 5. $x * x = 8$

$$(x-1)^2 + 4 = 8 \iff (x-1)^2 = 4 \iff x - 1 = \pm2 \iff x \in \{-1, 3\}.$$

**Răspuns:** $x \in \{-1, 3\}$. *Barem: 2p ecuația, 3p soluțiile.*

### 6. Numărul perechilor $(m, n)$ de întregi cu $m * n = 5$

$m * n = 5 \iff (m-1)(n-1) = 1$. Produsul a doi întregi este $1$ doar dacă ambii sunt $1$ sau ambii $-1$:

- $m - 1 = n - 1 = 1 \Rightarrow (m,n) = (2,2)$;
- $m - 1 = n - 1 = -1 \Rightarrow (m,n) = (0,0)$.

**Răspuns:** $2$ perechi. *Barem: 2p ecuația, 3p perechile.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&1\\2&0\end{pmatrix}$, $B = \begin{pmatrix}4&1\\2&3\end{pmatrix}$, $I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$.

### 1. $\det A$

$$\det A = 1\cdot0 - 1\cdot2 = -2.$$

*Barem: 3p formula, 2p calculul.*

### 2. $A\cdot A + I_2 = B$

$$A\cdot A = \begin{pmatrix}1 + 2 & 1 + 0\\2 + 0 & 2 + 0\end{pmatrix} = \begin{pmatrix}3&1\\2&2\end{pmatrix}, \qquad A\cdot A + I_2 = \begin{pmatrix}4&1\\2&3\end{pmatrix} = B.$$

*Barem: 2p $A\cdot A$, 3p finalizarea.*

### 3. $A\cdot B = B\cdot A$?

$$AB = \begin{pmatrix}4 + 2 & 1 + 3\\8 + 0 & 2 + 0\end{pmatrix} = \begin{pmatrix}6&4\\8&2\end{pmatrix}, \qquad BA = \begin{pmatrix}4 + 2 & 4 + 0\\2 + 6 & 2 + 0\end{pmatrix} = \begin{pmatrix}6&4\\8&2\end{pmatrix}.$$

**Răspuns:** da, $AB = BA$ (firesc, pentru că $B = A^2 + I_2$). *Barem: 2p $AB$, 3p $BA$.*

### 4. $C = \begin{pmatrix}0 & \frac12\\1 & -\frac12\end{pmatrix}$ este inversa lui $A$

$$A\cdot C = \begin{pmatrix}0 + 1 & \frac12 - \frac12\\0 + 0 & 1 + 0\end{pmatrix} = I_2, \qquad C\cdot A = \begin{pmatrix}0 + 1 & 0\\1 - 1 & 1 + 0\end{pmatrix} = I_2.$$

*Barem: 2p $AC$, 3p $CA$.*

### 5. $a$ cu $\det(A + aI_2) = 10$

$$\det\begin{pmatrix}1 + a & 1\\2 & a\end{pmatrix} = a(a+1) - 2 = a^2 + a - 2.$$

$a^2 + a - 2 = 10 \iff a^2 + a - 12 = 0 \iff (a + 4)(a - 3) = 0$.

**Răspuns:** $a \in \{-4, 3\}$. *Barem: 2p determinantul, 3p soluțiile.*

### 6. Ecuația $A\cdot X = B$

$A$ este inversabilă ($A^{-1} = C$), deci $X = A^{-1}B = CB$:

$$X = \begin{pmatrix}0 & \frac12\\1 & -\frac12\end{pmatrix}\begin{pmatrix}4&1\\2&3\end{pmatrix} = \begin{pmatrix}1 & \frac32\\3 & -\frac12\end{pmatrix}.$$

(Verificare: $AX = \begin{pmatrix}1 + 3 & \frac32 - \frac12\\2 & 3\end{pmatrix} = B$ ✔.)

**Răspuns:** $X = \begin{pmatrix}1 & \frac32\\3 & -\frac12\end{pmatrix}$. *Barem: 2p $X = A^{-1}B$, 3p calculul.*
