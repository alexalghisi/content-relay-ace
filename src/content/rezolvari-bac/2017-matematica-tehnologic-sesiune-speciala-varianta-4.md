## Subiectul I (30 de puncte)

### 1. Arătați că $\left(2 + \frac13\right) : \frac76 = 2$

$$2 + \frac13 = \frac73, \qquad \frac73 : \frac76 = \frac73\cdot\frac67 = 2.$$

*Barem: 3p paranteza, 2p împărțirea.*

### 2. $(x_1 + x_2)^2 - 6x_1x_2 = 1$ pentru rădăcinile lui $x^2 - 5x + 4 = 0$

Viète: $x_1 + x_2 = 5$, $x_1x_2 = 4$.

$$(x_1 + x_2)^2 - 6x_1x_2 = 25 - 24 = 1.$$

*Barem: 2p relațiile Viète, 3p calculul.*

### 3. Ecuația $\sqrt{3x - 5} = 2$

Ridicăm la pătrat: $3x - 5 = 4 \iff x = 3$. Verificare: $\sqrt{4} = 2$ ✔.

**Răspuns:** $x = 3$. *Barem: 3p ecuația, 2p soluția.*

### 4. După o ieftinire cu 25%, prețul este 600 lei

Fie $p$ prețul inițial: $p - \dfrac{25}{100}p = \dfrac34p = 600 \iff p = 800$.

**Răspuns:** 800 de lei. *Barem: 3p ecuația, 2p rezultatul.*

### 5. Distanța dintre $O(0,0)$ și $M(8,6)$

$$OM = \sqrt{8^2 + 6^2} = \sqrt{100} = 10.$$

*Barem: 3p formula, 2p calculul.*

### 6. $\sin^2 135^\circ + \sin^2 45^\circ = 1$

$\sin135^\circ = \sin(180^\circ - 45^\circ) = \sin45^\circ = \dfrac{\sqrt2}{2}$.

$$\left(\frac{\sqrt2}{2}\right)^2 + \left(\frac{\sqrt2}{2}\right)^2 = \frac12 + \frac12 = 1.$$

*Barem: 2p valorile, 3p calculul.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 2\\ 0 & 2\end{pmatrix}$, $B = \begin{pmatrix} -1 & -2\\ 2 & 0\end{pmatrix}$

#### a) $\det A = 2$

$$\det A = 1\cdot2 - 0\cdot2 = 2.$$

*Barem: 3p + 2p.*

#### b) $(A + B)(B - A) = \begin{pmatrix} 0 & 0\\ 0 & -12\end{pmatrix}$

$$A + B = \begin{pmatrix} 0 & 0\\ 2 & 2\end{pmatrix}, \qquad B - A = \begin{pmatrix} -2 & -4\\ 2 & -2\end{pmatrix},$$

$$(A+B)(B-A) = \begin{pmatrix} 0 & 0\\ 2(-2) + 2\cdot2 & 2(-4) + 2(-2)\end{pmatrix} = \begin{pmatrix} 0 & 0\\ 0 & -12\end{pmatrix}.$$

*Barem: 2p $A + B$, 3p produsul.*

#### c) $X$ cu $A\cdot X = B$

$\det A = 2 \ne 0$, deci $A^{-1} = \dfrac12\begin{pmatrix} 2 & -2\\ 0 & 1\end{pmatrix} = \begin{pmatrix} 1 & -1\\ 0 & \frac12\end{pmatrix}$.

$$X = A^{-1}B = \begin{pmatrix} 1 & -1\\ 0 & \frac12\end{pmatrix}\begin{pmatrix} -1 & -2\\ 2 & 0\end{pmatrix} = \begin{pmatrix} -3 & -2\\ 1 & 0\end{pmatrix}.$$

(Verificare: $AX = \begin{pmatrix} -3 + 2 & -2\\ 2 & 0\end{pmatrix} = B$ ✔.) *Barem: 3p inversa, 2p matricea $X$.*

### 2. Legea asociativă $x * y = x + y - 3$

#### a) $1 * 2 = 0$

$$1 * 2 = 1 + 2 - 3 = 0.$$

*Barem: 3p + 2p.*

#### b) $x^2 * x = -1$

$$x^2 + x - 3 = -1 \iff x^2 + x - 2 = 0 \iff (x+2)(x-1) = 0.$$

**Răspuns:** $x \in \{-2, 1\}$. *Barem: 3p ecuația, 2p soluțiile.*

#### c) $n * n * n * n < 3$, $n \in \mathbb N^*$

$n * n = 2n - 3$, $(2n - 3) * n = 3n - 6$, $(3n - 6) * n = 4n - 9$.

$$4n - 9 < 3 \iff n < 3.$$

**Răspuns:** $n \in \{1, 2\}$. *Barem: 2p expresia, 3p soluțiile.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^3 + 2x^2 + x$

#### a) $f'(x) = (x+1)(3x+1)$

$$f'(x) = 3x^2 + 4x + 1 = (x+1)(3x+1).$$

*Barem: 2p derivarea, 3p factorizarea.*

#### b) $\lim\limits_{x\to+\infty}\dfrac{f(x)}{xf'(x)} = \dfrac13$

$$\lim_{x\to+\infty}\frac{x^3 + 2x^2 + x}{x(x+1)(3x+1)} = \lim_{x\to+\infty}\frac{x^3\left(1 + \frac2x + \frac{1}{x^2}\right)}{x^3\left(1 + \frac1x\right)\left(3 + \frac1x\right)} = \frac{1}{3}.$$

*Barem: 2p scrierea, 3p calculul.*

#### c) $f(x) \ge -\frac{4}{27}$ pentru $x \in [-1, +\infty)$

$f'(x) = 0 \iff x \in \left\{-1, -\frac13\right\}$. Pe $\left[-1, -\frac13\right]$, $f' \le 0$ (descrescătoare); pe $\left[-\frac13, +\infty\right)$, $f' \ge 0$ (crescătoare). Minimul pe $[-1, +\infty)$ este în $-\frac13$:

$$f\left(-\frac13\right) = -\frac{1}{27} + \frac29 - \frac13 = \frac{-1 + 6 - 9}{27} = -\frac{4}{27}.$$

Deci $f(x) \ge -\dfrac{4}{27}$. $\blacksquare$ *Barem: 1p rădăcinile, 2p monotonia, 2p concluzia.*

### 2. $f(x) = x^2 + x + 1$

#### a) $\displaystyle\int_0^1 (f(x) - x^2 - 1)\,dx = \frac12$

$$\int_0^1 x\,dx = \frac{x^2}{2}\Big|_0^1 = \frac12.$$

*Barem: 2p simplificarea, 3p calculul.*

#### b) $F(x) = \frac13x^3 + \frac12x^2 + x + 2017$ este primitivă a lui $f$

$$F'(x) = \frac13\cdot3x^2 + \frac12\cdot2x + 1 + 0 = x^2 + x + 1 = f(x).$$

*Barem: 3p derivarea, 2p finalizarea.*

#### c) $n$ cu aria pe $[0,2]$ egală cu $n^2 - \frac73$

$f(x) > 0$ ($\Delta < 0$), deci

$$\mathcal A = \int_0^2 (x^2 + x + 1)\,dx = \left(\frac{x^3}{3} + \frac{x^2}{2} + x\right)\Big|_0^2 = \frac83 + 2 + 2 = \frac{20}{3}.$$

$n^2 - \dfrac73 = \dfrac{20}{3} \iff n^2 = 9$, iar $n$ natural.

**Răspuns:** $n = 3$. *Barem: 3p aria, 2p valoarea lui $n$.*
