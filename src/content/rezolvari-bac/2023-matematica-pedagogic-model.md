> **Cum să folosești rezolvarea:** lucrează întâi singur subiectul (deschide PDF-ul de mai sus), apoi compară fiecare pas. Dacă ai ajuns la alt drum corect, primești tot punctajul — baremul acceptă orice soluție corectă.

## Subiectul I (30 de puncte)

### 1. Arătați că $\left(\dfrac25\right)^{-1} + 2\dfrac12 = 5$

Puterea $-1$ inversează fracția: $\left(\dfrac25\right)^{-1} = \dfrac52$. Numărul mixt: $2\dfrac12 = \dfrac{2\cdot 2 + 1}{2} = \dfrac52$.

$$\frac52 + \frac52 = \frac{10}{2} = 5.$$

*Punctaj orientativ: 3p transformările, 2p calculul.*

### 2. $f(x) = x + 1$: $a$ pentru care $f(a)$ este media aritmetică a lui $f(1)$ și $f(5)$

$f(1) = 2$, $f(5) = 6$, iar media lor aritmetică este $\dfrac{2 + 6}{2} = 4$.

$$f(a) = 4 \iff a + 1 = 4 \iff a = 3.$$

**Răspuns:** $a = 3$. *Punctaj orientativ: 3p valorile funcției și media, 2p valoarea lui $a$.*

### 3. Ecuația $2\sqrt{x - 1} + 3 = 5$

**Condiție de existență:** $x - 1 \ge 0$, adică $x \ge 1$.

$$2\sqrt{x-1} = 2 \iff \sqrt{x - 1} = 1 \iff x - 1 = 1 \iff x = 2.$$

(Ridicarea la pătrat e permisă: ambii membri sunt nenegativi.) Verificare: $2\sqrt1 + 3 = 5$ ✔.

**Răspuns:** $x = 2$. *Punctaj orientativ: 3p izolarea radicalului și ridicarea la pătrat, 2p soluția care convine.*

### 4. Probabilitatea ca un număr din $M = \{1, 2, \dots, 2022\}$ să fie multiplu de 2

Cazuri posibile: **2022**. Multiplii lui 2 din $M$ sunt $2, 4, \dots, 2022 = 2\cdot 1011$, deci **1011** cazuri favorabile.

$$p = \frac{1011}{2022} = \frac12.$$

**Răspuns:** $p = \dfrac12$. *Punctaj orientativ: 2p cazurile posibile, 3p cazurile favorabile și probabilitatea.*

### 5. $A(1,3)$, $B(-2,-1)$, $C(1,-1)$: triunghiul $ABC$ este dreptunghic

Calculăm lungimile laturilor cu formula distanței $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$:

$$AB = \sqrt{(-3)^2 + (-4)^2} = 5, \quad AC = \sqrt{0^2 + (-4)^2} = 4, \quad BC = \sqrt{3^2 + 0^2} = 3.$$

$AC^2 + BC^2 = 16 + 9 = 25 = AB^2$, deci, după reciproca teoremei lui Pitagora, triunghiul $ABC$ este dreptunghic în $C$.

(Altfel: $AC$ este verticală — $A$ și $C$ au aceeași abscisă —, iar $BC$ este orizontală — aceeași ordonată —, deci $AC \perp BC$.) *Punctaj orientativ: 3p lungimile laturilor, 2p concluzia.*

### 6. $R = 5$, $BC = 10$: calculați $\sin A$

Teorema sinusurilor: $\dfrac{BC}{\sin A} = 2R$, deci

$$\sin A = \frac{BC}{2R} = \frac{10}{10} = 1.$$

(Deci $A = 90^\circ$: $BC$ este diametru al cercului circumscris.)

**Răspuns:** $\sin A = 1$. *Punctaj orientativ: 3p teorema sinusurilor, 2p rezultatul.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă pe $\mathbb R$: $x \circ y = xy + 8(x + y) + 56$.

### 1. Arătați că $(-5) \circ (-6) = -2$

$$(-5)\circ(-6) = 30 + 8(-11) + 56 = 30 - 88 + 56 = -2.$$

*Punctaj orientativ: 3p înlocuirea, 2p calculul.*

### 2. Demonstrați că $x \circ y = (x + 8)(y + 8) - 8$

Scriem $56 = 64 - 8$ și factorizăm:

$$x \circ y = xy + 8x + 8y + 64 - 8 = x(y + 8) + 8(y + 8) - 8 = (x + 8)(y + 8) - 8.$$

*Punctaj orientativ: 2p regruparea, 3p factorizarea.*

### 3. $e = -7$ este elementul neutru

$$x \circ (-7) = (x + 8)(-7 + 8) - 8 = x + 8 - 8 = x, \qquad (-7)\circ x = (1)(x + 8) - 8 = x,$$

pentru orice $x$ real, deci $e = -7$ este elementul neutru. *Punctaj orientativ: 2p + 3p.*

### 4. Inecuația $x \circ (x + 2) \le -8$

$$x \circ (x+2) = (x + 8)(x + 10) - 8 \le -8 \iff (x + 8)(x + 10) \le 0.$$

Funcția de gradul al II-lea $(x+8)(x+10)$ are rădăcinile $-10$ și $-8$ și este $\le 0$ între ele.

**Răspuns:** $x \in [-10, -8]$. *Punctaj orientativ: 2p forma produsului, 3p intervalul.*

### 5. Ecuația $2^x \circ (-7) = 16$

$-7$ este element neutru (punctul 3), deci $2^x \circ (-7) = 2^x$. Ecuația devine

$$2^x = 16 = 2^4 \iff x = 4.$$

**Răspuns:** $x = 4$. *Punctaj orientativ: 2p folosirea elementului neutru, 3p rezolvarea.*

### 6. $a$ real cu $2(a \circ 1) = a + (a \circ 2)$

Cu forma de la 2:

$$a \circ 1 = 9(a + 8) - 8 = 9a + 64, \qquad a \circ 2 = 10(a + 8) - 8 = 10a + 72.$$

$$2(9a + 64) = a + 10a + 72 \iff 18a + 128 = 11a + 72 \iff 7a = -56 \iff a = -8.$$

Verificare: $(-8)\circ 1 = -8$ și $(-8)\circ 2 = -8$ ($-8$ este element absorbant), iar $2\cdot(-8) = -16 = -8 + (-8)$ ✔.

**Răspuns:** $a = -8$. *Punctaj orientativ: 2p expresiile, 3p rezolvarea ecuației.*

## Subiectul al III-lea (30 de puncte)

$I_2 = \begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix}$, $A = \begin{pmatrix}0 & 3\\ 2 & 1\end{pmatrix}$, $M(x) = I_2 + xA$.

### 1. $\det A = -6$

$$\det A = \begin{vmatrix}0 & 3\\ 2 & 1\end{vmatrix} = 0\cdot 1 - 3\cdot 2 = -6.$$

*Punctaj orientativ: 3p dezvoltarea, 2p rezultatul.*

### 2. $M(x) = \begin{pmatrix}1 & 3x\\ 2x & x + 1\end{pmatrix}$

$$M(x) = \begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix} + \begin{pmatrix}0 & 3x\\ 2x & x\end{pmatrix} = \begin{pmatrix}1 & 3x\\ 2x & x + 1\end{pmatrix}.$$

*Punctaj orientativ: 2p $xA$, 3p suma.*

### 3. Suma elementelor lui $B = (-1)\cdot M(-1)\cdot M(1)$ este pătrat perfect

$M(-1) = \begin{pmatrix}1 & -3\\ -2 & 0\end{pmatrix}$, $M(1) = \begin{pmatrix}1 & 3\\ 2 & 2\end{pmatrix}$.

$$M(-1)\cdot M(1) = \begin{pmatrix}1 - 6 & 3 - 6\\ -2 + 0 & -6 + 0\end{pmatrix} = \begin{pmatrix}-5 & -3\\ -2 & -6\end{pmatrix}, \qquad B = \begin{pmatrix}5 & 3\\ 2 & 6\end{pmatrix}.$$

Suma elementelor: $5 + 3 + 2 + 6 = 16 = 4^2$, pătratul numărului natural 4. *Punctaj orientativ: 3p produsul, 2p suma și concluzia.*

### 4. $x$ real cu $\det(M(x)) = 0$

$$\det(M(x)) = 1\cdot(x + 1) - 3x\cdot 2x = -6x^2 + x + 1.$$

$-6x^2 + x + 1 = 0 \iff 6x^2 - x - 1 = 0$, cu $\Delta = 1 + 24 = 25$:

$$x_{1,2} = \frac{1 \pm 5}{12} \Rightarrow x_1 = \frac12,\ x_2 = -\frac13.$$

**Răspuns:** $x \in \left\{-\dfrac13, \dfrac12\right\}$. *Punctaj orientativ: 3p determinantul, 2p soluțiile.*

### 5. $C = M(1) - M(2) + M(3) - M(4)$ este inversabilă

Cu $M(x) = I_2 + xA$:

$$C = (1 - 1 + 1 - 1)I_2 + (1 - 2 + 3 - 4)A = 0\cdot I_2 - 2A = -2A = \begin{pmatrix}0 & -6\\ -4 & -2\end{pmatrix}.$$

$$\det C = 0\cdot(-2) - (-6)(-4) = -24 \ne 0,$$

deci $C$ este inversabilă. (Sau: $\det(-2A) = (-2)^2\det A = 4\cdot(-6) = -24$.) *Punctaj orientativ: 3p matricea $C$, 2p determinantul nenul.*

### 6. Perechile $(a, b)$ de numere naturale cu $aM(b) + bM(a) = I_2$

$$aM(b) + bM(a) = a(I_2 + bA) + b(I_2 + aA) = (a + b)I_2 + 2abA.$$

În formă explicită: $\begin{pmatrix}a + b & 6ab\\ 4ab & a + b + 2ab\end{pmatrix} = \begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix}$.

Din elementul $(1,2)$: $6ab = 0 \Rightarrow ab = 0$; din $(1,1)$: $a + b = 1$. Atunci și $(2,2)$: $1 + 0 = 1$ ✔. Numere naturale cu produs 0 și suma 1: $(a, b) \in \{(0, 1), (1, 0)\}$.

**Răspuns:** $(0, 1)$ și $(1, 0)$. *Punctaj orientativ: 3p forma $(a+b)I_2 + 2abA$, 2p perechile.*

## Ce merită reținut din model

- **Legea** $(x+k)(y+k) - k$: $-k$ este absorbant, $1 - k$ este neutru.
- **Teorema sinusurilor** $\frac{a}{\sin A} = 2R$ rezolvă direct problemele cu raza cercului circumscris.
- **Matrice de forma** $I_2 + xA$: lucrează cu $I_2$ și $A$ separat, fără să scrii elementele, ca la punctele 5 și 6.
