## Subiectul I (30 de puncte)

### 1. Arătați că $\left(\frac13 - \frac14\right) : \frac{1}{12} = 1$

$$\frac13 - \frac14 = \frac{1}{12}, \qquad \frac{1}{12} : \frac{1}{12} = 1.$$

*Barem: 3p + 2p.*

### 2. $4(x_1 + x_2) - 3x_1x_2 = 2$ pentru rădăcinile lui $x^2 - 5x + 6 = 0$

Viète: $x_1 + x_2 = 5$, $x_1x_2 = 6$. $4\cdot5 - 3\cdot6 = 2$. *Barem: 2p + 3p.*

### 3. Ecuația $\sqrt{x - 1} = 2$

$x - 1 = 4 \iff x = 5$, care verifică. *Barem: 3p + 2p.*

### 4. După o ieftinire cu 10%, prețul este 90 lei

$p - 0{,}1p = 0{,}9p = 90 \iff p = 100$.

**Răspuns:** 100 de lei. *Barem: 3p + 2p.*

### 5. Lungimea segmentului $AB$, $A(5,1)$, $B(3,1)$

$$AB = \sqrt{(3-5)^2 + 0^2} = 2.$$

*Barem: 3p + 2p.*

### 6. Dacă $x \in \left(0, \frac\pi2\right)$ și $\cos x = \frac45$, atunci $\sin x = \frac35$

$\sin^2 x = 1 - \frac{16}{25} = \frac{9}{25}$; în cadranul I, $\sin x = \frac35$. *Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 2 & 3\\ 3 & 2\end{pmatrix}$, $B = \begin{pmatrix} x & 1\\ 1 & x\end{pmatrix}$

#### a) $\det A = -5$

$$\det A = 4 - 9 = -5.$$

*Barem: 3p + 2p.*

#### b) $A\cdot B = B\cdot A$

$$A\cdot B = \begin{pmatrix} 2x + 3 & 2 + 3x\\ 3x + 2 & 3 + 2x\end{pmatrix}, \qquad B\cdot A = \begin{pmatrix} 2x + 3 & 3x + 2\\ 2 + 3x & 3 + 2x\end{pmatrix}.$$

Cele două matrice coincid pentru orice $x$. $\blacksquare$ *Barem: 2p + 3p.*

#### c) $x$ cu $A\cdot A - 3(A + B) = I_2$

$$A\cdot A = \begin{pmatrix} 13 & 12\\ 12 & 13\end{pmatrix}, \qquad A + B = \begin{pmatrix} 2 + x & 4\\ 4 & 2 + x\end{pmatrix},$$

$$A\cdot A - 3(A + B) = \begin{pmatrix} 13 - 3(2 + x) & 0\\ 0 & 13 - 3(2 + x)\end{pmatrix} = \begin{pmatrix} 7 - 3x & 0\\ 0 & 7 - 3x\end{pmatrix}.$$

$7 - 3x = 1 \iff x = 2$. **Răspuns:** $x = 2$. *Barem: 2p + 3p.*

### 2. $x * y = \frac13xy + x + y$

#### a) $1 * (-3) = -3$

$$\frac13\cdot1\cdot(-3) + 1 - 3 = -1 + 1 - 3 = -3.$$

*Barem: 3p + 2p.*

#### b) $x * y = \frac13(x+3)(y+3) - 3$

$$\frac13xy + x + y + 3 - 3 = \frac13(xy + 3x + 3y + 9) - 3 = \frac13(x+3)(y+3) - 3.$$

*Barem: 3p + 2p.*

#### c) $x \ne 0$ cu $x * \frac1x = -3$

$$\frac13(x + 3)\left(\frac1x + 3\right) - 3 = -3 \iff (x + 3)\left(\frac1x + 3\right) = 0.$$

$x + 3 = 0 \Rightarrow x = -3$; $\frac1x + 3 = 0 \Rightarrow x = -\frac13$.

**Răspuns:** $x \in \left\{-3, -\dfrac13\right\}$. *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^3 - 3x$

#### a) $f'(x) = 3(x-1)(x+1)$

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1).$$

*Barem: 3p + 2p.*

#### b) $\lim\limits_{x\to0}\dfrac{f(x) + 3x}{x} = 0$

$$\lim_{x\to0}\frac{x^3}{x} = \lim_{x\to0}x^2 = 0.$$

*Barem: 2p + 3p.*

#### c) $f(x) \ge -2$ pentru $x \in [-1, +\infty)$

$f' \le 0$ pe $[-1, 1]$, $f' \ge 0$ pe $[1, +\infty)$, deci minimul pe $[-1, +\infty)$ este $f(1) = 1 - 3 = -2$. $\blacksquare$ *Barem: 2p + 1p + 1p + 1p.*

### 2. $f(x) = x^4 + x + 1$

#### a) $\displaystyle\int_0^1(f(x) - x - 1)\,dx = \frac15$

$$\int_0^1 x^4\,dx = \frac{x^5}{5}\Big|_0^1 = \frac15.$$

*Barem: 2p + 3p.*

#### b) $\displaystyle\int_1^e\big(f(x) - x^4 - 1\big)\ln x\,dx = \frac{e^2 + 1}{4}$

$f(x) - x^4 - 1 = x$, deci integrala este $\displaystyle\int_1^e x\ln x\,dx$. Prin părți:

$$\frac{x^2}{2}\ln x\Big|_1^e - \int_1^e\frac{x^2}{2}\cdot\frac1x\,dx = \frac{e^2}{2} - \frac{x^2}{4}\Big|_1^e = \frac{e^2}{2} - \frac{e^2}{4} + \frac14 = \frac{e^2 + 1}{4}.$$

*Barem: 3p + 2p.*

#### c) Aria sub grafic pe $[0,1]$

$f(x) > 0$ pe $[0,1]$:

$$\mathcal A = \int_0^1(x^4 + x + 1)\,dx = \frac15 + \frac12 + 1 = \frac{17}{10}.$$

*Barem: 3p + 2p.*

## Ce merită reținut din varianta 5

- **Legea $\frac1a(x+a)(y+a) - a$**: $-a$ este absorbant, iar ecuațiile se reduc la un produs nul.
- **Matrice simetrice de forma $\begin{pmatrix}p&q\\q&p\end{pmatrix}$** comută între ele.
- **$\int x\ln x\,dx = \frac{x^2}{2}\ln x - \frac{x^2}{4} + C$**.
