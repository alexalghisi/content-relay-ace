## Subiectul I (30 de puncte)

### 1. Numerele întregi $x$ cu $-1 \le \dfrac{x+1}{3} < 1$

Înmulțim cu $3$: $-3 \le x + 1 < 3 \iff -4 \le x < 2$.

**Răspuns:** $x \in \{-4, -3, -2, -1, 0, 1\}$. *Barem: 2p, 2p dubla inegalitate, 1p soluțiile întregi.*

### 2. Intersecția graficelor $f(x) = 2x - 1$ și $g(x) = x^2 - 2x + 3$

$$2x - 1 = x^2 - 2x + 3 \iff x^2 - 4x + 4 = 0 \iff x = 2, \quad y = f(2) = 3.$$

**Răspuns:** $A(2, 3)$. *Barem: 1p ecuația, 2p rezolvarea, 2p punctul.*

### 3. Ecuația $2 - \sqrt{2 - x} = x$

Rescriem $\sqrt{2-x} = 2 - x$, cu condiția $2 - x \ge 0$, adică $x \le 2$. Ridicăm la pătrat:

$$2 - x = (2 - x)^2 \iff 2 - x = 4 - 4x + x^2 \iff x^2 - 3x + 2 = 0 \iff x \in \{1, 2\}.$$

Ambele respectă $x \le 2$ și verifică ecuația.

**Răspuns:** $x \in \{1, 2\}$. *Barem: 1p rescrierea, 1p condiția, 2p ecuația, 1p soluțiile.*

### 4. Calculați $\dfrac{P_5}{C_5^2 + A_6^2}$

$$P_5 = 5! = 120, \quad C_5^2 = \frac{5\cdot4}{2} = 10, \quad A_6^2 = 6\cdot5 = 30.$$

$$\frac{120}{10 + 30} = 3.$$

**Răspuns:** $3$. *Barem: 3p valorile, 2p calculul.*

### 5. Ecuația dreptei $AB$, $A(2,3)$, $B(-1,0)$

$$\frac{y - 3}{0 - 3} = \frac{x - 2}{-1 - 2} \iff y - 3 = x - 2 \iff y = x + 1.$$

**Răspuns:** $AB: y = x + 1$. *Barem: 3p formula, 2p ecuația.*

### 6. Perimetrul triunghiului $MNP$: $MN = 2$, $MP = 3$, $\angle NMP = 120^\circ$

Teorema cosinusului:

$$NP^2 = MN^2 + MP^2 - 2\cdot MN\cdot MP\cdot\cos120^\circ = 4 + 9 - 12\cdot\left(-\frac12\right) = 19.$$

$NP = \sqrt{19}$, deci perimetrul este $2 + 3 + \sqrt{19} = 5 + \sqrt{19}$.

**Răspuns:** $5 + \sqrt{19}$. *Barem: 2p teorema, 2p $NP$, 1p perimetrul.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}1&2\\0&1\end{pmatrix}$

#### a) $\det A$

$$\det A = 1\cdot1 - 2\cdot0 = 1.$$

*Barem: 2p scrierea, 3p calculul.*

#### b) $A^2 - 2A + I_2$

$$A^2 = \begin{pmatrix}1&4\\0&1\end{pmatrix}, \quad A^2 - 2A + I_2 = \begin{pmatrix}1 - 2 + 1 & 4 - 4 + 0\\0 & 1 - 2 + 1\end{pmatrix} = O_2.$$

**Răspuns:** $O_2$. *Barem: 2p $A^2$, 2p calculul, 1p rezultatul.*

#### c) Matricele $X \in \mathcal M_2(\mathbb R)$ cu $X^2 = A$

Fie $X = \begin{pmatrix}a&b\\c&d\end{pmatrix}$; $X^2 = \begin{pmatrix}a^2 + bc & b(a+d)\\c(a+d) & d^2 + bc\end{pmatrix}$.

$$X^2 = A \iff \begin{cases}a^2 + bc = 1\\b(a+d) = 2\\c(a+d) = 0\\d^2 + bc = 1\end{cases}$$

Din a doua, $a + d \ne 0$, deci din a treia $c = 0$. Atunci $a^2 = d^2 = 1$ și $a + d \ne 0$ dau $a = d$, iar $2ab = 2$, adică $ab = 1$.

- $a = d = 1$, $b = 1$;
- $a = d = -1$, $b = -1$.

**Răspuns:** $X = \begin{pmatrix}1&1\\0&1\end{pmatrix}$ sau $X = \begin{pmatrix}-1&-1\\0&-1\end{pmatrix}$. *Barem: 1p $X^2$, 3p sistemul, 1p soluțiile.*

### 2. $x * y = xy - 3x - 3y + 12$

#### a) $x * y = (x-3)(y-3) + 3$

$$(x-3)(y-3) + 3 = xy - 3x - 3y + 9 + 3 = x * y.$$

*Barem: 3p dezvoltarea, 2p concluzia.*

#### b) $x * x = 19$

$$(x-3)^2 + 3 = 19 \iff (x-3)^2 = 16 \iff x - 3 = \pm4 \iff x \in \{-1, 7\}.$$

**Răspuns:** $x \in \{-1, 7\}$. *Barem: 2p ecuația, 3p soluțiile.*

#### c) $\sqrt[3]1 * \sqrt[3]2 * \dots * \sqrt[3]{2011}$

$x * 3 = 3 * x = 3$ pentru orice $x$, iar printre termeni apare $\sqrt[3]{27} = 3$. Cu asociativitatea:

$$\left(\sqrt[3]1 * \dots * \sqrt[3]{26}\right) * 3 * \left(\sqrt[3]{28} * \dots * \sqrt[3]{2011}\right) = 3.$$

**Răspuns:** $3$. *Barem: 2p elementul absorbant, 2p gruparea, 1p rezultatul.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = e^x - x$

#### a) $f'(x) - f(x) = x - 1$

$f'(x) = e^x - 1$, deci $f'(x) - f(x) = (e^x - 1) - (e^x - x) = x - 1$. *Barem: 3p derivata, 2p calculul.*

#### b) Tangenta în $x = 0$

$f(0) = 1$, $f'(0) = 0$, deci $y - 1 = 0$.

**Răspuns:** $y = 1$. *Barem: 2p formula, 2p valorile, 1p ecuația.*

#### c) Asimptota oblică spre $-\infty$

$$m = \lim_{x\to-\infty}\frac{e^x - x}{x} = \lim_{x\to-\infty}\left(\frac{e^x}{x} - 1\right) = -1, \qquad n = \lim_{x\to-\infty}\big(f(x) + x\big) = \lim_{x\to-\infty}e^x = 0.$$

**Răspuns:** $y = -x$. *Barem: 2p $m$, 2p $n$, 1p ecuația.*

### 2. $f:(0,+\infty)\to\mathbb R$, $f(x) = \dfrac1x + \dfrac1{x+1}$

#### a) $\displaystyle\int_1^e\left(f(x) - \frac1{x+1}\right)dx$

$$\int_1^e\frac1x\,dx = \ln x\Big|_1^e = 1.$$

**Răspuns:** $1$. *Barem: 2p simplificarea, 2p primitiva, 1p rezultatul.*

#### b) Aria între grafic, $Ox$, $x = 1$, $x = 2$

$f > 0$ pe $[1,2]$:

$$\mathcal A = \int_1^2\left(\frac1x + \frac1{x+1}\right)dx = \big(\ln x + \ln(x+1)\big)\Big|_1^2 = (\ln2 + \ln3) - \ln2 = \ln3.$$

**Răspuns:** $\ln 3$. *Barem: 2p formula, 2p primitiva, 1p rezultatul.*

#### c) Volumul corpului de rotație pentru $g = f$ pe $[1,2]$

$$g^2(x) = \frac1{x^2} + \frac{1}{(x+1)^2} + \frac{2}{x(x+1)}, \qquad \frac{1}{x(x+1)} = \frac1x - \frac1{x+1}.$$

$$V = \pi\left[-\frac1x - \frac1{x+1} + 2\ln\frac{x}{x+1}\right]_1^2 = \pi\left[\left(-\frac12 - \frac13 + 2\ln\frac23\right) - \left(-1 - \frac12 + 2\ln\frac12\right)\right].$$

$$V = \pi\left(\frac23 + 2\ln\frac43\right).$$

**Răspuns:** $V = \pi\left(\dfrac23 + 2\ln\dfrac43\right)$. *Barem: 1p formula, 1p dezvoltarea, 2p primitivele, 1p rezultatul.*

## Ce merită reținut din model

- **Ecuații de tip $\sqrt{u} = u$**: pătratul dă $u(u - 1) = 0$; nu uita condiția $u \ge 0$.
- **Rădăcina pătrată a unei matrice**: scrie $X^2$ general și rezolvă sistemul începând cu ecuațiile simple.
- **Termenul absorbant** apare „ascuns”: $\sqrt[3]{27} = 3$.
- **Volume cu sume de fracții**: ridică la pătrat și descompune $\frac{1}{x(x+1)}$ în fracții simple.
