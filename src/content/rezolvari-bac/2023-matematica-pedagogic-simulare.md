## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt2\left(2\sqrt2 - \sqrt6\right) + 2\sqrt3 = 4$

Distribuim $\sqrt2$: $\sqrt2\cdot 2\sqrt2 = 2\cdot 2 = 4$ și $\sqrt2\cdot\sqrt6 = \sqrt{12} = 2\sqrt3$.

$$\sqrt2\left(2\sqrt2 - \sqrt6\right) + 2\sqrt3 = 4 - 2\sqrt3 + 2\sqrt3 = 4.$$

*Barem: 3p desfacerea parantezei, 2p finalizarea.*

### 2. $f(x) = 2x + 1$: $a > 0$ pentru care $f(a)$ este media geometrică a lui $f(0)$ și $f(4)$

$f(0) = 1$, $f(4) = 9$, iar media geometrică este $\sqrt{1\cdot 9} = 3$.

$$f(a) = 3 \iff 2a + 1 = 3 \iff a = 1 > 0.$$

**Răspuns:** $a = 1$. *Barem: 3p valorile $f(a)$, $f(0)$, $f(4)$, 2p ecuația și soluția.*

### 3. Ecuația $2\cdot 3^{x+1} = 18$

Împărțim la 2: $3^{x+1} = 9 = 3^2$. Funcția exponențială fiind injectivă, egalăm exponenții:

$$x + 1 = 2 \iff x = 1.$$

**Răspuns:** $x = 1$. *Barem: 3p $3^{x+1} = 3^2$, 2p soluția.*

### 4. Prețul de 300 de lei devine 360 de lei după o scumpire cu $p\%$

$$300 + \frac{p}{100}\cdot 300 = 360 \iff 3p = 60 \iff p = 20.$$

(Scumpirea este de 60 de lei, iar $\frac{60}{300} = \frac{20}{100}$.)

**Răspuns:** $p = 20$. *Barem: 3p ecuația, 2p valoarea lui $p$.*

### 5. $A(-1, 2)$, $B(1, 1)$, $C(3, m)$: $C$ aparține dreptei $AB$

Ecuația dreptei prin două puncte: $\dfrac{x - x_A}{x_B - x_A} = \dfrac{y - y_A}{y_B - y_A}$:

$$\frac{x + 1}{2} = \frac{y - 2}{-1} \iff -(x + 1) = 2(y - 2) \iff x + 2y - 3 = 0.$$

$C(3, m) \in AB \iff 3 + 2m - 3 = 0 \iff m = 0$.

**Răspuns:** $m = 0$. *Barem: 3p ecuația dreptei $AB$, 2p valoarea lui $m$.*

### 6. Triunghi dreptunghic în $A$, $AB = 6$, $\angle C = 60^\circ$: arătați că $BC = 4\sqrt3$

$AB$ este cateta opusă unghiului $C$, iar $BC$ este ipotenuza:

$$\sin C = \frac{AB}{BC} \Rightarrow \frac{\sqrt3}{2} = \frac{6}{BC} \Rightarrow BC = \frac{12}{\sqrt3} = \frac{12\sqrt3}{3} = 4\sqrt3.$$

*Barem: 3p relația cu $\sin C$, 2p calculul lui $BC$.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă pe $\mathbb R$: $x \circ y = \dfrac13 xy - x - y + 6$.

### 1. Arătați că $1 \circ (-3) = 7$

$$1 \circ (-3) = \frac13\cdot 1\cdot(-3) - 1 - (-3) + 6 = -1 - 1 + 3 + 6 = 7.$$

*Barem: 3p înlocuirea, 2p calculul.*

### 2. $e = 6$ este elementul neutru

$$x \circ 6 = \frac13\cdot 6x - x - 6 + 6 = 2x - x = x, \qquad 6 \circ x = \frac13\cdot 6x - 6 - x + 6 = x,$$

pentru orice $x$ real, deci $e = 6$ este elementul neutru. *Barem: 2p $x \circ 6 = x$, 3p $6 \circ x = x$ și concluzia.*

### 3. Ecuația $\sqrt x \circ 6 = 1$, $x > 0$

$6$ este element neutru, deci $\sqrt x \circ 6 = \sqrt x$. Ecuația devine $\sqrt x = 1 \iff x = 1$, care este pozitiv, deci convine.

**Răspuns:** $x = 1$. *Barem: 3p $\sqrt x \circ 6 = \sqrt x$, 2p soluția.*

### 4. Numerele naturale $n$ cu $2 \circ n < (2n) \circ 1 + 1$

$$2 \circ n = \frac{2n}{3} - 2 - n + 6 = 4 - \frac{n}{3}, \qquad (2n)\circ 1 = \frac{2n}{3} - 2n - 1 + 6 = 5 - \frac{4n}{3}.$$

Inecuația:

$$4 - \frac n3 < 5 - \frac{4n}{3} + 1 \iff \frac{4n}{3} - \frac n3 < 2 \iff n < 2.$$

Numerele naturale mai mici decât 2: $0$ și $1$.

**Răspuns:** $n \in \{0, 1\}$. *Barem: 2p expresiile, 3p rezolvarea și soluțiile naturale.*

### 5. Demonstrați că $x \circ y = \dfrac13(x - 3)(y - 3) + 3$

Pornim de la definiție și scriem $6 = 3 + 3$:

$$x \circ y = \frac13 xy - x - y + 3 + 3 = \frac13 x(y - 3) - (y - 3) + 3 = (y - 3)\left(\frac13 x - 1\right) + 3.$$

Cum $\dfrac13 x - 1 = \dfrac13(x - 3)$, obținem $x \circ y = \dfrac13(x-3)(y-3) + 3$. (Verificare inversă: $\frac13(xy - 3x - 3y + 9) + 3 = \frac13xy - x - y + 6$ ✔.) *Barem: 2p regruparea, 3p factorizarea.*

### 6. Calculați $\sqrt1 \circ \sqrt2 \circ \dots \circ \sqrt{2023}$

Din forma de la 5, $3$ este element absorbant:

$$x \circ 3 = \frac13(x - 3)\cdot 0 + 3 = 3, \qquad 3 \circ x = 3, \quad \forall x \in \mathbb R.$$

Printre termeni apare $\sqrt9 = 3$. Folosind asociativitatea, grupăm:

$$\left(\sqrt1 \circ \dots \circ \sqrt8\right) \circ 3 \circ \left(\sqrt{10} \circ \dots \circ \sqrt{2023}\right) = 3 \circ \left(\sqrt{10} \circ \dots \circ \sqrt{2023}\right) = 3.$$

**Răspuns:** $3$. *Barem: 2p elementul absorbant, 3p gruparea și rezultatul.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}-1 & 2\\ 2 & 1\end{pmatrix}$, $B(a) = \begin{pmatrix}a+2 & 1\\ 1 & a\end{pmatrix}$, $I_2 = \begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix}$.

### 1. $A\cdot A = 5I_2$

$$A\cdot A = \begin{pmatrix}1 + 4 & -2 + 2\\ -2 + 2 & 4 + 1\end{pmatrix} = \begin{pmatrix}5 & 0\\ 0 & 5\end{pmatrix} = 5I_2.$$

*Barem: 3p produsul, 2p concluzia.*

### 2. $a$ real cu $\det(B(a) + A) = 0$

$$B(a) + A = \begin{pmatrix}a + 1 & 3\\ 3 & a + 1\end{pmatrix}, \qquad \det(B(a) + A) = (a + 1)^2 - 9.$$

$(a+1)^2 = 9 \iff a + 1 = \pm 3 \iff a \in \{-4, 2\}$.

**Răspuns:** $a = -4$ sau $a = 2$. *Barem: 3p determinantul, 2p soluțiile.*

### 3. $B(q - 1)$ este inversabilă pentru orice $q$ rațional

$$B(q-1) = \begin{pmatrix}q + 1 & 1\\ 1 & q - 1\end{pmatrix}, \qquad \det(B(q-1)) = (q+1)(q-1) - 1 = q^2 - 2.$$

$q^2 - 2 = 0 \iff q = \pm\sqrt2$, numere iraționale. Pentru $q$ rațional, determinantul este nenul, deci $B(q-1)$ este inversabilă. *Barem: 2p determinantul, 3p justificarea.*

### 4. $a$ real cu $B(a)\cdot B(a) = B\left(\dfrac54\right)$

$$B(a)\cdot B(a) = \begin{pmatrix}(a+2)^2 + 1 & (a + 2) + a\\ (a+2) + a & 1 + a^2\end{pmatrix} = \begin{pmatrix}(a+2)^2 + 1 & 2a + 2\\ 2a + 2 & a^2 + 1\end{pmatrix},$$

$$B\left(\frac54\right) = \begin{pmatrix}\frac{13}{4} & 1\\ 1 & \frac54\end{pmatrix}.$$

Din elementul $(1,2)$: $2a + 2 = 1 \Rightarrow a = -\dfrac12$. Verificăm celelalte elemente: $\left(\frac32\right)^2 + 1 = \frac{13}{4}$ ✔ și $\frac14 + 1 = \frac54$ ✔.

**Răspuns:** $a = -\dfrac12$. *Barem: 3p calculul matricelor, 2p valoarea lui $a$.* Nu uita verificarea: o singură ecuație nu garantează egalitatea tuturor elementelor.

### 5. $x > 0$ cu $B(\log_2 x) - B(\log_4 x) = I_2$

Pentru orice $u, v$: $B(u) - B(v) = \begin{pmatrix}u - v & 0\\ 0 & u - v\end{pmatrix} = (u - v)I_2$. Deci condiția devine

$$\log_2 x - \log_4 x = 1.$$

Schimbăm baza: $\log_4 x = \dfrac{\log_2 x}{\log_2 4} = \dfrac{\log_2 x}{2}$. Atunci $\dfrac{\log_2 x}{2} = 1 \Rightarrow \log_2 x = 2 \Rightarrow x = 4$, pozitiv, deci convine.

**Răspuns:** $x = 4$. *Barem: 2p diferența matricelor, 3p rezolvarea ecuației logaritmice.*

### 6. $X \in \mathcal M_2(\mathbb R)$ cu $X\cdot B(0) = A$

Fie $X = \begin{pmatrix}a & b\\ c & d\end{pmatrix}$. Cu $B(0) = \begin{pmatrix}2 & 1\\ 1 & 0\end{pmatrix}$:

$$X\cdot B(0) = \begin{pmatrix}2a + b & a\\ 2c + d & c\end{pmatrix} = \begin{pmatrix}-1 & 2\\ 2 & 1\end{pmatrix}.$$

Identificăm: $a = 2$, $2a + b = -1 \Rightarrow b = -5$; $c = 1$, $2c + d = 2 \Rightarrow d = 0$.

**Răspuns:** $X = \begin{pmatrix}2 & -5\\ 1 & 0\end{pmatrix}$. (Același rezultat se obține cu $X = A\cdot B(0)^{-1}$, unde $B(0)^{-1} = \begin{pmatrix}0 & 1\\ 1 & -2\end{pmatrix}$.) *Barem: 2p produsul $X\cdot B(0)$, 3p identificarea și matricea $X$.*

## Ce merită reținut din această simulare

- **Media geometrică** a două numere pozitive $u, v$ este $\sqrt{uv}$.
- **Element absorbant în produse lungi**: caută un termen egal cu el (aici $\sqrt9 = 3$).
- **Diferența** $B(u) - B(v)$ depinde doar de $u - v$ — ecuația matriceală devine una logaritmică simplă.
- **Schimbarea bazei**: $\log_4 x = \frac12\log_2 x$.
