## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_3 = 5$, $a_5 = 11$: suma primilor șapte termeni

$$\begin{cases} a_1 + 2r = 5\\ a_1 + 4r = 11\end{cases} \Rightarrow 2r = 6,\ r = 3,\ a_1 = -1.$$

$a_7 = a_1 + 6r = 17$, iar $S_7 = \dfrac{(a_1 + a_7)\cdot 7}{2} = \dfrac{16\cdot 7}{2} = 56$.

**Răspuns:** $S_7 = 56$. *Barem: 3p, 2p.*

### 2. Intersecția graficelor lui $f(x) = 2x - 1$ și $g(x) = x + 3$

$2x - 1 = x + 3 \iff x = 4$, iar $y = g(4) = 7$.

**Răspuns:** $A(4, 7)$. *Barem: 2p, 2p, 1p.*

### 3. $\sqrt[3]{x^2 - 1} = 2$

Ridicăm la cub: $x^2 - 1 = 8 \iff x^2 = 9 \iff x = \pm3$.

**Răspuns:** $x \in \{-3, 3\}$. *Barem: 3p, 2p.*

### 4. $a\cdot b$, știind $a + b = 150$ și $a$ este $25\%$ din $b$

$a = \dfrac{b}{4}$, deci $\dfrac b4 + b = 150 \iff \dfrac{5b}{4} = 150 \iff b = 120$, $a = 30$.

**Răspuns:** $a\cdot b = 3600$. *Barem: 3p, 1p, 1p.*

### 5. $A(2,3)$, $B(4,5)$, $C(m + 1, m^2)$ coliniare

Dreapta $AB$: $\dfrac{x - 2}{2} = \dfrac{y - 3}{2} \iff y = x + 1$. $C \in AB \iff m^2 = m + 2 \iff m^2 - m - 2 = 0 \iff (m - 2)(m + 1) = 0$.

**Răspuns:** $m \in \{-1, 2\}$. *Barem: 2p, 1p, 2p.*

### 6. $\cos x$, știind $\sin x = \dfrac13$, $x \in \left(0, \dfrac\pi2\right)$

$\cos^2 x = 1 - \dfrac19 = \dfrac89$, deci $\cos x = \pm\dfrac{2\sqrt2}{3}$. În cadranul I cosinusul este pozitiv.

**Răspuns:** $\cos x = \dfrac{2\sqrt2}{3}$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} m & 1 & 0\\ 1 & 1 & 1\\ 1 & 1 & m\end{pmatrix}$, sistemul $\begin{cases} mx + y = -1\\ x + y + z = 3\\ x + y + mz = 0\end{cases}$

#### a) $\det(A)$

$$\det A = m\cdot1\cdot m + 1\cdot1\cdot1 + 0 - 0 - m\cdot1\cdot1 - 1\cdot1\cdot m = m^2 - 2m + 1 = (m - 1)^2.$$

**Răspuns:** $\det A = m^2 - 2m + 1$. *Barem: 1p, 4p.*

#### b) Sistemul pentru $m = 0$

$y = -1$; $x + y + z = 3$; $x + y = 0$. Din ultima, $x = 1$; din a doua, $z = 3 - x - y = 3$.

**Răspuns:** $(x, y, z) = (1, -1, 3)$. *Barem: 2p, 3p.*

#### c) Pentru $m = 1$ sistemul este incompatibil

Sistemul devine $x + y = -1$, $x + y + z = 3$, $x + y + z = 0$. Ultimele două ecuații dau $3 = 0$ — contradicție, deci sistemul este incompatibil. $\blacksquare$ *Barem: 2p, 3p.*

### 2. Legea $x * y = (x - 4)(y - 4) + 4$

#### a) Asociativitatea

$$(x * y) * z = (x * y - 4)(z - 4) + 4 = (x - 4)(y - 4)(z - 4) + 4,$$

$$x * (y * z) = (x - 4)(y * z - 4) + 4 = (x - 4)(y - 4)(z - 4) + 4.$$

Expresiile coincid pentru orice $x, y, z$. *Barem: 5 × 1p.*

#### b) $x * y \in (4, +\infty)$ pentru $x, y \in (4, +\infty)$

$x - 4 > 0$, $y - 4 > 0$, deci $(x - 4)(y - 4) > 0$ și $x * y > 4$. *Barem: 3p, 2p.*

#### c) $1 * 2 * 3 * \ldots * 2010$

$x * 4 = 4 * x = 4$ pentru orice $x$ (element absorbant). Grupând:

$$(1 * 2 * 3) * 4 * (5 * \ldots * 2010) = 4.$$

**Răspuns:** $4$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:\mathbb R^* \to \mathbb R$, $f(x) = x^2 + \dfrac2x$

#### a) $f'(x)$

$f'(x) = 2x - \dfrac{2}{x^2}$. *Barem: 2p, 3p.*

#### b) Tangenta în $A(2, 5)$

$f(2) = 4 + 1 = 5$, $f'(2) = 4 - \dfrac12 = \dfrac72$:

$$y - 5 = \frac72(x - 2) \iff y = \frac72x - 2.$$

**Răspuns:** $y = \dfrac72x - 2$. *Barem: 2p, 2p, 1p.*

#### c) Asimptota verticală

$$\lim_{\substack{x\to0\\x<0}}\left(x^2 + \frac2x\right) = -\infty, \qquad \lim_{\substack{x\to0\\x>0}}\left(x^2 + \frac2x\right) = +\infty.$$

**Răspuns:** dreapta $x = 0$. *Barem: 4p, 1p.*

### 2. $f(x) = \dfrac{\ln x}{\sqrt x}$, $g(x) = 2\sqrt x(\ln x - 2)$, pe $(0, +\infty)$

#### a) $g$ este primitivă a lui $f$

$$g'(x) = \frac{1}{\sqrt x}(\ln x - 2) + 2\sqrt x\cdot\frac1x = \frac{\ln x - 2 + 2}{\sqrt x} = \frac{\ln x}{\sqrt x} = f(x).$$

*Barem: 1p, 3p, 1p.*

#### b) $\displaystyle\int_1^4 f(x)\,dx$

$$g(4) - g(1) = 4(\ln 4 - 2) - 2(0 - 2) = 8\ln 2 - 8 + 4 = 8\ln2 - 4.$$

**Răspuns:** $8\ln 2 - 4$. *Barem: 1p, 2p, 2p.*

#### c) $\displaystyle\int_1^{e^2} 2^{g(x)}f(x)\,dx$

Cum $f = g'$, integrandul este $2^{g}g'$, cu primitiva $\dfrac{2^{g(x)}}{\ln 2}$. $g(e^2) = 2e(2 - 2) = 0$, $g(1) = -4$:

$$\frac{2^0 - 2^{-4}}{\ln 2} = \frac{1 - \frac1{16}}{\ln2} = \frac{15}{16\ln2}.$$

**Răspuns:** $\dfrac{15}{16\ln 2}$. *Barem: 3p, 2p.*

## Ce merită reținut din varianta 10

- **Semnul funcțiilor trigonometrice** se alege după cadran.
- **Legea $(x-a)(y-a) + a$** este asociativă și are pe $a$ element absorbant.
- **$\int a^{g(x)}g'(x)\,dx = \frac{a^{g(x)}}{\ln a}$** — recunoaște derivata funcției din exponent.
