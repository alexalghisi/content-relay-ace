## Subiectul I (30 de puncte)

### 1. Arătați că $3(2 + \sqrt2) - 3\sqrt2 = 6$

$$3(2 + \sqrt2) - 3\sqrt2 = 6 + 3\sqrt2 - 3\sqrt2 = 6.$$

*Barem: 2p + 3p.*

### 2. $f(x) = x + 1$; calculați $f(-2)\cdot f(0)$

$f(-2) = -1$, $f(0) = 1$, produsul este $-1$. *Barem: 2p + 2p + 1p.*

### 3. Ecuația $\log_3(x^2 + 1) = \log_3 1$

$x^2 + 1 = 1 \iff x^2 = 0 \iff x = 0$ (iar $x^2 + 1 > 0$ mereu). *Barem: 2p + 3p.*

### 4. Prețul de 1000 lei după o ieftinire cu 10%

Reducerea: $\frac{10}{100}\cdot1000 = 100$ lei, deci prețul nou este $900$ lei. *Barem: 2p + 3p.*

### 5. Mijlocul segmentului $PR$, $P(2,1)$, $R(2,3)$

$$x_M = \frac{2+2}{2} = 2, \qquad y_M = \frac{1+3}{2} = 2.$$

**Răspuns:** $M(2, 2)$. *Barem: 1p + 2p + 2p.*

### 6. $\cos B$, știind $\sin B = \frac{5}{13}$ și $B$ ascuțit

$$\cos^2 B = 1 - \frac{25}{169} = \frac{144}{169}, \qquad \cos B = \frac{12}{13}\ (B \text{ ascuțit, deci } \cos B > 0).$$

*Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 1\\ 1 & 0\end{pmatrix}$

#### a) $\det A$

$$\det A = 1\cdot0 - 1\cdot1 = -1.$$

*Barem: 3p + 2p.*

#### b) $x$ cu $A\cdot A - xI_2 = A$

$$A\cdot A = \begin{pmatrix} 2 & 1\\ 1 & 1\end{pmatrix}, \qquad A\cdot A - xI_2 = \begin{pmatrix} 2 - x & 1\\ 1 & 1 - x\end{pmatrix}.$$

Egalitatea cu $A = \begin{pmatrix} 1 & 1\\ 1 & 0\end{pmatrix}$ cere $2 - x = 1$ și $1 - x = 0$, deci $x = 1$.

**Răspuns:** $x = 1$. *Barem: 3p + 2p.*

#### c) $M = \begin{pmatrix} m & m\\ m & 1\end{pmatrix}$ cu $\det(M + A) = 0$

$$M + A = \begin{pmatrix} m+1 & m+1\\ m+1 & 1\end{pmatrix}, \qquad \det(M + A) = (m+1) - (m+1)^2 = -m(m+1).$$

$-m(m+1) = 0 \iff m \in \{-1, 0\}$.

**Răspuns:** $M = \begin{pmatrix} 0 & 0\\ 0 & 1\end{pmatrix}$ sau $M = \begin{pmatrix} -1 & -1\\ -1 & 1\end{pmatrix}$. *Barem: 3p + 2p.*

### 2. Legea asociativă $x * y = x + y - 2$

#### a) $5 * (-5)$

$$5 + (-5) - 2 = -2.$$

*Barem: 3p + 2p.*

#### b) Comutativitate

$x * y = x + y - 2 = y + x - 2 = y * x$ pentru orice $x, y$ reali. *Barem: 3p + 2p.*

#### c) $(-3) * (-2) * (-1) * 0 * 1 * 2 * 3$

Legea fiind asociativă și comutativă, putem grupa: $(-3) * 3 = -2$, $(-2) * 2 = -2$, $(-1) * 1 = -2$. Rămâne:

$$(-2) * (-2) * (-2) * 0 = (-6) * (-2) * 0 = (-10) * 0 = -12.$$

(Altfel: pentru 7 termeni, rezultatul este suma lor minus $2\cdot6$, adică $0 - 12 = -12$.)

**Răspuns:** $-12$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = xe^x$

#### a) $f'(x) = (x+1)e^x$

$$f'(x) = e^x + xe^x = (x+1)e^x.$$

*Barem: 3p + 2p.*

#### b) $f''(x) + f(x) = 2f'(x)$?

$f''(x) = e^x + (x+1)e^x = (x+2)e^x$.

$$f''(x) + f(x) = (x + 2)e^x + xe^x = (2x + 2)e^x = 2(x+1)e^x = 2f'(x).$$

**Răspuns:** da. *Barem: 2p + 3p.*

#### c) $f$ are un punct de extrem

$f'(x) = 0 \iff x = -1$. $f'(x) < 0$ pe $(-\infty, -1)$ și $f'(x) > 0$ pe $(-1, +\infty)$, deci $f'$ își schimbă semnul în $-1$: $x = -1$ este punct de extrem (minim). *Barem: 2p + 3p.*

### 2. $f(x) = \frac1x$, $x > 0$

#### a) $\displaystyle\int_4^5 xf(x)\,dx$

$xf(x) = 1$, deci $\displaystyle\int_4^5 1\,dx = 5 - 4 = 1$. *Barem: 2p + 3p.*

#### b) $F(x) = 4 + \ln x$ este primitivă a lui $f$

$F'(x) = 0 + \dfrac1x = f(x)$ pentru orice $x > 0$. *Barem: 3p + 2p.*

#### c) $a > 5$ cu aria între grafic, $Ox$, $x = 5$, $x = a$ egală cu $\ln 3$

$$\mathcal A = \int_5^a\frac1x\,dx = \ln a - \ln5 = \ln\frac a5 = \ln3 \iff a = 15.$$

**Răspuns:** $a = 15$. *Barem: 2p + 3p.*

## Ce merită reținut din varianta 3

- **Legea $x + y - k$** aplicată pe $n$ termeni dă suma lor minus $k(n-1)$.
- **Grupează termenii opuși** când legea e comutativă și asociativă.
- **Punct de extrem** = zerou al derivatei în care derivata **își schimbă semnul**.
- **$\int_a^b\frac1x dx = \ln\frac ba$**.
