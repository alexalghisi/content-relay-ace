## A. Mecanică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **d**, 2 – **d**, 3 – **b**, 4 – **a**, 5 – **b** (câte 3 puncte).

**1.** Dacă asupra corpului acționează numai greutatea (forță conservativă), energia mecanică se conservă: $E = E_c + E_p = \text{const.}$ → **d**.

**2.** Pentru un fir elastic, legea lui Hooke dă $F = \dfrac{ES}{\ell_0}\Delta\ell$, deci $k = \dfrac{ES}{\ell_0} = S\cdot E\cdot \ell_0^{-1}$ → **d**.

**3.** $[m\cdot g\cdot v] = \text{kg}\cdot\dfrac{\text{m}}{\text{s}^2}\cdot\dfrac{\text{m}}{\text{s}} = \text{N}\cdot\dfrac{\text{m}}{\text{s}} = \dfrac{\text{J}}{\text{s}} = \text{W}$ (este puterea greutății) → **b**.

**4.** La echilibru $k\Delta\ell = mg$: $\Delta\ell = \dfrac{0{,}27\cdot 10}{30} = 0{,}09\ \text{m} = 9{,}0\ \text{cm}$ → **a**.

**5.** Distanța este aria de sub graficul $v(t)$ între 0 s și 5 s: triunghiul de la 0 la 3 s, $\frac12\cdot 3\cdot 6 = 9\ \text{m}$, plus dreptunghiul de la 3 la 5 s, $2\cdot 6 = 12\ \text{m}$. Total $d = 21\ \text{m}$ → **b**.

### Subiectul al II-lea — corp și găleată legate peste un scripete (15 puncte)

Date: $m_1 = 6\ \text{kg}$, $m_2 = 1\ \text{kg}$ (găleata), $a = 2\ \text{m/s}^2$, $g = 10\ \text{m/s}^2$.

**a.** Asupra corpului $m_1$ acționează **greutatea** $m_1\vec g$, vertical în jos, și **tensiunea din fir** $\vec T_1$, vertical în sus. Corpul coboară accelerat, deci $m_1 g > T_1$. *Barem: 4p.*

**b.** Principiul fundamental pentru $m_1$, pe sensul mișcării (în jos):

$$m_1 g - T_1 = m_1 a \Rightarrow T_1 = m_1(g - a) = 6\cdot 8 = 48\ \text{N}.$$

*Barem: 2p ecuația, 1p rezultatul.*

**c.** Acum $m_1$ urcă, iar găleata cu nisip (masa $m_2 + m$) coboară, ambele cu $a = 2\ \text{m/s}^2$. Adunând ecuațiile celor două corpuri (tensiunea se reduce):

$$(m_2 + m - m_1)\,g = (m_2 + m + m_1)\,a$$

$$(m - 5)\cdot 10 = (m + 7)\cdot 2 \Rightarrow 8m = 64 \Rightarrow m = 8\ \text{kg}.$$

*Barem: 3p, 1p.*

**d.** Tensiunea în cazul c: $T_2 - m_1 g = m_1 a \Rightarrow T_2 = m_1(g + a) = 6\cdot 12 = 72\ \text{N}$.

Pe scripete trag în jos ambele ramuri ale firului: $F_{ax} = 2T_2 = 144\ \text{N}$. *Barem: 2p, 1p, 1p.*

### Subiectul al III-lea — energie mecanică și frecare pe porțiunea BC (15 puncte)

Date: $m = 2\ \text{kg}$, $H = 1{,}8\ \text{m}$, $d = BC = 2{,}5\ \text{m}$, $\mu = 0{,}4$. Pe AB și CD nu există frecare.

**a.** Pe AB energia mecanică se conservă: $E_A = E_B$, cu $E_A = mgH$ (corpul pleacă din repaus) și $E_B = E_{cB}$ (nivelul de referință este BC):

$$E_{cB} = mgH = 2\cdot 10\cdot 1{,}8 = 36\ \text{J}.$$

*Barem: 1p + 1p + 1p + 1p.*

**b.** Pe BC acționează frecarea: $L_{f,BC} = -\mu mg\,d = -0{,}4\cdot 2\cdot 10\cdot 2{,}5 = -20\ \text{J}$. Teorema variației energiei cinetice:

$$E_{cC} = mgH + L_{f,BC} = 36 - 20 = 16\ \text{J}, \qquad v_C = \sqrt{\frac{2E_{cC}}{m}} = \sqrt{16} = 4\ \text{m/s}.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** Pe CD nu există frecare, așa că prima oprire are loc la înălțimea $h$ dată de $\dfrac{mv_C^2}{2} = mgh$, adică $h = \dfrac{16}{20} = 0{,}8\ \text{m}$. Greutatea efectuează lucru mecanic doar pe diferența de nivel:

$$L_G = mg(H - h) = 20\cdot(1{,}8 - 0{,}8) = 20\ \text{J}.$$

*Barem: 2p, 1p, 1p.*

**d.** Corpul coboară înapoi pe CD fără frecare și trece a doua oară prin C cu aceeași viteză, $v_C = 4\ \text{m/s}$. Pe BC frecarea îl frânează până la oprire. Cu teorema variației impulsului:

$$m v_C = \mu m g\,\Delta t \Rightarrow \Delta t = \frac{v_C}{\mu g} = \frac{4}{4} = 1\ \text{s}.$$

Verificare: distanța de frânare este $\dfrac{v_C^2}{2\mu g} = 2\ \text{m} < 2{,}5\ \text{m}$, deci corpul se oprește într-adevăr pe BC. *Barem: 2p, 1p.*

## B. Elemente de termodinamică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **a**, 2 – **d**, 3 – **c**, 4 – **b**, 5 – **b** (câte 3 puncte).

**1.** Principiul întâi: $\Delta U = Q - L$ → **a**.

**2.** În destinderea adiabatică $Q = 0$, gazul efectuează lucru mecanic ($L > 0$) pe seama energiei interne: $\Delta U = -L < 0$ → **d**.

**3.** $c = \dfrac{Q}{m\Delta T}$, deci $[c]_{SI} = \text{J}\cdot\text{kg}^{-1}\cdot\text{K}^{-1}$ → **c**.

**4.** Energia internă a unei cantități date de gaz ideal este proporțională cu $T$, deci cu produsul $pV$. Din grafic, $p_1V < p_3V < p_3V_3$, deci $U_1 < U_2 < U_3$ → **b**.

**5.** $\mu = \dfrac{\nu_1\mu_1 + \nu_2\mu_2}{\nu_1 + \nu_2} = \dfrac{3\cdot 28 + 1\cdot 32}{4} = \dfrac{116}{4} = 29\ \text{g/mol}$ → **b**.

### Subiectul al II-lea — oxigen într-un cilindru cu piston (15 puncte)

Date: $\nu = 0{,}2\ \text{mol}$, $\mu = 32\ \text{g/mol}$, $\ell = 20\ \text{cm}$, $T = 300\ \text{K}$, $p_0 = 10^5\ \text{Pa}$, $d = 5\ \text{cm}$.

**a.** Din $pV = \dfrac{m}{\mu}RT$:

$$\rho = \frac{p_0\mu}{RT} = \frac{10^5\cdot 0{,}032}{8{,}31\cdot 300} \cong 1{,}28\ \text{kg/m}^3.$$

*Barem: 3p, 1p.*

**b.** Transformare izotermă, $p_0V_0 = p_1V_1$, cu $V_0 = \ell S$ și $V_1 = (\ell + d)S$:

$$p_1 = p_0\frac{\ell}{\ell + d} = 10^5\cdot\frac{20}{25} = 0{,}8\cdot 10^5\ \text{Pa}.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** Încălzirea are loc la volum constant (pistonul e blocat). Eliberat, pistonul rămâne în repaus, deci presiunea interioară a devenit egală cu cea atmosferică: $p_2 = p_0$. Legea transformării izocore:

$$\frac{p_1}{T} = \frac{p_2}{T_2} \Rightarrow T_2 = T\frac{p_0}{p_1} = \frac{300}{0{,}8} = 375\ \text{K}.$$

*Barem: 2p, 1p, 1p.*

**d.** Ca pistonul să revină în poziția inițială, gazul trebuie să ocupe din nou $V_0$ la presiunea $p_0$ și temperatura $T_2$:

$$p_0V_0 = (\nu - \Delta\nu)RT_2, \qquad p_0V_0 = \nu RT \Rightarrow \nu - \Delta\nu = \nu\frac{T}{T_2} = 0{,}2\cdot\frac{300}{375} = 0{,}16\ \text{mol}.$$

$$\Delta\nu = 0{,}04\ \text{mol}.$$

*Barem: 1p + 1p + 1p.*

### Subiectul al III-lea — ciclu izobar–izocor–izoterm (15 puncte)

Date: $\nu R = 0{,}24\cdot 8{,}31 \cong 2\ \text{J/K}$, $C_V = 2{,}5R$, $T_1 = 400\ \text{K}$, $\ln 2 = 0{,}7$. Ciclul: $1 \to 2$ izobar ($V_1 \to 2V_1$), $2 \to 3$ izocor, $3 \to 1$ izoterm ($T_3 = T_1$).

**a.** $L_{12} = p_1(2V_1 - V_1) = p_1V_1 = \nu RT_1 = 2\cdot 400 = 800\ \text{J}$. *Barem: 2p, 1p, 1p.*

**b.** La presiune constantă, dublarea volumului dublează temperatura: $T_2 = 2T_1 = 800\ \text{K}$.

$$\Delta U_{12} = \nu C_V(T_2 - T_1) = 2{,}5\cdot 2\cdot 400 = 2000\ \text{J} = 2\ \text{kJ}.$$

*Barem: 2p, 1p, 1p.*

**c.** Gazul cedează căldură în $2 \to 3$ (răcire izocoră) și în $3 \to 1$ (comprimare izotermă):

$$Q_{23} = \nu C_V(T_1 - T_2) = -2000\ \text{J}, \qquad Q_{31} = \nu RT_1\ln\frac{V_1}{2V_1} = -800\cdot 0{,}7 = -560\ \text{J}.$$

$$Q_c = Q_{23} + Q_{31} = -2560\ \text{J} = -2{,}56\ \text{kJ}.$$

*Barem: 1p + 1p + 1p + 1p.*

**d.** Căldura primită este doar cea din $1 \to 2$: $Q_p = L_{12} + \Delta U_{12} = 2800\ \text{J}$.

$$\eta = 1 - \frac{|Q_c|}{Q_p} = 1 - \frac{2560}{2800} = \frac{3}{35} \cong 8{,}6\%.$$

*Barem: 1p + 1p + 1p.*

## C. Producerea și utilizarea curentului continuu (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **b**, 2 – **a**, 3 – **c**, 4 – **b**, 5 – **d** (câte 3 puncte).

**1.** Sensul convențional al curentului este de la borna pozitivă la cea negativă **prin circuitul exterior** sursei → **b**.

**2.** $R = \dfrac{\rho\ell}{S}$ → **a**.

**3.** $P\cdot t = W$, energia, măsurată în joule → **c**.

**4.** Din grafic: la $I = 0$ tensiunea la borne este $E = 12\ \text{V}$, iar la scurtcircuit ($U = 0$) $I_{sc} = 3\ \text{A}$, deci $r = E/I_{sc} = 4\ \Omega$. La $I = 1\ \text{A}$: $u = Ir = 4\ \text{V}$ (în grafic $U = 8\ \text{V}$, iar $12 - 8 = 4$) → **b**.

**5.** $R = R_0(1 + \alpha t) \Rightarrow \alpha = \dfrac{R - R_0}{R_0 t} = \dfrac{30}{120\cdot 50} = 5\cdot 10^{-3}\ \text{K}^{-1}$ → **d**.

### Subiectul al II-lea — două surse, ampermetru, apoi voltmetru (15 puncte)

Date: $E_1 = E = 15\ \text{V}$, $r_1 = r = 5\ \Omega$, $R_1 = 10\ \Omega$, $R_2 = 6\ \Omega$, $I_1 = 0{,}2\ \text{A}$. Cele trei ramuri (sursa $E_1$ cu ampermetrul și $R_1$, sursa $E$, rezistoarele $R_3$ și $R_2$) sunt legate între aceleași două noduri.

**a.** $U_{b1} = E_1 - I_1r_1 = 15 - 0{,}2\cdot 5 = 14\ \text{V}$. *Barem: 2p, 1p.*

**b.** Teorema a II-a a lui Kirchhoff pe ochiul format de cele două surse:

$$E_1 - E = I_1r_1 + I_1R_1 - Ir \Rightarrow 0 = 1 + 2 - 5I \Rightarrow I = 0{,}6\ \text{A}.$$

*Barem: 3p, 1p.*

**c.** Prin nod: $I_2 = I + I_1 = 0{,}8\ \text{A}$, deci $U_2 = I_2R_2 = 0{,}8\cdot 6 = 4{,}8\ \text{V}$. *Barem: 2p, 1p, 1p.*

**d.** Mai întâi aflăm $R_3$ din ochiul sursei $E_1$ cu ramura $R_2R_3$:

$$E_1 = I_1(r_1 + R_1) + I_2(R_2 + R_3) \Rightarrow 15 = 3 + 0{,}8(6 + R_3) \Rightarrow R_3 = 9\ \Omega.$$

Cu voltmetrul ideal, prin ramura lui $E_1$ nu mai trece curent. Circuitul rămas este sursa $E$ cu $R_2 + R_3$:

$$I_0 = \frac{E}{R_2 + R_3 + r} = \frac{15}{20} = 0{,}75\ \text{A}.$$

Pe ochiul care conține voltmetrul: $E_1 = U_V + I_0(R_2 + R_3) \Rightarrow U_V = 15 - 0{,}75\cdot 15 = 3{,}75\ \text{V}$. *Barem: 1p + 1p + 1p + 1p.*

### Subiectul al III-lea — bec și rezistor în paralel (15 puncte)

Date: $E = 16\ \text{V}$, $R_1 = 24\ \Omega$, $U_b = 12\ \text{V}$, $I_b = 0{,}5\ \text{A}$ (becul funcționează normal). Becul și $R_1$ sunt în paralel, deci au aceeași tensiune $U_b$.

**a.** $P_b = U_bI_b = 6\ \text{W}$, $P_1 = \dfrac{U_b^2}{R_1} = \dfrac{144}{24} = 6\ \text{W}$, deci $P_{ext} = P_b + P_1 = 12\ \text{W}$. *Barem: 1p + 1p + 1p + 1p.*

**b.** $I_1 = \dfrac{U_b}{R_1} = 0{,}5\ \text{A}$, iar $I = I_b + I_1 = 1\ \text{A}$.

$$W_{total} = EI\Delta t = 16\cdot 1\cdot 300 = 4800\ \text{J} = 4{,}8\ \text{kJ}.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** $P_{total} = EI = 16\ \text{W}$, deci $\eta = \dfrac{P_{ext}}{P_{total}} = \dfrac{12}{16} = 75\%$. *Barem: 2p, 1p, 1p.*

**d.** Rezistența interioară: $U_b = E - Ir \Rightarrow r = \dfrac{16 - 12}{1} = 4\ \Omega$. Puterea pe reostat este maximă când $R = r = 4\ \Omega$, valoare cuprinsă în intervalul $[0;\,100\ \Omega]$:

$$P_{max} = \frac{E^2}{4r} = \frac{256}{16} = 16\ \text{W}.$$

*Barem: 1p + 1p + 1p.*

## D. Optică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **b**, 2 – **c**, 3 – **d**, 4 – **a**, 5 – **b** (câte 3 puncte).

**1.** Obiectul aflat între lentila convergentă și focar dă o imagine **virtuală, dreaptă** și mărită (principiul lupei) → **b**.

**2.** $\nu\lambda = c$, iar $c/n = v$ este viteza luminii în mediu, cu unitatea $\text{m}\cdot\text{s}^{-1}$ → **c**.

**3.** Un sistem afocal are $f_1 + f_2 = D$: $\dfrac{1}{C_2} = D - \dfrac{1}{C_1} = \dfrac{DC_1 - 1}{C_1}$, deci $C_2 = \dfrac{C_1}{DC_1 - 1}$ → **d**.

**4.** $\varepsilon = \dfrac{hc}{\lambda} = \dfrac{6{,}6\cdot 10^{-34}\cdot 3\cdot 10^8}{440\cdot 10^{-9}} = 4{,}5\cdot 10^{-19}\ \text{J}$; $E_c = \varepsilon - L = 0{,}8\cdot 10^{-19}\ \text{J}$ → **a**.

**5.** Pentru un obiect real aflat la distanța $d = -x_1$: $\dfrac{1}{\beta} = \dfrac{x_1}{x_2} = 1 + \dfrac{x_1}{f} = 1 - \dfrac{d}{f}$. Din grafic, la $d = 0{,}2\ \text{m}$, $\dfrac{1}{\beta} = 0{,}6$: $1 - \dfrac{0{,}2}{f} = 0{,}6 \Rightarrow f = 0{,}5\ \text{m}$ → **b**.

### Subiectul al II-lea — imagine pe ecran și sistem de lentile alipite (15 puncte)

Date: $h_1 = 10\ \text{mm}$, $h_2 = 5\ \text{mm}$, distanța obiect–ecran $d = 45\ \text{cm}$.

**a.** Imaginea de pe ecran este reală, deci răsturnată: $\beta = \dfrac{y_2}{y_1} = \dfrac{-h_2}{h_1} = -0{,}5$. *Barem: 1p + 1p + 1p.*

**b.** $-x_1 + x_2 = d$ și $x_2 = \beta x_1 = -0{,}5x_1$, deci $-1{,}5x_1 = 45\ \text{cm}$, adică $-x_1 = 30\ \text{cm}$ (iar $x_2 = 15\ \text{cm}$). *Barem: 2p, 1p, 1p.*

**c.** Formula lentilelor:

$$\frac{1}{f} = \frac{1}{x_2} - \frac{1}{x_1} = \frac{1}{15} + \frac{1}{30} = \frac{1}{10\ \text{cm}} \Rightarrow C = \frac{1}{f} = \frac{1}{0{,}1\ \text{m}} = 10\ \text{m}^{-1}.$$

*Barem: 2p, 1p, 1p.*

**d.** Sistemul se află la mijloc: $-x_1' = x_2' = \dfrac{d}{2} = 22{,}5\ \text{cm}$.

$$\frac{1}{f_{sistem}} = \frac{1}{22{,}5} + \frac{1}{22{,}5} \Rightarrow f_{sistem} = 11{,}25\ \text{cm}.$$

Lentilele alipite: $\dfrac{1}{f_{sistem}} = \dfrac{1}{f} + \dfrac{1}{f'}$:

$$\frac{1}{f'} = \frac{1}{11{,}25} - \frac{1}{10} = -\frac{1}{90} \Rightarrow f' = -90\ \text{cm}$$

(a doua lentilă este divergentă). *Barem: 1p + 1p + 1p + 1p.*

### Subiectul al III-lea — dispozitivul Young (15 puncte)

Date: $2\ell = 0{,}9\ \text{mm}$, $\lambda = 540\ \text{nm}$, $D = 2{,}5\ \text{m}$.

**a.** $i = \dfrac{\lambda D}{2\ell} = \dfrac{540\cdot 10^{-9}\cdot 2{,}5}{0{,}9\cdot 10^{-3}} = 1{,}5\cdot 10^{-3}\ \text{m} = 1{,}5\ \text{mm}$. *Barem: 2p, 1p.*

**b.** Franja întunecoasă de ordinul $k$ se află la $x_{k,\min} = (2k - 1)\dfrac{i}{2}$: a doua la $1{,}5\,i$, a treia la $2{,}5\,i$. Fiind de o parte și de alta a franjei centrale:

$$d_{23} = 1{,}5\,i + 2{,}5\,i = 4i = 6\ \text{mm}.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** $\Delta r = \dfrac{x\cdot 2\ell}{D} = \dfrac{7{,}5\cdot 10^{-3}\cdot 0{,}9\cdot 10^{-3}}{2{,}5} = 2{,}7\cdot 10^{-6}\ \text{m} = 2{,}7\ \mu\text{m}$ (exact $5\lambda$, deci acolo este un maxim). *Barem: 3p, 1p.*

**d.** Deplasarea sursei cu $h$ deplasează sistemul de franje în sens opus cu $\Delta x = \dfrac{hD}{d}$, unde $d$ este distanța sursă–fante. Franja centrală a ajuns pe locul maximului de ordinul 2, deci $\Delta x = 2i = 3\ \text{mm}$:

$$d = \frac{hD}{\Delta x} = \frac{0{,}3\cdot 10^{-3}\cdot 2{,}5}{3\cdot 10^{-3}} = 0{,}25\ \text{m} = 25\ \text{cm}.$$

*Barem: 2p, 1p, 1p.*
