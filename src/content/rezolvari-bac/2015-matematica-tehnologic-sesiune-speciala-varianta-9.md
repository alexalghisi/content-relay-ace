## Subiectul I (30 de puncte)

### 1. Arătați că $\left(2 - \frac12\right) : \frac{3}{10} = 5$

$$2 - \frac12 = \frac32, \qquad \frac32\cdot\frac{10}{3} = 5.$$

*Barem: 3p + 2p.*

### 2. $f(x) = x^2 - 4$; $f(-2) + f(2)$

$f(-2) = f(2) = 0$, suma este $0$. *Barem: 2p + 3p.*

### 3. Ecuația $\sqrt{2x - 1} = 3$

$2x - 1 = 9 \iff x = 5$, care verifică. *Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr din $\{1, \dots, 10\}$ să fie multiplu de 5

Favorabile: $5, 10$ — 2 din 10.

$$p = \frac{2}{10} = \frac15.$$

*Barem: 1p + 2p + 2p.*

### 5. Triunghiul $MON$, $O(0,0)$, $M(0,4)$, $N(4,0)$ este isoscel

$MO = 4$, $ON = 4$, deci $MO = ON$ și triunghiul este isoscel. *Barem: 2p + 3p.*

### 6. Aria triunghiului dreptunghic în $A$, $AB = 10$, $AC = 12$

$$\mathcal A = \frac{AB\cdot AC}{2} = \frac{10\cdot12}{2} = 60.$$

*Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 3 & -2\\ 5 & -3\end{pmatrix}$

#### a) $\det A = 1$

$$\det A = 3\cdot(-3) - (-2)\cdot5 = -9 + 10 = 1.$$

*Barem: 3p + 2p.*

#### b) $A\cdot A + I_2 = O_2$

$$A\cdot A = \begin{pmatrix} 9 - 10 & -6 + 6\\ 15 - 15 & -10 + 9\end{pmatrix} = \begin{pmatrix} -1 & 0\\ 0 & -1\end{pmatrix} = -I_2,$$

deci $A\cdot A + I_2 = O_2$. *Barem: 3p + 2p.*

#### c) $\det(A - aI_2) \ge 1$

$$\det\begin{pmatrix} 3 - a & -2\\ 5 & -3 - a\end{pmatrix} = (3 - a)(-3 - a) + 10 = a^2 - 9 + 10 = a^2 + 1 \ge 1. \ \blacksquare$$

*Barem: 3p + 2p.*

### 2. $f = X^3 + 5X^2 + X + 5$

#### a) $f(-5) = 0$

$$-125 + 125 - 5 + 5 = 0.$$

*Barem: 3p + 2p.*

#### b) Câtul și restul împărțirii la $X^2 + 6X + 5$

$$(X - 1)(X^2 + 6X + 5) = X^3 + 5X^2 - X - 5,$$

deci $f - (X - 1)(X^2 + 6X + 5) = 2X + 10$, care are grad mai mic decât împărțitorul.

**Răspuns:** câtul $X - 1$, restul $2X + 10$. *Barem: 3p + 2p.*

#### c) $\dfrac{x_3}{x_1x_2} + \dfrac{x_2}{x_1x_3} + \dfrac{x_1}{x_2x_3} = -\dfrac{23}{5}$

Aducând la numitorul comun $x_1x_2x_3$:

$$\frac{x_1^2 + x_2^2 + x_3^2}{x_1x_2x_3} = \frac{(\sum x_i)^2 - 2\sum x_ix_j}{x_1x_2x_3}.$$

Viète: $\sum x_i = -5$, $\sum x_ix_j = 1$, $x_1x_2x_3 = -5$:

$$\frac{25 - 2}{-5} = -\frac{23}{5}. \ \blacksquare$$

*Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^4 - 2x^2 + 1$

#### a) $f'(x) = 4x(x-1)(x+1)$

$$f'(x) = 4x^3 - 4x = 4x(x^2 - 1) = 4x(x-1)(x+1).$$

*Barem: 3p + 2p.*

#### b) Tangenta în $x = 1$

$f(1) = 0$, $f'(1) = 0$, deci tangenta este $y = 0$. *Barem: 2p + 3p.*

#### c) $0 \le f(x) \le 1$ pentru $x \in [-1, 1]$

$f' \ge 0$ pe $[-1, 0]$ (crescătoare) și $f' \le 0$ pe $[0, 1]$ (descrescătoare). Deci pe $[-1, 1]$ maximul este $f(0) = 1$, iar minimul este $f(\pm1) = 0$. (Sau direct: $f(x) = (x^2 - 1)^2 \ge 0$.) $\blacksquare$ *Barem: 2p + 3p.*

### 2. $f:(0,+\infty)\to\mathbb R$, $f(x) = x^2 + \sqrt x$

#### a) $\displaystyle\int_1^3(f(x) - \sqrt x)\,dx = \frac{26}{3}$

$$\int_1^3 x^2\,dx = \frac{27 - 1}{3} = \frac{26}{3}.$$

*Barem: 3p + 2p.*

#### b) $F(x) = \dfrac{x^3}{3} + \dfrac{2x\sqrt x}{3} + 2015$ este primitivă a lui $f$

$\dfrac{2x\sqrt x}{3} = \dfrac23x^{3/2}$, cu derivata $\dfrac23\cdot\dfrac32x^{1/2} = \sqrt x$. Deci

$$F'(x) = x^2 + \sqrt x = f(x).$$

*Barem: 3p + 2p.*

#### c) Aria sub $g(x) = (f(x) - \sqrt x)e^x = x^2e^x$ pe $[1,2]$ este $e(2e - 1)$

$g \ge 0$. Prin părți de două ori, primitiva lui $x^2e^x$ este $(x^2 - 2x + 2)e^x$ (verificare: derivata este $(2x - 2)e^x + (x^2 - 2x + 2)e^x = x^2e^x$ ✔).

$$\mathcal A = (x^2 - 2x + 2)e^x\Big|_1^2 = 2e^2 - e = e(2e - 1). \ \blacksquare$$

*Barem: 3p + 2p.*
