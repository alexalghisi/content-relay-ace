## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt7(\sqrt7 + 1) - \sqrt7 = 7$

$7 + \sqrt7 - \sqrt7 = 7$. $\blacksquare$ *Barem: 2p, 3p.*

### 2. Intersecția graficului lui $f(x) = x^2 - 6x + 8$ cu $Oy$

Pe $Oy$, $x = 0$: $f(0) = 8$.

**Răspuns:** $(0, 8)$. *Barem: 3p, 2p.*

### 3. Ecuația $\log_5(x^2 + 9) = 2$

$x^2 + 9 = 25 \iff x^2 = 16 \iff x = \pm 4$ (ambele convin).

**Răspuns:** $x \in \{-4, 4\}$. *Barem: 2p, 3p.*

### 4. După o ieftinire cu $40\%$ prețul este 300 de lei. Prețul inițial?

$x - 0{,}4x = 300 \iff 0{,}6x = 300 \iff x = 500$.

**Răspuns:** $500$ de lei. *Barem: 3p, 2p.*

### 5. Mediana din $C$ în $\triangle ABC$, $A(3,2)$, $B(-3,2)$, $C(0,6)$

Mijlocul lui $AB$: $M(0, 2)$; $CM = |6 - 2| = 4$.

**Răspuns:** $4$. *Barem: 2p, 3p.*

### 6. Arătați că $\frac{\sqrt3}{2}\sin60^\circ - \frac{\sqrt2}{2}\sin45^\circ = \frac14$

$\frac{\sqrt3}2\cdot\frac{\sqrt3}2 - \frac{\sqrt2}2\cdot\frac{\sqrt2}2 = \frac34 - \frac24 = \frac14$. $\blacksquare$ *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}6 & -10\\ 3 & -5\end{pmatrix}$, $M(a) = I_2 + aA$

**a)** $\det A = -30 + 30 = 0$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** $A^2 = \begin{pmatrix}36 - 30 & -60 + 50\\ 18 - 15 & -30 + 25\end{pmatrix} = \begin{pmatrix}6 & -10\\ 3 & -5\end{pmatrix} = A$. Atunci

$$M(a)M(b) = I_2 + aA + bA + abA^2 = I_2 + (a + b + ab)A = M(a + b + ab).\ \blacksquare$$

*Barem: 2p, 3p.*

**c)** $$M(1) + \dots + M(2019) = 2019I_2 + (1 + 2 + \dots + 2019)A = 2019I_2 + \frac{2019\cdot 2020}{2}A = 2019(I_2 + 1010A) = 2019M(1010).$$

**Răspuns:** $a = 1010$. *Barem: 3p, 2p.*

### 2. $f = mX^3 + 2X^2 - mX - 2$, $m \ne 0$

**a)** $f(1) = m + 2 - m - 2 = 0$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** Pentru $m = 3$: $f = 3X^3 + 2X^2 - 3X - 2 = X^2(3X + 2) - (3X + 2) = (X - 1)(X + 1)(3X + 2)$.

**Răspuns:** $-1$, $-\frac23$, $1$. *Barem: 2p, 3p.*

**c)** Viète: $x_1x_2 + x_1x_3 + x_2x_3 = \frac{-m}{m} = -1$, $x_1x_2x_3 = -\frac{-2}{m} = \frac2m$.

$$\frac1{x_1} + \frac1{x_2} + \frac1{x_3} = \frac{-1}{2/m} = -\frac m2 = -4 \iff m = 8.$$

**Răspuns:** $m = 8$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^3 - 3x + 5$

**a)** $f'(x) = 3x^2 - 3 = 3(x - 1)(x + 1)$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** $f''(x) = 6x \ge 0$ pe $[0, +\infty)$, deci $f$ este convexă acolo. $\blacksquare$ *Barem: 2p, 3p.*

**c)** $f$ crește pe $(-\infty, -1]$ și scade pe $[-1, 1]$, deci pe $(-\infty, 1]$ maximul este $f(-1) = -1 + 3 + 5 = 7$: $f(x) \le 7$. $\blacksquare$ *Barem: 2p, 3p.*

### 2. $f(x) = \sqrt{3x^2 + 6x + 7}$

**a)** $\int_0^1 f^2(x)\,dx = \int_0^1(3x^2 + 6x + 7)\,dx = (x^3 + 3x^2 + 7x)\Big|_0^1 = 11$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** $(3x^2 + 6x + 7)' = 6(x + 1)$, deci $\left(\sqrt{3x^2+6x+7}\right)' = \frac{3(x+1)}{\sqrt{3x^2+6x+7}}$:

$$\int_{-1}^1\frac{x + 1}{f(x)}dx = \frac13\sqrt{3x^2 + 6x + 7}\Big|_{-1}^1 = \frac13\left(\sqrt{16} - \sqrt4\right) = \frac23.$$

**Răspuns:** $\dfrac23$. *Barem: 3p, 2p.*

**c)** Pentru $x \ge 0$: $3x^2 + 6x + 7 \ge 7$, deci $f(x) \ge \sqrt7 > 0$ și

$$\mathcal A = \int_0^a f(x)\,dx \ge \int_0^a\sqrt7\,dx = a\sqrt7.\ \blacksquare$$

*Barem: 2p, 3p.*

## Ce merită reținut din varianta 6

- **Matrice idempotentă** ($A^2 = A$): $M(a) = I_2 + aA$ se înmulțește după regula $a + b + ab$.
- **Suma $1 + 2 + \dots + n = \frac{n(n+1)}{2}$** în sume de matrice.
