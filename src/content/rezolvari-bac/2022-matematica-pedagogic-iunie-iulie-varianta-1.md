## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{18} + \sqrt8 = 5\sqrt2$

Scoatem factorii de sub radical: $\sqrt{18} = \sqrt{9\cdot 2} = 3\sqrt2$, $\sqrt8 = \sqrt{4\cdot2} = 2\sqrt2$.

$$\sqrt{18} + \sqrt8 = 3\sqrt2 + 2\sqrt2 = 5\sqrt2.$$

*Barem: 3p scoaterea factorilor, 2p finalizarea.*

### 2. $f(x) = 3x - 2$; determinați $a$ pentru care $f(a) - f(2) = 12$

$f(a) = 3a - 2$, $f(2) = 6 - 2 = 4$. Atunci

$$3a - 2 - 4 = 12 \iff 3a = 18 \iff a = 6.$$

**Răspuns:** $a = 6$. *Barem: 2p calculul valorilor funcției, 3p ecuația și soluția.*

### 3. După o reducere cu 20%, prețul scade cu 28 de lei. Prețul inițial?

Fie $x$ prețul inițial. Reducerea este $20\%$ din $x$:

$$\frac{20}{100}\cdot x = 28 \iff \frac{x}{5} = 28 \iff x = 140.$$

**Răspuns:** prețul inițial este $140$ de lei. *Barem: 3p ecuația, 2p rezultatul.*

### 4. Ecuația $4^{2x-1} = 64$

Scriem $64 = 4^3$, deci $4^{2x-1} = 4^3$. Funcția exponențială este injectivă:

$$2x - 1 = 3 \iff x = 2.$$

**Răspuns:** $x = 2$. *Barem: 2p $64 = 4^3$, 3p soluția.*

### 5. Dreapta prin $A(2,3)$, perpendiculară pe $d: y = 2x + 1$

Panta lui $d$ este $m_d = 2$. Pentru drepte perpendiculare $m_d \cdot m = -1$, deci $m = -\dfrac12$.

$$y - 3 = -\frac12(x - 2) \iff 2y - 6 = -x + 2 \iff x + 2y - 8 = 0.$$

**Răspuns:** $x + 2y - 8 = 0$. *Barem: 3p panta, 2p ecuația.*

### 6. $\triangle ABC$ dreptunghic în $A$, $\angle B = 30^\circ$, $BC = 10$. Aria?

Cateta opusă unghiului de $30^\circ$ este jumătate din ipotenuză: $AC = \dfrac{BC}{2} = 5$.

Pitagora: $AB = \sqrt{BC^2 - AC^2} = \sqrt{100 - 25} = 5\sqrt3$.

$$\mathcal A_{ABC} = \frac{AB \cdot AC}{2} = \frac{5\sqrt3\cdot 5}{2} = \frac{25\sqrt3}{2}.$$

**Răspuns:** $\dfrac{25\sqrt3}{2}$. *Barem: 3p laturile, 2p aria.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă pe $\mathbb R$: $x * y = xy - \sqrt3(x+y) + \sqrt3 + 3$.

### 1. Arătați că $1 * 0 = 3$

$$1 * 0 = 1\cdot 0 - \sqrt3(1 + 0) + \sqrt3 + 3 = 0 - \sqrt3 + \sqrt3 + 3 = 3.$$

*Barem: 2p înlocuirea, 3p finalizarea.*

### 2. Arătați că $x * y = (x - \sqrt3)(y - \sqrt3) + \sqrt3$

Desfacem membrul drept: $(x-\sqrt3)(y-\sqrt3) + \sqrt3 = xy - \sqrt3 x - \sqrt3 y + 3 + \sqrt3 = xy - \sqrt3(x+y) + \sqrt3 + 3 = x * y.$ $\blacksquare$

*Barem: 3p, 2p.*

### 3. Numărul real $x$ cu $x * x = \sqrt3$

Cu forma de la 2: $(x - \sqrt3)^2 + \sqrt3 = \sqrt3 \iff (x - \sqrt3)^2 = 0 \iff x = \sqrt3.$

**Răspuns:** $x = \sqrt3$. *Barem: 2p ecuația, 3p soluția.*

### 4. $e = \sqrt3 + 1$ este elementul neutru

$$x * (\sqrt3+1) = (x - \sqrt3)(\sqrt3 + 1 - \sqrt3) + \sqrt3 = x - \sqrt3 + \sqrt3 = x,$$

și analog $(\sqrt3 + 1) * x = 1\cdot(x - \sqrt3) + \sqrt3 = x$ pentru orice $x$ real (legea e și comutativă). Deci $e = \sqrt3 + 1$ este element neutru. $\blacksquare$ *Barem: 2p + 3p.*

### 5. $\sqrt3 * x = \sqrt3$ pentru orice $x$ real

$$\sqrt3 * x = (\sqrt3 - \sqrt3)(x - \sqrt3) + \sqrt3 = 0 + \sqrt3 = \sqrt3.$$

Analog $x * \sqrt3 = \sqrt3$: $\sqrt3$ este „element absorbant”. *Barem: 2p + 3p.*

### 6. $n$ natural cu $\sqrt3 * \sqrt4 * \sqrt5 * \dots * \sqrt{2022} = \sqrt n$

Legea fiind asociativă, grupăm: $\sqrt3 * \big(\sqrt4 * \dots * \sqrt{2022}\big) = \sqrt3$ (cf. punctului 5). Deci $\sqrt n = \sqrt3$, adică $n = 3$.

**Răspuns:** $n = 3$. *Barem: 3p gruparea, 2p rezultatul.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&0\\3&1\end{pmatrix}$, $B = \begin{pmatrix}1&0\\-3&1\end{pmatrix}$, $I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$.

### 1. $\det A = 1$

$$\det A = \begin{vmatrix}1&0\\3&1\end{vmatrix} = 1\cdot1 - 3\cdot 0 = 1.$$

*Barem: 3p + 2p.*

### 2. $A\cdot A - 2A = -I_2$

$$A\cdot A = \begin{pmatrix}1&0\\6&1\end{pmatrix},\quad 2A = \begin{pmatrix}2&0\\6&2\end{pmatrix},\quad A\cdot A - 2A = \begin{pmatrix}-1&0\\0&-1\end{pmatrix} = -I_2.$$

*Barem: 3p calculul, 2p finalizarea.*

### 3. $A\cdot B = B\cdot A = I_2$

$$A B = \begin{pmatrix}1\cdot1 + 0 & 0\\ 3 - 3 & 1\end{pmatrix} = I_2,\qquad BA = \begin{pmatrix}1 & 0\\ -3 + 3 & 1\end{pmatrix} = I_2.$$

*Barem: 2p $AB$, 3p $BA$.*

### 4. $a$ real cu $\det(A - aI_2) = 0$

$$A - aI_2 = \begin{pmatrix}1-a&0\\3&1-a\end{pmatrix},\quad \det(A - aI_2) = (1-a)^2 = 0 \iff a = 1.$$

**Răspuns:** $a = 1$. *Barem: 3p matricea, 2p soluția.*

### 5. $m$ real cu $\det\big(m(A+B)\big) = m\cdot\det(A+B)$

$A + B = \begin{pmatrix}2&0\\0&2\end{pmatrix}$, $\det(A+B) = 4$; $m(A+B) = \begin{pmatrix}2m&0\\0&2m\end{pmatrix}$, cu determinantul $4m^2$.

$$4m^2 = 4m \iff 4m(m - 1) = 0 \iff m \in \{0, 1\}.$$

**Răspuns:** $m \in \{0, 1\}$. *Barem: 3p determinanții, 2p soluțiile.*

### 6. $x, y$ reali cu $xA + yB = 2I_2$

$$xA + yB = \begin{pmatrix}x + y & 0\\ 3x - 3y & x + y\end{pmatrix} = \begin{pmatrix}2&0\\0&2\end{pmatrix}.$$

Obținem $x + y = 2$ și $3x - 3y = 0$, deci $x = y = 1$.

**Răspuns:** $x = y = 1$. *Barem: 3p matricea, 2p soluția.*
