## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{48} - \sqrt{27} = \sqrt3$

$$4\sqrt3 - 3\sqrt3 = \sqrt3.$$

*Barem: 2p, 3p.*

### 2. Intersecția graficelor $f(x) = 2x - 1$ și $g(x) = 2 - x$

$$2x - 1 = 2 - x \iff x = 1, \quad y = 1.$$

**Răspuns:** $(1, 1)$. *Barem: 3p, 2p.*

### 3. Ecuația $3^{8 - 3x} = 9$

$8 - 3x = 2 \iff x = 2$. *Barem: 3p, 2p.*

### 4. Numere naturale pare de două cifre formate cu cifrele $5, 6, 7, 8, 9$

Cifra unităților: $6$ sau $8$ — 2 moduri; cifra zecilor: 5 moduri (cifrele se pot repeta). $2\cdot5 = 10$.

**Răspuns:** $10$. *Barem: 2p, 3p.*

### 5. $A(1,4)$, $B(5,4)$, $C(5,8)$: $AB = BC$

$AB = |5 - 1| = 4$ (aceeași ordonată), $BC = |8 - 4| = 4$ (aceeași abscisă). *Barem: 2p, 3p.*

### 6. Arătați că $\sin45^\circ\cdot\cos45^\circ + \cos60^\circ = 1$

$$\frac{\sqrt2}{2}\cdot\frac{\sqrt2}{2} + \frac12 = \frac12 + \frac12 = 1.$$

*Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x\circ y = xy - x - y + 1$.

### 1. $1\circ2016 = 0$

$$2016 - 1 - 2016 + 1 = 0.$$

*Barem: 3p, 2p.*

### 2. Legea este comutativă

$y\circ x = yx - y - x + 1 = x\circ y$. *Barem: 2p, 3p.*

### 3. $x\circ y = (x - 1)(y - 1)$

$$xy - x - y + 1 = x(y - 1) - (y - 1) = (x - 1)(y - 1).$$

*Barem: 2p, 3p.*

### 4. $(x - 1)\circ x = 0$

$(x - 2)(x - 1) = 0 \iff x \in \{1, 2\}$. *Barem: 2p, 3p.*

### 5. $x^2\circ x^2 = (x - 1)^2(x + 1)^2$

$$x^2\circ x^2 = (x^2 - 1)^2 = \big((x-1)(x+1)\big)^2 = (x-1)^2(x+1)^2.$$

*Barem: 2p, 3p.*

### 6. Numerele naturale $a, b$ cu $a\circ b = 3$

$(a - 1)(b - 1) = 3$, cu $a - 1, b - 1 \ge -1$ întregi: singurele descompuneri posibile sunt $1\cdot3$ și $3\cdot1$ (varianta $(-1)\cdot(-3)$ ar da $b = -2$).

**Răspuns:** $(a,b) \in \{(2,4), (4,2)\}$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}2&1\\-4&-2\end{pmatrix}$, $M(a) = A + aI_2$.

### 1. $\det A = 0$

$2\cdot(-2) - 1\cdot(-4) = 0$. *Barem: 3p, 2p.*

### 2. $a$ cu $\det(M(a)) = 16$

$$\det\begin{pmatrix}2 + a & 1\\-4 & a - 2\end{pmatrix} = (a + 2)(a - 2) + 4 = a^2.$$

$a^2 = 16 \iff a = \pm4$. *Barem: 3p, 2p.*

### 3. $M(-1) + M(0) + M(1) = 3A$

$$(A - I_2) + A + (A + I_2) = 3A.$$

*Barem: 3p, 2p.*

### 4. $M(a)\cdot M(b) = (a + b)A + abI_2$

$A\cdot A = \begin{pmatrix}4 - 4 & 2 - 2\\-8 + 8 & -4 + 4\end{pmatrix} = O_2$. Atunci

$$(A + aI_2)(A + bI_2) = A^2 + (a + b)A + abI_2 = (a + b)A + abI_2.$$

*Barem: 2p $A^2$, 3p dezvoltarea.*

### 5. $a$ pentru care $M(a)$ este inversabilă

$\det M(a) = a^2 \ne 0 \iff a \ne 0$. **Răspuns:** $a \in \mathbb R\setminus\{0\}$. *Barem: 2p, 3p.*

### 6. Ecuația $M(1)\cdot X = A$

$M(1) = \begin{pmatrix}3&1\\-4&-1\end{pmatrix}$, $\det = 1$, $M(1)^{-1} = \begin{pmatrix}-1&-1\\4&3\end{pmatrix}$.

$$X = M(1)^{-1}A = \begin{pmatrix}-1&-1\\4&3\end{pmatrix}\begin{pmatrix}2&1\\-4&-2\end{pmatrix} = \begin{pmatrix}2&1\\-4&-2\end{pmatrix} = A.$$

(Verificare: $M(1)A = A^2 + A = A$ ✔.) **Răspuns:** $X = A$. *Barem: 2p inversa, 3p soluția.*

## Ce merită reținut din varianta 8

- **Legea $(x-1)(y-1)$**: $1$ este element absorbant ($1\circ x = 0$).
- **Matrice nilpotente ($A^2 = O_2$)** simplifică produsele $(A + aI)(A + bI)$.
- **$\det(A + aI_2) = a^2 + a\operatorname{tr}A + \det A$** pentru $2\times2$.
- **Ecuații în numere naturale**: ține cont de semnele posibile ale factorilor.
