Pentru fiecare cerință găsești enunțul pe scurt, rezolvarea pas cu pas, răspunsul final și cum se punctează conform baremului oficial. Timp de lucru la examen: 3 ore; se acordă 10 puncte din oficiu.

> **Cum să folosești rezolvarea:** lucrează întâi singur subiectul (deschide PDF-ul de mai sus), apoi compară fiecare pas. Dacă ai ajuns la alt drum corect, primești tot punctajul — baremul acceptă orice soluție corectă.

## Subiectul I (30 de puncte)

### 1. Suma primilor trei termeni ai progresiei aritmetice cu $a_1 = 3$, $r = 2$

$$a_1 + a_2 + a_3 = 3 + 5 + 7 = 15.$$

**Răspuns:** $15$. *Barem: 3p, 2p.*

### 2. Vârful parabolei asociate funcției $f(x) = x^2 + 2x - 2$

$$x_V = -\frac{b}{2a} = -1, \qquad \Delta = 4 + 8 = 12, \qquad y_V = -\frac{\Delta}{4a} = -3.$$

**Răspuns:** $V(-1, -3)$. *Barem: 2p, 3p.*

### 3. Ecuația $\sqrt{x^2 - 4x + 5} = 1$

$x^2 - 4x + 5 = (x-2)^2 + 1 > 0$ mereu. Ridicând la pătrat: $x^2 - 4x + 5 = 1 \iff (x - 2)^2 = 0 \iff x = 2$.

**Răspuns:** $x = 2$. *Barem: 3p, 2p.*

### 4. Numărul submulțimilor cu trei elemente ale mulțimii $\{1, 2, 3, 4, 5\}$

$$C_5^3 = \frac{5\cdot 4\cdot 3}{3!} = 10.$$

**Răspuns:** $10$. *Barem: 3p, 2p.*

### 5. $A(2, 3)$, $B(-2, 1)$, $C(-2, 5)$; lungimea vectorului $\overrightarrow{AM}$, $M$ mijlocul lui $BC$

$M\left(\frac{-2 - 2}{2}, \frac{1 + 5}{2}\right) = M(-2, 3)$, deci

$$AM = \sqrt{(-2 - 2)^2 + (3 - 3)^2} = 4.$$

**Răspuns:** $4$. *Barem: 2p, 3p.*

### 6. $\operatorname{ctg} a$, știind că $\sin a = \frac13$ și $a \in \left(0, \frac\pi2\right)$

$\cos a = \sqrt{1 - \frac19} = \sqrt{\frac89} = \frac{2\sqrt2}{3}$ (pozitiv în cadranul I).

$$\operatorname{ctg} a = \frac{\cos a}{\sin a} = \frac{2\sqrt2/3}{1/3} = 2\sqrt2.$$

**Răspuns:** $2\sqrt2$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(x) = \begin{pmatrix} 2 & x\\ 1 & 3\end{pmatrix}$

#### a) $\det(A(3))$

$$\det A(3) = 2\cdot 3 - 3\cdot 1 = 3.$$

**Răspuns:** $3$. *Barem: 3p, 2p.*

#### b) $A(-2015) + A(2015) = 2A(0)$

$$\begin{pmatrix} 2 & -2015\\ 1 & 3\end{pmatrix} + \begin{pmatrix} 2 & 2015\\ 1 & 3\end{pmatrix} = \begin{pmatrix} 4 & 0\\ 2 & 6\end{pmatrix} = 2\begin{pmatrix} 2 & 0\\ 1 & 3\end{pmatrix} = 2A(0).$$

*Barem: 2p, 3p.*

#### c) $x$ cu $\det(A(x)) = x^2$

$$\det A(x) = 6 - x = x^2 \iff x^2 + x - 6 = 0 \iff (x + 3)(x - 2) = 0.$$

**Răspuns:** $x \in \{-3, 2\}$. *Barem: 2p, 3p.*

### 2. În $\mathbb Z_5[X]$: $f = X^3 + aX$, $a \in \mathbb Z_5$

#### a) $f(\hat 0)$

$f(\hat 0) = \hat 0 + a\cdot\hat 0 = \hat 0$.

**Răspuns:** $\hat 0$. *Barem: 2p, 3p.*

#### b) $a$ știind că $f(\hat 3) = \hat 3$

$\hat 3^3 = \widehat{27} = \hat 2$, deci $f(\hat 3) = \hat 2 + \hat 3a = \hat 3 \iff \hat 3a = \hat 1$. Cum $\hat 3\cdot\hat 2 = \hat 6 = \hat 1$, rezultă $a = \hat 2$.

**Răspuns:** $a = \hat 2$. *Barem: 2p, 3p.*

#### c) Dacă $f(\hat 1) = f(\hat 2)$, atunci $f(\hat 3) = f(\hat 4)$

$f(\hat 1) = \hat 1 + a$, $f(\hat 2) = \hat 8 + \hat 2a = \hat 3 + \hat 2a$. Egalitatea dă $\hat 1 + a = \hat 3 + \hat 2a$, adică $a = -\hat 2 = \hat 3$.

Pentru $a = \hat 3$:

$$f(\hat 3) = \hat 2 + \hat 9 = \widehat{11} = \hat 1, \qquad f(\hat 4) = \widehat{64} + \widehat{12} = \hat 4 + \hat 2 = \hat 1.$$

Deci $f(\hat 3) = f(\hat 4)$. $\blacksquare$ *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0, +\infty) \to \mathbb R$, $f(x) = \dfrac{x + \ln x}{x}$

#### a) $f'(x) = \dfrac{1 - \ln x}{x^2}$

$$f'(x) = \frac{\left(1 + \frac1x\right)x - (x + \ln x)}{x^2} = \frac{x + 1 - x - \ln x}{x^2} = \frac{1 - \ln x}{x^2}.$$

*Barem: 2p, 3p.*

#### b) Tangenta în punctul de abscisă $x_0 = 1$

$f(1) = 1$, $f'(1) = 1$:

$$y - 1 = 1\cdot(x - 1) \iff y = x.$$

**Răspuns:** $y = x$. *Barem: 2p, 3p.*

#### c) Intervalele de monotonie

$f'(x) = 0 \iff \ln x = 1 \iff x = e$.

- pe $(0, e]$: $\ln x \le 1$, $f' \ge 0$, $f$ **crescătoare**;
- pe $[e, +\infty)$: $f' \le 0$, $f$ **descrescătoare**.

*Barem: 1p, 2p, 2p.*

### 2. $f:(-1, +\infty) \to \mathbb R$, $f(x) = x + \dfrac{1}{x + 1}$

#### a) $\displaystyle\int_0^1\left(f(x) - \frac{1}{x+1}\right)dx$

$$\int_0^1 x\,dx = \frac12.$$

**Răspuns:** $\dfrac12$. *Barem: 3p, 2p.*

#### b) $\displaystyle\int_0^1 xf(x)\,dx = \frac43 - \ln 2$

$xf(x) = x^2 + \dfrac{x}{x + 1} = x^2 + 1 - \dfrac{1}{x + 1}$:

$$\int_0^1\left(x^2 + 1 - \frac{1}{x+1}\right)dx = \left(\frac{x^3}{3} + x - \ln(x + 1)\right)\Big|_0^1 = \frac13 + 1 - \ln 2 = \frac43 - \ln 2.$$

*Barem: 2p, 3p.*

#### c) $n \in \mathbb N^*$ pentru care aria delimitată de $G_f$, $Ox$, $x = 0$, $x = 1$ este $\frac12 + \ln(n^2 + n)$

$f > 0$ pe $[0, 1]$:

$$\mathcal A = \int_0^1\left(x + \frac{1}{x+1}\right)dx = \left(\frac{x^2}{2} + \ln(x + 1)\right)\Big|_0^1 = \frac12 + \ln 2.$$

$$\frac12 + \ln 2 = \frac12 + \ln(n^2 + n) \iff n^2 + n - 2 = 0 \iff (n + 2)(n - 1) = 0.$$

$n = -2$ nu este natural, deci $n = 1$.

**Răspuns:** $n = 1$. *Barem: 3p, 2p.*

## Ce merită reținut din model

- **Calcul în $\mathbb Z_5$**: reduci la fiecare pas modulo 5; inversul lui $\hat 3$ este $\hat 2$.
- **Funcția $\frac{\ln x}{x}$** (și variantele ei) are maximul în $x = e$.
- **$\frac{x}{x+1} = 1 - \frac{1}{x+1}$** — rescriere utilă la integrare.
- **Ecuații cu parametru natural**: verifică la final apartenența la $\mathbb N^*$.
