## Subiectul I (30 de puncte)

### 1. Arătați că $3(4 - \sqrt3) + 3\sqrt3 = 12$

$$3(4 - \sqrt3) + 3\sqrt3 = 12 - 3\sqrt3 + 3\sqrt3 = 12.$$

*Barem: 2p desfacerea parantezei, 3p finalizarea.*

### 2. $f(x) = x^2 - 16$; calculați $f(-4) + f(4)$

$f(-4) = 16 - 16 = 0$, $f(4) = 16 - 16 = 0$, deci suma este $0$.

**Răspuns:** $0$. *Barem: 2p, 3p.*

### 3. Ecuația $(x - 2)^2 - x^2 + 8 = 0$

$$x^2 - 4x + 4 - x^2 + 8 = 0 \iff -4x + 12 = 0 \iff x = 3.$$

**Răspuns:** $x = 3$. *Barem: 2p, 3p.*

### 4. Un obiect costă 100 lei; prețul după o ieftinire cu $30\%$

Reducerea: $\frac{30}{100}\cdot 100 = 30$ lei. Prețul nou: $100 - 30 = 70$ lei.

**Răspuns:** $70$ de lei. *Barem: 2p, 3p.*

### 5. Distanța de la $A(2, 4)$ la $B(2, 1)$

$$AB = \sqrt{(2-2)^2 + (1-4)^2} = \sqrt9 = 3.$$

**Răspuns:** $AB = 3$. *Barem: 3p, 2p.*

### 6. $\sin A = \frac12$, $A$ ascuțit; calculați $\cos A$

$$\cos^2 A = 1 - \sin^2 A = 1 - \frac14 = \frac34.$$

$A$ fiind ascuțit, $\cos A > 0$, deci $\cos A = \dfrac{\sqrt3}{2}$.

**Răspuns:** $\cos A = \dfrac{\sqrt3}{2}$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 2 & -2\\ 0 & 2\end{pmatrix}$, $B = \begin{pmatrix} b & 1\\ 0 & b\end{pmatrix}$

#### a) $\det A$

$$\det A = 2\cdot 2 - (-2)\cdot 0 = 4.$$

**Răspuns:** $4$. *Barem: 3p, 2p.*

#### b) $b$ cu $A\cdot B = 2I_2$

$$A\cdot B = \begin{pmatrix} 2b & 2 - 2b\\ 0 & 2b\end{pmatrix} = \begin{pmatrix} 2 & 0\\ 0 & 2\end{pmatrix} \iff 2b = 2 \text{ și } 2 - 2b = 0 \iff b = 1.$$

**Răspuns:** $b = 1$. *Barem: 3p, 2p.*

#### c) $b$ cu $\det(A + B) = 0$

$$A + B = \begin{pmatrix} 2 + b & -1\\ 0 & 2 + b\end{pmatrix}, \quad \det(A + B) = (2 + b)^2.$$

$(2 + b)^2 = 0 \iff b = -2$.

**Răspuns:** $b = -2$. *Barem: 3p, 2p.*

### 2. $f = X^3 - 3X^2 + 2X$

#### a) $f(1)$

$$f(1) = 1 - 3 + 2 = 0.$$

*Barem: 2p, 3p.*

#### b) Câtul și restul împărțirii lui $f$ la $X - 2$

$f = X(X^2 - 3X + 2) = X(X - 1)(X - 2) = (X^2 - X)(X - 2)$.

**Răspuns:** câtul $X^2 - X$, restul $0$. *Barem: 2p, 3p.*

#### c) $x_1^2 + x_2^2 + x_3^2$

Viète: $x_1 + x_2 + x_3 = 3$, $x_1x_2 + x_2x_3 + x_3x_1 = 2$.

$$x_1^2 + x_2^2 + x_3^2 = 3^2 - 2\cdot 2 = 5.$$

(Verificare: rădăcinile sunt $0, 1, 2$, iar $0 + 1 + 4 = 5$.) **Răspuns:** $5$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = (x + 2)^3$

#### a) $f'(x) = 3x^2 + 12x + 12$

$f(x) = x^3 + 6x^2 + 12x + 8$, deci

$$f'(x) = 3x^2 + 12x + 12.$$

*Barem: 2p, 3p.*

#### b) $f$ este crescătoare pe $\mathbb R$

$f'(x) = 3(x^2 + 4x + 4) = 3(x + 2)^2 \ge 0$ pentru orice $x$, deci $f$ este crescătoare pe $\mathbb R$. *Barem: 2p, 3p.*

#### c) $\lim\limits_{x\to+\infty}\dfrac{f'(x)}{x^2}$

$$\lim_{x\to+\infty}\frac{3x^2 + 12x + 12}{x^2} = \lim_{x\to+\infty}\left(3 + \frac{12}{x} + \frac{12}{x^2}\right) = 3.$$

**Răspuns:** $3$. *Barem: 3p, 2p.*

### 2. $f(x) = x^2 + 1$

#### a) $F(x) = \frac{x^3}{3} + x$ este o primitivă a lui $f$

$$F'(x) = \frac{3x^2}{3} + 1 = x^2 + 1 = f(x),$$

pentru orice $x$ real, deci $F$ este o primitivă a lui $f$. *Barem: 3p, 2p.*

#### b) Aria suprafeței delimitate de $G_f$, $Ox$, $x = 0$, $x = 1$

$f > 0$, deci

$$\mathcal A = \int_0^1(x^2 + 1)\,dx = \left(\frac{x^3}{3} + x\right)\Big|_0^1 = \frac13 + 1 = \frac43.$$

**Răspuns:** $\dfrac43$. *Barem: 3p, 2p.*

#### c) $\displaystyle\int_1^2\frac{f(x)}{x}\,dx = \frac32 + \ln 2$

$$\int_1^2\frac{x^2 + 1}{x}\,dx = \int_1^2\left(x + \frac1x\right)dx = \left(\frac{x^2}{2} + \ln x\right)\Big|_1^2 = 2 + \ln 2 - \frac12 = \frac32 + \ln 2.$$

*Barem: 2p, 3p.*
