## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{12} + 2\left(\sqrt2 - \sqrt3\right) - \sqrt8$ este natural

$\sqrt{12} = 2\sqrt3$, $\sqrt8 = 2\sqrt2$:

$$2\sqrt3 + 2\sqrt2 - 2\sqrt3 - 2\sqrt2 = 0 \in \mathbb N.$$

*Barem: 2p scoaterea factorilor, 3p calculul.*

### 2. Intersecția graficului $f(x) = 2x - 3$ cu axa absciselor

$y = 0$ și $f(x) = 0 \iff x = \dfrac32$.

**Răspuns:** $\left(\dfrac32, 0\right)$. *Barem: 2p $y = 0$, 3p $x$.*

### 3. Ecuația $7^{x^2+1} = 49$

$49 = 7^2$, deci $x^2 + 1 = 2 \iff x^2 = 1 \iff x = \pm1$.

**Răspuns:** $x \in \{-1, 1\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 4. Prețul inițial, știind că după o scumpire cu $10\%$ și o ieftinire cu $10\%$ produsul costă $1980$ lei

După scumpire: $x + \frac{10}{100}x = \frac{11x}{10}$. După ieftinire:

$$\frac{11x}{10} - \frac{10}{100}\cdot\frac{11x}{10} = \frac{11x}{10}\cdot\frac{9}{10} = \frac{99x}{100} = 1980 \iff x = 2000.$$

**Răspuns:** $2000$ de lei. *Barem: 2p scumpirea, 3p ecuația și soluția.*

### 5. $P(3,4)$, $Q(4,2)$, $R(7,2)$; $S$ astfel încât $PQRS$ paralelogram

Diagonalele $PR$ și $QS$ au același mijloc $M$:

$$M\left(\frac{3+7}{2}, \frac{4+2}{2}\right) = M(5, 3), \qquad x_S = 2\cdot5 - 4 = 6,\ y_S = 2\cdot3 - 2 = 4.$$

**Răspuns:** $S(6, 4)$. *Barem: 3p mijlocul, 2p coordonatele lui $S$.*

### 6. $\cos A$ în triunghiul cu $AB = 5$, $AC = 7$, $BC = 8$

$$\cos A = \frac{25 + 49 - 64}{2\cdot5\cdot7} = \frac{10}{70} = \frac17.$$

**Răspuns:** $\dfrac17$. *Barem: 3p formula, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = x + y - 1$.

### 1. $2 * 3$

$$2 + 3 - 1 = 4.$$

*Barem: 3p, 2p.*

### 2. Legea este comutativă

$x * y = x + y - 1 = y + x - 1 = y * x$. **Răspuns:** da. *Barem: 3p, 2p.*

### 3. Legea este asociativă

$$(x * y) * z = (x + y - 1) + z - 1 = x + y + z - 2 = x + (y + z - 1) - 1 = x * (y * z).$$

*Barem: 2p, 2p, 1p.*

### 4. $(x^2) * x = 11$

$$x^2 + x - 1 = 11 \iff x^2 + x - 12 = 0 \iff (x + 4)(x - 3) = 0.$$

**Răspuns:** $x \in \{-4, 3\}$. *Barem: 2p expresia, 3p soluțiile.*

### 5. $x * (x + 2014)$ și $(x + 1012) * (x + 1012)$

Calculăm ambii membri:

$$x * (x + 2014) = x + x + 2014 - 1 = 2x + 2013,$$

$$(x + 1012) * (x + 1012) = 2x + 2024 - 1 = 2x + 2023.$$

**Atenție — enunț eronat:** cu numerele din enunț, cei doi membri diferă prin $10$, deci egalitatea **nu** are loc. Baremul oficial scrie $(x+1012)*(x+1012) = 2x + 2013$, ceea ce este o greșeală de calcul. Egalitatea devine adevărată dacă al doilea membru este $(x + 1007) * (x + 1007) = 2x + 2014 - 1 = 2x + 2013$ — aceasta este, foarte probabil, varianta intenționată. Ideea de rezolvare (calculul direct al ambilor membri) rămâne aceeași. *Barem: 2p membrul stâng, 3p membrul drept.*

### 6. $x \ne 0$ cu $x * \dfrac1x = 1$

$$x + \frac1x - 1 = 1 \iff x^2 - 2x + 1 = 0 \iff (x - 1)^2 = 0 \iff x = 1.$$

**Răspuns:** $x = 1$. *Barem: 3p ecuația, 2p soluția.*

## Subiectul al III-lea (30 de puncte)

$A(m) = \begin{pmatrix}m & m & 1\\1 & 0 & 1\\m & 1 & 0\end{pmatrix}$.

### 1. $\det(A(0))$

$$\det\begin{pmatrix}0&0&1\\1&0&1\\0&1&0\end{pmatrix} = 1\cdot\begin{vmatrix}1 & 0\\0 & 1\end{vmatrix} = 1$$

(dezvoltare după prima linie). *Barem: 2p matricea, 3p determinantul.*

### 2. $A(0)\cdot A(1)$

$$A(0)A(1) = \begin{pmatrix}0&0&1\\1&0&1\\0&1&0\end{pmatrix}\begin{pmatrix}1&1&1\\1&0&1\\1&1&0\end{pmatrix} = \begin{pmatrix}1&1&0\\2&2&1\\1&0&1\end{pmatrix}.$$

*Barem: 2p $A(1)$, 3p produsul.*

### 3. $m$ cu $\det(A(m)) = m$

$$\det(A(m)) = 0 + m^2 + 1 - 0 - m - 0 = m^2 - m + 1.$$

$m^2 - m + 1 = m \iff (m-1)^2 = 0 \iff m = 1$.

**Răspuns:** $m = 1$. *Barem: 3p determinantul, 2p soluția.*

### 4. $A(2) + A(4) = 2A(3)$

$$A(2) + A(4) = \begin{pmatrix}6&6&2\\2&0&2\\6&2&0\end{pmatrix} = 2\begin{pmatrix}3&3&1\\1&0&1\\3&1&0\end{pmatrix} = 2A(3).$$

*Barem: 3p suma, 2p finalizarea.*

### 5. $B = \begin{pmatrix}-1&1&0\\0&0&1\\1&0&0\end{pmatrix}$ este inversa lui $A(0)$

$$A(0)\cdot B = \begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}, \qquad B\cdot A(0) = \begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix}.$$

(De exemplu, linia 2 a lui $A(0)$, $(1,0,1)$, înmulțită cu coloanele lui $B$: $-1 + 1 = 0$, $1$, $0$.) **Răspuns:** da. *Barem: 2p, 3p.*

### 6. $m$ pentru care sistemul $\begin{cases}mx + my + z = 0\\x + z = m\\mx + y = 1\end{cases}$ are soluția $(0,1,0)$

Înlocuim: $m = 0$, $0 = m$, $1 = 1$.

**Răspuns:** $m = 0$. *Barem: 3p înlocuirea, 2p valoarea.*

## Ce merită reținut din model

- **Scumpire urmată de ieftinire cu același procent** nu revine la prețul inițial: factorul este $1{,}1\cdot0{,}9 = 0{,}99$.
- **Al patrulea vârf al paralelogramului**: diagonalele se înjumătățesc.
- **Legea $x + y - 1$**: $\underbrace{x * \dots * x}$ și identitățile se verifică prin calcul direct — verifică și cifrele enunțului.
- **Matrice de permutare**: inversa este transpusa.
