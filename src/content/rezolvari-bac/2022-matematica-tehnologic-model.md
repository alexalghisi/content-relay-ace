## Subiectul I (30 de puncte)

### 1. Arătați că $(\sqrt8 + 1)(2\sqrt2 - 1) - \sqrt{36} = 1$

$\sqrt8 = 2\sqrt2$, deci $(2\sqrt2 + 1)(2\sqrt2 - 1) = (2\sqrt2)^2 - 1 = 7$, iar $\sqrt{36} = 6$:

$$7 - 6 = 1.$$

*Barem: 3p + 2p.*

### 2. Intersecția graficelor lui $f(x) = 5x - 1$ și $g(x) = 5 + 2x$

$$5x - 1 = 5 + 2x \iff 3x = 6 \iff x = 2,\qquad f(2) = 9.$$

**Răspuns:** punctul $(2, 9)$. *Barem: 2p + 3p.*

### 3. Ecuația $\sqrt{x^2 + 6x} = x$

Condiție $x \ge 0$. Ridicăm la pătrat: $x^2 + 6x = x^2 \iff x = 0$, care convine ($\sqrt0 = 0$).

**Răspuns:** $x = 0$. *Barem: 3p + 2p.*

### 4. $A = \{0, 1, \dots, 9\}$; probabilitatea ca $4n \in A$

10 cazuri posibile. $4n \le 9 \iff n \in \{0, 1, 2\}$: 3 cazuri favorabile.

$$p = \frac{3}{10}.$$

*Barem: 2p + 2p + 1p.*

### 5. $A(2,1)$, $B(3,4)$, $A$ mijlocul lui $BC$; triunghiul $AOC$ este dreptunghic isoscel

$\frac{3 + x_C}{2} = 2 \Rightarrow x_C = 1$; $\frac{4 + y_C}{2} = 1 \Rightarrow y_C = -2$. Deci $C(1, -2)$.

$OA = \sqrt{4 + 1} = \sqrt5$, $OC = \sqrt{1 + 4} = \sqrt5$, $AC = \sqrt{1 + 9} = \sqrt{10}$.

$OA = OC$ și $OA^2 + OC^2 = 10 = AC^2$, deci triunghiul $AOC$ este dreptunghic (în $O$) și isoscel. $\blacksquare$ *Barem: 2p + 3p.*

### 6. $\sin30^\circ\cdot\sin A = \cos60^\circ\cdot\cos A$; calculați $\operatorname{tg}A$

$\sin30^\circ = \cos60^\circ = \frac12$, deci $\sin A = \cos A$, iar $A$ ascuțit dă $\cos A \ne 0$:

$$\operatorname{tg}A = \frac{\sin A}{\cos A} = 1.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}3&-6\\2&-3\end{pmatrix}$, $B(a) = \begin{pmatrix}0 & a - 2\\ 1 & 3a\end{pmatrix}$

#### a) $\det A = 3$

$$\det A = 3\cdot(-3) - (-6)\cdot2 = -9 + 12 = 3.$$

*Barem: 3p + 2p.*

#### b) $x$ cu $A\cdot A + A = 2B(x)$

$$A\cdot A = \begin{pmatrix}9 - 12 & -18 + 18\\ 6 - 6 & -12 + 9\end{pmatrix} = \begin{pmatrix}-3&0\\0&-3\end{pmatrix},\quad A\cdot A + A = \begin{pmatrix}0&-6\\2&-6\end{pmatrix} = 2\begin{pmatrix}0&-3\\1&-3\end{pmatrix}.$$

$\begin{pmatrix}0&-3\\1&-3\end{pmatrix} = B(-1)$ (căci $-1 - 2 = -3$ și $3\cdot(-1) = -3$).

**Răspuns:** $x = -1$. *Barem: 2p + 3p.*

#### c) $a$ cu $\det\big(B(a)A + B(3a)\big) = 4$

$$B(a)A = \begin{pmatrix}2a - 4 & -3a + 6\\ 3 + 6a & -6 - 9a\end{pmatrix},\quad B(3a) = \begin{pmatrix}0 & 3a - 2\\ 1 & 9a\end{pmatrix},$$

$$B(a)A + B(3a) = \begin{pmatrix}2a - 4 & 4\\ 6a + 4 & -6\end{pmatrix},\quad \det = -6(2a - 4) - 4(6a + 4) = -36a + 8.$$

$-36a + 8 = 4 \iff a = \dfrac19$.

**Răspuns:** $a = \dfrac19$. *Barem: 3p + 2p.*

### 2. Legea $x * y = (xy + 1)(x + y)$

#### a) $1 * 2 = 9$

$$1 * 2 = (2 + 1)(1 + 2) = 9.$$

*Barem: 3p + 2p.*

#### b) $e = 0$ este elementul neutru

$x * 0 = (0 + 1)(x + 0) = x$ și $0 * x = x$, pentru orice $x$ real. $\blacksquare$ *Barem: 2p + 3p.*

#### c) $n \in \mathbb N^*$ cu $N = n * \frac1n$ întreg

$$N = \left(n\cdot\tfrac1n + 1\right)\left(n + \tfrac1n\right) = 2n + \frac2n.$$

$N \in \mathbb Z \iff \frac2n \in \mathbb Z \iff n \mid 2$, deci $n \in \{1, 2\}$.

**Răspuns:** $n \in \{1, 2\}$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = (x - 1)e^x - \dfrac{x^2}{2}$

#### a) $f'(x) = x(e^x - 1)$

$$f'(x) = e^x + (x - 1)e^x - x = xe^x - x = x(e^x - 1).$$

*Barem: 3p + 2p.*

#### b) $\lim\limits_{x\to0}\dfrac{f(x) - f(0)}{x^2} = 0$

Cazul $\frac00$; aplicăm l'Hôpital:

$$\lim_{x\to0}\frac{f'(x)}{2x} = \lim_{x\to0}\frac{x(e^x - 1)}{2x} = \lim_{x\to0}\frac{e^x - 1}{2} = 0.$$

*Barem: 2p + 3p.*

#### c) $f(x) \le f(x^2)$ pentru $x \le 0$

$x$ și $e^x - 1$ au mereu același semn (ambele $\le 0$ pentru $x \le 0$, ambele $\ge 0$ pentru $x \ge 0$), deci $f'(x) \ge 0$: $f$ e crescătoare pe $\mathbb R$.

Pentru $x \le 0$: $x \le 0 \le x^2$, deci $f(x) \le f(x^2)$. $\blacksquare$ *Barem: 2p + 3p.*

### 2. $f:(-4,\infty)\to\mathbb R$, $f(x) = \dfrac{4x}{x + 4}$

#### a) $\displaystyle\int_1^2(x + 4)f(x)dx = 6$

$$\int_1^2 4x\,dx = 2x^2\Big|_1^2 = 8 - 2 = 6.$$

*Barem: 3p + 2p.*

#### b) $\displaystyle\int_1^4\frac1x f(x^2)dx = 4\ln2$

$\frac1x f(x^2) = \frac{4x}{x^2 + 4} = 2\cdot\frac{(x^2+4)'}{x^2+4}$:

$$\int_1^4\frac{4x}{x^2+4}dx = 2\ln(x^2+4)\Big|_1^4 = 2\ln20 - 2\ln5 = 2\ln4 = 4\ln2.$$

*Barem: 3p + 2p.*

#### c) Orice primitivă a lui $f$ este convexă

Dacă $F' = f$, atunci $F'' = f'$, iar

$$f'(x) = \frac{4(x + 4) - 4x}{(x+4)^2} = \frac{16}{(x+4)^2} > 0,$$

deci $F'' > 0$ pe $(-4, \infty)$ și $F$ este convexă. $\blacksquare$ *Barem: 2p + 3p.*
