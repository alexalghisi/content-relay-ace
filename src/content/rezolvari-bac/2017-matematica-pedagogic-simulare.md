## Subiectul I (30 de puncte)

### 1. Rația progresiei aritmetice cu $a_1 + a_2 + a_3 + a_4 = 14$ și $a_1 = 2$

$$a_1 + (a_1 + r) + (a_1 + 2r) + (a_1 + 3r) = 4a_1 + 6r = 14 \iff 8 + 6r = 14 \iff r = 1.$$

**Răspuns:** $r = 1$. *Barem: 3p, 2p.*

### 2. $f(x) = x^2 - 5x + 4$; distanța dintre punctele de intersecție ale graficului cu $Ox$

$f(x) = 0 \iff x^2 - 5x + 4 = 0 \iff (x - 1)(x - 4) = 0$, deci punctele $(1, 0)$ și $(4, 0)$. Distanța este $4 - 1 = 3$.

**Răspuns:** $3$. *Barem: 2p, 3p.*

### 3. Ecuația $2^{x+2} + 2^{x+1} + 2^x = 7$

Dăm factor comun $2^x$:

$$2^x(2^2 + 2^1 + 1) = 7 \iff 7\cdot 2^x = 7 \iff 2^x = 1 \iff x = 0.$$

**Răspuns:** $x = 0$. *Barem: 3p, 2p.*

### 4. După două creșteri succesive cu câte $10\%$, produsul costă 242 lei. Prețul inițial

După prima scumpire prețul devine $p + \frac{10}{100}p = 1{,}1p$, după a doua $1{,}1\cdot 1{,}1p = 1{,}21p$.

$$1{,}21p = 242 \iff p = 200.$$

**Răspuns:** $200$ de lei. *Barem: 3p, 2p.*

### 5. $\vec v_1 = m\vec i + 6\vec j$ și $\vec v_2 = 2\vec i + 3\vec j$ coliniari

$$\frac m2 = \frac63 \iff m = 4.$$

**Răspuns:** $m = 4$. *Barem: 3p, 2p.*

### 6. Aria dreptunghiului $ABCD$ cu $AB = 3$, $AC = 5$

În triunghiul dreptunghic $ABC$ (unghiul drept în $B$): $BC = \sqrt{AC^2 - AB^2} = \sqrt{25 - 9} = 4$.

$$\mathcal A_{ABCD} = AB\cdot BC = 3\cdot 4 = 12.$$

**Răspuns:** $12$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă: $x * y = x + y - xy$.

### 1. $(-1) * 1$

$$(-1) * 1 = -1 + 1 - (-1)\cdot 1 = 0 + 1 = 1.$$

*Barem: 3p, 2p.*

### 2. Legea este comutativă?

$x * y = x + y - xy = y + x - yx = y * x$ pentru orice $x, y$, deci **legea este comutativă**. *Barem: 3p, 2p.*

### 3. $x * y = -(x-1)(y-1) + 1$

$$-(x-1)(y-1) + 1 = -(xy - x - y + 1) + 1 = -xy + x + y = x * y.$$

*Barem: 2p, 3p.*

### 4. $x * x = 0$

$$-(x-1)^2 + 1 = 0 \iff (x-1)^2 = 1 \iff x - 1 = \pm 1 \iff x \in \{0, 2\}.$$

**Răspuns:** $x \in \{0, 2\}$. *Barem: 3p, 2p.*

### 5. $a * a \ge 1$

$$-(a-1)^2 + 1 \ge 1 \iff (a-1)^2 \le 0 \iff a = 1.$$

**Răspuns:** $a = 1$. *Barem: 3p, 2p.*

### 6. $\dfrac{1}{2016} * \dfrac{2}{2016} * \dots * \dfrac{2017}{2016}$

Din 3): $x * 1 = -(x-1)\cdot 0 + 1 = 1$ și $1 * y = 1$ — **$1$ este element absorbant**.

Printre factori se află $\frac{2016}{2016} = 1$. Folosind asociativitatea, grupăm:

$$\left(\frac{1}{2016} * \dots * \frac{2015}{2016}\right) * 1 * \left(\frac{2017}{2016}\right) = 1 * \frac{2017}{2016} = 1.$$

**Răspuns:** $1$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

Matricea $A(n) = \begin{pmatrix} 1 & n\\ 0 & 1\end{pmatrix}$, $n \in \mathbb Z$.

### 1. $\det(A(2017))$

$$\det A(2017) = \begin{vmatrix} 1 & 2017\\ 0 & 1\end{vmatrix} = 1\cdot 1 - 2017\cdot 0 = 1.$$

*Barem: 2p, 3p.*

### 2. $A(-2017) + A(2017) = 2I_2$

$$\begin{pmatrix} 1 & -2017\\ 0 & 1\end{pmatrix} + \begin{pmatrix} 1 & 2017\\ 0 & 1\end{pmatrix} = \begin{pmatrix} 2 & 0\\ 0 & 2\end{pmatrix} = 2I_2.$$

*Barem: 3p, 2p.*

### 3. $A(m)\cdot A(n) = A(m + n)$

$$\begin{pmatrix} 1 & m\\ 0 & 1\end{pmatrix}\begin{pmatrix} 1 & n\\ 0 & 1\end{pmatrix} = \begin{pmatrix} 1 & n + m\\ 0 & 1\end{pmatrix} = A(m + n).$$

*Barem: 3p, 2p.*

### 4. Suma elementelor matricei $B = A(0) + A(1) + \dots + A(6)$ se divide cu 7

$$B = \begin{pmatrix} 7 & 0 + 1 + \dots + 6\\ 0 & 7\end{pmatrix} = \begin{pmatrix} 7 & 21\\ 0 & 7\end{pmatrix}.$$

Suma elementelor: $7 + 21 + 0 + 7 = 35 = 7\cdot 5$, divizibilă cu 7. *Barem: 3p, 2p.*

### 5. $A(n)$ este inversabilă

$\det A(n) = 1 \ne 0$ pentru orice $n$ întreg, deci $A(n)$ este inversabilă. Mai mult, din 3), $A(n)\cdot A(-n) = A(0) = I_2$, deci $(A(n))^{-1} = A(-n)$. *Barem: 2p, 3p.*

### 6. $X \in \mathcal M_2(\mathbb Z)$ cu $A(2017)\cdot X = A(2018)$

Înmulțim la stânga cu $(A(2017))^{-1} = A(-2017)$:

$$X = A(-2017)\cdot A(2018) = A(-2017 + 2018) = A(1) = \begin{pmatrix} 1 & 1\\ 0 & 1\end{pmatrix}.$$

**Răspuns:** $X = \begin{pmatrix} 1 & 1\\ 0 & 1\end{pmatrix}$. *Barem: 2p, 3p.*

## Ce merită reținut din simulare

- **Creșteri procentuale succesive** se înmulțesc: $+10\%$ de două ori înseamnă $\times 1{,}21$, nu $+20\%$.
- **Factor comun la exponențiale**: $2^{x+2} + 2^{x+1} + 2^x = 2^x\cdot 7$.
- **Element absorbant**: dacă apare printre factori, întregul produs este egal cu el.
- **Matrice de forma $A(m)A(n) = A(m+n)$**: inversa este $A(-n)$, iar ecuațiile matriceale devin calcule cu indici.
