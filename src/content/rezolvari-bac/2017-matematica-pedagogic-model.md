## Subiectul I (30 de puncte)

### 1. Arătați că $\left(\left(\frac13\right)^2 + 3\right) : \frac{28}{9} = 1$

$$\frac19 + 3 = \frac{1 + 27}{9} = \frac{28}{9}, \qquad \frac{28}{9} : \frac{28}{9} = 1.$$

*Barem: 3p paranteza, 2p împărțirea.*

### 2. $f(x) = 2x + m$: $f(1) - f(-1) = 4$ pentru orice $m$

$$f(1) - f(-1) = (2 + m) - (-2 + m) = 4.$$

*Barem: 2p $f(1)$, 3p diferența.*

### 3. Ecuația $2^{x^2+3} = 2^{4x}$

$$x^2 + 3 = 4x \iff x^2 - 4x + 3 = 0 \iff (x-1)(x-3) = 0.$$

**Răspuns:** $x \in \{1, 3\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 4. Prețul de $1200$ lei după două scumpiri succesive cu $5\%$

- După prima: $1200 + \dfrac{5}{100}\cdot1200 = 1200 + 60 = 1260$ lei.
- După a doua: $1260 + \dfrac{5}{100}\cdot 1260 = 1260 + 63 = 1323$ lei.

**Răspuns:** $1323$ de lei. *Barem: 3p prima scumpire, 2p a doua.*

### 5. $A(2,6)$, $B(2,3)$; distanța $OC$, $C$ simetricul lui $A$ față de $B$

$B$ este mijlocul lui $AC$: $x_C = 2x_B - x_A = 2$, $y_C = 2y_B - y_A = 0$, deci $C(2, 0)$ și $OC = 2$.

**Răspuns:** $OC = 2$. *Barem: 3p coordonatele lui $C$, 2p distanța.*

### 6. Aria triunghiului $ABC$ cu $\angle B = 45^\circ$, $AB = AC = 4$

$AB = AC \Rightarrow \angle C = \angle B = 45^\circ$, deci $\angle A = 90^\circ$.

$$\mathcal A = \frac{AB\cdot AC}{2} = \frac{4\cdot 4}{2} = 8.$$

**Răspuns:** $8$. *Barem: 3p triunghi dreptunghic și formula, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = x + y - 2017$.

### 1. $2000 * 17 = 0$

$$2000 * 17 = 2000 + 17 - 2017 = 0.$$

*Barem: 3p înlocuirea, 2p calculul.*

### 2. Legea este asociativă

$$(x * y) * z = (x + y - 2017) + z - 2017 = x + y + z - 4034,$$

$$x * (y * z) = x + (y + z - 2017) - 2017 = x + y + z - 4034.$$

Expresiile coincid pentru orice $x, y, z$, deci legea este asociativă. *Barem: 2p $(x*y)*z$, 3p $x*(y*z)$ și concluzia.*

### 3. $a * (a + 2017) = (a + 1009) * (a + 1008)$

$$a * (a+2017) = 2a + 2017 - 2017 = 2a, \qquad (a+1009)*(a+1008) = 2a + 2017 - 2017 = 2a.$$

*Barem: 2p membrul stâng, 3p membrul drept.*

### 4. $4^x * 2^x = -2011$

$$4^x + 2^x - 2017 = -2011 \iff (2^x)^2 + 2^x - 6 = 0 \iff (2^x + 3)(2^x - 2) = 0.$$

Cum $2^x > 0$, rămâne $2^x = 2$, adică $x = 1$.

**Răspuns:** $x = 1$. *Barem: 3p descompunerea, 2p soluția.*

### 5. Cel mai mare $n$ natural cu $n * n \le n$

$$n + n - 2017 \le n \iff n \le 2017.$$

**Răspuns:** $n = 2017$. *Barem: 3p inecuația, 2p concluzia.*

### 6. $\dfrac{2}{3 - \sqrt5} * \dfrac{2}{3 + \sqrt5}$ este întreg

Raționalizăm (numitorul comun $(3-\sqrt5)(3+\sqrt5) = 4$):

$$\frac{2}{3-\sqrt5} + \frac{2}{3+\sqrt5} = \frac{2(3+\sqrt5) + 2(3-\sqrt5)}{4} = \frac{12}{4} = 3.$$

Deci numărul este $3 - 2017 = -2014 \in \mathbb Z$. *Barem: 2p scrierea, 3p calculul.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&2\\2&2\end{pmatrix}$, $I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$.

### 1. $\det A$

$$\det A = 1\cdot 2 - 2\cdot 2 = -2.$$

*Barem: 3p formula, 2p calculul.*

### 2. Inversa lui $A$ este $\begin{pmatrix}-1 & 1\\1 & -\frac12\end{pmatrix}$

Notăm $B = \begin{pmatrix}-1 & 1\\1 & -\frac12\end{pmatrix}$:

$$A B = \begin{pmatrix}-1 + 2 & 1 - 1\\-2 + 2 & 2 - 1\end{pmatrix} = I_2, \qquad BA = \begin{pmatrix}-1 + 2 & -2 + 2\\1 - 1 & 2 - 1\end{pmatrix} = I_2.$$

Deci $B = A^{-1}$. *Barem: 2p $AB$, 3p $BA$ și concluzia.*

### 3. $A\cdot A - 3A = 2I_2$

$$A\cdot A = \begin{pmatrix}5 & 6\\6 & 8\end{pmatrix}, \quad 3A = \begin{pmatrix}3&6\\6&6\end{pmatrix}, \quad A\cdot A - 3A = \begin{pmatrix}2 & 0\\0 & 2\end{pmatrix} = 2I_2.$$

*Barem: 3p calculele, 2p finalizarea.*

### 4. $x$ cu $\det(A - xI_2) = 2$

$$\det\begin{pmatrix}1 - x & 2\\2 & 2 - x\end{pmatrix} = (1-x)(2-x) - 4 = x^2 - 3x - 2.$$

$x^2 - 3x - 2 = 2 \iff x^2 - 3x - 4 = 0 \iff x \in \{-1, 4\}$.

**Răspuns:** $x \in \{-1, 4\}$. *Barem: 3p determinantul, 2p soluțiile.*

### 5. $a$ cu $A\cdot A\cdot A = aA + 6I_2$

Din 3), $A\cdot A = 3A + 2I_2$. Atunci

$$A^3 = (3A + 2I_2)A = 3A^2 + 2A = 3(3A + 2I_2) + 2A = 11A + 6I_2.$$

$11A + 6I_2 = aA + 6I_2 \iff (11 - a)A = O_2$, iar $A \ne O_2$, deci $a = 11$.

**Răspuns:** $a = 11$. *Barem: 3p calculul lui $A^3$, 2p valoarea lui $a$.*

### 6. $p, q$ cu $AX = XA$, $X = \begin{pmatrix}2&1\\p&q\end{pmatrix}$

$$AX = \begin{pmatrix}2 + 2p & 1 + 2q\\4 + 2p & 2 + 2q\end{pmatrix}, \qquad XA = \begin{pmatrix}4 & 6\\p + 2q & 2p + 2q\end{pmatrix}.$$

Din $2 + 2p = 4$: $p = 1$; din $1 + 2q = 6$: $q = \dfrac52$. Verificare: $4 + 2 = 6 = 1 + 5$ și $2 + 5 = 7 = 2 + 5$ ✔.

**Răspuns:** $p = 1$, $q = \dfrac52$. *Barem: 2p produsele, 3p valorile.*
