## Subiectul I (30 de puncte)

### 1. $N = (4 + 3i)^2 + (3 - 4i)^2$ este natural

$(4 + 3i)^2 = 16 + 24i - 9 = 7 + 24i$, $(3 - 4i)^2 = 9 - 24i - 16 = -7 - 24i$. Suma: $N = 0 \in \mathbb N$. $\blacksquare$

*Barem: 2p, 3p.*

### 2. $A(a, a)$ aparține graficului lui $f(x) = 2 - x^2$

$2 - a^2 = a \iff a^2 + a - 2 = 0 \iff a \in \{-2, 1\}$. *Barem: 3p, 2p.*

### 3. Ecuația $5^x + 5^{x+1} = 30$

$5^x(1 + 5) = 30 \iff 5^x = 5 \iff x = 1$. *Barem: 3p, 2p.*

### 4. $M = \{\sqrt1, \sqrt2, \dots, \sqrt{49}\}$: probabilitatea ca elementul să fie natural

49 de cazuri; pătratele perfecte $1, 4, \dots, 49$ dau 7 cazuri favorabile. $p = \frac7{49} = \frac17$. *Barem: 1p, 2p, 2p.*

### 5. Mediana din $B$ în $\triangle ABC$, $A(2,5)$, $B(3,5)$, $C(2,1)$

Mijlocul lui $AC$: $M(2, 3)$. $BM = \sqrt{1^2 + 2^2} = \sqrt5$.

**Răspuns:** $\sqrt5$. *Barem: 2p, 3p.*

### 6. $(\sin x + \cos x)^2 + (\sin x - \cos x)^2 = 2$

Termenii $\pm 2\sin x\cos x$ se reduc: $2(\sin^2 x + \cos^2x) = 2$. $\blacksquare$ *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(x, y) = \begin{pmatrix}x & -y\\ y & x\end{pmatrix}$

**a)** $\det A(1, 1) = 1 + 1 = 2$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** $A(n - 1, 0) + A(n + 1, 0) = \begin{pmatrix}2n & 0\\ 0 & 2n\end{pmatrix} = \begin{pmatrix}2018 & 0\\ 0 & 2018\end{pmatrix} \iff n = 1009$. *Barem: 3p, 2p.*

**c)** $$A(x,1)^2 = \begin{pmatrix}x & -1\\ 1 & x\end{pmatrix}^2 = \begin{pmatrix}x^2 - 1 & -2x\\ 2x & x^2 - 1\end{pmatrix} = \begin{pmatrix}a & 2\\ -2 & a\end{pmatrix}.$$

$-2x = 2 \Rightarrow x = -1$, apoi $a = x^2 - 1 = 0$.

**Răspuns:** $a = 0$. *Barem: 3p, 2p.*

### 2. $f = X^3 - 7X^2 + mX - 8$

**a)** $f(-1) = -1 - 7 - m - 8 = -m - 16$, $f(1) = 1 - 7 + m - 8 = m - 14$; suma: $-30$. $\blacksquare$ *Barem: 2p, 3p.*

**b)** $f(2) = 8 - 28 + 2m - 8 = 2m - 28 = 0 \Rightarrow m = 14$. Împărțim $X^3 - 7X^2 + 14X - 8$ la $X^2 - 3X + 1$:

$$X^3 - 7X^2 + 14X - 8 = (X^2 - 3X + 1)(X - 4) + (X - 4).$$

**Răspuns:** câtul $X - 4$, restul $X - 4$. *Barem: 2p, 3p.*

**c)** În progresie geometrică: $x_1x_3 = x_2^2$, deci $x_1x_2x_3 = x_2^3 = 8 \Rightarrow x_2 = 2$. Atunci $f(2) = 0 \Rightarrow m = 14$, iar $f = (X - 2)(X^2 - 5X + 4) = (X-1)(X-2)(X-4)$: rădăcinile $1, 2, 4$ — pozitive, în progresie geometrică ✔.

**Răspuns:** $m = 14$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = \dfrac{x^2 + 2x + 1}{x + 2}$, $x > -2$

**a)** $$f'(x) = \frac{(2x + 2)(x + 2) - (x^2 + 2x + 1)}{(x+2)^2} = \frac{x^2 + 4x + 3}{(x+2)^2} = \frac{(x+1)(x+3)}{(x+2)^2}.\ \blacksquare$$

*Barem: 3p, 2p.*

**b)** $m = \lim\frac{f(x)}{x} = 1$; $n = \lim(f(x) - x) = \lim\frac{x^2 + 2x + 1 - x^2 - 2x}{x + 2} = \lim\frac{1}{x+2} = 0$.

**Răspuns:** $y = x$. *Barem: 2p, 3p.*

**c)** Scriem $f(x) = x + \frac{1}{x + 2}$ (din b), deci $f'(x) = 1 - \frac{1}{(x+2)^2}$ și $f''(x) = \frac{2}{(x+2)^3} > 0$ pentru $x > -2$: $f$ convexă. $\blacksquare$ *Barem: 2p, 3p.*

### 2. $f(x) = x^2 + \dfrac1x$, $x > 0$

**a)** $F(x) = \frac{x^3}{3} + \ln x + c$; $F(1) = \frac13 + c = 0 \Rightarrow c = -\frac13$.

**Răspuns:** $F(x) = \dfrac{x^3}{3} + \ln x - \dfrac13$. *Barem: 3p, 2p.*

**b)** $g = f$ pe $[1, 2]$:

$$V = \pi\int_1^2\left(x^4 + 2x + \frac1{x^2}\right)dx = \pi\left(\frac{x^5}{5} + x^2 - \frac1x\right)\Big|_1^2 = \pi\left(\frac{32}{5} + 4 - \frac12 - \frac15 - 1 + 1\right) = \frac{97\pi}{10}.\ \blacksquare$$

*Barem: 3p, 2p.*

**c)** $(f(x) - x^2)\ln x = \frac{\ln x}{x} = (\ln x)'\ln x$:

$$\int_1^m\frac{\ln x}{x}dx = \frac{\ln^2x}{2}\Big|_1^m = \frac{\ln^2 m}{2} = \frac12 \iff \ln m = \pm1.$$

$m = \frac1e$ nu convine ($m > 1$), deci $m = e$. **Răspuns:** $m = e$. *Barem: 3p, 2p.*
