## Subiectul I (30 de puncte)

### 1. Arătați că $\left(2 + \left(\frac12\right)^4\right) : \frac{33}{16} = 1$

$$2 + \frac1{16} = \frac{33}{16}, \qquad \frac{33}{16} : \frac{33}{16} = 1.$$

*Barem: 3p paranteza, 2p împărțirea.*

### 2. $f(x) = x + a$; $a$ cu $f(2) + f(-2) = 4$

$$(2 + a) + (-2 + a) = 2a = 4 \iff a = 2.$$

**Răspuns:** $a = 2$. *Barem: 3p suma, 2p valoarea.*

### 3. Ecuația $3^{x^2+2} = 3^{3x}$

$$x^2 + 2 = 3x \iff x^2 - 3x + 2 = 0 \iff x \in \{1, 2\}.$$

**Răspuns:** $x \in \{1, 2\}$. *Barem: 3p, 2p.*

### 4. Prețul de $200$ lei după două scumpiri succesive cu $10\%$

- După prima: $200 + 20 = 220$ lei;
- după a doua: $220 + 22 = 242$ lei.

**Răspuns:** $242$ de lei. *Barem: 2p, 3p.*

### 5. Distanța $OM$, $M$ mijlocul lui $AB$, $A(-3,4)$, $B(3,4)$

$M(0, 4)$, deci $OM = 4$. *Barem: 2p mijlocul, 3p distanța.*

### 6. Aria triunghiului cu $\angle B = 45^\circ$, $AB = AC = \sqrt2$

$AB = AC \Rightarrow \angle C = \angle B = 45^\circ$, deci $\angle A = 90^\circ$:

$$\mathcal A = \frac{AB\cdot AC}{2} = \frac{\sqrt2\cdot\sqrt2}{2} = 1.$$

**Răspuns:** $1$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = x + y - 2015$.

### 1. $1007 * 1008 = 0$

$$1007 + 1008 - 2015 = 0.$$

*Barem: 3p, 2p.*

### 2. Legea este asociativă

$$(x * y) * z = x + y + z - 4030 = x * (y * z).$$

*Barem: 2p, 3p.*

### 3. $e = 2015$ este element neutru

$x * 2015 = x + 2015 - 2015 = x$ și $2015 * x = x$. **Răspuns:** da. *Barem: 2p, 3p.*

### 4. $x * x = 2015$

$$2x - 2015 = 2015 \iff x = 2015.$$

*Barem: 3p, 2p.*

### 5. $x * (x + 2015) = (x + 1007) * (x + 1008)$

$$x * (x + 2015) = 2x + 2015 - 2015 = 2x, \qquad (x + 1007) * (x + 1008) = 2x + 2015 - 2015 = 2x.$$

*Barem: 2p, 3p.*

### 6. Ecuația $5^x * 25^x = -1985$

$$5^x + 25^x - 2015 = -1985 \iff (5^x)^2 + 5^x - 30 = 0.$$

Cu $t = 5^x > 0$: $t^2 + t - 30 = 0 \iff t \in \{5, -6\}$. $t = -6$ nu convine; $5^x = 5 \Rightarrow x = 1$.

**Răspuns:** $x = 1$. *Barem: 2p ecuația, 2p $x = 1$, 1p cazul $-6$.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&-1\\3&0\end{pmatrix}$, $B = \begin{pmatrix}a&b\\3&4\end{pmatrix}$.

### 1. $\det A = 3$

$$1\cdot0 - (-1)\cdot3 = 3.$$

*Barem: 3p, 2p.*

### 2. $a, b$ cu $B - A = 4I_2$

$$\begin{pmatrix}a - 1 & b + 1\\0 & 4\end{pmatrix} = \begin{pmatrix}4&0\\0&4\end{pmatrix} \iff a = 5,\ b = -1.$$

*Barem: 3p, 2p.*

### 3. Pentru $a = 0$: $b$ cu $\det B = 9$

$$\det B = 0\cdot4 - 3b = -3b = 9 \iff b = -3.$$

*Barem: 3p, 2p.*

### 4. $a, b$ cu $AB = BA$

$$AB = \begin{pmatrix}a - 3 & b - 4\\3a & 3b\end{pmatrix}, \qquad BA = \begin{pmatrix}a + 3b & -a\\15 & -3\end{pmatrix}.$$

Din $3a = 15$: $a = 5$; din $3b = -3$: $b = -1$. Verificare: $a - 3 = 2 = a + 3b$ și $b - 4 = -5 = -a$ ✔.

**Răspuns:** $a = 5$, $b = -1$. *Barem: 2p produsele, 3p valorile.*

### 5. Inversa lui $A$ este $\begin{pmatrix}0 & \frac13\\-1 & \frac13\end{pmatrix}$

$$A\begin{pmatrix}0 & \frac13\\-1 & \frac13\end{pmatrix} = \begin{pmatrix}0 + 1 & \frac13 - \frac13\\0 & 1\end{pmatrix} = I_2, \qquad \begin{pmatrix}0 & \frac13\\-1 & \frac13\end{pmatrix}A = \begin{pmatrix}1 & 0\\-1 + 1 & 1\end{pmatrix} = I_2.$$

*Barem: 3p, 2p.*

### 6. Pentru $a = b = 1$: ecuația $B\cdot X = A$

$B = \begin{pmatrix}1&1\\3&4\end{pmatrix}$, $\det B = 1$, $B^{-1} = \begin{pmatrix}4&-1\\-3&1\end{pmatrix}$.

$$X = B^{-1}A = \begin{pmatrix}4&-1\\-3&1\end{pmatrix}\begin{pmatrix}1&-1\\3&0\end{pmatrix} = \begin{pmatrix}1 & -4\\0 & 3\end{pmatrix}.$$

**Răspuns:** $X = \begin{pmatrix}1&-4\\0&3\end{pmatrix}$. *Barem: 3p inversa, 2p soluția.*
