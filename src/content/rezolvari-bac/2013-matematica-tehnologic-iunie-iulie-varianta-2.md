## Subiectul I (30 de puncte)

### 1. Arătați că $3(2 - \sqrt2) + 3\sqrt2 = 6$

$$3(2 - \sqrt2) + 3\sqrt2 = 6 - 3\sqrt2 + 3\sqrt2 = 6.$$

*Barem: 2p, 3p.*

### 2. $f(x) = x - 1$; calculați $f(0)\cdot f(2)$

$f(0) = -1$, $f(2) = 1$, deci $f(0)\cdot f(2) = -1$.

**Răspuns:** $-1$. *Barem: 2p, 2p, 1p.*

### 3. Ecuația $5^{x-2} = 25$

$25 = 5^2$, deci $x - 2 = 2 \iff x = 4$.

**Răspuns:** $x = 4$. *Barem: 2p, 3p.*

### 4. Un obiect costă 100 lei; prețul după o scumpire cu $10\%$

Scumpirea: $\frac{10}{100}\cdot 100 = 10$ lei; prețul nou: $110$ lei.

**Răspuns:** $110$ lei. *Barem: 2p, 3p.*

### 5. Distanța de la $A(1, 1)$ la $B(1, 3)$

$$AB = \sqrt{(1-1)^2 + (3-1)^2} = \sqrt4 = 2.$$

**Răspuns:** $2$. *Barem: 3p, 2p.*

### 6. $\cos 45^\circ + \cos 135^\circ$

$\cos 45^\circ = \dfrac{\sqrt2}{2}$, $\cos 135^\circ = -\cos 45^\circ = -\dfrac{\sqrt2}{2}$, deci suma este $0$.

**Răspuns:** $0$. *Barem: 2p, 2p, 1p.*

## Subiectul al II-lea (30 de puncte)

### 1. $M(a) = \begin{pmatrix} 2a & 0\\ 0 & 2a\end{pmatrix}$

#### a) $M\left(\frac12\right) + M\left(-\frac12\right) = M(0)$

$$M\left(\tfrac12\right) = \begin{pmatrix} 1 & 0\\ 0 & 1\end{pmatrix}, \quad M\left(-\tfrac12\right) = \begin{pmatrix} -1 & 0\\ 0 & -1\end{pmatrix},$$

iar suma lor este $\begin{pmatrix} 0 & 0\\ 0 & 0\end{pmatrix} = M(0)$. *Barem: 2p, 2p, 1p.*

#### b) $a$ cu $\det(M(a)) = 0$

$$\det M(a) = 2a\cdot 2a - 0 = 4a^2 = 0 \iff a = 0.$$

**Răspuns:** $a = 0$. *Barem: 3p, 2p.*

#### c) $M(-2) + M(-1) + M(0) + M(1) + M(2)$

$M(-a) + M(a) = O_2$ și $M(0) = O_2$, deci

$$\big(M(-2) + M(2)\big) + \big(M(-1) + M(1)\big) + M(0) = O_2 = \begin{pmatrix} 0 & 0\\ 0 & 0\end{pmatrix}.$$

*Barem: 2p, 3p.*

### 2. $f = X^3 - 2X^2 + 1$

#### a) $f(1) = 0$

$$f(1) = 1 - 2 + 1 = 0.$$

*Barem: 3p, 2p.*

#### b) Câtul și restul împărțirii la $g = X^2 - 2X + 1$

$X^3 : X^2 = X$; $X\cdot g = X^3 - 2X^2 + X$; restul: $X^3 - 2X^2 + 1 - (X^3 - 2X^2 + X) = -X + 1$ (grad mai mic decât 2, ne oprim).

**Răspuns:** câtul $X$, restul $-X + 1$. *Barem: 2p, 3p.*

#### c) $x_1^2 + x_2^2 + x_3^2$

Viète: $x_1 + x_2 + x_3 = 2$, $x_1x_2 + x_2x_3 + x_3x_1 = 0$.

$$x_1^2 + x_2^2 + x_3^2 = 2^2 - 2\cdot 0 = 4.$$

**Răspuns:** $4$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:[0, +\infty) \to \mathbb R$, $f(x) = \sqrt x - 1$

#### a) $2\sqrt x f'(x) = 1$

$$f'(x) = \frac{1}{2\sqrt x}, \qquad 2\sqrt x\cdot\frac{1}{2\sqrt x} = 1, \quad x > 0.$$

*Barem: 3p, 2p.*

#### b) $y = \frac14x$ este tangenta în punctul de abscisă $x_0 = 4$

$f(4) = 2 - 1 = 1$, $f'(4) = \dfrac14$. Tangenta:

$$y - 1 = \frac14(x - 4) \iff y = \frac14x.$$

*Barem: 2p, 3p.*

#### c) $f$ este concavă pe $(0, +\infty)$

$$f''(x) = \left(\frac12x^{-1/2}\right)' = -\frac14x^{-3/2} = -\frac{1}{4x\sqrt x} < 0,$$

pentru orice $x > 0$, deci $f$ este concavă. *Barem: 3p, 2p.*

### 2. $f:(0, +\infty) \to \mathbb R$, $f(x) = 2x + 1 + \frac1x$

#### a) $\displaystyle\int_1^2\left(f(x) - \frac1x\right)dx$

$$\int_1^2(2x + 1)\,dx = (x^2 + x)\Big|_1^2 = 6 - 2 = 4.$$

**Răspuns:** $4$. *Barem: 2p, 3p.*

#### b) $F(x) = x^2 + x + \ln x$ este o primitivă a lui $f$

$$F'(x) = 2x + 1 + \frac1x = f(x), \quad x > 0.$$

*Barem: 3p, 2p.*

#### c) Aria suprafeței delimitate de $G_f$, $Ox$, $x = 1$, $x = 2$

$f > 0$ pe $[1, 2]$, deci

$$\mathcal A = \int_1^2 f(x)\,dx = F(2) - F(1) = (4 + 2 + \ln 2) - (1 + 1 + 0) = 4 + \ln 2.$$

**Răspuns:** $4 + \ln 2$. *Barem: 2p, 3p.*

## Ce merită reținut din varianta 2

- **$\cos(180^\circ - x) = -\cos x$**: suma $\cos x + \cos(180^\circ - x)$ este mereu $0$.
- **Restul împărțirii la un polinom de grad 2** are grad cel mult 1.
- **Concavitate**: $f'' < 0$ pe interval; pentru $\sqrt x$, $f''(x) = -\frac{1}{4x\sqrt x}$.
- **Aria cu o primitivă dată**: $\mathcal A = F(b) - F(a)$ când $f \ge 0$.
