## Subiectul I (30 de puncte)

### 1. $(2 + \sqrt3)^2 + (1 - 2\sqrt3)^2 = 20$

$$(2 + \sqrt3)^2 = 4 + 4\sqrt3 + 3 = 7 + 4\sqrt3, \qquad (1 - 2\sqrt3)^2 = 1 - 4\sqrt3 + 12 = 13 - 4\sqrt3.$$

Suma: $7 + 13 = 20$. *Barem: 2p, 3p.*

### 2. $f(x) = x^2 - 3x$; $f(1)\cdot f(2)\cdot f(3)\cdot f(4)$

$f(3) = 9 - 9 = 0$, deci produsul este $0$.

**Răspuns:** $0$. *Barem: 3p $f(3) = 0$, 2p concluzia.*

### 3. $8^x = 4^{2x+1}$

$2^{3x} = 2^{4x + 2} \iff 3x = 4x + 2 \iff x = -2$.

**Răspuns:** $x = -2$. *Barem: 3p, 2p.*

### 4. După o scumpire cu $25\%$, prețul este 250 lei; prețul inițial

$$p + \frac{25}{100}p = 250 \iff \frac54p = 250 \iff p = 200.$$

**Răspuns:** 200 de lei. *Barem: 2p, 3p.*

### 5. $A(1,5)$, $B(1,1)$, $C(5,5)$: triunghiul $ABC$ este isoscel

$AB = \sqrt{0 + 16} = 4$, $AC = \sqrt{16 + 0} = 4$, deci $AB = AC$ și triunghiul este isoscel. *Barem: 2p, 3p.*

### 6. $\sin 60^\circ + \operatorname{tg} 45^\circ = \cos 30^\circ + \operatorname{ctg} 45^\circ$

$\sin 60^\circ = \cos 30^\circ = \dfrac{\sqrt3}{2}$ și $\operatorname{tg}45^\circ = \operatorname{ctg}45^\circ = 1$; ambii membri valorează $\dfrac{\sqrt3}{2} + 1$. *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(x) = \begin{pmatrix} x & 2\\ x & x\end{pmatrix}$

#### a) $\det(A(3)) = 3$

$3\cdot 3 - 3\cdot 2 = 9 - 6 = 3$. *Barem: 3p, 2p.*

#### b) $A(2017 + x) + A(2017 - x) = 2A(2017)$

$$\begin{pmatrix} 2017 + x & 2\\ 2017 + x & 2017 + x\end{pmatrix} + \begin{pmatrix} 2017 - x & 2\\ 2017 - x & 2017 - x\end{pmatrix} = \begin{pmatrix} 4034 & 4\\ 4034 & 4034\end{pmatrix} = 2A(2017).$$

*Barem: 3p, 2p.*

#### c) $\det(A(2) + mA(1)) = 0$

$$A(2) + mA(1) = \begin{pmatrix} 2 + m & 2 + 2m\\ 2 + m & 2 + m\end{pmatrix},$$

$$\det = (2 + m)^2 - (2 + m)(2 + 2m) = (2 + m)(2 + m - 2 - 2m) = -m(m + 2).$$

$-m(m + 2) = 0 \iff m \in \{-2, 0\}$.

**Răspuns:** $m \in \{-2, 0\}$. *Barem: 3p, 2p.*

### 2. Legea $x * y = 2xy + 6x + 6y + 15$

#### a) $x * y = 2(x + 3)(y + 3) - 3$

$$2(x+3)(y+3) - 3 = 2xy + 6x + 6y + 18 - 3 = 2xy + 6x + 6y + 15.$$

*Barem: 2p, 3p.*

#### b) $7 * 98 = 2017$

$2\cdot 10\cdot 101 - 3 = 2020 - 3 = 2017$. *Barem: 3p, 2p.*

#### c) $x * (x + 2) = 3$

$$2(x + 3)(x + 5) - 3 = 3 \iff (x + 3)(x + 5) = 3 \iff x^2 + 8x + 12 = 0 \iff (x + 6)(x + 2) = 0.$$

**Răspuns:** $x \in \{-6, -2\}$. *Barem: 3p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(2, +\infty) \to \mathbb R$, $f(x) = x + 1 + \dfrac{1}{x - 2}$

#### a) $\lim\limits_{x\to3}\dfrac{f(x) - f(3)}{x - 3} = 0$

Limita este $f'(3)$. $f'(x) = 1 - \dfrac{1}{(x - 2)^2}$, deci $f'(3) = 1 - 1 = 0$. *Barem: 2p, 3p.*

#### b) Asimptota oblică spre $+\infty$

$$m = \lim_{x\to+\infty}\frac{f(x)}{x} = \lim_{x\to+\infty}\left(1 + \frac1x + \frac{1}{x(x-2)}\right) = 1,$$

$$n = \lim_{x\to+\infty}(f(x) - x) = \lim_{x\to+\infty}\left(1 + \frac{1}{x - 2}\right) = 1.$$

**Răspuns:** $y = x + 1$. *Barem: 2p $m$, 3p $n$ și concluzia.*

#### c) $f$ convexă pe $(2, +\infty)$

$f''(x) = \dfrac{2}{(x - 2)^3} > 0$ pentru $x > 2$, deci $f$ este convexă. *Barem: 3p, 2p.*

### 2. $f(x) = 1 + \ln x$, $F(x) = x\ln x$, pe $(0, +\infty)$

#### a) $\displaystyle\int_1^e(f(x) - \ln x)\,dx$

$$\int_1^e 1\,dx = x\Big|_1^e = e - 1.$$

**Răspuns:** $e - 1$. *Barem: 3p, 2p.*

#### b) $F$ este primitivă a lui $f$

$F'(x) = \ln x + x\cdot\dfrac1x = \ln x + 1 = f(x)$. *Barem: 3p, 2p.*

#### c) $\displaystyle\int_1^e f(x)F(x)\,dx = \frac{e^2}{2}$

Cum $f = F'$, $\displaystyle\int F'F\,dx = \frac{F^2}{2}$:

$$\frac{F^2(x)}{2}\Big|_1^e = \frac{(e\ln e)^2 - (1\cdot\ln 1)^2}{2} = \frac{e^2}{2}.$$

*Barem: 3p, 2p.*

## Ce merită reținut din simulare

- **Un factor nul anulează produsul**: caută întâi un $f(k) = 0$.
- **Asimptota oblică**: $m = \lim\frac{f(x)}{x}$, $n = \lim(f(x) - mx)$.
- **$\int F'F = \frac{F^2}{2}$** — recunoaște derivata în integrand.
