## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{81} - \sqrt{18} + \sqrt{50} - \sqrt8 = 9$

$$9 - 3\sqrt2 + 5\sqrt2 - 2\sqrt2 = 9.$$

*Barem: 3p scoaterea factorilor, 2p calculul.*

### 2. $f(x) = x - m$; $m$ cu $f(2) = 0$

$f(2) = 2 - m = 0 \iff m = 2$. *Barem: 2p, 3p.*

### 3. Ecuația $\sqrt{x^2 + 1} = 1$

$x^2 + 1 = 1 \iff x = 0$, care verifică ecuația.

**Răspuns:** $x = 0$. *Barem: 2p, 3p.*

### 4. Profitul anual, știind că $5\%$ din el înseamnă $2000$ lei

$$\frac{5}{100}x = 2000 \iff \frac{x}{20} = 2000 \iff x = 40\,000.$$

**Răspuns:** $40\,000$ de lei. *Barem: 3p ecuația, 2p soluția.*

### 5. Dreapta prin $M(1,-1)$, paralelă cu $y = x - 1$

Panta este $1$: $y + 1 = x - 1 \iff y = x - 2$.

**Răspuns:** $y = x - 2$. *Barem: 3p panta, 2p ecuația.*

### 6. Arătați că $\sin30^\circ + \sqrt3\cos30^\circ = 2$

$$\frac12 + \sqrt3\cdot\frac{\sqrt3}{2} = \frac12 + \frac32 = 2.$$

*Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = x + y - 2$.

### 1. $(-2) * 2$

$$-2 + 2 - 2 = -2.$$

*Barem: 3p, 2p.*

### 2. Legea este asociativă

$$(x * y) * z = x + y + z - 4 = x * (y * z).$$

*Barem: 2p, 3p.*

### 3. $e = 2$ este element neutru

$x * 2 = x + 2 - 2 = x$ și $2 * x = x$. **Răspuns:** da. *Barem: 3p, 2p.*

### 4. $(x + 1) * x = 3$

$$x + 1 + x - 2 = 3 \iff 2x = 4 \iff x = 2.$$

*Barem: 3p, 2p.*

### 5. Ecuația $9^x * 3^x = 0$

$$9^x + 3^x - 2 = 0 \iff (3^x + 2)(3^x - 1) = 0.$$

$3^x > 0$, deci $3^x = 1$ și $x = 0$. **Răspuns:** $x = 0$. *Barem: 3p, 2p.*

### 6. $x^2 * \dfrac{1}{x^2} \ge 0$ pentru $x \ne 0$

$$x^2 + \frac1{x^2} - 2 = \frac{x^4 - 2x^2 + 1}{x^2} = \frac{(x^2 - 1)^2}{x^2} \ge 0. \ \blacksquare$$

*Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$A(a) = \begin{pmatrix}a & 1\\-1 & a\end{pmatrix}$.

### 1. $\det(A(0))$

$$\det\begin{pmatrix}0&1\\-1&0\end{pmatrix} = 0 + 1 = 1.$$

*Barem: 3p, 2p.*

### 2. $4A(1) - 3A(-1) = A(7)$

$$4\begin{pmatrix}1&1\\-1&1\end{pmatrix} - 3\begin{pmatrix}-1&1\\-1&-1\end{pmatrix} = \begin{pmatrix}7&1\\-1&7\end{pmatrix} = A(7).$$

*Barem: 3p, 2p.*

### 3. $a$ cu $\det(A(a)) = 10$

$$\det A(a) = a^2 + 1 = 10 \iff a = \pm3.$$

**Răspuns:** $a \in \{-3, 3\}$. *Barem: 2p, 3p.*

### 4. $\det(A(a) - I_2) > 0$ pentru orice $a$

$$\det\begin{pmatrix}a - 1 & 1\\-1 & a - 1\end{pmatrix} = (a-1)^2 + 1 > 0. \ \blacksquare$$

*Barem: 3p, 2p.*

### 5. Inversa matricei $A(2)$

$\det A(2) = 5$:

$$A^{-1}(2) = \frac15\begin{pmatrix}2 & -1\\1 & 2\end{pmatrix} = \begin{pmatrix}\frac25 & -\frac15\\\frac15 & \frac25\end{pmatrix}.$$

*Barem: 2p, 3p.*

### 6. Numărul matricelor $A(a)$, $a \in \mathbb Z$, cu $\det(A(a)) \le 401$

$$a^2 + 1 \le 401 \iff a^2 \le 400 \iff -20 \le a \le 20.$$

Sunt $41$ de valori întregi.

**Răspuns:** $41$. *Barem: 2p, 3p.*

## Ce merită reținut din model

- **Procente**: $p\%$ din $x$ înseamnă $\frac{p}{100}x$.
- **Legea $x + y - 2$**: neutrul este $2$.
- **$a + \frac1a - 2 = \frac{(a-1)^2}{a}$** — inegalitate clasică.
- **Matricele $\begin{pmatrix}a&1\\-1&a\end{pmatrix}$** au determinantul $a^2 + 1 > 0$, deci sunt mereu inversabile.
