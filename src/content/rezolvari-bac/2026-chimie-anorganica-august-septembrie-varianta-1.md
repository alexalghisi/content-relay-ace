### Subiectul E (15 puncte)

**1.** Reacția degajă 882,6 kJ, deci $\Delta_r H^0 = -882{,}6\ \text{kJ}$:

$$-882{,}6 = 2(-350{,}5) + 2(-296{,}8) - 2\Delta_f H^0_\text{ZnS} = -1294{,}6 - 2\Delta_f H^0_\text{ZnS}$$

$$\Delta_f H^0_\text{ZnS} = \frac{-1294{,}6 + 882{,}6}{2} = \mathbf{-206\ kJ/mol}$$

**2.** $n_\text{ZnO} = 8{,}1 : 81 = 0{,}1\ \text{mol}$; la formarea a 2 mol de ZnO se degajă 882,6 kJ, deci

$$Q = \frac{0{,}1 \cdot 882{,}6}{2} = \mathbf{44{,}13\ kJ}$$

*Barem: 2p. + 1p.*

**3.** $\Delta T = 68 - 18 = 50\ \text{K}$; $m = \dfrac{Q}{c\,\Delta T} = \dfrac{1045}{4{,}18 \cdot 50} = \mathbf{5\ kg}$. *(2p. + 1p.)*

**4. Legea lui Hess.** Reacția cerută este C(grafit) + H₂ + N₂ → CH₂N₂(s).

- păstrăm (3): C + O₂ → CO₂, cu $+\Delta_r H_3^0$
- păstrăm (1): H₂ + ½ O₂ → H₂O, cu $+\Delta_r H_1^0$
- inversăm (2): CO₂ + H₂O + N₂ → CH₂N₂ + 3/2 O₂, cu $-\Delta_r H_2^0$

Prin adunare se simplifică O₂, CO₂ și H₂O:

$$\Delta_r H^0 = \Delta_r H_1^0 - \Delta_r H_2^0 + \Delta_r H_3^0$$

*Barem: 4p.*

**5.** Stabilitatea crește cu scăderea entalpiei de formare: +91,5 > +45,2 > −21 kJ/mol, deci ordinea este **C₃H₅I, C₃H₅Br, C₃H₅Cl**. *2p.*
