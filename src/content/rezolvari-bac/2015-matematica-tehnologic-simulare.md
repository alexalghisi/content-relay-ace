> **Cum să folosești rezolvarea:** lucrează întâi singur subiectul (deschide PDF-ul de mai sus), apoi compară fiecare pas. Dacă ai ajuns la alt drum corect, primești tot punctajul — baremul acceptă orice soluție corectă.

## Subiectul I (30 de puncte)

### 1. Suma primilor trei termeni, $a_1 = 1$, $a_3 = 5$

$a_2 = \frac{a_1 + a_3}{2} = 3$, deci $a_1 + a_2 + a_3 = 1 + 3 + 5 = 9$. *Barem: 3p + 2p.*

### 2. Abscisele punctelor de intersecție ale graficelor lui $f(x) = x^2 - x$ și $g(x) = 2x - 2$

$$x^2 - x = 2x - 2 \iff x^2 - 3x + 2 = 0 \iff (x-1)(x-2) = 0.$$

**Răspuns:** $x_1 = 1$, $x_2 = 2$. *Barem: 3p + 2p.*

### 3. Ecuația $3^{2-x} = \frac19$

$3^{2-x} = 3^{-2} \iff 2 - x = -2 \iff x = 4$. *Barem: 3p + 2p.*

### 4. După o ieftinire cu 15%, prețul este 34 lei

$p - 0{,}15p = 0{,}85p = 34 \iff p = 40$.

**Răspuns:** 40 de lei. *Barem: 2p + 3p.*

### 5. Mediana din $A(1,4)$ în triunghiul cu $B(-3,2)$, $C(5,2)$

Mijlocul lui $BC$: $M(1, 2)$. $AM = \sqrt{0^2 + 2^2} = 2$.

**Răspuns:** $2$. *Barem: 2p + 3p.*

### 6. $\operatorname{tg}30^\circ\operatorname{ctg}60^\circ + \operatorname{tg}60^\circ\operatorname{ctg}30^\circ = \frac{10}{3}$

$$\frac{1}{\sqrt3}\cdot\frac{1}{\sqrt3} + \sqrt3\cdot\sqrt3 = \frac13 + 3 = \frac{10}{3}.$$

*Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 3 & 6\\ 1 & 2\end{pmatrix}$

#### a) $\det A$

$$\det A = 6 - 6 = 0.$$

*Barem: 3p + 2p.*

#### b) $x$ cu $A\cdot A = xA$

$$A\cdot A = \begin{pmatrix} 9 + 6 & 18 + 12\\ 3 + 2 & 6 + 4\end{pmatrix} = \begin{pmatrix} 15 & 30\\ 5 & 10\end{pmatrix} = 5A.$$

**Răspuns:** $x = 5$. *Barem: 3p + 2p.*

#### c) $a$ cu $\det(A + aI_2) = 0$

$$\det\begin{pmatrix} 3 + a & 6\\ 1 & 2 + a\end{pmatrix} = (3 + a)(2 + a) - 6 = a^2 + 5a = a(a + 5).$$

**Răspuns:** $a \in \{-5, 0\}$. *Barem: 3p + 2p.*

### 2. Legea asociativă $x * y = xy + 2x + 2y + 2$

#### a) $x * y = (x+2)(y+2) - 2$

$$xy + 2x + 2y + 4 - 2 = x(y+2) + 2(y+2) - 2 = (x+2)(y+2) - 2.$$

*Barem: 2p + 3p.*

#### b) $(-2015) * (-2) * 0 * 2 * 2015$

$-2$ este element absorbant: $x * (-2) = (x+2)\cdot0 - 2 = -2$ și $(-2) * y = -2$. Atunci

$$\big((-2015) * (-2)\big) * (0 * 2 * 2015) = (-2) * (\dots) = -2.$$

**Răspuns:** $-2$. *Barem: 3p + 2p.*

#### c) $n$ natural cu $n * (-n)$ natural

$$n * (-n) = (n + 2)(2 - n) - 2 = 4 - n^2 - 2 = 2 - n^2.$$

$2 - n^2 \ge 0$ cu $n$ natural: $n \in \{0, 1\}$ (dau $2$, respectiv $1$).

**Răspuns:** $n \in \{0, 1\}$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(-2,+\infty)\to\mathbb R$, $f(x) = \dfrac{x - 2}{x + 2}$

#### a) $f'(x)$

$$f'(x) = \frac{(x + 2) - (x - 2)}{(x+2)^2} = \frac{4}{(x+2)^2}.$$

*Barem: 3p + 2p.*

#### b) Tangenta în $x = 0$

$f(0) = -1$, $f'(0) = 1$, deci $y = x - 1$. *Barem: 3p + 2p.*

#### c) Asimptota orizontală spre $+\infty$

$\lim\limits_{x\to+\infty}\dfrac{x - 2}{x + 2} = 1$. **Răspuns:** $y = 1$. *Barem: 3p + 2p.*

### 2. $f(x) = 2x - 1$, $F(x) = x^2 - x + 1$

#### a) $\displaystyle\int_0^1(f(x) + 1)\,dx$

$$\int_0^1 2x\,dx = x^2\Big|_0^1 = 1.$$

*Barem: 2p + 3p.*

#### b) $F$ este primitivă a lui $f$

$F'(x) = 2x - 1 = f(x)$. *Barem: 3p + 2p.*

#### c) $n \in \mathbb N^*$ cu $\displaystyle\int_0^n F(x)\,dx = \frac{n^3}{3}$

$$\int_0^n(x^2 - x + 1)\,dx = \frac{n^3}{3} - \frac{n^2}{2} + n.$$

$\dfrac{n^3}{3} - \dfrac{n^2}{2} + n = \dfrac{n^3}{3} \iff n - \dfrac{n^2}{2} = 0 \iff n(2 - n) = 0$; cu $n$ nenul: $n = 2$.

**Răspuns:** $n = 2$. *Barem: 2p + 3p.*

## Ce merită reținut din simularea 2015

- **Legea $(x+a)(y+a) - a$**: $-a$ este element absorbant.
- **O matrice $2\times2$ cu $\det = 0$** verifică $A^2 = (\operatorname{tr}A)\cdot A$ (aici $\operatorname{tr}A = 5$).
- **Ieftinire cu $p\%$**: prețul vechi $= \frac{\text{prețul nou}}{1 - p/100}$.
- **$\operatorname{tg}$ și $\operatorname{ctg}$** ale unghiurilor complementare sunt egale: $\operatorname{tg}30^\circ = \operatorname{ctg}60^\circ$.
