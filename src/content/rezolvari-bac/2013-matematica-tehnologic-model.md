## Subiectul I (30 de puncte)

### 1. Ecuația $(3x + 2)^2 = 4$

$$9x^2 + 12x + 4 = 4 \iff 9x^2 + 12x = 0 \iff 3x(3x + 4) = 0 \iff x \in \left\{0, -\frac43\right\}.$$

(Sau: $3x + 2 = \pm 2$.) **Răspuns:** $x \in \left\{-\dfrac43, 0\right\}$. *Barem: 3p, 2p.*

### 2. $m$ pentru care vârful parabolei lui $f(x) = -x^2 + 3mx + 1$ are abscisa $\frac32$

$$x_V = -\frac{b}{2a} = -\frac{3m}{-2} = \frac{3m}{2} = \frac32 \iff m = 1.$$

**Răspuns:** $m = 1$. *Barem: 2p, 2p, 1p.*

### 3. Ecuația $3^{2x} = 9$

$9 = 3^2$, deci $2x = 2 \iff x = 1$.

**Răspuns:** $x = 1$. *Barem: 2p, 3p.*

### 4. $5C_4^2 - A_5^2$

$$C_4^2 = \frac{4\cdot 3}{2} = 6, \qquad A_5^2 = 5\cdot 4 = 20, \qquad 5\cdot 6 - 20 = 10.$$

**Răspuns:** $10$. *Barem: 2p, 2p, 1p.*

### 5. $A(-6, 3)$, $B(2, 5)$; coordonatele mijlocului segmentului $(AB)$

$$x_C = \frac{-6 + 2}{2} = -2, \qquad y_C = \frac{3 + 5}{2} = 4.$$

**Răspuns:** $C(-2, 4)$. *Barem: 1p, 2p, 2p.*

### 6. Diagonala $BD$ a rombului $ABCD$ cu $AB = 4$ și $m(\angle ABC) = 120^\circ$

Unghiurile alăturate ale rombului sunt suplementare: $m(\angle BAD) = 180^\circ - 120^\circ = 60^\circ$. Triunghiul $ABD$ are $AB = AD = 4$ și unghiul dintre ele de $60^\circ$, deci este echilateral: $BD = 4$.

**Răspuns:** $BD = 4$. *Barem: 2p, 1p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(x) = \begin{pmatrix} -1 & 2 & x\\ 2 & -1 & x\\ x & x & 2\end{pmatrix}$, $\Delta(x) = \det A(x)$

#### a) $\Delta(1)$

$$\Delta(1) = \begin{vmatrix} -1 & 2 & 1\\ 2 & -1 & 1\\ 1 & 1 & 2\end{vmatrix} = 2 + 2 + 2 - (-1) - (-1) - 8 = 0.$$

**Răspuns:** $\Delta(1) = 0$. *Barem: 2p, 3p.*

#### b) $\Delta(x) = 6(x^2 - 1)$

Regula lui Sarrus:

$$\Delta(x) = 2 + 2x^2 + 2x^2 - \left(-x^2 - x^2 + 8\right) = 6x^2 - 6 = 6(x^2 - 1).$$

*Barem: 3p, 2p.*

#### c) Inversa matricei $A(0)$

$A(0) = \begin{pmatrix} -1 & 2 & 0\\ 2 & -1 & 0\\ 0 & 0 & 2\end{pmatrix}$, $\Delta(0) = -6 \ne 0$. Calculând complemenții algebrici (adjuncta este $A^* = \begin{pmatrix} -2 & -4 & 0\\ -4 & -2 & 0\\ 0 & 0 & -3\end{pmatrix}$):

$$(A(0))^{-1} = \frac{1}{-6}A^* = \frac16\begin{pmatrix} 2 & 4 & 0\\ 4 & 2 & 0\\ 0 & 0 & 3\end{pmatrix}.$$

Verificare (prima linie a produsului $A(0)\cdot A(0)^{-1}$): $\frac16(-2 + 8,\ -4 + 4,\ 0) = (1, 0, 0)$ ✔. *Barem: 2p, 3p.*

### 2. $f = X^3 - X^2 + aX + b$

#### a) $a + b$, știind că $f(1) = 0$

$f(1) = 1 - 1 + a + b = a + b = 0$.

**Răspuns:** $a + b = 0$. *Barem: 3p, 2p.*

#### b) Pentru $a = -1$, $b = 1$: rădăcinile lui $f$

$$f = X^3 - X^2 - X + 1 = X^2(X - 1) - (X - 1) = (X - 1)(X^2 - 1) = (X - 1)^2(X + 1).$$

**Răspuns:** $x_1 = x_2 = 1$, $x_3 = -1$. *Barem: 3p, 2p.*

#### c) $a, b$ știind că $x_1 = 1$ și $x_2 = 2$ sunt rădăcini

$f(1) = 0 \Rightarrow a + b = 0$; $f(2) = 8 - 4 + 2a + b = 0 \Rightarrow 2a + b = -4$. Scăzând: $a = -4$, deci $b = 4$.

**Răspuns:** $a = -4$, $b = 4$. *Barem: 1p, 2p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0, +\infty) \to \mathbb R$, $f(x) = x\ln x$

#### a) $f'(x) = 1 + \ln x$

$$f'(x) = 1\cdot\ln x + x\cdot\frac1x = \ln x + 1.$$

*Barem: 3p, 2p.*

#### b) $f$ este crescătoare pe $\left[\frac1e, +\infty\right)$

$f'(x) = 0 \iff \ln x = -1 \iff x = \frac1e$. Pentru $x \ge \frac1e$, $\ln x \ge -1$, deci $f'(x) \ge 0$ și $f$ este crescătoare. *Barem: 2p, 3p.*

#### c) $f(x) \ge -\frac1e$ pentru orice $x > 0$

Pe $\left(0, \frac1e\right]$, $f' \le 0$ ($f$ descrescătoare), iar pe $\left[\frac1e, +\infty\right)$ $f$ este crescătoare. Deci $x = \frac1e$ este punct de minim global:

$$f(x) \ge f\left(\frac1e\right) = \frac1e\ln\frac1e = -\frac1e. \ \blacksquare$$

*Barem: 3p, 2p.*

### 2. $f:(0, +\infty) \to \mathbb R$, $f(x) = 1 + \frac1x + \frac{1}{x^2}$

#### a) $F(x) = x - \frac1x + \ln x$ este o primitivă a lui $f$

$$F'(x) = 1 + \frac{1}{x^2} + \frac1x = f(x).$$

*Barem: 3p, 2p.*

#### b) $\displaystyle\int_1^e x\cdot f(x^2)\,dx$

Substituția $t = x^2$, $dt = 2x\,dx$; pentru $x = 1$, $t = 1$, iar pentru $x = e$, $t = e^2$:

$$\int_1^e x f(x^2)\,dx = \frac12\int_1^{e^2} f(t)\,dt = \frac12\big(F(e^2) - F(1)\big) = \frac12\left(e^2 - \frac{1}{e^2} + 2 - 0\right).$$

**Răspuns:** $\dfrac12\left(e^2 - \dfrac{1}{e^2} + 2\right)$. *Barem: 3p, 2p.*

#### c) $a > 1$ cu $\displaystyle\int_1^a\left(f(x) - \frac1x\right)dx = \frac32$

$$\int_1^a\left(1 + \frac{1}{x^2}\right)dx = \left(x - \frac1x\right)\Big|_1^a = a - \frac1a.$$

$$a - \frac1a = \frac32 \iff 2a^2 - 3a - 2 = 0 \iff (a - 2)(2a + 1) = 0.$$

Cum $a > 1$, $a = 2$.

**Răspuns:** $a = 2$. *Barem: 2p, 2p, 1p.*

## Ce merită reținut din model

- **Romb cu un unghi de $60^\circ$**: diagonala mică este egală cu latura.
- **Gruparea termenilor** ($X^2(X-1) - (X-1)$) este cea mai rapidă factorizare pentru polinoame de grad 3.
- **Minimul lui $x\ln x$** este $-\frac1e$, atins în $x = \frac1e$ — rezultat clasic.
- **Substituția $t = x^2$** transformă $\int x f(x^2)dx$ în $\frac12\int f(t)dt$.
