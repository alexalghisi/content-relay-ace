Pentru fiecare cerință găsești enunțul pe scurt, rezolvarea pas cu pas, răspunsul final și cum se punctează conform baremului oficial. Timp de lucru la examen: 3 ore; se acordă 10 puncte din oficiu.

> **Cum să folosești rezolvarea:** lucrează întâi singur subiectul (deschide PDF-ul de mai sus), apoi compară fiecare pas. Dacă ai ajuns la alt drum corect, primești tot punctajul — baremul acceptă orice soluție corectă.

## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_1 = 5$, $r = 2$: suma primilor 5 termeni

$$S_5 = \frac{(2a_1 + 4r)\cdot 5}{2} = \frac{(10 + 8)\cdot 5}{2} = 45.$$

**Răspuns:** $S_5 = 45$. *Barem: 3p, 2p.*

### 2. $m$ pentru care $x^2 - (m+1)x + m = 0$ are soluții reale egale

$$\Delta = (m + 1)^2 - 4m = m^2 - 2m + 1 = (m - 1)^2 = 0 \iff m = 1.$$

**Răspuns:** $m = 1$. *Barem: 1p, 2p, 2p.*

### 3. Intersecțiile graficului lui $f(x) = 2^{x+1} - 1$ cu axele

- cu $Ox$: $2^{x+1} = 1 = 2^0 \Rightarrow x = -1$, punctul $A(-1, 0)$;
- cu $Oy$: $f(0) = 2 - 1 = 1$, punctul $B(0, 1)$.

**Răspuns:** $A(-1, 0)$ și $B(0, 1)$. *Barem: 2p, 1p, 1p, 1p.*

### 4. $2C_4^2 - 3A_4^1$

$C_4^2 = 6$, $A_4^1 = 4$, deci $12 - 12 = 0$.

**Răspuns:** $0$. *Barem: 2p, 2p, 1p.*

### 5. $a > 0$ cu $\vec v_1 = 2\vec i + a\vec j$ și $\vec v_2 = (a + 3)\vec i + 2\vec j$ coliniari

$$\frac{2}{a + 3} = \frac{a}{2} \iff a^2 + 3a - 4 = 0 \iff (a - 1)(a + 4) = 0.$$

Cu $a > 0$: $a = 1$.

**Răspuns:** $a = 1$. *Barem: 2p, 2p, 1p.*

### 6. $\sin N$, aria triunghiului $MNP$ fiind $16$, $MN = NP = 8$

$$16 = \frac{MN\cdot NP\cdot\sin N}{2} = 32\sin N \Rightarrow \sin N = \frac12.$$

**Răspuns:** $\sin N = \dfrac12$. *Barem: 2p, 2p, 1p.*

## Subiectul al II-lea (30 de puncte)

### 1. Punctele $A_n(n - 1, n + 2)$, $n \in \mathbb N^*$

#### a) Ecuația dreptei $A_1A_2$

$A_1(0, 3)$, $A_2(1, 4)$: panta $1$, deci $y = x + 3$.

**Răspuns:** $y = x + 3$. *Barem: 2p, 2p, 1p.*

#### b) $A_m, A_n, A_p$ coliniare

Toate punctele verifică $y = x + 3$, căci $(n + 2) = (n - 1) + 3$. Echivalent,

$$\begin{vmatrix} m - 1 & m + 2 & 1\\ n - 1 & n + 2 & 1\\ p - 1 & p + 2 & 1\end{vmatrix} = 0$$

(scăzând prima coloană din a doua obținem coloana $(3, 3, 3)$, proporțională cu a treia). *Barem: 3p, 2p.*

#### c) $M_{2011} = \{n \in \mathbb N^* \mid A_nA_{2011} \le 2\}$

$$A_nA_{2011} = \sqrt{(n - 2011)^2 + (n - 2011)^2} = \sqrt2\,|n - 2011| \le 2 \iff |n - 2011| \le \sqrt2.$$

Pentru $n$ natural: $|n - 2011| \in \{0, 1\}$.

**Răspuns:** $M_{2011} = \{2010, 2011, 2012\}$. *Barem: 1p, 1p, 1p, 2p.*

### 2. $f = X^3 + (m - 3)X^2 - 17X + (2m + 7)$

#### a) Pentru $m = 4$: câtul și restul împărțirii la $X - 3$

$f = X^3 + X^2 - 17X + 15$. Horner cu $3$: $1,\ 3 + 1 = 4,\ 12 - 17 = -5,\ -15 + 15 = 0$.

**Răspuns:** câtul $X^2 + 4X - 5$, restul $0$. *Barem: 1p, 3p, 1p.*

#### b) $m$ cu $X - 1 \mid f$

$f(1) = 1 + m - 3 - 17 + 2m + 7 = 3m - 12 = 0 \iff m = 4$.

**Răspuns:** $m = 4$. *Barem: 2p, 1p, 2p.*

#### c) $27^x + 9^x - 17\cdot 3^x + 15 = 0$

Cu $y = 3^x > 0$: $y^3 + y^2 - 17y + 15 = 0$, adică polinomul de la a). Din a), $f = (X - 3)(X^2 + 4X - 5) = (X - 3)(X - 1)(X + 5)$, deci $y \in \{1, 3, -5\}$; $y = -5$ nu convine.

$3^x = 1 \Rightarrow x = 0$, $3^x = 3 \Rightarrow x = 1$.

**Răspuns:** $x \in \{0, 1\}$. *Barem: 2p, 1p, 1p, 1p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = \begin{cases}\dfrac{-4}{x^2 + 1}, & x \le 0\\ x - 4, & x > 0\end{cases}$

#### a) $f$ continuă în $x_0 = 0$

$\lim\limits_{x\nearrow0}\dfrac{-4}{x^2+1} = -4$, $\lim\limits_{x\searrow0}(x - 4) = -4$, $f(0) = -4$. Deci $f$ continuă în 0. *Barem: 3p, 2p.*

#### b) $\lim\limits_{x\to4}\dfrac{f(x)}{16 - x^2}$

Lângă 4, $f(x) = x - 4$:

$$\lim_{x\to4}\frac{x - 4}{(4 - x)(4 + x)} = \lim_{x\to4}\frac{-1}{4 + x} = -\frac18.$$

**Răspuns:** $-\dfrac18$. *Barem: 3p, 2p.*

#### c) Tangenta în $A(-1, -2)$

Pentru $x < 0$: $f'(x) = \dfrac{8x}{(x^2+1)^2}$, deci $f'(-1) = \dfrac{-8}{4} = -2$; $f(-1) = -2$.

$$y + 2 = -2(x + 1) \iff y = -2x - 4.$$

**Răspuns:** $y = -2x - 4$. *Barem: 2p, 2p, 1p.*

### 2. $f_m(x) = 3m^2x^2 + 6mx + 9$

#### a) Primitivele lui $f_0$

$f_0(x) = 9$, deci $\displaystyle\int 9\,dx = 9x + C$. *Barem: 2p, 3p.*

#### b) Aria pentru $f_1$ între $x = 0$ și $x = 1$

$f_1(x) = 3x^2 + 6x + 9 > 0$ pe $[0,1]$:

$$\mathcal A = \int_0^1(3x^2 + 6x + 9)\,dx = (x^3 + 3x^2 + 9x)\Big|_0^1 = 13.$$

**Răspuns:** $13$. *Barem: 2p, 2p, 1p.*

#### c) $\displaystyle\int_1^2\frac{f_2(x) - 9}{x}e^x\,dx$

$f_2(x) = 12x^2 + 12x + 9$, deci $\dfrac{f_2(x) - 9}{x} = 12x + 12$. Observăm $(12xe^x)' = 12e^x + 12xe^x$:

$$\int_1^2(12x + 12)e^x\,dx = 12xe^x\Big|_1^2 = 24e^2 - 12e.$$

**Răspuns:** $24e^2 - 12e$. *Barem: 3p, 2p.*

## Ce merită reținut din model

- **Soluții egale** $\iff \Delta = 0$.
- **Vectori coliniari**: coordonatele sunt proporționale.
- **Ecuații exponențiale**: substituția $y = 3^x$ duce la polinomul de la punctul anterior — refolosește factorizarea.
- **$\int(x + 1)e^x\,dx = xe^x + C$** — recunoaște derivata produsului.
