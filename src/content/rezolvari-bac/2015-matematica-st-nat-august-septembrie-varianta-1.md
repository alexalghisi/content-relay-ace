## Subiectul I (30 de puncte)

### 1. Al doilea termen al progresiei aritmetice cu $a_1 = 1$, $r = 2$

$$a_2 = a_1 + r = 1 + 2 = 3.$$

**Răspuns:** $a_2 = 3$. *Barem: 3p, 2p.*

### 2. $m$ știind că $A(m, 0)$ aparține graficului lui $f(x) = x + 1$

$f(m) = 0 \iff m + 1 = 0 \iff m = -1$.

**Răspuns:** $m = -1$. *Barem: 3p, 2p.*

### 3. Ecuația $\log_2(x^2 + 4) = \log_2 8$

$x^2 + 4 = 8 \iff x^2 = 4 \iff x = \pm 2$ (ambele verifică).

**Răspuns:** $x \in \{-2, 2\}$. *Barem: 2p, 3p.*

### 4. Probabilitatea ca un număr din $M = \{1, 2, \dots, 8\}$ să fie divizibil cu 3

Cazuri posibile: **8**. Divizibile cu 3: $3, 6$ — **2**.

$$p = \frac28 = \frac14.$$

*Barem: 1p, 2p, 2p.*

### 5. $a$ pentru care $\vec u = (a + 1)\vec i + 4\vec j$ și $\vec v = \vec i + 2\vec j$ sunt coliniari

$$\frac{a + 1}{1} = \frac42 \iff a + 1 = 2 \iff a = 1.$$

**Răspuns:** $a = 1$. *Barem: 3p, 2p.*

### 6. $\sin 2x = \frac{\sqrt3}{2}$, știind că $\sin x = \frac12$ și $x \in \left(0, \frac\pi2\right)$

Pe $\left(0, \frac\pi2\right)$, $\cos x > 0$: $\cos x = \sqrt{1 - \frac14} = \frac{\sqrt3}{2}$.

$$\sin 2x = 2\sin x\cos x = 2\cdot\frac12\cdot\frac{\sqrt3}{2} = \frac{\sqrt3}{2}.$$

*Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(a) = \begin{pmatrix} a & 3\\ a - 1 & 2\end{pmatrix}$

#### a) $A(2014) + A(2016) = 2A(2015)$

$$A(2014) + A(2016) = \begin{pmatrix} 2014 + 2016 & 6\\ 2013 + 2015 & 4\end{pmatrix} = \begin{pmatrix} 4030 & 6\\ 4028 & 4\end{pmatrix} = 2\begin{pmatrix} 2015 & 3\\ 2014 & 2\end{pmatrix} = 2A(2015).$$

*Barem: 3p, 2p.*

#### b) $a$ cu $\det(A(a)) = 0$

$$\det A(a) = 2a - 3(a - 1) = 3 - a = 0 \iff a = 3.$$

**Răspuns:** $a = 3$. *Barem: 3p, 2p.*

#### c) Ecuația $\det(A(2) + xA(3)) = 0$

$$A(2) + xA(3) = \begin{pmatrix} 2 + 3x & 3 + 3x\\ 1 + 2x & 2 + 2x\end{pmatrix}.$$

$$\det = (2 + 3x)(2 + 2x) - (3 + 3x)(1 + 2x) = (4 + 10x + 6x^2) - (3 + 9x + 6x^2) = x + 1.$$

$x + 1 = 0 \iff x = -1$.

**Răspuns:** $x = -1$. *Barem: 3p, 2p.*

### 2. $x * y = -xy - x - y - 2$

#### a) $(-1) * 1 = -1$

$$(-1) * 1 = 1 + 1 - 1 - 2 = -1.$$

*Barem: 3p, 2p.*

#### b) $x * y = -(x + 1)(y + 1) - 1$

$$-(x+1)(y+1) - 1 = -xy - x - y - 1 - 1 = -xy - x - y - 2 = x * y.$$

*Barem: 2p, 3p.*

#### c) Ecuația $(x + 2) * (2x - 3) = 5$

$$(x + 2) * (2x - 3) = -(x + 3)(2x - 2) - 1 = 5 \iff (x + 3)(2x - 2) = -6 \iff 2x^2 + 4x - 6 = -6 \iff 2x(x + 2) = 0.$$

**Răspuns:** $x \in \{-2, 0\}$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^4 - 8x^2 + 16$

#### a) $f'(x) = 4x(x - 2)(x + 2)$

$$f'(x) = 4x^3 - 16x = 4x(x^2 - 4) = 4x(x - 2)(x + 2).$$

*Barem: 3p, 2p.*

#### b) $\lim\limits_{x\to+\infty}\dfrac{f(x) - x^4}{x^2 + 1}$

$$\lim_{x\to+\infty}\frac{-8x^2 + 16}{x^2 + 1} = -8.$$

**Răspuns:** $-8$. *Barem: 2p, 3p.*

#### c) Punctele graficului în care tangenta este paralelă cu $Ox$

Tangentă orizontală $\iff f'(x) = 0 \iff x \in \{-2, 0, 2\}$. Ordonatele: $f(\pm 2) = 16 - 32 + 16 = 0$, $f(0) = 16$.

**Răspuns:** $(-2, 0)$, $(0, 16)$, $(2, 0)$. *Barem: 2p, 3p.*

### 2. $f:(0, +\infty) \to \mathbb R$, $f(x) = \dfrac{x + 2}{x}$

#### a) $\displaystyle\int_1^2 xf(x)\,dx = \frac72$

$$\int_1^2(x + 2)\,dx = \left(\frac{x^2}{2} + 2x\right)\Big|_1^2 = 6 - \frac52 = \frac72.$$

*Barem: 3p, 2p.*

#### b) $F(x) = x + 2\ln x + 2015$ este o primitivă a lui $f$

$$F'(x) = 1 + \frac2x = \frac{x + 2}{x} = f(x), \quad x > 0.$$

*Barem: 3p, 2p.*

#### c) Aria delimitată de graficul lui $g(x) = (f(x) - 1)\ln x$, $Ox$, $x = 1$, $x = e$ este 1

$g(x) = \frac2x\ln x \ge 0$ pe $[1, e]$, iar $\frac{2\ln x}{x} = 2\ln x\cdot(\ln x)'$:

$$\mathcal A = \int_1^e\frac{2\ln x}{x}\,dx = \ln^2 x\Big|_1^e = 1 - 0 = 1. \ \blacksquare$$

*Barem: 3p, 2p.*

## Ce merită reținut din varianta 1

- **Tangentă paralelă cu $Ox$** $\iff$ derivata se anulează.
- **Legea $-(x+1)(y+1) - 1$**: forma factorizată transformă ecuațiile în ecuații algebrice simple.
- **$\int\frac{\ln x}{x}dx = \frac{\ln^2 x}{2}$** — tipul $u\cdot u'$.
