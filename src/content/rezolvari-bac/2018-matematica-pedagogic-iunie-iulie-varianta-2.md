## Subiectul I (30 de puncte)

### 1. Arătați că $2\left(0{,}1(6) + \dfrac13\right) = 1$

Transformăm fracția periodică mixtă: $0{,}1(6) = \dfrac{16 - 1}{90} = \dfrac{15}{90} = \dfrac16$.

$$2\left(\frac16 + \frac13\right) = 2\cdot\frac{1 + 2}{6} = 2\cdot\frac12 = 1.$$

*Barem: 3p $0{,}1(6) = \frac16$, 2p finalizarea.*

### 2. $f(x) = 2x - 2$; determinați $a$ cu $f(a) = a$

$$f(a) = a \iff 2a - 2 = a \iff a = 2.$$

**Răspuns:** $a = 2$. *Barem: 2p $f(a) = 2a-2$, 3p valoarea lui $a$.*

### 3. Ecuația $5^{x^2+6} = 5^{5x}$

Funcția exponențială este injectivă, deci egalăm exponenții:

$$x^2 + 6 = 5x \iff x^2 - 5x + 6 = 0 \iff (x-2)(x-3) = 0.$$

**Răspuns:** $x \in \{2, 3\}$. *Barem: 3p ecuația de gradul 2, 2p soluțiile.*

### 4. Prețul de $900$ lei după două ieftiniri succesive cu $10\%$

- După prima ieftinire: $900 - \dfrac{10}{100}\cdot 900 = 900 - 90 = 810$ lei.
- După a doua: $810 - \dfrac{10}{100}\cdot 810 = 810 - 81 = 729$ lei.

(Altfel: $900\cdot 0{,}9^2 = 900 \cdot 0{,}81 = 729$.)

**Răspuns:** $729$ de lei. *Barem: 3p prima ieftinire, 2p a doua.*

### 5. $A(2,-1)$, $B(1,2)$, $C(-1,-2)$: triunghiul $ABC$ este dreptunghic isoscel

$$AB = \sqrt{(1-2)^2 + (2+1)^2} = \sqrt{10}, \quad AC = \sqrt{(-1-2)^2 + (-2+1)^2} = \sqrt{10},$$

$$BC = \sqrt{(-1-1)^2 + (-2-2)^2} = \sqrt{20}.$$

$AB = AC$, deci triunghiul este isoscel; $AB^2 + AC^2 = 10 + 10 = 20 = BC^2$, deci (reciproca teoremei lui Pitagora) este dreptunghic în $A$. *Barem: 3p laturile și isoscel, 2p dreptunghic.*

### 6. Arătați că $\sin^2 30^\circ + \sin^2 45^\circ + \sin^2 60^\circ = \dfrac32$

$$\left(\frac12\right)^2 + \left(\frac{\sqrt2}{2}\right)^2 + \left(\frac{\sqrt3}{2}\right)^2 = \frac14 + \frac24 + \frac34 = \frac64 = \frac32.$$

*Barem: 3p valorile, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = 2(x + y) + xy + 2$.

### 1. Arătați că $0 * (-2) = -2$

$$0 * (-2) = 2(0 - 2) + 0 + 2 = -4 + 2 = -2.$$

*Barem: 3p înlocuirea, 2p finalizarea.*

### 2. $x * y = (x+2)(y+2) - 2$

$$x * y = xy + 2x + 2y + 4 - 2 = x(y+2) + 2(y+2) - 2 = (x+2)(y+2) - 2.$$

*Barem: 2p adunarea și scăderea lui 2, 3p gruparea.*

### 3. $e = -1$ este element neutru

$$x * (-1) = (x+2)(1) - 2 = x, \qquad (-1) * x = 1\cdot(x+2) - 2 = x,$$

pentru orice $x$ real, deci $e = -1$ este elementul neutru. *Barem: 2p $x*(-1)$, 3p comutarea și concluzia.*

### 4. $(x+1) * (x+1) = 2$

$$(x+3)^2 - 2 = 2 \iff (x+3)^2 = 4 \iff x^2 + 6x + 5 = 0 \iff x \in \{-5, -1\}.$$

**Răspuns:** $x \in \{-5, -1\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 5. $x > 0$ cu $\lg x * \lg(2x) = -2$

$$(\lg x + 2)(\lg(2x) + 2) - 2 = -2 \iff (\lg x + 2)(\lg(2x) + 2) = 0.$$

- $\lg x = -2 \Rightarrow x = 10^{-2} = \dfrac{1}{100}$;
- $\lg(2x) = -2 \Rightarrow 2x = \dfrac1{100} \Rightarrow x = \dfrac{1}{200}$.

Ambele sunt pozitive, deci convin. **Răspuns:** $x \in \left\{\dfrac1{100}, \dfrac1{200}\right\}$. *Barem: 3p descompunerea, 2p soluțiile.*

### 6. $a, b \in \mathbb Q \setminus \mathbb Z$ cu $a * b \in \mathbb Z$

$a * b \in \mathbb Z \iff (a+2)(b+2) \in \mathbb Z$. Alegem $a + 2 = \dfrac23$ și $b + 2 = \dfrac32$, adică

$$a = -\frac43, \quad b = -\frac12, \qquad a * b = \frac23\cdot\frac32 - 2 = 1 - 2 = -1 \in \mathbb Z.$$

**Răspuns (un exemplu):** $a = -\dfrac43$, $b = -\dfrac12$. *Barem: 2p condiția, 3p exemplul.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&1\\0&2\end{pmatrix}$, $I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$, $M(a) = aA + I_2$.

### 1. $\det A = 2$

$$\det A = 1\cdot 2 - 0\cdot 1 = 2.$$

*Barem: 3p formula, 2p calculul.*

### 2. $\det(M(a)) = (a+1)(2a+1)$

$$M(a) = \begin{pmatrix}a & a\\0 & 2a\end{pmatrix} + \begin{pmatrix}1&0\\0&1\end{pmatrix} = \begin{pmatrix}a+1 & a\\0 & 2a+1\end{pmatrix},$$

$$\det(M(a)) = (a+1)(2a+1) - 0 = (a+1)(2a+1).$$

*Barem: 3p matricea $M(a)$, 2p determinantul.*

### 3. Inversa matricei $M(-2)$

$M(-2) = \begin{pmatrix}-1 & -2\\0 & -3\end{pmatrix}$, $\det = (-1)(-3) = 3 \ne 0$.

$$M^{-1}(-2) = \frac13\begin{pmatrix}-3 & 2\\0 & -1\end{pmatrix} = \begin{pmatrix}-1 & \frac23\\[2pt] 0 & -\frac13\end{pmatrix}.$$

(Verificare: $M(-2)\cdot M^{-1}(-2) = I_2$ ✔.) *Barem: 2p determinantul, 3p inversa.*

### 4. $M(1)\cdot M(2) = 3(A\cdot A + I_2)$

$$M(1)M(2) = \begin{pmatrix}2&1\\0&3\end{pmatrix}\begin{pmatrix}3&2\\0&5\end{pmatrix} = \begin{pmatrix}6&9\\0&15\end{pmatrix} = 3\begin{pmatrix}2&3\\0&5\end{pmatrix},$$

$$A\cdot A + I_2 = \begin{pmatrix}1&3\\0&4\end{pmatrix} + \begin{pmatrix}1&0\\0&1\end{pmatrix} = \begin{pmatrix}2&3\\0&5\end{pmatrix}.$$

Deci egalitatea are loc. *Barem: 3p produsul, 2p finalizarea.*

### 5. $\det(M(a) - 2aA) \ne 1$ pentru orice $a$ întreg nenul

$M(a) - 2aA = I_2 - aA = M(-a)$, deci din 2):

$$\det(M(a) - 2aA) = (1-a)(1-2a).$$

$(1-a)(1-2a) = 1 \iff 2a^2 - 3a = 0 \iff a(2a - 3) = 0 \iff a \in \left\{0, \tfrac32\right\}$ — niciuna nu este întreg nenul. $\blacksquare$ *Barem: 2p determinantul, 3p concluzia.*

### 6. $X \in \mathcal M_{2,1}(\mathbb R)$ cu $A\cdot X = \begin{pmatrix}0\\-4\end{pmatrix}$

Fie $X = \begin{pmatrix}x\\y\end{pmatrix}$:

$$\begin{pmatrix}x + y\\2y\end{pmatrix} = \begin{pmatrix}0\\-4\end{pmatrix} \iff \begin{cases}x + y = 0\\2y = -4\end{cases} \iff y = -2,\ x = 2.$$

**Răspuns:** $X = \begin{pmatrix}2\\-2\end{pmatrix}$. *Barem: 2p sistemul, 3p soluția.*
