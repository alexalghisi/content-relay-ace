## Subiectul I (30 de puncte)

### 1. Arătați că $(1{,}5 - 0{,}5)\cdot3 - 2\cdot0{,}5 = 2$

$$(1{,}5 - 0{,}5)\cdot3 - 2\cdot0{,}5 = 1\cdot3 - 1 = 2.$$

*Barem: 3p + 2p.*

### 2. $f(x) = 2x - 3$; $a$ cu $f(a) = 9$

$$2a - 3 = 9 \iff a = 6.$$

*Barem: 2p + 3p.*

### 3. Ecuația $\log_4(3x - 1) = \log_4 5$

Logaritmul e injectiv: $3x - 1 = 5 \iff x = 2$; condiția $3x - 1 > 0$ e îndeplinită.

**Răspuns:** $x = 2$. *Barem: 3p + 2p.*

### 4. $A = \{0, 1, \dots, 9\}$; probabilitatea ca $5n \le 22$

10 cazuri posibile; $5n \le 22 \iff n \le 4{,}4$, deci $n \in \{0,1,2,3,4\}$: 5 cazuri favorabile.

$$p = \frac{5}{10} = \frac12.$$

*Barem: 2p + 3p.*

### 5. Mijlocul segmentului $AB$, $A(-2,1)$, $B(6,3)$

$$x_M = \frac{-2 + 6}{2} = 2,\quad y_M = \frac{1 + 3}{2} = 2.$$

**Răspuns:** $M(2, 2)$. *Barem: 3p + 2p.*

### 6. $\triangle ABC$ dreptunghic în $A$, $AC = 4$, $BC = 5$; aria $= 6$

Pitagora: $AB = \sqrt{25 - 16} = 3$.

$$\mathcal A = \frac{AB\cdot AC}{2} = \frac{3\cdot4}{2} = 6.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}2&1\\1&3\end{pmatrix}$, $B(x) = \begin{pmatrix}2 - x & x\\ x & 2\end{pmatrix}$

#### a) $\det A = 5$

$$\det A = 2\cdot3 - 1\cdot1 = 5.$$

*Barem: 3p + 2p.*

#### b) $2A - B(2) = 2B(0)$

$$2A - B(2) = \begin{pmatrix}4&2\\2&6\end{pmatrix} - \begin{pmatrix}0&2\\2&2\end{pmatrix} = \begin{pmatrix}4&0\\0&4\end{pmatrix} = 2\begin{pmatrix}2&0\\0&2\end{pmatrix} = 2B(0).$$

*Barem: 3p + 2p.*

#### c) $x$ cu $\det\big(B(x)B(1) - (x+1)A\big) = 1$

$B(1) = \begin{pmatrix}1&1\\1&2\end{pmatrix}$:

$$B(x)B(1) = \begin{pmatrix}2 & x + 2\\ x + 2 & x + 4\end{pmatrix},\quad (x+1)A = \begin{pmatrix}2x + 2 & x + 1\\ x + 1 & 3x + 3\end{pmatrix},$$

$$B(x)B(1) - (x+1)A = \begin{pmatrix}-2x & 1\\ 1 & 1 - 2x\end{pmatrix},\quad \det = -2x(1 - 2x) - 1 = 4x^2 - 2x - 1.$$

$4x^2 - 2x - 1 = 1 \iff 2x^2 - x - 1 = 0 \iff (x - 1)(2x + 1) = 0$.

**Răspuns:** $x \in \left\{-\frac12, 1\right\}$. *Barem: 3p + 2p.*

### 2. Legea $x\circ y = x + y - 6xy$

#### a) $1\circ1 = -4$

$$1\circ1 = 1 + 1 - 6 = -4.$$

*Barem: 3p + 2p.*

#### b) $e = 0$ este elementul neutru

$0\circ x = 0 + x - 0 = x$ și $x\circ0 = x$, pentru orice $x$ real. $\blacksquare$ *Barem: 2p + 3p.*

#### c) $m$ întreg cu $m\circ(3 - m) < 3$

$$m\circ(3 - m) = m + 3 - m - 6m(3 - m) = 3 - 6m(3 - m).$$

$3 - 6m(3 - m) < 3 \iff m(3 - m) > 0 \iff m(m - 3) < 0 \iff m \in (0, 3)$.

**Răspuns:** $m \in \{1, 2\}$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = 2x^3 - 3x^4 + 2$

#### a) $f'(x) = 6x^2(1 - 2x)$

$$f'(x) = 6x^2 - 12x^3 = 6x^2(1 - 2x).$$

*Barem: 3p + 2p.*

#### b) $\lim\limits_{x\to+\infty}\dfrac{f(x) + 3x^4}{x^3 + 4} = 2$

$$\lim_{x\to\infty}\frac{2x^3 + 2}{x^3 + 4} = \lim_{x\to\infty}\frac{2 + \frac2{x^3}}{1 + \frac4{x^3}} = 2.$$

*Barem: 2p + 3p.*

#### c) $-32 \le 2x^3 - 3x^4 \le \frac1{16}$ pentru $x \in [0, 2]$

$f'(x) = 0 \iff x \in \{0, \frac12\}$. Pe $\left[0, \frac12\right]$: $f' \ge 0$, $f$ crescătoare; pe $\left[\frac12, 2\right]$: $f' \le 0$, $f$ descrescătoare.

$f(0) = 2$, $f\left(\frac12\right) = \frac14 - \frac3{16} + 2 = \frac{33}{16}$, $f(2) = 16 - 48 + 2 = -30$.

Deci pe $[0,2]$: $-30 \le f(x) \le \frac{33}{16}$; scăzând 2: $-32 \le 2x^3 - 3x^4 \le \frac1{16}$. $\blacksquare$ *Barem: 2p + 3p.*

### 2. $f(x) = 2x + 3e^x$

#### a) $\displaystyle\int_2^3\left(f(x) - 3e^x\right)dx = 5$

$$\int_2^3 2x\,dx = x^2\Big|_2^3 = 9 - 4 = 5.$$

*Barem: 3p + 2p.*

#### b) $\displaystyle\int_0^1 x\left(f(x) - 2x\right)dx = 3$

Prin părți:

$$\int_0^1 3xe^xdx = 3xe^x\Big|_0^1 - 3\int_0^1e^xdx = 3e - 3(e - 1) = 3.$$

*Barem: 3p + 2p.*

#### c) $a$ cu $\displaystyle\int_0^1\frac{f'(x) - x}{2f(x) - x^2}dx = a\ln\left(e + \frac12\right)$

$(2f(x) - x^2)' = 2(f'(x) - x)$, iar $2f(x) - x^2 = 4x + 6e^x - x^2 > 0$ pe $[0,1]$. Deci

$$\int_0^1\frac{f' - x}{2f - x^2}dx = \frac12\ln(2f(x) - x^2)\Big|_0^1 = \frac12\ln\frac{3 + 6e}{6} = \frac12\ln\left(e + \frac12\right).$$

**Răspuns:** $a = \dfrac12$. *Barem: 3p + 2p.*
