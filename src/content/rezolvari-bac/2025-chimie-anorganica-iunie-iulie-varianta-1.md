## Subiectul al III-lea (25 de puncte)

### Subiectul E (15 puncte)

**1.** Reacția degajă 518,2 kJ, deci $\Delta_r H^0 = -518{,}2\ \text{kJ}$ ($\Delta_f H^0_{\text{O}_2} = 0$).

$$\Delta_r H^0 = \Delta_f H^0_{\text{SO}_2} + \Delta_f H^0_{\text{H}_2\text{O}} - \Delta_f H^0_{\text{H}_2\text{S}}$$

$$-518{,}2 = -296{,}8 - 241{,}6 - \Delta_f H^0_{\text{H}_2\text{S}} \Rightarrow \Delta_f H^0_{\text{H}_2\text{S}} = \mathbf{-20{,}2\ kJ/mol}$$

*Barem: 2p. + 1p.*

**2.** $n_{\text{SO}_2} = 6{,}4 : 64 = 0{,}1\ \text{mol}$; la formarea unui mol de SO₂ se degajă 518,2 kJ, deci $Q = 0{,}1 \cdot 518{,}2 = \mathbf{51{,}82\ kJ}$. *(2p. + 1p.)*

**3.** $\Delta T = 52 - 2 = 50\ \text{K}$:

$$m = \frac{Q}{c \cdot \Delta T} = \frac{20{,}9}{4{,}18 \cdot 50} = \mathbf{0{,}1\ kg\ apă}$$

*Barem: 2p. + 1p.*

**4. Legea lui Hess.** Reacția cerută este C(grafit) + 2 S(rombic) → CS₂(l).

- păstrăm (1): C + O₂ → CO₂, cu $+\Delta_r H_1^0$
- (2) înmulțită cu 2: 2 S + 2 O₂ → 2 SO₂, cu $+2\Delta_r H_2^0$
- inversăm (3): CO₂ + 2 SO₂ → CS₂ + 3 O₂, cu $-\Delta_r H_3^0$

Prin adunare se simplifică 3 O₂, CO₂ și 2 SO₂:

$$\Delta_r H^0 = \Delta_r H_1^0 + 2\Delta_r H_2^0 - \Delta_r H_3^0$$

*Barem: 4p.*

**5.** Stabilitatea crește cu cât entalpia de formare este mai negativă: −249,8 > −341,8 > −702,9 kJ/mol, deci ordinea este **FeBr₂, FeCl₂, FeF₂**. *2p.*
