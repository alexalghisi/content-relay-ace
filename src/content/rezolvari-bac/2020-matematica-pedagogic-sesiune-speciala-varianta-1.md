## Subiectul I (30 de puncte)

### 1. Rația progresiei geometrice cu $b_1 = 2$, $b_4 = -2$

$b_4 = b_1 q^3 \Rightarrow 2q^3 = -2 \Rightarrow q^3 = -1 \Rightarrow q = -1.$

**Răspuns:** $q = -1$. *Barem: 3p relația, 2p rația.*

### 2. $f(x) = x^2 - 6x + 3$: arătați că $f(0) = f(6)$

$f(0) = 3$ și $f(6) = 36 - 36 + 3 = 3$, deci $f(0) = f(6)$. $\blacksquare$

**Observație:** $0$ și $6$ sunt simetrice față de axa parabolei $x = 3$. *Barem: 2p, 3p.*

### 3. Ecuația $\log_3(x - 2) = 1$

Condiție: $x > 2$. Din definiție, $x - 2 = 3 \iff x = 5$, care convine.

**Răspuns:** $x = 5$. *Barem: 3p, 2p.*

### 4. Probabilitatea ca un număr din $A = \{1,2,3,7,8,9\}$ să fie $\le$ media aritmetică a elementelor

Cazuri posibile: $6$. Media: $m_a = \dfrac{1+2+3+7+8+9}{6} = \dfrac{30}{6} = 5$. Numere $\le 5$: $1, 2, 3$ — 3 cazuri favorabile.

$$p = \frac36 = \frac12.$$

*Barem: 2p, 2p, 1p.*

### 5. $d_1: y = 3x - 1$, $d_2: y = ax + 5$ perpendiculare

Pantele: $m_{d_1} = 3$, $m_{d_2} = a$. Perpendicularitate: $m_{d_1}\cdot m_{d_2} = -1 \iff 3a = -1 \iff a = -\frac13$.

**Răspuns:** $a = -\dfrac13$. *Barem: 2p pantele, 3p condiția și rezultatul.*

### 6. $\triangle ABC$ dreptunghic în $A$, $BD$ bisectoare, $BD = CD$: arătați că $\angle ACB = 30^\circ$

$BD = CD$, deci $\triangle BDC$ este isoscel: $\angle DCB = \angle DBC$. Cum $BD$ e bisectoare, $\angle DBC = \frac12\angle ABC$. Așadar $\angle ACB = \frac12\angle ABC$, adică $\angle ABC = 2\angle ACB$.

În triunghiul dreptunghic: $\angle ABC + \angle ACB = 90^\circ \Rightarrow 3\angle ACB = 90^\circ \Rightarrow \angle ACB = 30^\circ$. $\blacksquare$

*Barem: 3p triunghiul isoscel, 2p concluzia.*

## Subiectul al II-lea (30 de puncte)

Legea: $x * y = x + ay + 5$, $a \in \mathbb R$.

### 1. $4 * 0 = 9$ pentru orice $a$

$4 * 0 = 4 + a\cdot 0 + 5 = 9$. $\blacksquare$ *Barem: 3p, 2p.*

### 2. Pentru $a = 1$ legea este asociativă

Cu $a = 1$: $x * y = x + y + 5$.

$$(x * y) * z = (x + y + 5) + z + 5 = x + y + z + 10,$$
$$x * (y * z) = x + (y + z + 5) + 5 = x + y + z + 10.$$

Expresiile coincid pentru orice $x, y, z$. $\blacksquare$ *Barem: 3p, 2p.*

### 3. Valoarea lui $a$ pentru care legea este comutativă

$x * y = y * x \iff x + ay + 5 = y + ax + 5 \iff (a - 1)(x - y) = 0$ pentru orice $x, y$, deci $a = 1$.

**Răspuns:** $a = 1$. *Barem: 2p, 3p.*

### 4. Dacă există element neutru, atunci $a = 1$

Fie $e$ neutru. Din $e * 0 = 0$: $e + 5 = 0$, deci $e = -5$. Din $0 * e = 0$: $0 + a\cdot(-5) + 5 = 0$, deci $a = 1$. $\blacksquare$

*Barem: 2p $e = -5$, 3p $a = 1$.*

### 5. Pentru $a = 1$: $(x * x^2) * (x * x^2) = 15$

$x * x^2 = x + x^2 + 5$, iar $t * t = 2t + 5$:

$$2(x^2 + x + 5) + 5 = 2x^2 + 2x + 15 = 15 \iff 2x(x + 1) = 0.$$

**Răspuns:** $x \in \{-1, 0\}$. *Barem: 2p, 3p.*

### 6. Pentru $a = -3$: $4^x * 2^x = 3$

$x * y = x - 3y + 5$, deci $4^x - 3\cdot 2^x + 5 = 3 \iff (2^x)^2 - 3\cdot2^x + 2 = 0 \iff (2^x - 1)(2^x - 2) = 0$.

**Răspuns:** $x \in \{0, 1\}$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}5 & 4\\ 4 & 5\end{pmatrix}$.

### 1. $\det A = 9$

$\det A = 5\cdot 5 - 4\cdot 4 = 25 - 16 = 9$. *Barem: 3p, 2p.*

### 2. $(A - I_2)(A - 9I_2) = O_2$

$$A - I_2 = \begin{pmatrix}4&4\\4&4\end{pmatrix},\quad A - 9I_2 = \begin{pmatrix}-4&4\\4&-4\end{pmatrix},$$
$$(A - I_2)(A - 9I_2) = \begin{pmatrix}-16+16 & 16-16\\ -16+16 & 16-16\end{pmatrix} = O_2.\ \blacksquare$$

*Barem: 2p, 3p.*

### 3. $B = A - 5I_2$: suma elementelor lui $B\cdot B$ este divizibilă cu $2^5$

$B = \begin{pmatrix}0&4\\4&0\end{pmatrix}$, $B\cdot B = \begin{pmatrix}16&0\\0&16\end{pmatrix}$. Suma elementelor: $16 + 16 = 32 = 2^5$, divizibilă cu $2^5$. $\blacksquare$

*Barem: 3p, 2p.*

### 4. $\det(aA + I_2) = 0$

$$aA + I_2 = \begin{pmatrix}5a + 1 & 4a\\ 4a & 5a + 1\end{pmatrix},\quad \det = (5a+1)^2 - 16a^2 = 9a^2 + 10a + 1.$$

$9a^2 + 10a + 1 = 0 \iff (9a + 1)(a + 1) = 0$.

**Răspuns:** $a \in \left\{-1, -\frac19\right\}$. *Barem: 3p, 2p.*

### 5. $A\cdot M = M\cdot A$, $M = \begin{pmatrix}x & 1\\ y & 2\end{pmatrix}$

$$AM = \begin{pmatrix}5x + 4y & 13\\ 4x + 5y & 14\end{pmatrix},\qquad MA = \begin{pmatrix}5x + 4 & 4x + 5\\ 5y + 8 & 4y + 10\end{pmatrix}.$$

Egalând: $4x + 5 = 13 \Rightarrow x = 2$; $4y + 10 = 14 \Rightarrow y = 1$; verificare: $5\cdot2 + 4 = 14 = 5\cdot 2 + 4\cdot 1$ ✔, $4\cdot2 + 5 = 13 = 5 + 8$ ✔.

**Răspuns:** $x = 2$, $y = 1$. *Barem: 2p produsele, 3p soluția.*

### 6. $\det(A + xI_2) + \det(A - xI_2) \ge 18$

$$\det(A + xI_2) + \det(A - xI_2) = (5+x)^2 - 16 + (5 - x)^2 - 16 = 2x^2 + 18 \ge 18.\ \blacksquare$$

*Barem: 2p matricele, 3p calculul și concluzia.*
