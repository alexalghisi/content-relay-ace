## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $r = -2$ și $a_1 = 19$. Calculați $a_7$

$$a_7 = a_1 + 6r = 19 - 12 = 7.$$

**Răspuns:** $a_7 = 7$. *Barem: 3p, 2p.*

### 2. Intersecțiile graficului funcției $f(x) = 4 - \frac{4x}{3}$ cu axele

- cu $Ox$: $f(x) = 0 \iff \frac{4x}{3} = 4 \iff x = 3$, punctul $A(3, 0)$;
- cu $Oy$: $f(0) = 4$, punctul $B(0, 4)$.

**Răspuns:** $A(3, 0)$ și $B(0, 4)$. *Barem: 3p, 2p.*

### 3. $x^2 - (2m+1)x + m^2 + m = 0$ are două soluții reale distincte pentru orice $m$

$$\Delta = (2m + 1)^2 - 4(m^2 + m) = 4m^2 + 4m + 1 - 4m^2 - 4m = 1 > 0,$$

deci ecuația are mereu două soluții reale distincte (chiar $x_1 = m$, $x_2 = m + 1$). $\blacksquare$ *Barem: 2p, 3p.*

### 4. Ecuația $3^{x+1} + 2\cdot 3^x = 45$

$$3\cdot 3^x + 2\cdot 3^x = 45 \iff 5\cdot 3^x = 45 \iff 3^x = 9 \iff x = 2.$$

**Răspuns:** $x = 2$. *Barem: 3p, 2p.*

### 5. Paralelogramul $ABCD$, $M, N, P, Q$ mijloacele laturilor; arătați că $\overrightarrow{AM} + \overrightarrow{AQ} + \overrightarrow{CN} + \overrightarrow{CP} = \vec 0$

Fie $O$ centrul paralelogramului (mijlocul diagonalelor).

$$\overrightarrow{AM} + \overrightarrow{AQ} = \frac12\left(\overrightarrow{AB} + \overrightarrow{AD}\right) = \frac12\overrightarrow{AC} = \overrightarrow{AO},$$

și analog $\overrightarrow{CN} + \overrightarrow{CP} = \frac12\left(\overrightarrow{CB} + \overrightarrow{CD}\right) = \frac12\overrightarrow{CA} = \overrightarrow{CO}$.

Cum $O$ este mijlocul lui $AC$, $\overrightarrow{AO} + \overrightarrow{CO} = \vec 0$. $\blacksquare$ *Barem: 2p, 2p, 1p.*

### 6. Triunghi dreptunghic cu ipotenuza $BC = 20$ și $\cos B = \frac35$. Perimetrul

$\cos B = \dfrac{AB}{BC} \Rightarrow AB = 20\cdot\frac35 = 12$. Pitagora: $AC = \sqrt{400 - 144} = 16$.

$$P = 12 + 16 + 20 = 48.$$

**Răspuns:** $48$. *Barem: 2p, 2p, 1p.*

## Subiectul al II-lea (30 de puncte)

Legea: $x * y = x + y + 1$.

### a) $(-5) * 5 = (-10) * 10$

$(-5) * 5 = -5 + 5 + 1 = 1$ și $(-10) * 10 = -10 + 10 + 1 = 1$, deci sunt egale. *Barem: 2p, 2p, 1p.*

### b) Inecuația $x^2 * x \le 13$

$$x^2 + x + 1 \le 13 \iff x^2 + x - 12 \le 0 \iff (x + 4)(x - 3) \le 0 \iff x \in [-4, 3].$$

**Răspuns:** $x \in [-4, 3]$. *Barem: 2p, 3p.*

### c) Ecuația $4^x * 2^x = 21$

$4^x + 2^x + 1 = 21 \iff 4^x + 2^x = 20$. Cu $t = 2^x > 0$: $t^2 + t - 20 = 0 \iff (t - 4)(t + 5) = 0$.

$t = -5$ nu convine; $2^x = 4 \iff x = 2$.

**Răspuns:** $x = 2$. *Barem: 1p, 1p, 2p, 1p.*

### d) $(x * y) * z = x * (y * z)$

$$(x * y) * z = (x + y + 1) + z + 1 = x + y + z + 2 = x + (y + z + 1) + 1 = x * (y * z).$$

*Barem: 2p, 2p, 1p.*

### e) Simetricul lui $x = 3$ (elementul neutru $e = -1$)

$$3 * x' = -1 \iff 3 + x' + 1 = -1 \iff x' = -5$$

(și $x' * 3 = -1$, legea fiind comutativă).

**Răspuns:** $x' = -5$. *Barem: 2p, 3p.*

### f) Numărul elementelor mulțimii $A = \{n \in \mathbb N \mid n * (n+1) \le 2012\}$

$$n * (n + 1) = 2n + 2 \le 2012 \iff n \le 1005.$$

$A = \{0, 1, \dots, 1005\}$ are **1006** elemente.

**Răspuns:** $1006$. *Barem: 1p, 2p, 2p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix} 1 & 2 & 3\\ 2 & 3 & 1\\ 3 & 1 & 2\end{pmatrix}$, $B = \begin{pmatrix} 0 & a & a\\ a & a & 0\\ a & 0 & a\end{pmatrix}$, sistemul $(S)$: $\begin{cases} ay + az = 1\\ ax + ay = 0\\ ax + az = 2\end{cases}$, $a \ne 0$.

### a) $\det A$

$$\det A = 6 + 6 + 6 - 27 - 1 - 8 = 18 - 36 = -18.$$

*Barem: 3p, 2p.*

### b) $B$ este inversabilă pentru orice $a \ne 0$

$$\det B = 0 + 0 + 0 - a^3 - 0 - a^3 = -2a^3 \ne 0 \text{ pentru } a \ne 0,$$

deci $B$ este inversabilă. *Barem: 3p, 2p.*

### c) Pentru $a = 1$: ${}^t(AB) = BA$

$$B = \begin{pmatrix} 0 & 1 & 1\\ 1 & 1 & 0\\ 1 & 0 & 1\end{pmatrix}, \quad AB = \begin{pmatrix} 5 & 3 & 4\\ 4 & 5 & 3\\ 3 & 4 & 5\end{pmatrix}, \quad BA = \begin{pmatrix} 5 & 4 & 3\\ 3 & 5 & 4\\ 4 & 3 & 5\end{pmatrix}.$$

Transpusa lui $AB$ este $\begin{pmatrix} 5 & 4 & 3\\ 3 & 5 & 4\\ 4 & 3 & 5\end{pmatrix} = BA$. (Explicație: $A$ și $B$ sunt simetrice, iar ${}^t(AB) = {}^tB\,{}^tA = BA$.) *Barem: 1p, 2p, 2p.*

### d) Pentru $a = 1$, $\left(\frac12, -\frac12, \frac32\right)$ este soluție

$$y + z = -\frac12 + \frac32 = 1, \quad x + y = \frac12 - \frac12 = 0, \quad x + z = \frac12 + \frac32 = 2. \ ✔$$

*Barem: 2p, 3p.*

### e) Rezolvarea sistemului pentru $a \ne 0$

Matricea sistemului este $B$, cu $\det B \ne 0$: sistem Cramer. Adunând cele trei ecuații: $2a(x + y + z) = 3$, deci $x + y + z = \dfrac{3}{2a}$. Scăzând pe rând ecuațiile:

$$x = \frac{3}{2a} - \frac1a = \frac{1}{2a}, \quad z = \frac{3}{2a} - 0 = \frac{3}{2a}, \quad y = \frac{3}{2a} - \frac2a = -\frac{1}{2a}.$$

**Răspuns:** $(x, y, z) = \left(\dfrac{1}{2a}, -\dfrac{1}{2a}, \dfrac{3}{2a}\right)$. *Barem: 2p, 3p.*

### f) $a$ pentru care $x_0 + y_0 + z_0 = \frac14$

$$\frac{3}{2a} = \frac14 \iff 2a = 12 \iff a = 6.$$

**Răspuns:** $a = 6$. *Barem: 3p, 2p.*

## Ce merită reținut din varianta 9

- **Mijloacele laturilor și centrul paralelogramului**: $\overrightarrow{AM} + \overrightarrow{AQ} = \frac12\overrightarrow{AC}$.
- **Discriminant constant** (aici $\Delta = 1$) arată că ecuația are mereu rădăcini reale distincte.
- **${}^t(AB) = {}^tB\,{}^tA$** — pentru matrice simetrice devine $BA$.
- **Sisteme simetrice**: adună toate ecuațiile ca să afli $x + y + z$, apoi scade fiecare ecuație.
