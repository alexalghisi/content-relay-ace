## Subiectul I (30 de puncte)

### 1. Verificați dacă $(2^5 - 1)(2^5 + 1) = 1023$

$$(2^5 - 1)(2^5 + 1) = 2^{10} - 1 = 1024 - 1 = 1023.$$

**Răspuns:** da. *Barem: 2p formula, 3p calculul.*

### 2. Punctul de pe graficul lui $f(x) = 3x + 2$ cu abscisa egală cu ordonata

$$f(x) = x \iff 3x + 2 = x \iff x = -1.$$

**Răspuns:** $A(-1, -1)$. *Barem: 3p ecuația, 2p coordonatele.*

### 3. Ecuația $\log_2 x^3 = 12 - \log_2 x$

Condiția $x > 0$. $\log_2 x^3 = 3\log_2 x$:

$$3\log_2 x = 12 - \log_2 x \iff 4\log_2 x = 12 \iff \log_2 x = 3 \iff x = 8.$$

**Răspuns:** $x = 8$. *Barem: 3p ecuația, 2p soluția.*

### 4. Prețul fără TVA, știind prețul de vânzare $186$ lei și TVA-ul $24\%$

$$x + \frac{24}{100}x = 186 \iff 1{,}24x = 186 \iff x = 150.$$

**Răspuns:** $150$ de lei. *Barem: 2p ecuația, 3p soluția.*

### 5. $M(3,4)$, $N(2,1)$, $P(a,b)$; $N$ este mijlocul lui $MP$

$$2 = \frac{3 + a}{2} \Rightarrow a = 1, \qquad 1 = \frac{4 + b}{2} \Rightarrow b = -2.$$

**Răspuns:** $a = 1$, $b = -2$. *Barem: 3p relațiile, 2p valorile.*

### 6. $\cos A$ pentru $A(2,3)$, $B(5,3)$, $C(5,7)$

$AB = 3$, $BC = 4$, $AC = \sqrt{9 + 16} = 5$. Cum $AB^2 + BC^2 = AC^2$, triunghiul este dreptunghic în $B$:

$$\cos A = \frac{AB}{AC} = \frac35.$$

**Răspuns:** $\cos A = \dfrac35$. *Barem: 3p laturile, 2p cosinusul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x\circ y = (x - 3)(y - 3) + 3$.

### 1. $2014\circ3$

$$(2014 - 3)\cdot0 + 3 = 3.$$

*Barem: 3p, 2p.*

### 2. Legea este asociativă

$$(x\circ y)\circ z = (x-3)(y-3)(z-3) + 3 = x\circ(y\circ z).$$

(La compunere, $(x\circ y) - 3 = (x-3)(y-3)$.) *Barem: 2p, 3p.*

### 3. Elementul neutru

Legea este comutativă. $x\circ e = x \iff (x - 3)(e - 3) + 3 = x \iff (x - 3)(e - 4) = 0$ pentru orice $x$, deci $e = 4$.

**Răspuns:** $e = 4$. *Barem: 2p comutativitatea, 3p valoarea.*

### 4. $x\circ3 = 3\circ x = 3$

$$x\circ3 = (x - 3)\cdot 0 + 3 = 3, \qquad 3\circ x = 0\cdot(x - 3) + 3 = 3.$$

*Barem: 2p, 3p.*

### 5. Ecuația $x\circ(x + 1) = 3$

$$(x - 3)(x - 2) + 3 = 3 \iff (x - 3)(x - 2) = 0 \iff x \in \{2, 3\}.$$

**Răspuns:** $x \in \{2, 3\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 6. Numerele întregi $a, b$ cu $a\circ b = 4$

$(a - 3)(b - 3) = 1$, cu factori întregi: ambii $1$ sau ambii $-1$.

**Răspuns:** $a = b = 4$ sau $a = b = 2$. *Barem: 3p ecuația, 2p soluțiile.*

## Subiectul al III-lea (30 de puncte)

$M = \left\{A(x,y) = \begin{pmatrix}x & y\\-y & x\end{pmatrix} \,\middle|\, x, y \in \mathbb R,\ x^2 + y^2 = 1\right\}$.

### 1. $\det(A(x,y)) = 1$

$$\det A(x,y) = x\cdot x - y\cdot(-y) = x^2 + y^2 = 1.$$

*Barem: 3p, 2p.*

### 2. Un exemplu de matrice din $M$

$A(1, 0) = I_2$, deoarece $1^2 + 0^2 = 1$. *Barem: 3p, 2p.*

### 3. $A\left(\frac12, \frac{\sqrt3}{2}\right) + A\left(\frac12, -\frac{\sqrt3}{2}\right)$

$$\begin{pmatrix}\frac12 & \frac{\sqrt3}{2}\\-\frac{\sqrt3}{2} & \frac12\end{pmatrix} + \begin{pmatrix}\frac12 & -\frac{\sqrt3}{2}\\\frac{\sqrt3}{2} & \frac12\end{pmatrix} = \begin{pmatrix}1&0\\0&1\end{pmatrix} = I_2.$$

**Răspuns:** $I_2$. *Barem: 2p, 3p.*

### 4. $A(x,y)\cdot A(x,-y) = A(1,0)$

$$\begin{pmatrix}x&y\\-y&x\end{pmatrix}\begin{pmatrix}x&-y\\y&x\end{pmatrix} = \begin{pmatrix}x^2 + y^2 & 0\\0 & x^2 + y^2\end{pmatrix} = I_2 = A(1,0).$$

*Barem: 2p produsul, 3p finalizarea.*

### 5. Numărul matricelor din $M$ cu toate elementele întregi

$x, y \in \mathbb Z$ și $x^2 + y^2 = 1$: unul dintre pătrate este $1$, celălalt $0$:

$$(x, y) \in \{(1,0), (-1,0), (0,1), (0,-1)\}.$$

**Răspuns:** $4$ matrice. *Barem: 2p, 2p, 1p.*

### 6. Pentru $p^2 + q^2 = 1$, matricea $\begin{pmatrix}p - 2 & q + 2\\-(q+2) & p - 2\end{pmatrix} \notin M$

Matricea este $A(p - 2, q + 2)$; ar aparține lui $M$ doar dacă $(p-2)^2 + (q+2)^2 = 1$.

Din $p^2 + q^2 = 1$: $-1 \le p \le 1$, deci $p - 2 \le -1$ și $(p-2)^2 \ge 1$; analog $-1 \le q \le 1$, deci $q + 2 \ge 1$ și $(q+2)^2 \ge 1$. Rezultă

$$(p - 2)^2 + (q + 2)^2 \ge 2 > 1,$$

deci matricea nu aparține lui $M$. $\blacksquare$ *Barem: 3p încadrările, 2p concluzia.*

## Ce merită reținut din simulare

- **$(a - 1)(a + 1) = a^2 - 1$** simplifică imediat produse de tipul $(2^5 - 1)(2^5 + 1)$.
