## Subiectul I (30 de puncte)

### 1. Arătați că $\left(-3 + \left(-\frac12\right)^2\right) : \left(-\frac{11}{2}\right) = \frac12$

$$-3 + \frac14 = -\frac{11}{4}, \qquad -\frac{11}{4} : \left(-\frac{11}{2}\right) = \frac{11}{4}\cdot\frac{2}{11} = \frac12.$$

*Barem: 3p paranteza, 2p împărțirea.*

### 2. Intersecția graficului $f(x) = -\frac13x + \frac23$ cu axa $Ox$

$f(x) = 0 \iff x = 2$. **Răspuns:** $(2, 0)$. *Barem: 3p, 2p.*

### 3. Ecuația $2^{x^2 - 3x} = 4^{x - 2}$

$4^{x-2} = 2^{2x - 4}$, deci

$$x^2 - 3x = 2x - 4 \iff x^2 - 5x + 4 = 0 \iff x \in \{1, 4\}.$$

**Răspuns:** $x \in \{1, 4\}$. *Barem: 3p, 2p.*

### 4. Prețul înainte de o scumpire cu $10\%$, știind că după scumpire costă $594$ lei

$$1{,}1p = 594 \iff p = 540.$$

**Răspuns:** $540$ de lei. *Barem: 2p, 3p.*

### 5. Mijlocul medianei din $D$ în triunghiul $D(2,4)$, $E(-2,-2)$, $F(6,-2)$

Mijlocul lui $[EF]$: $M(2, -2)$. Mijlocul lui $[DM]$: $N\left(2, \frac{4 - 2}{2}\right) = N(2, 1)$.

**Răspuns:** $N(2, 1)$. *Barem: 3p $M$, 2p $N$.*

### 6. Perimetrul triunghiului dreptunghic în $A$ cu $\operatorname{tg}B = \frac34$, $AC = 9$

$\operatorname{tg} B = \dfrac{AC}{AB} = \dfrac34 \Rightarrow AB = 12$. $BC = \sqrt{144 + 81} = 15$.

$$P = 12 + 9 + 15 = 36.$$

**Răspuns:** $36$. *Barem: 2p $AB$, 3p perimetrul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x\circ y = xy - 2x - 2y + 6$ (asociativă).

### 1. $4\circ2$

$$8 - 8 - 4 + 6 = 2.$$

*Barem: 3p, 2p.*

### 2. Legea este comutativă

$y\circ x = yx - 2y - 2x + 6 = x\circ y$. **Răspuns:** da. *Barem: 2p, 3p.*

### 3. $x\circ y = (x - 2)(y - 2) + 2$

$$xy - 2x - 2y + 4 + 2 = x(y - 2) - 2(y - 2) + 2 = (x-2)(y-2) + 2.$$

*Barem: 2p, 3p.*

### 4. $2\circ x = 2$

$$2\circ x = 0\cdot(x - 2) + 2 = 2.$$

*Barem: 3p, 2p.*

### 5. Ecuația $x\circ x\circ x = 10$

$$(x - 2)^3 + 2 = 10 \iff (x-2)^3 = 8 \iff x = 4.$$

**Răspuns:** $x = 4$. *Barem: 2p, 3p.*

### 6. Perechile de întregi $(m, n)$ cu $m\circ n = 3$

$(m - 2)(n - 2) = 1$: ambii factori $1$ sau ambii $-1$.

**Răspuns:** $(m,n) \in \{(1,1), (3,3)\}$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$G = \left\{A(x) = \begin{pmatrix}1 - x & x\\-2x & 1 + 2x\end{pmatrix} \,\middle|\, x \in \mathbb R\right\}$.

### 1. $I_2 \in G$

$A(0) = \begin{pmatrix}1&0\\0&1\end{pmatrix} = I_2$, deci $I_2 \in G$. *Barem: 3p, 2p.*

### 2. $\det(A(1))$

$$\det\begin{pmatrix}0 & 1\\-2 & 3\end{pmatrix} = 0 + 2 = 2.$$

*Barem: 2p, 3p.*

### 3. Ecuația $A(x^2) - A(2x) = O_2$

Observăm $A(t) = I_2 + tN$, cu $N = \begin{pmatrix}-1 & 1\\-2 & 2\end{pmatrix} \ne O_2$. Deci

$$A(x^2) - A(2x) = (x^2 - 2x)N = O_2 \iff x^2 - 2x = 0 \iff x \in \{0, 2\}.$$

**Răspuns:** $x \in \{0, 2\}$. *Barem: 3p diferența, 2p soluțiile.*

### 4. Valorile lui $x$ pentru care $A(x)$ este inversabilă

$$\det A(x) = (1 - x)(1 + 2x) + 2x^2 = 1 + x.$$

$A(x)$ inversabilă $\iff 1 + x \ne 0 \iff x \ne -1$.

**Răspuns:** $x \in \mathbb R\setminus\{-1\}$. *Barem: 3p, 2p.*

### 5. $A(x)\cdot A(y) = A(x + y + xy)$

$$A(x)A(y) = \begin{pmatrix}(1-x)(1-y) - 2xy & (1-x)y + x(1+2y)\\-2x(1-y) - 2y(1+2x) & -2xy + (1+2x)(1+2y)\end{pmatrix} = \begin{pmatrix}1 - (x + y + xy) & x + y + xy\\-2(x + y + xy) & 1 + 2(x + y + xy)\end{pmatrix}.$$

Aceasta este $A(x + y + xy)$. *Barem: 3p, 2p.*

### 6. Ecuația $A(x)\cdot A(x)\cdot A(x)\cdot A(x) = A(0)$

$x + y + xy = (x+1)(y+1) - 1$, deci $A(x)^4 = A\big((x+1)^4 - 1\big)$. Cum $A(s) = A(t) \iff s = t$:

$$(x+1)^4 - 1 = 0 \iff x + 1 = \pm1 \iff x \in \{-2, 0\}.$$

**Răspuns:** $x \in \{-2, 0\}$. *Barem: 3p puterea, 2p soluțiile.*
