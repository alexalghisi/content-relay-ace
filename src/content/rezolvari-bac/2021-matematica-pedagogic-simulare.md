## Subiectul I (30 de puncte)

### 1. Suma primilor trei termeni ai progresiei aritmetice cu $a_1 = \frac12$, $a_4 = 5$

$a_4 = a_1 + 3r \Rightarrow 5 = \frac12 + 3r \Rightarrow r = \frac32$.

$$a_1 + a_2 + a_3 = 3a_1 + 3r = \frac32 + \frac92 = 6.$$

*Barem: 2p + 3p.*

### 2. $f(x) = ax + a - 2$; $a$ cu $f(1) + f(-2) = 0$

$f(1) = 2a - 2$, $f(-2) = -a - 2$. Suma: $a - 4 = 0 \iff a = 4$.

*Barem: 2p + 3p.*

### 3. Ecuația $1 + \log_6(2x + 6) = 3$

$\log_6(2x + 6) = 2 \iff 2x + 6 = 36 \iff x = 15$ (convine, $2x + 6 > 0$).

*Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr natural de o cifră să fie de forma $n^3$

10 cazuri posibile ($0, \dots, 9$). Cuburi de o cifră: $0, 1, 8$ — 3 cazuri.

$$p = \frac3{10}.$$

*Barem: 2p + 2p + 1p.*

### 5. $A(0,2)$, $B(0,6)$, $C(4,2)$, $D$ mijlocul lui $BC$; ecuația dreptei $AD$

$D\left(\frac{0+4}{2}, \frac{6+2}{2}\right) = D(2, 4)$. Panta $m_{AD} = \frac{4 - 2}{2 - 0} = 1$, deci

$$AD:\ y - 2 = x \iff y = x + 2.$$

*Barem: 2p + 3p.*

### 6. Calculați $2\sin30^\circ\cos60^\circ - \cos120^\circ$

$$2\cdot\tfrac12\cdot\tfrac12 - \left(-\tfrac12\right) = \tfrac12 + \tfrac12 = 1.$$

*Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă pe $\mathbb R$: $x * y = \dfrac{(x-1)(y-1)}{2} + 1$.

### 1. $2 * (-5) = -2$

$$2 * (-5) = \frac{1\cdot(-6)}{2} + 1 = -3 + 1 = -2.$$

*Barem: 3p + 2p.*

### 2. $e = 3$ este elementul neutru

$x * 3 = \frac{(x-1)\cdot2}{2} + 1 = x$ și $3 * x = x$, pentru orice $x$ real. $\blacksquare$ *Barem: 2p + 3p.*

### 3. $a$ cu $a * 5 = 3$

$a * 5 = \frac{(a-1)\cdot4}{2} + 1 = 2a - 1 = 3 \iff a = 2$.

*Barem: 3p + 2p.*

### 4. $x$ cu $x * (1 - x) \ge -5$

$x * (1 - x) = \frac{(x - 1)(-x)}{2} + 1 = \frac{-x^2 + x + 2}{2}$.

$$\frac{-x^2 + x + 2}{2} \ge -5 \iff -x^2 + x + 12 \ge 0 \iff x^2 - x - 12 \le 0 \iff (x - 4)(x + 3) \le 0.$$

**Răspuns:** $x \in [-3, 4]$. *Barem: 2p + 3p.*

### 5. Infinitate de $n$ naturale pentru care $N = (\sqrt n + 1) * (\sqrt n + 1)$ e natural par

$$N = \frac{\sqrt n\cdot\sqrt n}{2} + 1 = \frac n2 + 1.$$

Pentru $n = 4k + 2$, $k \in \mathbb N$: $N = 2k + 1 + 1 = 2(k + 1)$, număr natural par. Cum $k$ ia o infinitate de valori, există o infinitate de astfel de $n$. $\blacksquare$ *Barem: 2p + 3p.*

### 6. Triplete $(m, n, p)$ de naturale, $m < n < p$, cu $m * n * p = 8$

$$m * n * p = \frac{(m-1)(n-1)(p-1)}{4} + 1 = 8 \iff (m-1)(n-1)(p-1) = 28.$$

Factorii sunt distincți, $\ge -1$, cu produs pozitiv; nu poate apărea $-1$ (ar trebui doi factori negativi distincți). Deci căutăm $1 \le a < b < c$ cu $abc = 28$: $(1, 2, 14)$ și $(1, 4, 7)$.

**Răspuns:** $(2, 3, 15)$ și $(2, 5, 8)$. *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&3\\-1&1\end{pmatrix}$, $B(n) = \underbrace{A\cdot A\cdots A}_{n}$.

### 1. $\det A = 4$

$$\det A = 1\cdot1 - 3\cdot(-1) = 4.$$

*Barem: 3p + 2p.*

### 2. $\det(A + xI_2) \ge 3$

$$\det\begin{pmatrix}1 + x & 3\\ -1 & 1 + x\end{pmatrix} = (1 + x)^2 + 3 \ge 3.$$

*Barem: 3p + 2p.*

### 3. Există $a$ cu $B(3) = aI_2$

$$A^2 = \begin{pmatrix}-2&6\\-2&-2\end{pmatrix},\quad B(3) = A^2\cdot A = \begin{pmatrix}-2 - 6 & -6 + 6\\ -2 + 2 & -6 - 2\end{pmatrix} = \begin{pmatrix}-8&0\\0&-8\end{pmatrix} = -8I_2.$$

**Răspuns:** $a = -8$. *Barem: 3p + 2p.*

### 4. $m$ cu $\det(2mA + I_2) + 2m\det(A - I_2) = 0$

$$\det\begin{pmatrix}2m + 1 & 6m\\ -2m & 2m + 1\end{pmatrix} = (2m+1)^2 + 12m^2 = 16m^2 + 4m + 1,$$

$\det(A - I_2) = \det\begin{pmatrix}0&3\\-1&0\end{pmatrix} = 3$, deci $2m\cdot3 = 6m$.

$$16m^2 + 10m + 1 = 0 \iff m = \frac{-10 \pm 6}{32} \iff m \in \left\{-\tfrac12, -\tfrac18\right\}.$$

*Barem: 3p + 2p.*

### 5. Dacă $A\cdot M = M\cdot A$, $M = \begin{pmatrix}x&y\\z&t\end{pmatrix}$, atunci $x + y + 3z - t = 0$

$$AM = \begin{pmatrix}x + 3z & y + 3t\\ -x + z & -y + t\end{pmatrix},\quad MA = \begin{pmatrix}x - y & 3x + y\\ z - t & 3z + t\end{pmatrix}.$$

Din elementul $(1,1)$: $3z = -y$; din elementul $(2,2)$: $-y + t = 3z + t$ (aceeași relație); din $(2,1)$: $-x + z = z - t \Rightarrow t = x$. Atunci

$$x + y + 3z - t = x + y - y - x = 0.\ \blacksquare$$

*Barem: 2p + 3p.*

### 6. $B(6n)$ are toate elementele numere naturale

$B(6n) = A^{6n} = \left(A^3\right)^{2n} = (-8I_2)^{2n} = 64^nI_2$, ale cărei elemente sunt $64^n$ și $0$ — numere naturale. $\blacksquare$

*Barem: 3p + 2p.*

## Ce merită reținut din simulare

- **Puteri de matrice:** dacă $A^3 = kI_2$, atunci $A^{3m} = k^mI_2$.
- **Compunere multiplă** la legea $\frac{(x-1)(y-1)}{2} + 1$: $m * n * p = \frac{(m-1)(n-1)(p-1)}{4} + 1$.
- **Matrice care comută cu $A$:** egalează element cu element și extrage relațiile.
