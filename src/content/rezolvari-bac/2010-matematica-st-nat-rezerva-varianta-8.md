## Subiectul I (30 de puncte)

### 1. $\log_2(3 + \sqrt5) + \log_2(3 - \sqrt5)$

$$\log_2\big((3 + \sqrt5)(3 - \sqrt5)\big) = \log_2(9 - 5) = \log_2 4 = 2.$$

**Răspuns:** $2$. *Barem: 3p, 2p.*

### 2. $f(x) = mx^2 + 2x - 5$; $m$ pentru care abscisa vârfului parabolei este $2$

$$x_V = -\frac{b}{2a} = -\frac{2}{2m} = 2 \iff -\frac1m = 2 \iff m = -\frac12.$$

**Răspuns:** $m = -\dfrac12$. *Barem: 3p, 2p.*

### 3. Ecuația $3^{1 - x^2} = \dfrac{1}{27}$

$\frac{1}{27} = 3^{-3}$, deci $1 - x^2 = -3 \iff x^2 = 4 \iff x \in \{-2, 2\}$.

**Răspuns:** $x \in \{-2, 2\}$. *Barem: 3p, 2p.*

### 4. $C_6^2 - A_4^2$

$$C_6^2 = \frac{6!}{2!\cdot 4!} = 15, \qquad A_4^2 = \frac{4!}{2!} = 12, \qquad C_6^2 - A_4^2 = 3.$$

**Răspuns:** $3$. *Barem: 2p, 2p, 1p.*

### 5. $O(0,0)$, $A(2,-2)$, $B(6,8)$; distanța de la $O$ la mijlocul lui $(AB)$

Mijlocul: $C\left(\frac{2 + 6}{2}, \frac{-2 + 8}{2}\right) = C(4, 3)$.

$$OC = \sqrt{4^2 + 3^2} = 5.$$

**Răspuns:** $5$. *Barem: 2p, 3p.*

### 6. $\cos 130^\circ + \cos 50^\circ$

$\cos(180^\circ - x) = -\cos x$, deci $\cos 130^\circ = -\cos 50^\circ$ și

$$\cos 130^\circ + \cos 50^\circ = 0.$$

**Răspuns:** $0$. *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & -1 & -1\\ 1 & 3 & -1\\ m & 0 & 2\end{pmatrix}$ și sistemul $\begin{cases} x - y - z = -2\\ x + 3y - z = -2\\ mx + 2z = 4\end{cases}$

#### a) Determinantul matricei $A$

Regula lui Sarrus:

$$\det A = 6 + m + 0 - (-3m) - 0 - (-2) = 8 + 4m.$$

**Răspuns:** $\det A = 4m + 8$. *Barem: 3p, 2p.*

#### b) $m$ pentru care $A$ este inversabilă

$A$ inversabilă $\iff \det A \ne 0 \iff 8 + 4m \ne 0 \iff m \ne -2$.

**Răspuns:** $m \in \mathbb R\setminus\{-2\}$. *Barem: 3p, 2p.*

#### c) Rezolvați sistemul pentru $m = -1$

$\det A = 4 \ne 0$, sistem Cramer. Scăzând prima ecuație din a doua: $4y = 0$, deci $y = 0$. Rămân:

$$\begin{cases} x - z = -2\\ -x + 2z = 4\end{cases} \Rightarrow z = 2,\ x = 0.$$

**Răspuns:** $(x, y, z) = (0, 0, 2)$. *Barem: 2p, 3p.*

### 2. $x \circ y = 2xy - 2x - 2y + 3$

#### a) $x \circ y = 2(x - 1)(y - 1) + 1$

$$2(x-1)(y-1) + 1 = 2xy - 2x - 2y + 2 + 1 = x \circ y.$$

*Barem: 2p, 3p.*

#### b) Elementul neutru

Legea e comutativă; căutăm $e$ cu $x \circ e = x$ pentru orice $x$:

$$2(x-1)(e-1) + 1 = x \iff 2(x-1)(e-1) = x - 1,\ \forall x \iff 2(e - 1) = 1 \iff e = \frac32.$$

**Răspuns:** $e = \dfrac32$. *Barem: 2p, 3p.*

#### c) Un exemplu de $a, b \in \mathbb Q\setminus\mathbb Z$ cu $a \circ b \in \mathbb Z$

Alegem $a - 1 = \frac32$ și $b - 1 = \frac23$, adică $a = \frac52$, $b = \frac53$ (ambele raționale, neîntregi):

$$\frac52\circ\frac53 = 2\cdot\frac32\cdot\frac23 + 1 = 3 \in \mathbb Z.$$

**Răspuns (un exemplu):** $a = \frac52$, $b = \frac53$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = \sqrt{x^2 + 3}$

#### a) $f'(x)$

$$f'(x) = \frac{(x^2 + 3)'}{2\sqrt{x^2 + 3}} = \frac{2x}{2\sqrt{x^2+3}} = \frac{x}{\sqrt{x^2 + 3}}.$$

*Barem: 3p, 2p.*

#### b) Tangenta în $A(1, 2)$

$f(1) = 2$, $f'(1) = \dfrac12$:

$$y - 2 = \frac12(x - 1) \iff y = \frac12x + \frac32.$$

**Răspuns:** $y = \dfrac12x + \dfrac32$. *Barem: 1p, 2p, 2p.*

#### c) Asimptota oblică spre $+\infty$

$$m = \lim_{x\to+\infty}\frac{\sqrt{x^2+3}}{x} = \lim_{x\to+\infty}\sqrt{1 + \frac{3}{x^2}} = 1,$$

$$n = \lim_{x\to+\infty}\left(\sqrt{x^2+3} - x\right) = \lim_{x\to+\infty}\frac{3}{\sqrt{x^2+3} + x} = 0.$$

**Răspuns:** asimptota oblică spre $+\infty$ este $y = x$. *Barem: 2p, 1p, 1p, 1p.*

### 2. $f_n:(0, +\infty) \to \mathbb R$, $f_n(x) = x^n\ln x$

#### a) $\displaystyle\int_e^{e^2}\frac{\ln x}{f_1(x)}\,dx$

$f_1(x) = x\ln x$, deci $\dfrac{\ln x}{x\ln x} = \dfrac1x$ (pe $[e, e^2]$, $\ln x \ne 0$):

$$\int_e^{e^2}\frac1x\,dx = \ln x\Big|_e^{e^2} = 2 - 1 = 1.$$

**Răspuns:** $1$. *Barem: 1p, 1p, 1p, 2p.*

#### b) Primitivele lui $f_1$ sunt convexe pe $\left[\frac1e, +\infty\right)$

Dacă $F' = f_1$, atunci $F''(x) = f_1'(x) = \ln x + x\cdot\frac1x = 1 + \ln x$.

Pentru $x \ge \frac1e$: $\ln x \ge -1$, deci $F''(x) = 1 + \ln x \ge 0$, iar $F$ este convexă pe $\left[\frac1e, +\infty\right)$. $\blacksquare$ *Barem: 3p, 2p.*

#### c) $\displaystyle\int_1^e\frac{f_{2009}(x)}{x^{2010}}\,dx$

$\dfrac{x^{2009}\ln x}{x^{2010}} = \dfrac{\ln x}{x} = \ln x\cdot(\ln x)'$:

$$\int_1^e\frac{\ln x}{x}\,dx = \frac{\ln^2 x}{2}\Big|_1^e = \frac12 - 0 = \frac12.$$

**Răspuns:** $\dfrac12$. *Barem: 1p, 1p, 2p, 1p.*

## Ce merită reținut din varianta 8

- **Produsul conjugatelor** $(a + \sqrt b)(a - \sqrt b) = a^2 - b$ simplifică sume de logaritmi.
- **Unghiuri suplementare**: $\cos(180^\circ - x) = -\cos x$, $\sin(180^\circ - x) = \sin x$.
- **Asimptota oblică** $y = mx + n$: $m = \lim\frac{f(x)}{x}$, $n = \lim(f(x) - mx)$.
- **Convexitatea unei primitive** se studiază cu $F'' = f'$.
- **$\int\frac{\ln x}{x}dx = \frac{\ln^2 x}{2}$** — forma $u\cdot u'$.
