## Subiectul I (30 de puncte)

### 1. Rația progresiei aritmetice cu $a_3 = 6$ și $a_4 = 8$

$$r = a_4 - a_3 = 8 - 6 = 2.$$

**Răspuns:** $r = 2$. *Barem: 3p, 2p.*

### 2. Valoarea minimă a funcției $f(x) = x^2 - 9$

$x^2 \ge 0$, deci $f(x) \ge -9$, cu egalitate în $x = 0$. (Cu formula: $-\frac{\Delta}{4a} = -\frac{36}{4} = -9$.)

**Răspuns:** $-9$. *Barem: 2p, 3p.*

### 3. Ecuația $\sqrt{x^2 + 3} = x + 1$

Condiție: $x + 1 \ge 0$. Ridicăm la pătrat:

$$x^2 + 3 = x^2 + 2x + 1 \iff 2x = 2 \iff x = 1,$$

care verifică ($\sqrt4 = 2$). **Răspuns:** $x = 1$. *Barem: 3p, 2p.*

### 4. Numărul submulțimilor cu două elemente ale mulțimii $\{1, 2, \dots, 7\}$

$$C_7^2 = \frac{7!}{2!\cdot 5!} = 21.$$

**Răspuns:** $21$. *Barem: 3p, 2p.*

### 5. Ecuația dreptei $AB$, $A(2, 1)$, $B(0, 3)$

$$\frac{y - 1}{3 - 1} = \frac{x - 2}{0 - 2} \iff y - 1 = -(x - 2) \iff y = -x + 3.$$

**Răspuns:** $y = -x + 3$. *Barem: 3p, 2p.*

### 6. Raza cercului circumscris triunghiului cu $AB = 8$ și $C = \frac\pi6$

Teorema sinusurilor: $\dfrac{AB}{\sin C} = 2R$, deci

$$R = \frac{8}{2\cdot\frac12} = 8.$$

**Răspuns:** $R = 8$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 2\\ 3 & 4\end{pmatrix}$, $B(x) = \begin{pmatrix} x & 2\\ 3 & 6\end{pmatrix}$

#### a) $\det A = -2$

$$\det A = 1\cdot 4 - 2\cdot 3 = -2.$$

*Barem: 3p, 2p.*

#### b) Ecuația $\det(B(x) + I_2) = 8$

$$B(x) + I_2 = \begin{pmatrix} x + 1 & 2\\ 3 & 7\end{pmatrix}, \quad \det = 7(x + 1) - 6 = 7x + 1.$$

$7x + 1 = 8 \iff x = 1$.

**Răspuns:** $x = 1$. *Barem: 3p, 2p.*

#### c) $x$ cu $A\cdot B(x) = B(x)\cdot A$

$$A\cdot B(x) = \begin{pmatrix} x + 6 & 14\\ 3x + 12 & 30\end{pmatrix}, \qquad B(x)\cdot A = \begin{pmatrix} x + 6 & 2x + 8\\ 21 & 30\end{pmatrix}.$$

Egalitatea cere $2x + 8 = 14$ și $3x + 12 = 21$, adică $x = 3$ (ambele condiții).

**Răspuns:** $x = 3$. *Barem: 2p, 2p, 1p.*

### 2. $x * y = xy - 7x - 7y + 56$ (asociativă)

#### a) $(-7) * 7 = 7$

$$(-7) * 7 = -49 + 49 - 49 + 56 = 7.$$

*Barem: 3p, 2p.*

#### b) $x * y = (x - 7)(y - 7) + 7$

$$(x - 7)(y - 7) + 7 = xy - 7x - 7y + 49 + 7 = x * y.$$

*Barem: 2p, 3p.*

#### c) $1 * 2 * 3 * \dots * 2015$

Din b), $x * 7 = 7 * y = 7$ — **$7$ este element absorbant**. Prin asociativitate:

$$(1 * 2 * \dots * 6) * 7 * (8 * 9 * \dots * 2015) = 7.$$

**Răspuns:** $7$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0, +\infty) \to \mathbb R$, $f(x) = e^x - \ln x + x$

#### a) $\lim\limits_{x\to 1}\dfrac{f(x) - f(1)}{x - 1} = e$

Limita este $f'(1)$. $f'(x) = e^x - \dfrac1x + 1$, deci $f'(1) = e - 1 + 1 = e$. *Barem: 2p, 3p.*

#### b) Tangenta în punctul de abscisă $x = 1$

$f(1) = e + 1$, $f'(1) = e$:

$$y - (e + 1) = e(x - 1) \iff y = ex + 1.$$

**Răspuns:** $y = ex + 1$. *Barem: 2p, 3p.*

#### c) $f$ este convexă pe $(0, +\infty)$

$f''(x) = e^x + \dfrac{1}{x^2} > 0$, deci $f$ este convexă. *Barem: 2p, 3p.*

### 2. $f:(-1, +\infty) \to \mathbb R$, $f(x) = \dfrac{1}{x + 1}$

#### a) $\displaystyle\int_0^1\frac{1}{f(x)}\,dx = \frac32$

$$\int_0^1(x + 1)\,dx = \left(\frac{x^2}{2} + x\right)\Big|_0^1 = \frac32.$$

*Barem: 3p, 2p.*

#### b) $\displaystyle\int_0^1 x^2 f(x)\,dx = -\frac12 + \ln 2$

$\dfrac{x^2}{x + 1} = x - 1 + \dfrac{1}{x + 1}$, deci

$$\int_0^1\left(x - 1 + \frac{1}{x+1}\right)dx = \left(\frac{x^2}{2} - x + \ln(x + 1)\right)\Big|_0^1 = \frac12 - 1 + \ln 2 = -\frac12 + \ln 2.$$

*Barem: 3p, 2p.*

#### c) Volumul corpului de rotație pentru $g:[0, 1] \to \mathbb R$, $g = f$

$$V = \pi\int_0^1\frac{dx}{(x+1)^2} = \pi\left(-\frac{1}{x+1}\right)\Big|_0^1 = \pi\left(-\frac12 + 1\right) = \frac\pi2.$$

**Răspuns:** $V = \dfrac\pi2$. *Barem: 3p, 2p.*
