## Subiectul I (30 de puncte)

### 1. $\dfrac{2}{\sqrt3 - 1} - \sqrt3 = 1$

Raționalizăm: $\dfrac{2(\sqrt3 + 1)}{3 - 1} = \sqrt3 + 1$, deci $\sqrt3 + 1 - \sqrt3 = 1$. *Barem: 3p, 2p.*

### 2. Intersecția graficului lui $f(x) = 2x^2 + x + 2015$ cu $Oy$

$f(0) = 2015$. **Răspuns:** $(0, 2015)$. *Barem: 3p, 2p.*

### 3. $\sqrt{x + 2} = 2$

$x + 2 = 4 \iff x = 2$, care verifică. **Răspuns:** $x = 2$. *Barem: 2p, 3p.*

### 4. După o reducere cu $10\%$ obiectul costă 99 lei; prețul inițial

$p - \dfrac{10}{100}p = 99 \iff \dfrac{9}{10}p = 99 \iff p = 110$.

**Răspuns:** 110 lei. *Barem: 3p, 2p.*

### 5. Lungimea segmentului $MN$, $M(2,1)$, $N(4,1)$

$MN = \sqrt{(4 - 2)^2 + 0} = 2$. *Barem: 3p, 2p.*

### 6. $\sin x = \dfrac45$, știind $x \in \left(0, \dfrac\pi2\right)$ și $\cos x = \dfrac35$

$\sin^2 x = 1 - \dfrac{9}{25} = \dfrac{16}{25}$, iar în cadranul I $\sin x > 0$, deci $\sin x = \dfrac45$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 2 & 1\\ 2 & 1\end{pmatrix}$

#### a) $\det A = 0$

$2\cdot 1 - 2\cdot 1 = 0$. *Barem: 2p, 3p.*

#### b) $x$ cu $A\cdot A = xA$

$$A\cdot A = \begin{pmatrix} 4 + 2 & 2 + 1\\ 4 + 2 & 2 + 1\end{pmatrix} = \begin{pmatrix} 6 & 3\\ 6 & 3\end{pmatrix} = 3A.$$

**Răspuns:** $x = 3$. *Barem: 3p, 2p.*

#### c) $\det(A + I_2) + \det(A - I_2) = 2$

$$\det\begin{pmatrix} 3 & 1\\ 2 & 2\end{pmatrix} = 6 - 2 = 4, \qquad \det\begin{pmatrix} 1 & 1\\ 2 & 0\end{pmatrix} = 0 - 2 = -2.$$

Suma: $4 - 2 = 2$. *Barem: 3p, 2p.*

### 2. $f = X^3 - 2X^2 - 2X + 1$

#### a) $f(1) = -2$

$1 - 2 - 2 + 1 = -2$. *Barem: 3p, 2p.*

#### b) $X + 1 \mid f$

$f(-1) = -1 - 2 + 2 + 1 = 0$, deci (Bézout) $X + 1$ divide $f$. *Barem: 3p, 2p.*

#### c) $a$ cu $\dfrac1{x_1x_2} + \dfrac1{x_2x_3} + \dfrac1{x_3x_1} = a(x_1x_2 + x_2x_3 + x_3x_1)$

Viète: $\sum x_i = 2$, $\sum x_ix_j = -2$, $x_1x_2x_3 = -1$.

$$\frac1{x_1x_2} + \frac1{x_2x_3} + \frac1{x_3x_1} = \frac{x_3 + x_1 + x_2}{x_1x_2x_3} = \frac{2}{-1} = -2.$$

$-2 = a\cdot(-2) \iff a = 1$.

**Răspuns:** $a = 1$. *Barem: 3p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0, +\infty) \to \mathbb R$, $f(x) = x - \dfrac1x$

#### a) $f'(x) = 1 + \dfrac1{x^2}$

$\left(\dfrac1x\right)' = -\dfrac1{x^2}$, deci $f'(x) = 1 + \dfrac1{x^2}$. *Barem: 2p, 3p.*

#### b) Asimptota oblică spre $+\infty$

$$m = \lim_{x\to\infty}\frac{x^2 - 1}{x^2} = 1, \qquad n = \lim_{x\to\infty}\left(-\frac1x\right) = 0.$$

**Răspuns:** $y = x$. *Barem: 2p, 3p.*

#### c) $f$ concavă pe $(0, +\infty)$

$f''(x) = -\dfrac{2}{x^3} < 0$ pentru $x > 0$. *Barem: 2p, 3p.*

### 2. $f(x) = x^2 + 2$

#### a) $\displaystyle\int_0^1(f(x) - 2)\,dx = \frac13$

$\displaystyle\int_0^1 x^2\,dx = \frac13$. *Barem: 3p, 2p.*

#### b) Primitiva $F$ cu $F(3) = 5$

$F(x) = \dfrac{x^3}{3} + 2x + c$; $F(3) = 9 + 6 + c = 5 \Rightarrow c = -10$.

**Răspuns:** $F(x) = \dfrac{x^3}{3} + 2x - 10$. *Barem: 2p, 3p.*

#### c) Aria pentru $g(x) = e^xf(x)$ între $x = 0$ și $x = 1$ este $3e - 4$

$g > 0$. Integrând de două ori prin părți (sau verificând că $\big(e^x(x^2 - 2x + 4)\big)' = e^x(x^2 + 2)$):

$$\mathcal A = \int_0^1 e^x(x^2 + 2)\,dx = e^x(x^2 - 2x + 4)\Big|_0^1 = 3e - 4. \ \blacksquare$$

*Barem: 3p, 2p.*
