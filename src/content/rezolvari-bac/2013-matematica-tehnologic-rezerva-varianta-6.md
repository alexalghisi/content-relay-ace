## Subiectul I (30 de puncte)

### 1. $2(5 - \sqrt2) + 2\sqrt2 = 10$

$10 - 2\sqrt2 + 2\sqrt2 = 10$. *Barem: 2p, 3p.*

### 2. $f(x) = x^2 - 9$: $f(-3) + f(3)$

$f(-3) = 9 - 9 = 0$, $f(3) = 0$, suma $0$.

**Răspuns:** $0$. *Barem: 2p, 2p, 1p.*

### 3. $5^{2x} = 25$

$25 = 5^2$, deci $2x = 2 \iff x = 1$.

**Răspuns:** $x = 1$. *Barem: 2p, 3p.*

### 4. Prețul de 100 lei după o scumpire cu $20\%$

Scumpirea: $20\%\cdot 100 = 20$ lei, deci noul preț este $120$ lei.

**Răspuns:** 120 de lei. *Barem: 2p, 3p.*

### 5. Distanța $AB$, $A(1,1)$, $B(3,1)$

$$AB = \sqrt{(3 - 1)^2 + (1 - 1)^2} = 2.$$

**Răspuns:** $AB = 2$. *Barem: 3p, 2p.*

### 6. $\cos 30^\circ + \cos 150^\circ$

$\cos 150^\circ = \cos(180^\circ - 30^\circ) = -\cos 30^\circ = -\dfrac{\sqrt3}{2}$, deci suma este $\dfrac{\sqrt3}{2} - \dfrac{\sqrt3}{2} = 0$.

**Răspuns:** $0$. *Barem: 2p, 2p, 1p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & -1\\ 0 & 1\end{pmatrix}$, $B = \begin{pmatrix} x & -1\\ 0 & x\end{pmatrix}$

#### a) $\det A$

$1\cdot 1 - (-1)\cdot 0 = 1$. *Barem: 3p, 2p.*

#### b) Pentru $x = 0$: $A - B = I_2$

$$A - B = \begin{pmatrix} 1 & -1\\ 0 & 1\end{pmatrix} - \begin{pmatrix} 0 & -1\\ 0 & 0\end{pmatrix} = \begin{pmatrix} 1 & 0\\ 0 & 1\end{pmatrix} = I_2.$$

*Barem: 2p, 3p.*

#### c) $x$ cu $\det(A + B) = 0$

$A + B = \begin{pmatrix} 1 + x & -2\\ 0 & 1 + x\end{pmatrix}$, $\det = (1 + x)^2 = 0 \iff x = -1$.

**Răspuns:** $x = -1$. *Barem: 3p, 2p.*

### 2. Legea $x\circ y = x + y + 3$

#### a) $2\circ(-2)$

$2 - 2 + 3 = 3$. **Răspuns:** $3$. *Barem: 3p, 2p.*

#### b) $e = -3$ este element neutru

$x\circ(-3) = x - 3 + 3 = x$ și $(-3)\circ x = x$, pentru orice $x$. *Barem: 2p, 3p.*

#### c) $2013\circ(-2013) = x\circ x$

$2013\circ(-2013) = 3$, iar $x\circ x = 2x + 3$; $2x + 3 = 3 \iff x = 0$.

**Răspuns:** $x = 0$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0, +\infty) \to \mathbb R$, $f(x) = \dfrac{x+1}{x}$

#### a) $\lim\limits_{x\to+\infty} f(x)$

$$\lim_{x\to+\infty}\left(1 + \frac1x\right) = 1.$$

**Răspuns:** $1$. *Barem: 3p, 2p.*

#### b) $f$ descrescătoare pe $(0, +\infty)$

$f(x) = 1 + \dfrac1x$, $f'(x) = -\dfrac{1}{x^2} < 0$. *Barem: 2p, 3p.*

#### c) Tangenta în $x_0 = 1$

$f(1) = 2$, $f'(1) = -1$: $y - 2 = -(x - 1) \iff y = -x + 3$.

**Răspuns:** $y = -x + 3$. *Barem: 2p, 3p.*

### 2. $f(x) = 3x^2 + 1$

#### a) $\displaystyle\int_0^1 f'(x)\,dx$

$$\int_0^1 f'(x)\,dx = f(1) - f(0) = 4 - 1 = 3.$$

**Răspuns:** $3$. *Barem: 3p, 2p.*

#### b) $F(x) = x^3 + x + 1$ este primitivă a lui $f$

$F'(x) = 3x^2 + 1 = f(x)$. *Barem: 3p, 2p.*

#### c) Aria între grafic, $Ox$, $x = 0$, $x = 1$

$f > 0$, deci

$$\mathcal A = \int_0^1(3x^2 + 1)\,dx = (x^3 + x)\Big|_0^1 = 2.$$

**Răspuns:** $2$. *Barem: 2p, 3p.*
