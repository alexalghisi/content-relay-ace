## Subiectul I (30 de puncte)

### 1. Arătați că $2(2 + \sqrt3) - 2\sqrt3 = 4$

$$2(2 + \sqrt3) - 2\sqrt3 = 4 + 2\sqrt3 - 2\sqrt3 = 4.$$

*Barem: 2p + 3p.*

### 2. $f(x) = x + 4$; calculați $f(4) + f(-4)$

$f(4) = 8$, $f(-4) = 0$, suma este $8$. *Barem: 2p + 2p + 1p.*

### 3. Ecuația $7^{2x} = 49$

$7^{2x} = 7^2 \iff 2x = 2 \iff x = 1$. *Barem: 2p + 3p.*

### 4. Prețul de 1000 lei după o scumpire cu 10%

Scumpirea: $\frac{10}{100}\cdot1000 = 100$ lei, deci prețul nou este $1100$ lei. *Barem: 2p + 3p.*

### 5. Distanța dintre $A(4,3)$ și $B(4,1)$

$$AB = \sqrt{(4-4)^2 + (1-3)^2} = 2.$$

*Barem: 3p + 2p.*

### 6. Calculați $\sin45^\circ - \sin135^\circ$

$\sin135^\circ = \sin(180^\circ - 45^\circ) = \sin45^\circ = \frac{\sqrt2}{2}$, deci diferența este $0$. *Barem: 2p + 2p + 1p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} -1 & 2\\ 2 & 1\end{pmatrix}$, $B = \begin{pmatrix} 1 & m\\ m & m+1\end{pmatrix}$

#### a) $\det A$

$$\det A = (-1)\cdot1 - 2\cdot2 = -5.$$

*Barem: 3p + 2p.*

#### b) Pentru $m = -2$, $A + B = O_2$

$$A + B = \begin{pmatrix} -1 & 2\\ 2 & 1\end{pmatrix} + \begin{pmatrix} 1 & -2\\ -2 & -1\end{pmatrix} = \begin{pmatrix} 0 & 0\\ 0 & 0\end{pmatrix} = O_2.$$

*Barem: 3p + 2p.*

#### c) $m$ cu $A\cdot B = \begin{pmatrix} 9 & 7\\ 7 & 16\end{pmatrix}$

$$A\cdot B = \begin{pmatrix} -1 + 2m & -m + 2m + 2\\ 2 + m & 2m + m + 1\end{pmatrix} = \begin{pmatrix} 2m - 1 & m + 2\\ m + 2 & 3m + 1\end{pmatrix}.$$

$2m - 1 = 9$, $m + 2 = 7$, $3m + 1 = 16$ — toate dau $m = 5$.

**Răspuns:** $m = 5$. *Barem: 3p + 2p.*

### 2. $f = X^3 + 2X^2 + X$

#### a) $f(-1) = 0$

$$f(-1) = -1 + 2 - 1 = 0.$$

*Barem: 2p + 3p.*

#### b) Câtul și restul împărțirii la $g = X^2 + X$

$f = X(X^2 + 2X + 1) = X(X+1)^2$, iar $g = X(X+1)$. Deci $f = g\cdot(X + 1)$.

**Răspuns:** câtul $X + 1$, restul $0$. *Barem: 2p + 3p.*

#### c) $x_1^2 + x_2^2 + x_3^2$

Viète: $\sum x_i = -2$, $\sum x_ix_j = 1$.

$$x_1^2 + x_2^2 + x_3^2 = (-2)^2 - 2\cdot1 = 2.$$

(Verificare: rădăcinile sunt $0, -1, -1$ și $0 + 1 + 1 = 2$ ✔.) *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0,+\infty)\to\mathbb R$, $f(x) = x + 10 - \frac{11}{x}$

#### a) $f'(x) = \dfrac{x^2 + 11}{x^2}$

$$f'(x) = 1 + \frac{11}{x^2} = \frac{x^2 + 11}{x^2}.$$

**Răspuns:** da. *Barem: 3p + 2p.*

#### b) $f$ crescătoare pe $(0, +\infty)$

$x^2 + 11 > 0$ și $x^2 > 0$, deci $f'(x) > 0$ și $f$ este crescătoare. *Barem: 3p + 2p.*

#### c) $f$ concavă pe $(0, +\infty)$

$$f''(x) = \left(1 + 11x^{-2}\right)' = -\frac{22}{x^3} < 0 \quad\text{pentru } x > 0,$$

deci $f$ este concavă. *Barem: 2p + 3p.*

### 2. $f(x) = x^2 + 9$

#### a) $\displaystyle\int_1^2 f'(x)\,dx$

$$\int_1^2 f'(x)\,dx = f(2) - f(1) = 13 - 10 = 3.$$

*Barem: 3p + 2p.*

#### b) $\displaystyle\int_1^2\frac{f(x)}{x}\,dx = \frac32 + 9\ln2$

$$\int_1^2\left(x + \frac9x\right)dx = \left(\frac{x^2}{2} + 9\ln x\right)\Big|_1^2 = 2 - \frac12 + 9\ln2 = \frac32 + 9\ln2.$$

*Barem: 2p + 3p.*

#### c) Volumul pentru $g(x) = f(x) - x^2 = 9$ pe $[0,1]$

$$V = \pi\int_0^1 81\,dx = 81\pi.$$

(Corpul este un cilindru cu raza $9$ și înălțimea $1$.) *Barem: 2p + 3p.*

## Ce merită reținut din varianta 4

- **$\int_a^b f'(x)\,dx = f(b) - f(a)$** — nu e nevoie să calculezi derivata.
- **Factorizarea polinomului** ($X(X+1)^2$) face împărțirea imediată.
- **Monotonie / convexitate**: semnul lui $f'$, respectiv $f''$.
- **Rotația unei funcții constante** $g = c$ pe $[a,b]$ dă un cilindru: $V = \pi c^2(b - a)$.
