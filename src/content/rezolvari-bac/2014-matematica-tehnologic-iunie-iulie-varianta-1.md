## Subiectul I (30 de puncte)

### 1. Arătați că $5(2 + \sqrt3) - 5\sqrt3 = 10$

$$5(2 + \sqrt3) - 5\sqrt3 = 10 + 5\sqrt3 - 5\sqrt3 = 10.$$

*Barem: 3p + 2p.*

### 2. $a$ cu $f(1) = a$, $f(x) = x + 3$

$a = f(1) = 1 + 3 = 4$. *Barem: 3p + 2p.*

### 3. Ecuația $\log_2(2x + 1) = \log_2 5$

$2x + 1 = 5 \iff x = 2$, care verifică ($2x + 1 = 5 > 0$). *Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr de două cifre să fie divizibil cu 10

Favorabile: $10, 20, \dots, 90$ — 9; posibile: 90.

$$p = \frac{9}{90} = \frac{1}{10}.$$

*Barem: 2p + 1p + 2p.*

### 5. Distanța dintre $A(2,5)$ și $B(3,5)$

$$AB = \sqrt{(2-3)^2 + (5-5)^2} = 1.$$

*Barem: 3p + 2p.*

### 6. $\sin^2 30^\circ + \cos^2 45^\circ = \frac34$

$$\left(\frac12\right)^2 + \left(\frac{\sqrt2}{2}\right)^2 = \frac14 + \frac24 = \frac34.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 4 & 8\\ 1 & 2\end{pmatrix}$, $B = \begin{pmatrix} 1 & 2\\ -1 & -2\end{pmatrix}$, $C = \begin{pmatrix} 3 & x\\ 2 & 4\end{pmatrix}$

#### a) $\det A = 0$

$$\det A = 4\cdot2 - 1\cdot8 = 0.$$

*Barem: 2p + 3p.*

#### b) $x$ cu $B + C = A$

$$B + C = \begin{pmatrix} 4 & 2 + x\\ 1 & 2\end{pmatrix} = \begin{pmatrix} 4 & 8\\ 1 & 2\end{pmatrix} \iff 2 + x = 8 \iff x = 6.$$

*Barem: 3p + 2p.*

#### c) $B\cdot B + B = O_2$

$$B\cdot B = \begin{pmatrix} 1 - 2 & 2 - 4\\ -1 + 2 & -2 + 4\end{pmatrix} = \begin{pmatrix} -1 & -2\\ 1 & 2\end{pmatrix} = -B,$$

deci $B\cdot B + B = -B + B = O_2$. $\blacksquare$ *Barem: 3p + 2p.*

### 2. $x\circ y = xy + 4x + 4y + 12$

#### a) $0\circ(-4) = -4$

$$0 + 0 - 16 + 12 = -4.$$

*Barem: 3p + 2p.*

#### b) $x\circ y = (x+4)(y+4) - 4$

$$xy + 4x + 4y + 16 - 4 = x(y+4) + 4(y+4) - 4 = (x+4)(y+4) - 4.$$

*Barem: 2p + 3p.*

#### c) $x\circ x = 12$

$$(x+4)^2 - 4 = 12 \iff (x+4)^2 = 16 \iff x + 4 = \pm4 \iff x \in \{-8, 0\}.$$

*Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0,+\infty)\to\mathbb R$, $f(x) = \ln x - \frac1x$

#### a) $f'(x) = \dfrac{x+1}{x^2}$

$$f'(x) = \frac1x + \frac{1}{x^2} = \frac{x + 1}{x^2}.$$

*Barem: 3p + 2p.*

#### b) $\lim\limits_{x\to2}\dfrac{f(x) - f(2)}{x - 2} = \dfrac34$

Limita este $f'(2) = \dfrac{2+1}{4} = \dfrac34$. *Barem: 3p + 2p.*

#### c) Tangenta în $x_0 = 1$

$f(1) = 0 - 1 = -1$, $f'(1) = 2$.

$$y + 1 = 2(x - 1) \iff y = 2x - 3.$$

*Barem: 2p + 3p.*

### 2. $f(x) = e^x - x$, $F(x) = e^x - \frac{x^2}{2} - 1$

#### a) $\displaystyle\int_0^1 e^x\,dx = e - 1$

$$e^x\Big|_0^1 = e - 1.$$

*Barem: 3p + 2p.*

#### b) $F$ este primitivă a lui $f$

$$F'(x) = e^x - x = f(x).$$

*Barem: 3p + 2p.*

#### c) $\displaystyle\int_0^1 F(x)\,dx$

$$\int_0^1\left(e^x - \frac{x^2}{2} - 1\right)dx = (e - 1) - \frac{x^3}{6}\Big|_0^1 - 1 = e - 1 - \frac16 - 1 = e - \frac{13}{6}.$$

**Răspuns:** $e - \dfrac{13}{6}$. *Barem: 2p + 3p.*

## Ce merită reținut din varianta 1

- **Legea $(x+a)(y+a) - a$**: ecuația $x\circ x = c$ devine $(x+a)^2 = c + a$.
- **Dacă $B^2 = -B$**, atunci $B^2 + B = O_2$ fără alte calcule.
- **Limita $\frac{f(x)-f(a)}{x-a}$** este $f'(a)$.
- **Integrala unei sume** = suma integralelor; separă termenii.
