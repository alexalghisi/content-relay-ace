## Subiectul I (30 de puncte)

### 1. Arătați că $1 - \frac14 : 0{,}25 = 0$

$0{,}25 = \frac14$, deci $\frac14 : \frac14 = 1$ și $1 - 1 = 0$. *Barem: 3p + 2p.*

### 2. $f(x) = x + 1$; calculați $f(-1)\cdot f(1)$

$f(-1) = 0$, deci produsul este $0$. *Barem: 3p + 2p.*

### 3. Ecuația $\sqrt{2x - 3} = 5$

$2x - 3 = 25 \iff x = 14$, care verifică. *Barem: 3p + 2p.*

### 4. Prețul de 100 lei după o scumpire cu 20%

$\frac{20}{100}\cdot100 = 20$ lei, deci prețul nou este $120$ lei. *Barem: 3p + 2p.*

### 5. Distanța dintre $A(2,4)$ și $B(5,4)$

$$AB = \sqrt{3^2 + 0^2} = 3.$$

*Barem: 3p + 2p.*

### 6. Triunghi dreptunghic în $A$, $AC = 6$, $B = \frac\pi4$; aflați $AB$

$C = \frac\pi2 - \frac\pi4 = \frac\pi4 = B$, deci triunghiul este isoscel: $AB = AC = 6$. *Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 2\\ 1 & -2\end{pmatrix}$, $B = \begin{pmatrix} x & 1\\ y & -1\end{pmatrix}$

#### a) $\det A = -4$

$$\det A = -2 - 2 = -4.$$

*Barem: 3p + 2p.*

#### b) $\det(A - 2B) = 0$

$$A - 2B = \begin{pmatrix} 1 - 2x & 0\\ 1 - 2y & 0\end{pmatrix}.$$

A doua coloană este nulă, deci $\det(A - 2B) = 0$ pentru orice $x, y$. *Barem: 2p + 3p.*

#### c) $x, y$ cu $A\cdot B = B\cdot A$

$$A\cdot B = \begin{pmatrix} x + 2y & -1\\ x - 2y & 3\end{pmatrix}, \qquad B\cdot A = \begin{pmatrix} x + 1 & 2x - 2\\ y - 1 & 2y + 2\end{pmatrix}.$$

Din $(1,1)$: $2y = 1 \Rightarrow y = \frac12$. Din $(1,2)$: $2x - 2 = -1 \Rightarrow x = \frac12$. Verificare: $(2,1)$: $\frac12 - 1 = -\frac12 = \frac12 - 1$ ✔; $(2,2)$: $3 = 1 + 2$ ✔.

**Răspuns:** $x = y = \dfrac12$. *Barem: 2p + 3p.*

### 2. $x\circ y = xy + 2x + 2y + 2$

#### a) $1\circ(-2) = -2$

$$-2 + 2 - 4 + 2 = -2.$$

*Barem: 3p + 2p.*

#### b) $x\circ y = (x+2)(y+2) - 2$

$$xy + 2x + 2y + 4 - 2 = x(y+2) + 2(y+2) - 2 = (x+2)(y+2) - 2.$$

*Barem: 3p + 2p.*

#### c) $x \ne 0$ cu $x\circ\frac1x = x$

$$(x + 2)\left(\frac1x + 2\right) - 2 = x \iff (x+2)\left(\frac1x + 2\right) = x + 2 \iff (x + 2)\left(\frac1x + 1\right) = 0.$$

$x = -2$ sau $\frac1x = -1 \Rightarrow x = -1$.

**Răspuns:** $x \in \{-2, -1\}$. *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^3 + x^2 - x + 1$

#### a) $f'(x) = 3x^2 + 2x - 1$

Derivăm termen cu termen: $3x^2 + 2x - 1 + 0$. *Barem: 2p + 3p.*

#### b) $\lim\limits_{x\to+\infty}\dfrac{xf'(x)}{f(x)} = 3$

$$\lim_{x\to+\infty}\frac{3x^3 + 2x^2 - x}{x^3 + x^2 - x + 1} = \frac31 = 3.$$

*Barem: 2p + 3p.*

#### c) Punctele în care tangenta este paralelă cu $y = 4x + 1$

Tangenta paralelă $\iff$ aceeași pantă: $f'(x) = 4$.

$$3x^2 + 2x - 1 = 4 \iff 3x^2 + 2x - 5 = 0 \iff (x - 1)(3x + 5) = 0.$$

**Răspuns:** $x \in \left\{-\dfrac53, 1\right\}$. *Barem: 2p + 3p.*

### 2. $f(x) = x^5 + x^3 + 2x$

#### a) $\displaystyle\int_{-1}^1(f(x) - x^3 - 2x)\,dx = 0$

$$\int_{-1}^1 x^5\,dx = \frac{x^6}{6}\Big|_{-1}^1 = 0.$$

*Barem: 2p + 3p.*

#### b) $\displaystyle\int_0^2 e^x\big(f(x) - x^5 - x^3 + 1\big)dx = 3e^2 + 1$

$f(x) - x^5 - x^3 + 1 = 2x + 1$. Prin părți:

$$\int_0^2 e^x(2x + 1)\,dx = e^x(2x + 1)\Big|_0^2 - 2\int_0^2 e^x\,dx = (5e^2 - 1) - 2(e^2 - 1) = 3e^2 + 1.$$

*Barem: 3p + 2p.*

#### c) Orice primitivă a lui $f$ este convexă pe $\mathbb R$

Dacă $F' = f$, atunci $F''(x) = f'(x) = 5x^4 + 3x^2 + 2 > 0$ pentru orice $x$, deci $F$ este convexă. $\blacksquare$ *Barem: 2p + 3p.*
