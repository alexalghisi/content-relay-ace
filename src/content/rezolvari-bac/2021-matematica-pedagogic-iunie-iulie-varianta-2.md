## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt2\cdot(3 + \sqrt2) - \sqrt{18} = 2$

$$\sqrt2(3 + \sqrt2) - \sqrt{18} = 3\sqrt2 + 2 - 3\sqrt2 = 2.$$

*Barem: 2p + 3p.*

### 2. $f(x) = x + 1$, $g(x) = 3x + 7$; $a$ cu $f(a) = g(a)$

$$a + 1 = 3a + 7 \iff -2a = 6 \iff a = -3.$$

*Barem: 3p + 2p.*

### 3. Ecuația $\sqrt{4 + 2x} = 4$

$4 + 2x = 16 \iff x = 6$ (convine: $\sqrt{16} = 4$).

*Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr natural nenul de o cifră să fie divizor al lui 18

9 cazuri posibile ($1, \dots, 9$). Divizorii lui 18 de o cifră: $1, 2, 3, 6, 9$ — 5 cazuri.

$$p = \frac59.$$

*Barem: 2p + 2p + 1p.*

### 5. $A(-1, 2)$, $B(3, a)$; $A$ aparține dreptei $OB$

$O, A, B$ coliniare $\iff m_{OA} = m_{OB}$: $\dfrac{2}{-1} = \dfrac a3 \iff a = -6$.

**Răspuns:** $a = -6$. *Barem: 2p + 3p.*

### 6. $\triangle ABC$ dreptunghic în $A$, $BC = 4$, $\angle C = 2\angle B$; lungimea lui $AC$

$\angle B + \angle C = 90^\circ$ și $\angle C = 2\angle B$ $\Rightarrow 3\angle B = 90^\circ$, $\angle B = 30^\circ$. Cateta opusă unghiului de $30^\circ$ este $AC$:

$$AC = \frac{BC}{2} = 2.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = 3x + 3y - 3xy - 2$.

### 1. $1 * 2 = 1$

$$1 * 2 = 3 + 6 - 6 - 2 = 1.$$

*Barem: 3p + 2p.*

### 2. $x * y = 1 - 3(x - 1)(y - 1)$

$$1 - 3(x-1)(y-1) = 1 - 3xy + 3x + 3y - 3 = 3x + 3y - 3xy - 2 = x * y.$$

*Barem: 3p + 2p.*

### 3. $e = \frac23$ este elementul neutru

$$x * \tfrac23 = 1 - 3(x - 1)\left(-\tfrac13\right) = 1 + x - 1 = x,$$

și analog $\tfrac23 * x = x$. $\blacksquare$ *Barem: 2p + 3p.*

### 4. $x$ cu $(2 - x) * 2 = 2 + x$

$(2 - x) * 2 = 1 - 3(1 - x)\cdot1 = 3x - 2$. Atunci $3x - 2 = 2 + x \iff x = 2$.

*Barem: 3p + 2p.*

### 5. Perechile $(m,n)$ de numere naturale cu $m * n = 19$

$1 - 3(m-1)(n-1) = 19 \iff (m-1)(n-1) = -6$.

Cum $m - 1 \ge -1$ și $n - 1 \ge -1$, un factor trebuie să fie $-1$ și celălalt $6$: $(m,n) = (0, 7)$ sau $(7, 0)$.

**Răspuns:** $(0,7)$ și $(7,0)$. *Barem: 2p + 3p.*

### 6. $a$ cu $(a * 1) + (a * 2) + (a * 3) = 3a^2$

$a * 1 = 1$, $a * 2 = 1 - 3(a - 1) = 4 - 3a$, $a * 3 = 1 - 6(a - 1) = 7 - 6a$. Suma: $12 - 9a$.

$$12 - 9a = 3a^2 \iff a^2 + 3a - 4 = 0 \iff a \in \{-4, 1\}.$$

*Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&-1\\-2&4\end{pmatrix}$, $B(x) = \begin{pmatrix}x - 2 & -x\\ -2x & 4x - 2\end{pmatrix}$.

### 1. $\det A = 2$

$$\det A = 1\cdot4 - (-1)(-2) = 4 - 2 = 2.$$

*Barem: 3p + 2p.*

### 2. $xA - 2I_2 = B(x)$

$$xA - 2I_2 = \begin{pmatrix}x & -x\\ -2x & 4x\end{pmatrix} - \begin{pmatrix}2&0\\0&2\end{pmatrix} = \begin{pmatrix}x - 2 & -x\\ -2x & 4x - 2\end{pmatrix} = B(x).$$

*Barem: 3p + 2p.*

### 3. $A\cdot A = B(5)$

$$A\cdot A = \begin{pmatrix}1 + 2 & -1 - 4\\ -2 - 8 & 2 + 16\end{pmatrix} = \begin{pmatrix}3&-5\\-10&18\end{pmatrix},\quad B(5) = \begin{pmatrix}3&-5\\-10&18\end{pmatrix}.$$

*Barem: 3p + 2p.*

### 4. $x$ cu $\det B(x) = 4$

$$\det B(x) = (x-2)(4x-2) - 2x^2 = 2x^2 - 10x + 4 = 4 \iff x(x - 5) = 0.$$

**Răspuns:** $x \in \{0, 5\}$. *Barem: 3p + 2p.*

### 5. $B(xy) - xB(y) = 2(x - 1)I_2$

$$B(xy) - xB(y) = xyA - 2I_2 - x(yA - 2I_2) = -2I_2 + 2xI_2 = 2(x - 1)I_2.$$

*Barem: 3p + 2p.*

### 6. $x$ cu $B(6^x) - 2^xB(3^x) = 6I_2$

Din punctul 5 cu $x \to 2^x$, $y \to 3^x$ (deci $xy \to 6^x$): $B(6^x) - 2^xB(3^x) = 2(2^x - 1)I_2$.

$2(2^x - 1) = 6 \iff 2^x = 4 \iff x = 2$.

*Barem: 3p + 2p.*
