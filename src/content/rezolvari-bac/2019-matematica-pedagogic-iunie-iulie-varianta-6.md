## Subiectul I (30 de puncte)

### 1. Suma primilor trei termeni ai progresiei geometrice cu termeni pozitivi, $b_1 = 2$, $b_3 = 8$

$b_2^2 = b_1b_3 = 16$ și $b_2 > 0$, deci $b_2 = 4$. $S_3 = 2 + 4 + 8 = 14$.

**Răspuns:** $14$. *Barem: 2p, 3p.*

### 2. $A(m, 2m)$ aparține graficului lui $f(x) = 5x - 6$

$f(m) = 2m \iff 5m - 6 = 2m \iff m = 2$. *Barem: 2p, 3p.*

### 3. Ecuația $\sqrt{x^2 - 10x + 25} = 5$

$x^2 - 10x + 25 = 25 \iff x(x - 10) = 0 \iff x \in \{0, 10\}$; ambele convin (sau: $|x - 5| = 5$).

**Răspuns:** $x \in \{0, 10\}$. *Barem: 2p, 3p.*

### 4. Ieftinire cu $10\%$, apoi scumpire cu 10 lei: prețul final 190 de lei

$x - \frac{10}{100}x + 10 = 190 \iff 0{,}9x = 180 \iff x = 200$.

**Răspuns:** $200$ de lei. *Barem: 3p, 2p.*

### 5. Mediana din $A$ în $\triangle AOB$, $A(4,4)$, $B(6,0)$

Mijlocul lui $OB$: $M(3, 0)$. Panta $AM$: $\frac{4 - 0}{4 - 3} = 4$, deci $y - 0 = 4(x - 3)$.

**Răspuns:** $y = 4x - 12$. *Barem: 2p, 3p.*

### 6. Arătați că $2\sin30^\circ - \sin 90^\circ = 0$

$2\cdot\frac12 - 1 = 0$. $\blacksquare$ *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

Legea: $x \circ y = 2(xy + x + y) + 1$.

### 1. $(-1)\circ 1 = -1$

$2(-1 - 1 + 1) + 1 = -2 + 1 = -1$. $\blacksquare$ *Barem: 3p, 2p.*

### 2. Legea este comutativă

$x \circ y = 2(xy + x + y) + 1 = 2(yx + y + x) + 1 = y \circ x$. $\blacksquare$ *Barem: 3p, 2p.*

### 3. $x \circ y = 2(x + 1)(y + 1) - 1$

$2xy + 2x + 2y + 2 - 1 = 2x(y + 1) + 2(y + 1) - 1 = 2(x+1)(y+1) - 1$. $\blacksquare$ *Barem: 2p, 3p.*

### 4. $e = -\frac12$ este element neutru

$x \circ \left(-\frac12\right) = 2(x + 1)\cdot\frac12 - 1 = x$, iar prin comutativitate și $\left(-\frac12\right)\circ x = x$. $\blacksquare$ *Barem: 2p, 3p.*

### 5. $(x - 1)\circ(x + 2) = -5$

$2x(x + 3) - 1 = -5 \iff 2x^2 + 6x + 4 = 0 \iff x^2 + 3x + 2 = 0 \iff x \in \{-2, -1\}$. *Barem: 3p, 2p.*

### 6. Numerele naturale nenule $n$ cu $n \circ (n - 1) \le 11$

$2(n + 1)n - 1 \le 11 \iff n^2 + n - 6 \le 0 \iff (n + 3)(n - 2) \le 0 \iff n \in [-3, 2]$.

**Răspuns:** $n \in \{1, 2\}$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1 & 1\\ 2 & 0\end{pmatrix}$, $B = \begin{pmatrix}3 & 1\\ 2 & 2\end{pmatrix}$.

### 1. $\det A = -2$

$1\cdot 0 - 2\cdot 1 = -2$. $\blacksquare$ *Barem: 3p, 2p.*

### 2. $\det(A + B)$

$A + B = \begin{pmatrix}4 & 2\\ 4 & 2\end{pmatrix}$, cu liniile egale: $\det = 8 - 8 = 0$.

**Răspuns:** $0$. *Barem: 3p, 2p.*

### 3. $A\cdot A = B$

$$A^2 = \begin{pmatrix}1 + 2 & 1 + 0\\ 2 + 0 & 2 + 0\end{pmatrix} = \begin{pmatrix}3 & 1\\ 2 & 2\end{pmatrix} = B.\ \blacksquare$$

*Barem: 3p, 2p.*

### 4. $aA + bB = \begin{pmatrix}5 & 3\\ 6 & 2\end{pmatrix}$

$$aA + bB = \begin{pmatrix}a + 3b & a + b\\ 2a + 2b & 2b\end{pmatrix}.$$

Din $2b = 2$: $b = 1$; din $a + b = 3$: $a = 2$; verificare: $a + 3b = 5$ ✔, $2a + 2b = 6$ ✔.

**Răspuns:** $a = 2$, $b = 1$. *Barem: 2p, 3p.*

### 5. Dacă $X + A = B$, atunci $X$ este inversabilă

$X = B - A = \begin{pmatrix}2 & 0\\ 0 & 2\end{pmatrix}$, $\det X = 4 \ne 0$, deci $X$ este inversabilă. $\blacksquare$ *Barem: 3p, 2p.*

### 6. $\det(A + B - aI_2) \le 0$

$$A + B - aI_2 = \begin{pmatrix}4 - a & 2\\ 4 & 2 - a\end{pmatrix},\quad \det = (4 - a)(2 - a) - 8 = a^2 - 6a.$$

$a(a - 6) \le 0 \iff a \in [0, 6]$.

**Răspuns:** $a \in [0, 6]$. *Barem: 3p, 2p.*
