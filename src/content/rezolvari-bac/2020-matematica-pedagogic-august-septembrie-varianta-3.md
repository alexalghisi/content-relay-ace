## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{96}\left(\frac{\sqrt6}4 - \frac1{\sqrt6}\right) = 2$

$\sqrt{96} = 4\sqrt6$, deci

$$4\sqrt6\cdot\frac{\sqrt6}4 - 4\sqrt6\cdot\frac1{\sqrt6} = 6 - 4 = 2.$$

*Barem: 3p + 2p.*

### 2. $f(x) = 3x + 1$, $g(x) = x - 1$; $n$ natural cu $f(n)\cdot g(n) = 0$

$(3n + 1)(n - 1) = 0 \iff n \in \left\{-\frac13, 1\right\}$. Cum $n \in \mathbb N$: $n = 1$.

*Barem: 2p + 3p.*

### 3. Ecuația $3^{2x+5} = 3^{6x-3}$

$2x + 5 = 6x - 3 \iff 4x = 8 \iff x = 2$.

*Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr de două cifre să aibă cifra zecilor egală cu dublul cifrei unităților

90 cazuri posibile. Favorabile: $21, 42, 63, 84$ (cifra unităților $1..4$; $\overline{00}$ nu e de două cifre) — 4 cazuri.

$$p = \frac4{90} = \frac2{45}.$$

*Barem: 2p + 2p + 1p.*

### 5. $A(1,3)$, $B(3,5)$, $C(0,a)$; $\triangle ABC$ dreptunghic în $A$

$m_{AB} = \frac{5-3}{3-1} = 1$, $m_{AC} = \frac{a - 3}{0 - 1} = 3 - a$. $AB \perp AC \iff 1\cdot(3 - a) = -1 \iff a = 4$.

*Barem: 2p + 3p.*

### 6. Arătați că $\sqrt3\sin60^\circ + \sin30^\circ - 4\sin^230^\circ = 1$

$$\sqrt3\cdot\tfrac{\sqrt3}2 + \tfrac12 - 4\cdot\tfrac14 = \tfrac32 + \tfrac12 - 1 = 1.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă pe $\mathbb R$: $x\circ y = -xy + 4x + 4y - 12$.

### 1. $2\circ3 = 2$

$$2\circ3 = -6 + 8 + 12 - 12 = 2.$$

*Barem: 3p + 2p.*

### 2. Legea este comutativă

$x\circ y = -xy + 4x + 4y - 12 = -yx + 4y + 4x - 12 = y\circ x$. $\blacksquare$ *Barem: 2p + 3p.*

### 3. $x\circ y = -(x - 4)(y - 4) + 4$

$$-(x - 4)(y - 4) + 4 = -xy + 4x + 4y - 16 + 4 = x\circ y.$$

*Barem: 2p + 3p.*

### 4. $x\circ4 = 4$

$$x\circ4 = -(x - 4)\cdot0 + 4 = 4.$$

*Barem: 3p + 2p.*

### 5. $x$ cu $x\circ x = x$

$$-(x - 4)^2 + 4 = x \iff -(x-4)^2 - (x - 4) = 0 \iff -(x - 4)(x - 3) = 0.$$

**Răspuns:** $x \in \{3, 4\}$. *Barem: 2p + 3p.*

### 6. Progresia aritmetică cu $a_1 = -5$, $r = 3$: $a_1\circ a_2\circ a_3\circ a_4 = 4$

$a_4 = a_1 + 3r = -5 + 9 = 4$. Cu asociativitatea și punctul 4 (și comutativitatea):

$$(a_1\circ a_2\circ a_3)\circ4 = 4.\ \blacksquare$$

*Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&2\\-1&1\end{pmatrix}$, $B(x) = \begin{pmatrix}1&x\\0&1\end{pmatrix}$.

### 1. $\det A = 3$

$$\det A = 1\cdot1 - 2\cdot(-1) = 3.$$

*Barem: 3p + 2p.*

### 2. $B(1) + B(3) = 2B(2)$

$$\begin{pmatrix}1&1\\0&1\end{pmatrix} + \begin{pmatrix}1&3\\0&1\end{pmatrix} = \begin{pmatrix}2&4\\0&2\end{pmatrix} = 2\begin{pmatrix}1&2\\0&1\end{pmatrix} = 2B(2).$$

*Barem: 3p + 2p.*

### 3. $\det B(x) = 1$

$$\det B(x) = 1\cdot1 - x\cdot0 = 1.$$

*Barem: 2p + 3p.*

### 4. $B(x)B(y) = B(x + y)$

$$\begin{pmatrix}1&x\\0&1\end{pmatrix}\begin{pmatrix}1&y\\0&1\end{pmatrix} = \begin{pmatrix}1 & y + x\\0&1\end{pmatrix} = B(x + y).$$

*Barem: 3p + 2p.*

### 5. $x$ cu $A\cdot B(x) = B(x)\cdot A$

$$AB(x) = \begin{pmatrix}1 & x + 2\\ -1 & -x + 1\end{pmatrix},\quad B(x)A = \begin{pmatrix}1 - x & 2 + x\\ -1 & 1\end{pmatrix}.$$

Egalând elementele $(1,1)$: $1 = 1 - x \iff x = 0$ (și atunci toate elementele coincid).

**Răspuns:** $x = 0$. *Barem: 3p + 2p.*

### 6. Perechi $(m, n)$ de naturale cu $B(2^m)B(2^n) = B(2^{m+n} - 2)$

Din 4: $B(2^m + 2^n) = B(2^{m+n} - 2)$, deci $2^m + 2^n = 2^{m+n} - 2$, adică

$$2^{m+n} - 2^m - 2^n + 1 = 3 \iff (2^m - 1)(2^n - 1) = 3.$$

Factorii sunt naturali: $\{2^m - 1, 2^n - 1\} = \{1, 3\}$, deci $\{m, n\} = \{1, 2\}$.

**Răspuns:** $(1, 2)$ și $(2, 1)$. *Barem: 3p + 2p.*
