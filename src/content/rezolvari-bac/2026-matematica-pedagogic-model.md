## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{64} - 4\sqrt2 + 2\sqrt2\cdot\left(2 - \sqrt2\right) = 4$

$\sqrt{64} = 8$. Desfacem paranteza: $2\sqrt2\cdot 2 - 2\sqrt2\cdot\sqrt2 = 4\sqrt2 - 2\cdot 2 = 4\sqrt2 - 4$.

$$8 - 4\sqrt2 + 4\sqrt2 - 4 = 8 - 4 = 4.$$

Termenii cu $\sqrt2$ se reduc. *Barem: 3p calculul termenilor, 2p finalizarea.*

### 2. $f(x) = 7x - 4$; determinați $a$ cu $f(a) = 5a$

$f(a) = 7a - 4$, deci $7a - 4 = 5a \iff 2a = 4 \iff a = 2$.

**Răspuns:** $a = 2$. *Barem: 2p $f(a)$, 3p rezolvarea.*

### 3. Ecuația $9\cdot 3^x = 3^5$

Scriem $9 = 3^2$: $3^2\cdot 3^x = 3^{2+x}$. Ecuația devine $3^{2+x} = 3^5$, iar cum funcția exponențială este injectivă, $2 + x = 5$, deci $x = 3$.

Verificare: $9\cdot 27 = 243 = 3^5$ ✔.

**Răspuns:** $x = 3$. *Barem: 3p aducerea la aceeași bază, 2p soluția.*

### 4. O ieftinire cu 15% micșorează prețul cu 75 de lei; prețul inițial

Dacă $x$ este prețul înainte de ieftinire, scăderea de preț este $15\%$ din $x$:

$$\frac{15}{100}\cdot x = 75 \Rightarrow x = \frac{75\cdot 100}{15} = 500 \text{ lei}.$$

**Atenție:** 75 de lei este **scăderea**, nu prețul nou (prețul nou ar fi 425 de lei).

**Răspuns:** 500 de lei. *Barem: 3p ecuația, 2p rezultatul.*

### 5. $A(0,4)$, $B(2,0)$, $C(6,6)$, $M$ mijlocul lui $OC$; arătați că $MA = MB$

$M\left(\dfrac{0+6}{2}, \dfrac{0+6}{2}\right) = M(3,3)$.

$$MA = \sqrt{(3-0)^2 + (3-4)^2} = \sqrt{9 + 1} = \sqrt{10}, \qquad MB = \sqrt{(3-2)^2 + (3-0)^2} = \sqrt{1 + 9} = \sqrt{10}.$$

Deci $MA = MB$. *Barem: 2p coordonatele lui $M$, 3p cele două distanțe.*

### 6. Arătați că $4(\sin60^\circ)^2 - (\sin45^\circ)^2 - 2(\sin30^\circ)^2 = 2$

Valori: $\sin60^\circ = \dfrac{\sqrt3}{2}$, $\sin45^\circ = \dfrac{\sqrt2}{2}$, $\sin30^\circ = \dfrac12$. La pătrat: $\dfrac34$, $\dfrac24 = \dfrac12$, $\dfrac14$.

$$4\cdot\frac34 - \frac12 - 2\cdot\frac14 = 3 - \frac12 - \frac12 = 2.$$

*Barem: 3p valorile, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Pe $\mathbb R$ se definește legea de compoziție $x * y = \dfrac{x + y}{3} - 4$.

### 1. Arătați că $7 * 8 = 1$

$$7 * 8 = \frac{7 + 8}{3} - 4 = \frac{15}{3} - 4 = 5 - 4 = 1.$$

*Barem: 3p înlocuirea, 2p calculul.*

### 2. Determinați $x$ cu $4 * x = x$

$4 * x = \dfrac{4 + x}{3} - 4$. Ecuația: $\dfrac{4 + x}{3} - 4 = x$; înmulțim cu 3: $4 + x - 12 = 3x \iff -8 = 2x \iff x = -4$.

Verificare: $4 * (-4) = 0 - 4 = -4$ ✔.

**Răspuns:** $x = -4$. *Barem: 2p expresia, 3p soluția.*

### 3. Determinați $x$ cu $x * x^2 = 0$

$$x * x^2 = \frac{x + x^2}{3} - 4 = \frac{x^2 + x - 12}{3}.$$

Ecuația: $x^2 + x - 12 = 0$, cu $\Delta = 1 + 48 = 49$, deci $x = \dfrac{-1 \pm 7}{2}$: $x_1 = -4$, $x_2 = 3$.

**Răspuns:** $x \in \{-4, 3\}$. *Barem: 3p expresia, 2p soluțiile.*

### 4. Arătați că $(2x) * (2y) = 2\cdot\left(x * (y + 6)\right)$

Membrul stâng: $(2x) * (2y) = \dfrac{2x + 2y}{3} - 4$.

Membrul drept: $x * (y + 6) = \dfrac{x + y + 6}{3} - 4 = \dfrac{x + y}{3} + 2 - 4 = \dfrac{x + y}{3} - 2$, deci

$$2\cdot\left(x * (y + 6)\right) = \frac{2x + 2y}{3} - 4.$$

Cei doi membri sunt egali pentru orice $x, y$ reali. *Barem: 2p membrul stâng, 3p membrul drept și concluzia.*

### 5. Numerele naturale $n$ cu $(3n) * \left((2n) * n\right) \le -n$

Lucrăm din interior spre exterior:

$$(2n) * n = \frac{2n + n}{3} - 4 = n - 4,$$

$$(3n) * (n - 4) = \frac{3n + n - 4}{3} - 4 = \frac{4n - 4 - 12}{3} = \frac{4n - 16}{3}.$$

Inecuația: $\dfrac{4n - 16}{3} \le -n \iff 4n - 16 \le -3n \iff 7n \le 16 \iff n \le \dfrac{16}{7} \approx 2{,}28$.

Cum $n$ este natural: $n \in \{0, 1, 2\}$.

**Răspuns:** $n \in \{0, 1, 2\}$. Nu uita de $n = 0$ — și 0 este număr natural. *Barem: 2p expresia, 3p rezolvarea inecuației.*

### 6. Determinați $x \in (0, +\infty)$ cu $\lg x * \lg x = (-3) * \lg\dfrac1x$

Notăm $t = \lg x$ (definit pentru $x > 0$). Atunci $\lg\dfrac1x = -\lg x = -t$.

$$\lg x * \lg x = \frac{2t}{3} - 4, \qquad (-3) * (-t) = \frac{-3 - t}{3} - 4.$$

Egalăm și simplificăm cu $-4$, apoi înmulțim cu 3: $2t = -3 - t \iff 3t = -3 \iff t = -1$.

$\lg x = -1 \iff x = 10^{-1} = \dfrac{1}{10}$, care aparține lui $(0, +\infty)$, deci convine.

**Răspuns:** $x = \dfrac1{10}$. *Barem: 2p cele două expresii, 3p soluția.*

## Subiectul al III-lea (30 de puncte)

Se consideră $I_2 = \begin{pmatrix}1 & 0\\ 0 & 1\end{pmatrix}$, $A = \begin{pmatrix}1 & 6\\ 0 & -2\end{pmatrix}$, $B = \begin{pmatrix}1 & 2\\ 0 & 0\end{pmatrix}$ și $M(x,y) = xA + yB$.

### 1. Arătați că $\det A = -2$

$$\det A = \begin{vmatrix}1 & 6\\ 0 & -2\end{vmatrix} = 1\cdot(-2) - 6\cdot 0 = -2.$$

*Barem: 3p formula, 2p rezultatul.*

### 2. Numărul $a$ cu $A + 2I_2 = aB$

$$A + 2I_2 = \begin{pmatrix}1 & 6\\ 0 & -2\end{pmatrix} + \begin{pmatrix}2 & 0\\ 0 & 2\end{pmatrix} = \begin{pmatrix}3 & 6\\ 0 & 0\end{pmatrix} = 3\begin{pmatrix}1 & 2\\ 0 & 0\end{pmatrix} = 3B.$$

Din $3B = aB$ (comparăm elementul de pe poziția $(1,1)$: $3 = a$) obținem $a = 3$.

**Răspuns:** $a = 3$. *Barem: 3p calculul, 2p valoarea lui $a$.*

### 3. Arătați că $A\cdot A + A = 2I_2$

$$A\cdot A = \begin{pmatrix}1\cdot1 + 6\cdot0 & 1\cdot6 + 6\cdot(-2)\\ 0 & (-2)\cdot(-2)\end{pmatrix} = \begin{pmatrix}1 & -6\\ 0 & 4\end{pmatrix}.$$

$$A\cdot A + A = \begin{pmatrix}2 & 0\\ 0 & 2\end{pmatrix} = 2I_2.$$

*Barem: 3p $A\cdot A$, 2p finalizarea.*

### 4. Numerele $x$, $y$ cu $M(x,y)\cdot A = B$

$$M(x,y) = \begin{pmatrix}x + y & 6x + 2y\\ 0 & -2x\end{pmatrix},$$

$$M(x,y)\cdot A = \begin{pmatrix}x + y & 6(x+y) - 2(6x + 2y)\\ 0 & 4x\end{pmatrix} = \begin{pmatrix}x + y & -6x + 2y\\ 0 & 4x\end{pmatrix}.$$

Egalăm cu $B$: $4x = 0 \Rightarrow x = 0$; $x + y = 1 \Rightarrow y = 1$; verificăm a treia ecuație: $-6\cdot 0 + 2\cdot 1 = 2$ ✔.

**Răspuns:** $x = 0$, $y = 1$. *Barem: 3p produsul, 2p valorile.*

### 5. Dacă $x \ne y$ și $\det(M(x,y)) = \det(M(y,x))$, atunci $x + y = 0$

Matricea $M(x,y)$ este superior triunghiulară, deci determinantul este produsul elementelor de pe diagonală:

$$\det(M(x,y)) = (x + y)(-2x) = -2x(x + y), \qquad \det(M(y,x)) = -2y(x + y).$$

Egalitatea devine $-2x(x+y) = -2y(x+y) \iff -2(x+y)(x - y) = 0$.

Cum $x \ne y$, avem $x - y \ne 0$, deci obligatoriu $x + y = 0$. $\blacksquare$

*Barem: 2p cei doi determinanți, 3p raționamentul.*

### 6. Numerele $x$ cu $M(x,x)\cdot M(x,-x) = M(-2,2)$

$$M(x,x) = \begin{pmatrix}2x & 8x\\ 0 & -2x\end{pmatrix}, \qquad M(x,-x) = \begin{pmatrix}0 & 4x\\ 0 & -2x\end{pmatrix}.$$

$$M(x,x)\cdot M(x,-x) = \begin{pmatrix}0 & 8x^2 - 16x^2\\ 0 & 4x^2\end{pmatrix} = \begin{pmatrix}0 & -8x^2\\ 0 & 4x^2\end{pmatrix} = x^2\begin{pmatrix}0 & -8\\ 0 & 4\end{pmatrix}.$$

Iar $M(-2,2) = -2A + 2B = \begin{pmatrix}0 & -8\\ 0 & 4\end{pmatrix}$. Deci ecuația este $x^2 M(-2,2) = M(-2,2)$, adică $x^2 = 1$.

**Răspuns:** $x \in \{-1, 1\}$. *Barem: 3p produsul, 2p soluțiile.*

## Ce merită reținut din model

- **Compuneri imbricate** de forma $a * (b * c)$: calculează întâi paranteza interioară, apoi aplică din nou legea.
