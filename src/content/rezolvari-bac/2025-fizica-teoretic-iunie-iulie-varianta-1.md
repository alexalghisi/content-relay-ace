## A. Mecanică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **b**, 2 – **a**, 3 – **c**, 4 – **c**, 5 – **a** (câte 3 puncte).

**1.** Legea lui Hooke, $F = k\Delta\ell$: alungirea este direct proporțională cu forța, deci se dublează → **b**.

**2.** Accelerația medie este variația vitezei raportată la intervalul de timp: $\vec a_m = \dfrac{\Delta\vec v}{\Delta t}$ → **a**.

**3.** În $v = \alpha x + \beta$, termenul $\beta$ are unitatea vitezei (m/s), iar $\alpha x$ la fel, deci $[\alpha] = \text{s}^{-1}$. Atunci $\left[\dfrac{\beta}{\alpha}\right] = \dfrac{\text{m/s}}{\text{s}^{-1}} = \text{m}$ → **c**.

**4.** $P = Fv \Rightarrow v = \dfrac{25\,000}{1000} = 25\ \text{m/s} = 90\ \text{km/h}$ → **c**.

**5.** Graficul $x(t)$ este o dreaptă, deci mișcarea este uniformă: $v = \dfrac{\Delta x}{\Delta t} = \dfrac{6 - 2}{4} = 1\ \text{m/s}$ → **a**.

### Subiectul al II-lea — două corpuri legate peste un scripete, cu frecare (15 puncte)

Date: $m_1 = 2\ \text{kg}$, $m_2 = 1\ \text{kg}$, $F = 8\ \text{N}$, $\mu_1 = 0{,}1$; corpurile se mișcă cu viteză constantă.

**a.** Asupra lui $m_1$ acționează: greutatea $m_1\vec g$ (în jos), reacțiunea normală $\vec N_1$ (în sus), forța $\vec F$ (orizontal, spre stânga, în sensul mișcării), tensiunea din fir $\vec T$ (orizontal, spre scripete) și forța de frecare $\vec F_{f1}$ (opusă mișcării). *Barem: 4p.*

**b.** Viteza este constantă, deci rezultanta este nulă. Pe orizontală:

$$F - T - F_{f1} = 0, \qquad F_{f1} = \mu_1N_1 = \mu_1m_1g = 2\ \text{N} \Rightarrow T = 8 - 2 = 6\ \text{N}.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** Corpul $m_2$ este tras de fir tot cu viteză constantă:

$$T - F_{f2} = 0, \qquad F_{f2} = \mu_2m_2g \Rightarrow \mu_2 = \frac{T}{m_2g} = \frac{6}{10} = 0{,}6.$$

*Barem: 1p + 1p + 1p + 1p.*

**d.** Cele două ramuri ale firului sunt orizontale și trag în același sens, deci reacțiunea din axul scripetelui este $F_s = 2T = 12\ \text{N}$. *Barem: 2p, 1p.*

### Subiectul al III-lea — pendul al cărui fir se rupe (15 puncte)

Date: $m = 0{,}05\ \text{kg}$, $\ell = 1\ \text{m}$, $H = 3{,}8\ \text{m}$, $\cos\alpha = 0{,}6$, $\cos\beta = 0{,}8$; $E_p = 0$ la nivelul solului.

**a.** În A corpul este în repaus, deci $E_A = E_{pA} = mgh_A$, cu $h_A = H - \ell\cos\alpha = 3{,}8 - 0{,}6 = 3{,}2\ \text{m}$:

$$E_A = 0{,}05\cdot 10\cdot 3{,}2 = 1{,}6\ \text{J}.$$

*Barem: 1p + 1p + 1p + 1p.*

**b.** $h_B = H - \ell\cos\beta = 3{,}8 - 0{,}8 = 3{,}0\ \text{m}$, deci

$$L_G = mg(h_A - h_B) = 0{,}5\cdot 0{,}2 = 0{,}1\ \text{J}.$$

*Barem: 1p + 1p + 1p.*

**c.** Tensiunea este perpendiculară pe traiectorie și nu efectuează lucru mecanic, deci $E_{cB} - E_{cA} = L_G$:

$$\frac{mv_B^2}{2} = 0{,}1\ \text{J} \Rightarrow v_B = \sqrt{\frac{2\cdot 0{,}1}{0{,}05}} = 2\ \text{m/s}.$$

*Barem: 1p + 1p + 1p + 1p.*

**d.** După ruperea firului, energia mecanică se conservă până la sol (punctul C):

$$\frac{mv_C^2}{2} = mgh_B + \frac{mv_B^2}{2} \Rightarrow v_C^2 = 2\cdot 10\cdot 3 + 4 = 64 \Rightarrow v_C = 8\ \text{m/s}.$$

$$p_C = mv_C = 0{,}05\cdot 8 = 0{,}4\ \text{kg}\cdot\text{m/s}.$$

*Barem: 1p, 2p, 1p.*

## B. Elemente de termodinamică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **c**, 2 – **d**, 3 – **c**, 4 – **a**, 5 – **b** (câte 3 puncte).

**1.** $C = \dfrac{Q}{\Delta T}$ este **capacitatea calorică** a corpului → **c**.

**2.** Randamentul ciclului Carnot: $\eta = 1 - \dfrac{T_{rece}}{T_{cald}}$ → **d**.

**3.** $c = \dfrac{Q}{m\Delta T}$, deci $\text{J}\cdot\text{kg}^{-1}\cdot\text{K}^{-1}$ → **c**.

**4.** $V = \dfrac{\nu RT}{p}$ este minim acolo unde raportul $T/p$ este minim. Pe grafic, starea 1 are presiunea cea mai mare și temperatura cea mai mică → **a**.

**5.** Bilanț caloric (aceeași substanță): $m_1(t_1 - \theta) = m_2(\theta - t_2)$, deci

$$\theta = \frac{m_1t_1 + m_2t_2}{m_1 + m_2} = \frac{160 + 30}{5} = 38\ °\text{C}$$

→ **b**.

### Subiectul al II-lea — amestec de oxigen și heliu la presiune constantă (15 puncte)

Date: $\nu_1 = 2\ \text{mol}$ O₂ ($\mu_1 = 32\ \text{g/mol}$, $C_{V1} = 2{,}5R$), He ($\mu_2 = 4\ \text{g/mol}$, $C_{V2} = 1{,}5R$), $T = 300\ \text{K}$, $p = 1{,}5\cdot 10^5\ \text{Pa}$.

**a.** $m_1 = \nu_1\mu_1 = 2\cdot 32 = 64\ \text{g}$. *Barem: 3p, 1p.*

**b.** $\rho_1 = \dfrac{m_1}{V}$, cu $pV = \dfrac{m_1}{\mu_1}RT$:

$$\rho_1 = \frac{p\mu_1}{RT} = \frac{1{,}5\cdot 10^5\cdot 0{,}032}{8{,}31\cdot 300} \cong 1{,}9\ \text{kg/m}^3.$$

*Barem: 2p, 1p, 1p.*

**c.** Înainte: $pV = \nu_1RT$. După introducerea heliului, la aceeași presiune și temperatură: $p\cdot 2V = (\nu_1 + \nu_2)RT$. Împărțind cele două relații: $\nu_1 + \nu_2 = 2\nu_1$, deci $\nu_2 = 2\ \text{mol}$. *Barem: 1p + 1p + 1p.*

**d.** Energia internă a amestecului este suma energiilor componentelor:

$$U = \nu_1C_{V1}T + \nu_2C_{V2}T = (2\cdot 2{,}5 + 2\cdot 1{,}5)\cdot 8{,}31\cdot 300 \cong 2\cdot 10^4\ \text{J}.$$

*Barem: 1p + 1p + 1p + 1p.*

### Subiectul al III-lea — ciclu cu o transformare $p \sim V$ (15 puncte)

Date: $\nu R \cong 2\ \text{J/K}$, gaz monoatomic $C_V = 1{,}5R$, $T_1 = 300\ \text{K}$. Ciclul: $1 \to 2$ izocor ($V_1$), $2 \to 3$ izobar ($V_1 \to 2V_1$), $3 \to 1$ pe o dreaptă care trece prin origine ($p \sim V$).

**a.** Stările 3 și 1 sunt pe aceeași dreaptă prin origine: $\dfrac{p_2}{2V_1} = \dfrac{p_1}{V_1}$, deci $p_2 = 2p_1$. Atunci $T_3 = \dfrac{p_2\cdot 2V_1}{\nu R} = 4T_1 = 1200\ \text{K}$.

$$\Delta U_{31} = \nu C_V(T_1 - T_3) = 1{,}5\cdot 2\cdot(300 - 1200) = -2{,}7\cdot 10^3\ \text{J}.$$

*Barem: 1p + 1p + 1p + 1p.*

**b.** Lucrul mecanic pe ciclu este aria triunghiului 1-2-3:

$$L = \frac{(p_2 - p_1)(2V_1 - V_1)}{2} = \frac{p_1V_1}{2} = \frac{\nu RT_1}{2} = 3\cdot 10^2\ \text{J}.$$

*Barem: 2p, 1p, 1p.*

**c.** Pe $1 \to 2$ și $2 \to 3$ temperatura crește, deci gazul primește căldură. Cedează doar pe $3 \to 1$. Lucrul mecanic pe $3 \to 1$ este minus aria trapezului de sub dreaptă:

$$L_{31} = -\frac{(p_1 + 2p_1)V_1}{2} = -1{,}5\,p_1V_1 = -900\ \text{J}.$$

$$Q_c = Q_{31} = \Delta U_{31} + L_{31} = -2700 - 900 = -3{,}6\cdot 10^3\ \text{J}.$$

*Barem: 1p + 1p + 1p + 1p.*

**d.** $Q_p = L + |Q_c| = 300 + 3600 = 3900\ \text{J}$:

$$\eta = \frac{L}{Q_p} = \frac{300}{3900} = \frac{1}{13} \cong 7{,}7\%.$$

*Barem: 1p + 1p + 1p.*

## C. Producerea și utilizarea curentului continuu (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **d**, 2 – **a**, 3 – **b**, 4 – **d**, 5 – **c** (câte 3 puncte).

**1.** Puterea pe circuitul exterior este maximă când $R = r$: $P_{max} = \dfrac{E^2}{4r}$ → **d**.

**2.** $\rho = \rho_0(1 + \alpha t)$ → **a**.

**3.** $U\cdot I = P$, puterea, măsurată în watt → **b**.

**4.** La $I = 0$, $U = E = 12\ \text{V}$; la scurtcircuit, $I_{sc} = 3\ \text{A}$, deci $r = \dfrac{E}{I_{sc}} = 4\ \Omega$ → **d**.

**5.** $\eta = \dfrac{R}{R + r} = \dfrac{12}{15} = 80\%$ → **c**.

### Subiectul al II-lea — rezistoare mixte, voltmetru și ampermetru (15 puncte)

Date: $E = 12\ \text{V}$, $r = 4\ \Omega$, $R_1 = 12\ \Omega$, $R_2 = R_3 = 16\ \Omega$. $R_2$ și $R_3$ sunt în paralel, iar gruparea lor este în serie cu $R_1$. Voltmetrul este legat la bornele lui $R_1$.

**a.** $\dfrac{1}{R_{23}} = \dfrac{1}{16} + \dfrac{1}{16}$, deci $R_{23} = 8\ \Omega$ și $R_e = R_1 + R_{23} = 20\ \Omega$. *Barem: 2p, 1p, 1p.*

**b.** $I = \dfrac{E}{R_e + r} = \dfrac{12}{24} = 0{,}5\ \text{A}$, deci $U_b = E - Ir = 12 - 2 = 10\ \text{V}$. *Barem: 2p, 1p, 1p.*

**c.** Voltmetrul ideal măsoară tensiunea pe $R_1$: $U_V = IR_1 = 0{,}5\cdot 12 = 6\ \text{V}$. *Barem: 2p, 1p.*

**d.** Ampermetrul ideal scurtcircuitează $R_1$, deci tot curentul trece prin el:

$$I_A = \frac{E}{R_{23} + r} = \frac{12}{12} = 1\ \text{A}.$$

*Barem: 3p, 1p.*

### Subiectul al III-lea — bec, rezistoare și întrerupător (15 puncte)

Date: $E = 12\ \text{V}$, $r = 4\ \Omega$, $U_b = 9\ \text{V}$, $P_b = 4{,}5\ \text{W}$. Cu K deschis, becul este în serie cu $R_1$.

**a.** $P_b = \dfrac{U_b^2}{R_b} \Rightarrow R_b = \dfrac{81}{4{,}5} = 18\ \Omega$. *Barem: 2p, 1p.*

**b.** Curentul nominal: $I_n = \dfrac{P_b}{U_b} = 0{,}5\ \text{A}$.

$$W_{total} = EI_n\Delta t = 12\cdot 0{,}5\cdot 600 = 3600\ \text{J} = 3{,}6\ \text{kJ}.$$

*Barem: 2p, 1p, 1p.*

**c.** Teorema a II-a a lui Kirchhoff: $E = I_nr + I_nR_1 + U_b \Rightarrow 12 = 2 + 0{,}5R_1 + 9 \Rightarrow R_1 = 2\ \Omega$. *Barem: 3p, 1p.*

**d.** Cu K închis, $R_2$ este în paralel cu ramura bec + $R_1$ ($R_b + R_1 = 20\ \Omega$), prin care trebuie să treacă tot $I_n = 0{,}5\ \text{A}$:

$$E' = I'r + I_n(R_b + R_1) \Rightarrow 17 = 4I' + 10 \Rightarrow I' = 1{,}75\ \text{A}.$$

$$I_2 = I' - I_n = 1{,}25\ \text{A}, \qquad I_n(R_b + R_1) = I_2R_2 \Rightarrow R_2 = \frac{10}{1{,}25} = 8\ \Omega.$$

*Barem: 1p + 1p + 1p + 1p.*

## D. Optică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **c**, 2 – **a**, 3 – **d**, 4 – **b**, 5 – **c** (câte 3 puncte).

**1.** Unghiul de reflexie este egal cu cel de incidență. Dacă raza reflectată este perpendiculară pe cea incidentă, $i + r = 90°$, deci $i = 45°$ → **c**.

**2.** $\varepsilon = h\nu \Rightarrow \dfrac{\varepsilon}{\nu} = h$, constanta lui Planck → **a**.

**3.** Frecvența se măsoară în $\text{s}^{-1}$, iar convergența în $\text{m}^{-1}$, deci au unități diferite. Celelalte perechi au aceeași unitate (m, J, rad) → **d**.

**4.** $\varepsilon = \dfrac{hc}{\lambda} = \dfrac{6{,}6\cdot 10^{-34}\cdot 3\cdot 10^8}{600\cdot 10^{-9}} = 3{,}3\cdot 10^{-19}\ \text{J} \cong 2\ \text{eV}$ → **b**.

**5.** $E_c = \varepsilon - L$: dreapta are panta 1 și intersectează axa energiei fotonilor la $\varepsilon = L = 2{,}5\ \text{eV}$. Pentru $\varepsilon = 15\ \text{eV}$: $E_c = 15 - 2{,}5 = 12{,}5\ \text{eV}$ → **c**.

### Subiectul al II-lea — obiect la dublul distanței focale (15 puncte)

Date: $y_1 = 10\ \text{mm}$, lentilă biconvexă simetrică, $f = 20\ \text{cm}$; obiectul și imaginea sunt la distanțe egale de lentilă, de o parte și de alta.

**a.** $x_2 = -x_1$ în formula lentilelor:

$$\frac{1}{x_2} - \frac{1}{x_1} = \frac{1}{f} \Rightarrow -\frac{2}{x_1} = \frac{1}{20} \Rightarrow -x_1 = 40\ \text{cm} = 2f.$$

*Barem: 1p, 2p, 1p.*

**b.** $\beta = \dfrac{x_2}{x_1} = -1 = \dfrac{y_2}{y_1}$, deci $y_2 = -10\ \text{mm}$: imaginea are 10 mm și este răsturnată. *Barem: 1p, 2p, 1p.*

**c.** Construcția: din vârful obiectului, aflat în $2F$, se duce o rază paralelă cu axa optică, care după lentilă trece prin $F'$, și o rază prin centrul optic, nedeviată. Ele se intersectează în $2F'$: imaginea este **reală, răsturnată, egală cu obiectul**. *Barem: 4p.*

**d.** Lentila întreagă are $C = \dfrac{1}{f} = 5\ \text{m}^{-1}$. Cele două jumătăți plan-convexe identice, alipite, refac lentila: $C = 2C'$, deci $C' = 2{,}5\ \text{m}^{-1}$. *Barem: 1p + 1p + 1p.*

### Subiectul al III-lea — dispozitivul Young, în aer și în lichid (15 puncte)

Date: $2\ell = 0{,}9\ \text{mm}$, $D = 2{,}25\ \text{m}$, $\nu = 5\cdot 10^{14}\ \text{Hz}$, $\Delta D = 0{,}75\ \text{m}$.

**a.** $\lambda = \dfrac{c}{\nu} = \dfrac{3\cdot 10^8}{5\cdot 10^{14}} = 6\cdot 10^{-7}\ \text{m} = 600\ \text{nm}$. *Barem: 3p, 1p.*

**b.** $i = \dfrac{\lambda D}{2\ell} = \dfrac{600\cdot 10^{-9}\cdot 2{,}25}{0{,}9\cdot 10^{-3}} = 1{,}5\ \text{mm}$. *Barem: 2p, 1p.*

**c.** Noua interfranjă este $i' = \dfrac{\lambda(D + \Delta D)}{2\ell} = \dfrac{600\cdot 10^{-9}\cdot 3}{0{,}9\cdot 10^{-3}} = 2\ \text{mm}$. Maximul de ordinul 3 se deplasează cu

$$\Delta x = k(i' - i) = 3\cdot(2 - 1{,}5) = 1{,}5\ \text{mm}.$$

*Barem: 1p, 2p, 1p.*

**d.** În lichid lungimea de undă devine $\lambda/n$, deci $i'' = \dfrac{\lambda(D + \Delta D)}{2\ell n}$. Maximul revine în vechea poziție dacă $i'' = i$:

$$n = \frac{D + \Delta D}{D} = \frac{3}{2{,}25} = \frac43 \cong 1{,}33.$$

*Barem: 1p, 2p, 1p.*
