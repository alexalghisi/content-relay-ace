## Subiectul I (30 de puncte)

### 1. Media aritmetică a numerelor $a = 2(5 - \sqrt5)$ și $b = 2\sqrt5$

$$m_a = \frac{10 - 2\sqrt5 + 2\sqrt5}{2} = \frac{10}{2} = 5.$$

*Barem: 3p + 2p.*

### 2. Abscisele punctelor de intersecție ale graficului lui $f(x) = x^2 - 4x + 3$ cu $Ox$

$x^2 - 4x + 3 = 0 \iff (x-1)(x-3) = 0$.

**Răspuns:** $x_1 = 1$, $x_2 = 3$. *Barem: 3p + 2p.*

### 3. Ecuația $\log_5(2x - 1) - \log_5 3 = 0$

$$\log_5\frac{2x-1}{3} = 0 \iff \frac{2x-1}{3} = 1 \iff x = 2,$$

care verifică ($2x - 1 = 3 > 0$). *Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr natural de o cifră să fie multiplu de 3

Multiplii lui 3 de o cifră: $0, 3, 6, 9$ — 4 favorabile din 10 posibile.

$$p = \frac{4}{10} = \frac25.$$

(Atenție: $0$ este multiplu al oricărui număr.) *Barem: 2p + 1p + 2p.*

### 5. Mijlocul segmentului $AB$, $A(2,4)$, $B(6,4)$

$x_M = 4$, $y_M = 4$. **Răspuns:** $M(4, 4)$. *Barem: 3p + 2p.*

### 6. $\sin(a + b) = \frac{63}{65}$, cu $a, b \in \left(0, \frac\pi2\right)$, $\sin a = \frac35$, $\sin b = \frac{12}{13}$

În cadranul I cosinusurile sunt pozitive: $\cos a = \frac45$, $\cos b = \frac{5}{13}$.

$$\sin(a + b) = \sin a\cos b + \cos a\sin b = \frac35\cdot\frac{5}{13} + \frac45\cdot\frac{12}{13} = \frac{15 + 48}{65} = \frac{63}{65}.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 2 & -2\\ 1 & -1\end{pmatrix}$

#### a) $\det A$

$$\det A = -2 + 2 = 0.$$

*Barem: 3p + 2p.*

#### b) $p$ cu $A\cdot A = pA$

$$A\cdot A = \begin{pmatrix} 4 - 2 & -4 + 2\\ 2 - 1 & -2 + 1\end{pmatrix} = \begin{pmatrix} 2 & -2\\ 1 & -1\end{pmatrix} = A,$$

deci $A = pA$, iar $A \ne O_2$ impune $p = 1$. *Barem: 3p + 2p.*

#### c) $B = \begin{pmatrix} 0 & b\\ b & 0\end{pmatrix}$ cu $\det(A + B) = 0$

$$A + B = \begin{pmatrix} 2 & b - 2\\ b + 1 & -1\end{pmatrix}, \qquad \det(A + B) = -2 - (b-2)(b+1) = -b^2 + b.$$

$-b^2 + b = 0 \iff b \in \{0, 1\}$.

**Răspuns:** $B = O_2$ sau $B = \begin{pmatrix} 0 & 1\\ 1 & 0\end{pmatrix}$. *Barem: 2p + 3p.*

### 2. $x\circ y = -xy + x + y$

#### a) $1\circ2015$

$$-2015 + 1 + 2015 = 1.$$

*Barem: 3p + 2p.*

#### b) $x\circ y = -(x-1)(y-1) + 1$

$$-xy + x + y = -x(y - 1) + (y - 1) + 1 = -(x-1)(y-1) + 1.$$

*Barem: 3p + 2p.*

#### c) $3^x\circ5^x = 1$

$$-(3^x - 1)(5^x - 1) + 1 = 1 \iff (3^x - 1)(5^x - 1) = 0.$$

$3^x = 1$ sau $5^x = 1$; în ambele cazuri $x = 0$.

**Răspuns:** $x = 0$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = \dfrac{3x}{x^2 + 1}$

#### a) $\lim\limits_{x\to1} f(x)$

$f$ continuă, deci limita este $f(1) = \dfrac32$. *Barem: 2p + 3p.*

#### b) $f'(x) = -\dfrac{3(x-1)(x+1)}{(x^2+1)^2}$

$$f'(x) = \frac{3(x^2 + 1) - 3x\cdot2x}{(x^2+1)^2} = \frac{3 - 3x^2}{(x^2+1)^2} = -\frac{3(x-1)(x+1)}{(x^2+1)^2}.$$

*Barem: 2p + 3p.*

#### c) Intervalele de monotonie

$f'(x) = 0 \iff x = \pm1$; semnul lui $f'$ este semnul lui $3 - 3x^2$.

| $x$ | $(-\infty, -1]$ | $[-1, 1]$ | $[1, +\infty)$ |
|---|---|---|---|
| $f'$ | $-$ | $+$ | $-$ |
| $f$ | descrescătoare | crescătoare | descrescătoare |

*Barem: 2p + 1p + 1p + 1p.*

### 2. $f(x) = x^5 + x$

#### a) $\displaystyle\int_{-1}^1 x^5\,dx$

$$\frac{x^6}{6}\Big|_{-1}^1 = \frac16 - \frac16 = 0.$$

(Funcție impară pe interval simetric.) *Barem: 3p + 2p.*

#### b) $\displaystyle\int_0^1(f(x) - x^5)e^x\,dx = 1$

$$\int_0^1 xe^x\,dx = xe^x\Big|_0^1 - \int_0^1 e^x\,dx = e - (e - 1) = 1.$$

*Barem: 3p + 2p.*

#### c) Volumul pentru $g(x) = \dfrac{f(x) - x}{x^3} = x^2$ pe $[1,2]$

$$V = \pi\int_1^2 x^4\,dx = \pi\frac{x^5}{5}\Big|_1^2 = \frac{31\pi}{5}.$$

*Barem: 3p + 2p.*

## Ce merită reținut din modelul 2015

- **$\sin(a + b) = \sin a\cos b + \cos a\sin b$**; cosinusurile se obțin din $\sin^2 + \cos^2 = 1$ și cadran.
- **Legea $-(x-1)(y-1) + 1$**: ecuația $u\circ v = 1$ înseamnă $(u-1)(v-1) = 0$.
- **Integrala unei funcții impare** pe $[-a, a]$ este $0$.
- **Matrice idempotentă** ($A^2 = A$) cu determinant $0$.
