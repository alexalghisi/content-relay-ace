## Subiectul I (30 de puncte)

### 1. Arătați că $\left(\left(\frac13\right)^2 + 2\right) : \frac{19}{9} = 1$

$$\frac19 + 2 = \frac{1 + 18}{9} = \frac{19}{9}, \qquad \frac{19}{9} : \frac{19}{9} = 1.$$

*Barem: 3p paranteza, 2p împărțirea.*

### 2. Intersecția graficelor $f(x) = 2014 - x$ și $g(x) = x - 2014$

$$2014 - x = x - 2014 \iff 2x = 4028 \iff x = 2014, \quad y = 0.$$

**Răspuns:** $(2014, 0)$. *Barem: 3p ecuația, 2p coordonatele.*

### 3. Ecuația $9^{x^2 + 3x} = 9^{x - 1}$

$$x^2 + 3x = x - 1 \iff x^2 + 2x + 1 = 0 \iff (x+1)^2 = 0 \iff x = -1.$$

**Răspuns:** $x = -1$. *Barem: 3p ecuația, 2p soluția.*

### 4. Prețul unui aparat de $360$ lei după o reducere de $25\%$

Reducerea: $\dfrac{25}{100}\cdot360 = 90$ lei, deci noul preț este $360 - 90 = 270$ de lei.

**Răspuns:** $270$ de lei. *Barem: 3p reducerea, 2p prețul.*

### 5. Mijlocul segmentului $AB$, $A(-2,3)$, $B(2,3)$

$$x_M = \frac{-2 + 2}{2} = 0, \qquad y_M = \frac{3 + 3}{2} = 3.$$

**Răspuns:** $M(0, 3)$. *Barem: 3p $x_M$, 2p $y_M$.*

### 6. $BC$ în triunghiul dreptunghic în $A$ cu $AC = 6$, $\sin B = \frac35$

$\sin B = \dfrac{AC}{BC}$ (cateta opusă / ipotenuza):

$$\frac35 = \frac{6}{BC} \iff BC = 10.$$

**Răspuns:** $BC = 10$. *Barem: 3p relația, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = x + y + 11$.

### 1. $8 * (-3)$

$$8 - 3 + 11 = 16.$$

*Barem: 3p înlocuirea, 2p rezultatul.*

### 2. Legea este asociativă

$$(x * y) * z = (x + y + 11) + z + 11 = x + y + z + 22,$$

$$x * (y * z) = x + (y + z + 11) + 11 = x + y + z + 22.$$

*Barem: 2p, 3p.*

### 3. $e = -11$ este element neutru

$$x * (-11) = x - 11 + 11 = x, \qquad (-11) * x = -11 + x + 11 = x.$$

**Răspuns:** da. *Barem: 3p, 2p.*

### 4. Numerele întregi $x$ cu $(x^2) * x = 121$

$$x^2 + x + 11 = 121 \iff x^2 + x - 110 = 0 \iff (x - 10)(x + 11) = 0.$$

**Răspuns:** $x \in \{-11, 10\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 5. $x * (x + 23) = (x * x) * 12$

$$x * (x + 23) = 2x + 34, \qquad (x * x) * 12 = (2x + 11) + 12 + 11 = 2x + 34.$$

*Barem: 2p membrul stâng, 3p membrul drept.*

### 6. Ecuația $\lg x * \lg x = 13$

Condiția $x > 0$. $2\lg x + 11 = 13 \iff \lg x = 1 \iff x = 10$.

**Răspuns:** $x = 10$. *Barem: 2p ecuația, 3p soluția.*

## Subiectul al III-lea (30 de puncte)

$A(a) = \begin{pmatrix}1 & a\\0 & 1\end{pmatrix}$.

### 1. $\det(A(0))$

$A(0) = I_2$, $\det = 1\cdot1 - 0 = 1$. *Barem: 3p, 2p.*

### 2. $a$ cu $2A(a) + A(a - 3) = 3A(0)$

$$\begin{pmatrix}2 & 2a\\0 & 2\end{pmatrix} + \begin{pmatrix}1 & a - 3\\0 & 1\end{pmatrix} = \begin{pmatrix}3 & 3a - 3\\0 & 3\end{pmatrix} = \begin{pmatrix}3&0\\0&3\end{pmatrix} \iff 3a - 3 = 0 \iff a = 1.$$

**Răspuns:** $a = 1$. *Barem: 3p egalitatea, 2p valoarea.*

### 3. $A(1) + A(2) + \dots + A(9) = 9A(5)$

$$\sum_{k=1}^9 A(k) = \begin{pmatrix}9 & 1 + 2 + \dots + 9\\0 & 9\end{pmatrix} = \begin{pmatrix}9 & 45\\0 & 9\end{pmatrix} = 9\begin{pmatrix}1 & 5\\0 & 1\end{pmatrix} = 9A(5).$$

*Barem: 2p suma, 3p finalizarea.*

### 4. $\det(A(a) + A(b)) = 4\det(A(a)\cdot A(b))$

$$A(a) + A(b) = \begin{pmatrix}2 & a + b\\0 & 2\end{pmatrix} \Rightarrow \det = 4,$$

$$A(a)A(b) = \begin{pmatrix}1 & a + b\\0 & 1\end{pmatrix} \Rightarrow \det = 1.$$

Deci $4 = 4\cdot1$. *Barem: 2p primul determinant, 3p al doilea și concluzia.*

### 5. $A(-a)$ este inversa lui $A(a)$

$$A(a)A(-a) = \begin{pmatrix}1 & -a + a\\0 & 1\end{pmatrix} = I_2, \qquad A(-a)A(a) = \begin{pmatrix}1 & a - a\\0 & 1\end{pmatrix} = I_2.$$

**Răspuns:** da. *Barem: 3p, 2p.*

### 6. $X = \begin{pmatrix}p & 2\\q & 1\end{pmatrix}$ cu $X\cdot A(a) = A(a)\cdot X$ pentru orice $a$

$$XA(a) = \begin{pmatrix}p & pa + 2\\q & qa + 1\end{pmatrix}, \qquad A(a)X = \begin{pmatrix}p + qa & 2 + a\\q & 1\end{pmatrix}.$$

Pentru orice $a$: $qa = 0 \Rightarrow q = 0$; $pa + 2 = 2 + a \Rightarrow p = 1$.

**Răspuns:** $X = \begin{pmatrix}1 & 2\\0 & 1\end{pmatrix}$. *Barem: 3p produsele, 2p valorile.*

## Ce merită reținut din varianta 1

- **Legea $x + y + c$**: neutrul este $-c$, iar compunerile se reduc la sume.
- **Matricele $A(a) = \begin{pmatrix}1&a\\0&1\end{pmatrix}$**: $A(a)A(b) = A(a+b)$, deci $A(a)^{-1} = A(-a)$.
- **„Pentru orice $a$”**: identifică coeficienții lui $a$ și termenii liberi.
- **Sinusul în triunghiul dreptunghic**: cateta opusă / ipotenuză.
