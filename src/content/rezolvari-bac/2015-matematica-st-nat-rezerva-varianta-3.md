## Subiectul I (30 de puncte)

### 1. $z_1 = 3 + i$, $z_2 = 3 - i$; $z_1z_2$ este real

$$z_1z_2 = (3 + i)(3 - i) = 9 - i^2 = 10 \in \mathbb R.$$

*Barem: 3p produsul, 2p concluzia.*

### 2. $a$ știind că $A(1,1)$ aparține graficului lui $f(x) = x + a$

$f(1) = 1 \iff 1 + a = 1 \iff a = 0$. *Barem: 3p, 2p.*

### 3. Ecuația $\sqrt[3]{x^3 + 2x - 4} = x$

Ridicăm la cub: $x^3 + 2x - 4 = x^3 \iff 2x = 4 \iff x = 2$.

**Răspuns:** $x = 2$. *Barem: 3p, 2p.*

### 4. Probabilitatea ca un număr din $\{1, \dots, 80\}$ să fie divizibil cu 7

Multiplii lui 7: $7, 14, \dots, 77$ — **11**; posibile: **80**.

$$p = \frac{11}{80}.$$

*Barem: 1p, 2p, 2p.*

### 5. $O(0,0)$, $A(1,2)$, $B(2,a)$ coliniare

$m_{OA} = 2$, $m_{OB} = \dfrac a2$; coliniare $\iff \dfrac a2 = 2 \iff a = 4$.

**Răspuns:** $a = 4$. *Barem: 2p pantele, 3p valoarea.*

### 6. $E(x) = \cos\dfrac x2 + \sin x$; $E\left(\frac\pi3\right) = \sqrt3$

$$E\left(\frac\pi3\right) = \cos\frac\pi6 + \sin\frac\pi3 = \frac{\sqrt3}{2} + \frac{\sqrt3}{2} = \sqrt3.$$

*Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(x) = \begin{pmatrix}2 & x\\x & 2\end{pmatrix}$

#### a) $\det(A(0)) = 4$

$A(0) = 2I_2$, $\det = 4$. *Barem: 3p, 2p.*

#### b) $a$ cu $A(1) + A(3) = aA(2)$

$$A(1) + A(3) = \begin{pmatrix}4&4\\4&4\end{pmatrix} = 2\begin{pmatrix}2&2\\2&2\end{pmatrix} = 2A(2).$$

**Răspuns:** $a = 2$. *Barem: 3p, 2p.*

#### c) $A(x)A(y) = 2A(x+y) + xyI_2$

$$A(x)A(y) = \begin{pmatrix}4 + xy & 2y + 2x\\2x + 2y & xy + 4\end{pmatrix},$$

$$2A(x+y) + xyI_2 = \begin{pmatrix}4 & 2(x+y)\\2(x+y) & 4\end{pmatrix} + \begin{pmatrix}xy & 0\\0 & xy\end{pmatrix} = \begin{pmatrix}4 + xy & 2(x+y)\\2(x+y) & 4 + xy\end{pmatrix}.$$

*Barem: 2p produsul, 3p finalizarea.*

### 2. $x * y = 3xy + 6x + 6y + 10$ (asociativă)

#### a) $2 * (-2) = -2$

$$3\cdot2\cdot(-2) + 12 - 12 + 10 = -2.$$

*Barem: 3p, 2p.*

#### b) $x * y = 3(x+2)(y+2) - 2$

$$3xy + 6x + 6y + 12 - 2 = 3x(y + 2) + 6(y + 2) - 2 = 3(x+2)(y+2) - 2.$$

*Barem: 2p, 3p.*

#### c) $x * x * x = x$

$x * x * x = 9(x+2)^3 - 2$. Ecuația:

$$9(x+2)^3 - 2 = x \iff 9(x+2)^3 = x + 2 \iff (x + 2)\big(9(x+2)^2 - 1\big) = 0.$$

$x + 2 = 0$ sau $x + 2 = \pm\frac13$.

**Răspuns:** $x \in \left\{-\frac73, -2, -\frac53\right\}$. *Barem: 2p expresia, 3p soluțiile.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = (x + 1)e^x$

#### a) $f'(x) = (x + 2)e^x$

$$f'(x) = e^x + (x + 1)e^x = (x + 2)e^x.$$

*Barem: 2p, 3p.*

#### b) Tangenta în $x = 0$

$f(0) = 1$, $f'(0) = 2$: $y = 2x + 1$. *Barem: 2p, 3p.*

#### c) $f$ este convexă pe $[-3, +\infty)$

$f''(x) = e^x + (x + 2)e^x = (x + 3)e^x \ge 0$ pentru $x \ge -3$. *Barem: 2p, 3p.*

### 2. $f(x) = \dfrac{x^3 + 3x}{x^2 + 1}$

Observație: $f(x) = x + \dfrac{2x}{x^2 + 1}$.

#### a) $\displaystyle\int_{-1}^1(x^2 + 1)f(x)\,dx = 0$

$$\int_{-1}^1(x^3 + 3x)\,dx = \left(\frac{x^4}{4} + \frac{3x^2}{2}\right)\Big|_{-1}^1 = \left(\frac14 + \frac32\right) - \left(\frac14 + \frac32\right) = 0.$$

(Sau: integrandul este impar pe un interval simetric.) *Barem: 3p, 2p.*

#### b) $\displaystyle\int_0^1 f(x)\,dx = \frac12 + \ln2$

$$\int_0^1\left(x + \frac{2x}{x^2+1}\right)dx = \left(\frac{x^2}{2} + \ln(x^2 + 1)\right)\Big|_0^1 = \frac12 + \ln2.$$

*Barem: 2p descompunerea, 3p calculul.*

#### c) $m > 0$ cu aria pentru $g(x) = f(x) - x$ egală cu $\ln 2$

$g(x) = \dfrac{2x}{x^2 + 1} \ge 0$ pe $[0, m]$:

$$\mathcal A = \int_0^m\frac{2x}{x^2+1}\,dx = \ln(m^2 + 1) = \ln 2 \iff m^2 = 1 \iff m = 1.$$

**Răspuns:** $m = 1$. *Barem: 3p aria, 2p valoarea.*
