## Subiectul I (30 de puncte)

### 1. Arătați că $\left(1 - \frac12\right)\left(1 - \frac13\right)\left(1 - \frac14\right) = \frac14$

$$\frac12\cdot\frac23\cdot\frac34 = \frac{1\cdot2\cdot3}{2\cdot3\cdot4} = \frac14.$$

*Barem: 3p + 2p.*

### 2. Abscisele punctelor de intersecție ale graficului lui $f(x) = x^2 - 3x + 2$ cu $Ox$

$x^2 - 3x + 2 = 0 \iff (x-1)(x-2) = 0$. **Răspuns:** $1$ și $2$. *Barem: 3p + 2p.*

### 3. Ecuația $\log_5(2x - 1) = 2$

$2x - 1 = 25 \iff x = 13$, care verifică. *Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr din $\{10, 20, \dots, 90\}$ să fie divizor al lui $1000$

$1000 = 2^3\cdot5^3$. Dintre elementele mulțimii, divizori sunt $10, 20, 40, 50$ (de exemplu $30$ conține factorul $3$, $80 = 2^4\cdot5$ conține $2^4$). 4 favorabile din 9.

$$p = \frac49.$$

*Barem: 1p + 2p + 2p.*

### 5. Perimetrul triunghiului $O(0,0)$, $A(0,3)$, $B(4,0)$

$AO = 3$, $BO = 4$, $AB = \sqrt{9 + 16} = 5$, deci $P = 12$. *Barem: 3p + 2p.*

### 6. $\sin x = \frac35$, știind $x \in \left(0, \frac\pi2\right)$ și $\cos x = \frac45$

$\sin^2 x = 1 - \frac{16}{25} = \frac{9}{25}$; în cadranul I, $\sin x = \frac35$. *Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} -1 & 1\\ 0 & 0\end{pmatrix}$

#### a) $\det A = 0$

A doua linie este nulă, deci $\det A = 0$. *Barem: 2p + 3p.*

#### b) $A\cdot(A + I_2) = O_2$?

$$A + I_2 = \begin{pmatrix} 0 & 1\\ 0 & 1\end{pmatrix}, \qquad A(A + I_2) = \begin{pmatrix} 0 & -1 + 1\\ 0 & 0\end{pmatrix} = O_2.$$

**Răspuns:** da. *Barem: 2p + 3p.*

#### c) $m$ cu $\det B = 0$, $B = A\cdot A + mI_2$

$$A\cdot A = \begin{pmatrix} 1 & -1\\ 0 & 0\end{pmatrix}, \qquad B = \begin{pmatrix} 1 + m & -1\\ 0 & m\end{pmatrix}, \qquad \det B = m(m + 1).$$

**Răspuns:** $m \in \{-1, 0\}$. *Barem: 3p + 2p.*

### 2. $f = X^3 + X^2 + 4X + 4$

#### a) $f(-1) = 0$

$$-1 + 1 - 4 + 4 = 0.$$

*Barem: 3p + 2p.*

#### b) Câtul și restul împărțirii la $X^2 + 3X + 2$

$(X - 2)(X^2 + 3X + 2) = X^3 + X^2 - 4X - 4$, deci $f - (X-2)(X^2 + 3X + 2) = 8X + 8$.

**Răspuns:** câtul $X - 2$, restul $8X + 8$. *Barem: 3p + 2p.*

#### c) $\frac{1}{x_1} + \frac{1}{x_2} + \frac{1}{x_3} + \frac{1}{x_1x_2} + \frac{1}{x_2x_3} + \frac{1}{x_3x_1} = -\frac34$

Viète: $\sum x_i = -1$, $\sum x_ix_j = 4$, $x_1x_2x_3 = -4$. Cu numitorul comun $x_1x_2x_3$:

$$\frac{(x_2x_3 + x_1x_3 + x_1x_2) + (x_3 + x_1 + x_2)}{x_1x_2x_3} = \frac{4 - 1}{-4} = -\frac34. \ \blacksquare$$

*Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^3 - 12x$

#### a) $f'(x) = 3(x-2)(x+2)$

$$f'(x) = 3x^2 - 12 = 3(x^2 - 4) = 3(x-2)(x+2).$$

*Barem: 3p + 2p.*

#### b) Tangenta în $x = 2$

$f(2) = 8 - 24 = -16$, $f'(2) = 0$, deci $y = -16$. *Barem: 2p + 3p.*

#### c) $-16 \le f(x) \le 16$ pentru $x \in [-2, 2]$

Pe $[-2, 2]$, $f'(x) \le 0$, deci $f$ este descrescătoare: $f(2) \le f(x) \le f(-2)$, adică $-16 \le f(x) \le 16$ ($f(-2) = -8 + 24 = 16$). $\blacksquare$ *Barem: 3p + 2p.*

### 2. $f(x) = 5x^4 + 3x^2 + 1$

#### a) $\displaystyle\int_0^1(f(x) - 3x^2 - 1)\,dx = 1$

$$\int_0^1 5x^4\,dx = x^5\Big|_0^1 = 1.$$

*Barem: 3p + 2p.*

#### b) Aria sub grafic pe $[1,2]$

$f > 0$:

$$\mathcal A = (x^5 + x^3 + x)\Big|_1^2 = (32 + 8 + 2) - (1 + 1 + 1) = 39.$$

*Barem: 3p + 2p.*

#### c) Orice primitivă a lui $f$ este crescătoare pe $\mathbb R$

$F' = f = 5x^4 + 3x^2 + 1 > 0$ pentru orice $x$ real, deci $F$ este (strict) crescătoare. $\blacksquare$ *Barem: 2p + 3p.*

## Ce merită reținut din modelul 2016

- **Produse telescopice**: $\frac12\cdot\frac23\cdot\frac34$ se simplifică în lanț.
- **Divizori ai lui $10^k$**: au doar factorii primi $2$ și $5$, fiecare cu exponent cel mult $k$.
- **Sume de inverse ale rădăcinilor**: adu la numitorul comun $x_1x_2x_3$.
- **Primitivele unei funcții strict pozitive** sunt strict crescătoare.
