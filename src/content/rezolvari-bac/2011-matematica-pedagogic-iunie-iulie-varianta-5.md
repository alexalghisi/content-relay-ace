## Subiectul I (30 de puncte)

### 1. Progresie aritmetică cu $a_2 = 5$, $a_4 = 11$; calculați $a_6$

$a_4 - a_2 = 2r = 6 \Rightarrow r = 3$, deci $a_6 = a_4 + 2r = 11 + 6 = 17$.

**Răspuns:** $a_6 = 17$. *Barem: 3p rația, 2p rezultatul.*

### 2. Dacă $f(1) = g(1)$ și $f(3) = g(3)$, atunci $f(5) = g(5)$ ($f, g$ de gradul I)

Din ipoteză: $a + b = c + d$ și $3a + b = 3c + d$. Scăzând: $2a = 2c \Rightarrow a = c$, apoi $b = d$. Deci $f = g$ și, în particular, $f(5) = g(5)$. $\blacksquare$ *Barem: 2p + 2p + 1p.*

### 3. $\frac{1}{x_1} + \frac{1}{x_2}$ pentru $x^2 - 5x + 3 = 0$

Viète: $S = 5$, $P = 3$.

$$\frac{1}{x_1} + \frac{1}{x_2} = \frac{x_1 + x_2}{x_1x_2} = \frac53.$$

*Barem: 1p + 1p + 2p + 1p.*

### 4. Ecuația $\log_2(x^2 + x + 2) = 2$

$x^2 + x + 2 > 0$ pentru orice $x$ ($\Delta < 0$). Ecuația: $x^2 + x + 2 = 4 \iff x^2 + x - 2 = 0 \iff (x+2)(x-1) = 0$.

**Răspuns:** $S = \{-2, 1\}$. *Barem: 3p + 2p.*

### 5. $\overrightarrow{AM} = 3\overrightarrow{MB}$, $\overrightarrow{AN} = 3\overrightarrow{NC}$: $MN \parallel BC$

Din relațiile vectoriale, $M \in [AB]$ cu $\dfrac{AM}{MB} = 3$ și $N \in [AC]$ cu $\dfrac{AN}{NC} = 3$. Cum $\dfrac{AM}{MB} = \dfrac{AN}{NC}$, din reciproca teoremei lui Thales, $MN \parallel BC$. $\blacksquare$

(Vectorial: $\overrightarrow{AM} = \frac34\overrightarrow{AB}$, $\overrightarrow{AN} = \frac34\overrightarrow{AC}$, deci $\overrightarrow{MN} = \frac34\overrightarrow{BC}$.) *Barem: 2p + 2p + 1p.*

### 6. $A = 30^\circ$, $C = 90^\circ$, $BC = 6$; aflați $AC$

$\operatorname{tg} A = \dfrac{BC}{AC}$, deci

$$AC = \frac{BC}{\operatorname{tg}30^\circ} = BC\cdot\operatorname{ctg}30^\circ = 6\sqrt3.$$

**Răspuns:** $AC = 6\sqrt3$. *Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

Legea: $x * y = xy - 2x - 2y + 6$.

### a) Comutativitate

$$y * x = yx - 2y - 2x + 6 = xy - 2x - 2y + 6 = x * y.$$

*Barem: 2p + 2p + 1p.*

### b) Asociativitate

Folosind forma de la c), $x * y = (x-2)(y-2) + 2$:

$$(x*y)*z = (x-2)(y-2)(z-2) + 2 = x*(y*z).$$

Dezvoltat, ambele dau $xyz - 2xy - 2xz - 2yz + 4x + 4y + 4z - 6$. *Barem: 2p + 2p + 1p.*

### c) $a$ cu $x * y = (2-x)(2-y) + a$

$(2-x)(2-y) = 4 - 2x - 2y + xy$, deci $xy - 2x - 2y + 6 = xy - 2x - 2y + 4 + a \iff a = 2$.

**Răspuns:** $a = 2$. *Barem: 2p + 3p.*

### d) $x * x = x$

$$x^2 - 4x + 6 = x \iff x^2 - 5x + 6 = 0 \iff (x-2)(x-3) = 0.$$

**Răspuns:** $x \in \{2, 3\}$. *Barem: 3p + 2p.*

### e) Elementul neutru

$x * e = x$ pentru orice $x$: $(x-2)(e-2) + 2 = x \iff (x-2)(e-2) = x - 2$ pentru orice $x$, deci $e - 2 = 1$.

**Răspuns:** $e = 3$. *Barem: 1p + 2p + 2p.*

### f) $(x+2) * \left(\frac1x + 2\right) = 3$ pentru $x \ne 0$

$$(x+2) * \left(\frac1x + 2\right) = (2 - x - 2)\left(2 - \frac1x - 2\right) + 2 = (-x)\left(-\frac1x\right) + 2 = 1 + 2 = 3. \ \blacksquare$$

*Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix} 0 & a & 0\\ 0 & 0 & -a\\ -a & 0 & 0\end{pmatrix}$.

### a) $\det(A + I_3) = 1$

$$A + I_3 = \begin{pmatrix} 1 & a & 0\\ 0 & 1 & -a\\ -a & 0 & 1\end{pmatrix}, \qquad \det(A + I_3) = 1 + a\cdot(-a)\cdot(-a) = 1 + a^3.$$

$1 + a^3 = 1 \iff a = 0$. **Răspuns:** $a = 0$. *Barem: 1p + 3p + 1p.*

### b) $\det(A + {}^tA)$

$${}^tA = \begin{pmatrix} 0 & 0 & -a\\ a & 0 & 0\\ 0 & -a & 0\end{pmatrix}, \qquad A + {}^tA = \begin{pmatrix} 0 & a & -a\\ a & 0 & -a\\ -a & -a & 0\end{pmatrix}.$$

Sarrus: diagonala principală $0$; termenii $a\cdot(-a)\cdot(-a) = a^3$ și $(-a)\cdot a\cdot(-a) = a^3$; termenii scăzuți conțin toți un $0$.

**Răspuns:** $\det(A + {}^tA) = 2a^3$. *Barem: 1p + 2p + 2p.*

### c) Inversa lui $A$ pentru $a = 1$

$A = \begin{pmatrix} 0 & 1 & 0\\ 0 & 0 & -1\\ -1 & 0 & 0\end{pmatrix}$, $\det A = a^3 = 1 \ne 0$. Din d), $A^3 = I_3$, deci $A^{-1} = A^2$:

$$A^{-1} = \begin{pmatrix} 0 & 0 & -1\\ 1 & 0 & 0\\ 0 & -1 & 0\end{pmatrix}.$$

*Barem: 2p inversabilitatea, 3p inversa.*

### d) $A^3 = a^3I_3$

$$A^2 = \begin{pmatrix} 0 & 0 & -a^2\\ a^2 & 0 & 0\\ 0 & -a^2 & 0\end{pmatrix}, \qquad A^3 = A^2\cdot A = \begin{pmatrix} a^3 & 0 & 0\\ 0 & a^3 & 0\\ 0 & 0 & a^3\end{pmatrix} = a^3I_3.$$

(De exemplu $(1,1)$: $(-a^2)(-a) = a^3$.) *Barem: 2p + 3p.*

### e) Pentru $a = 1$: $(A + I_3)(A^2 - A + I_3) = 2I_3$

$A$ comută cu $I_3$, deci se aplică identitatea $x^3 + 1 = (x+1)(x^2 - x + 1)$:

$$(A + I_3)(A^2 - A + I_3) = A^3 + I_3 = I_3 + I_3 = 2I_3. \ \blacksquare$$

*Barem: 3p + 2p.*

### f) $\det(A + {}^tA + I_3) = 1$

$$A + {}^tA + I_3 = \begin{pmatrix} 1 & a & -a\\ a & 1 & -a\\ -a & -a & 1\end{pmatrix},$$

$$\det = 1 + a^3 + a^3 - \big(a^2 + a^2 + a^2\big) = 2a^3 - 3a^2 + 1.$$

$2a^3 - 3a^2 + 1 = 1 \iff a^2(2a - 3) = 0$.

**Răspuns:** $a \in \left\{0, \dfrac32\right\}$. *Barem: 1p + 2p + 2p.*

## Ce merită reținut din varianta 5

- **Două funcții de gradul I egale în două puncte** sunt identice.
- **Legea $(x-a)(y-a) + a$** are elementul neutru $a + 1$.
