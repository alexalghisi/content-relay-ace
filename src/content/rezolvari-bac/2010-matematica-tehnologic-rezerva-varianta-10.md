## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_3 = 5$, $a_5 = 11$; suma primilor șapte termeni

$$\begin{cases}a_1 + 2r = 5\\a_1 + 4r = 11\end{cases} \Rightarrow 2r = 6,\ r = 3,\ a_1 = -1.$$

$a_7 = a_1 + 6r = 17$, deci

$$S_7 = \frac{(a_1 + a_7)\cdot 7}{2} = \frac{16\cdot 7}{2} = 56.$$

**Răspuns:** $S_7 = 56$. *Barem: 3p $a_1$ și $r$, 2p suma.*

### 2. Intersecția graficelor $f(x) = 2x - 1$ și $g(x) = x + 3$

$$2x - 1 = x + 3 \iff x = 4, \quad y = f(4) = 7.$$

**Răspuns:** $A(4, 7)$. *Barem: 2p ecuația, 2p coordonatele, 1p punctul.*

### 3. Ecuația $\sqrt[3]{x^2 - 1} = 2$

Ridicăm la puterea a treia: $x^2 - 1 = 8 \iff x^2 = 9 \iff x = \pm3$.

**Răspuns:** $x \in \{-3, 3\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 4. $a\cdot b$, știind $a + b = 150$ și $a = 25\%$ din $b$

$a = \dfrac{b}{4}$, deci $\dfrac b4 + b = 150 \Rightarrow \dfrac{5b}{4} = 150 \Rightarrow b = 120$, $a = 30$.

$$a\cdot b = 30\cdot 120 = 3600.$$

**Răspuns:** $3600$. *Barem: 3p $b$, 1p $a$, 1p produsul.*

### 5. $m$ pentru care $A(2,3)$, $B(4,5)$, $C(m+1, m^2)$ sunt coliniare

Dreapta $AB$: $\dfrac{x - 2}{2} = \dfrac{y - 3}{2} \iff x - y + 1 = 0$.

$C \in AB \iff (m + 1) - m^2 + 1 = 0 \iff m^2 - m - 2 = 0 \iff m \in \{-1, 2\}$.

**Răspuns:** $m \in \{-1, 2\}$. *Barem: 2p ecuația dreptei, 1p condiția, 2p soluțiile.*

### 6. $\cos x$, știind $\sin x = \dfrac13$ și $x \in \left(0, \frac\pi2\right)$

$$\cos^2 x = 1 - \frac19 = \frac89 \Rightarrow \cos x = \pm\frac{2\sqrt2}{3}.$$

În cadranul I, $\cos x > 0$, deci $\cos x = \dfrac{2\sqrt2}{3}$. *Barem: 3p formula fundamentală, 2p semnul.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}m&1&0\\1&1&1\\1&1&m\end{pmatrix}$, sistemul $\begin{cases}mx + y = -1\\x + y + z = 3\\x + y + mz = 0\end{cases}$

#### a) $\det A$

$$\det A = m(m - 1) - 1\cdot(m - 1) + 0 = (m-1)^2 = m^2 - 2m + 1.$$

*Barem: 1p scrierea, 4p calculul.*

#### b) Rezolvarea pentru $m = 0$

$$\begin{cases}y = -1\\x + y + z = 3\\x + y = 0\end{cases} \Rightarrow y = -1,\ x = 1,\ z = 3.$$

**Răspuns:** $(1, -1, 3)$. *Barem: 2p sistemul, 3p soluția.*

#### c) Pentru $m = 1$ sistemul este incompatibil

$$\begin{cases}x + y = -1\\x + y + z = 3\\x + y + z = 0\end{cases}$$

Scăzând ultimele două ecuații obținem $0 = 3$, contradicție, deci sistemul este incompatibil. *Barem: 2p sistemul, 3p contradicția.*

### 2. $x * y = (x - 4)(y - 4) + 4$

#### a) Legea este asociativă

$$(x*y)*z = \big((x-4)(y-4) + 4 - 4\big)(z - 4) + 4 = (x-4)(y-4)(z-4) + 4,$$

$$x*(y*z) = (x - 4)\big((y-4)(z-4) + 4 - 4\big) + 4 = (x-4)(y-4)(z-4) + 4.$$

Rezultatele coincid. *Barem: 1p pe fiecare pas, 5p total.*

#### b) $x * y \in (4, +\infty)$ pentru $x, y \in (4, +\infty)$

$x > 4$ și $y > 4$ $\Rightarrow$ $(x-4)(y-4) > 0$ $\Rightarrow$ $x * y = (x-4)(y-4) + 4 > 4$. $\blacksquare$ *Barem: 3p produsul pozitiv, 2p concluzia.*

#### c) $1 * 2 * 3 * \dots * 2010$

$x * 4 = (x-4)\cdot0 + 4 = 4$ și $4 * x = 4$ pentru orice $x$. Folosind asociativitatea:

$$1 * 2 * \dots * 2010 = \big((1*2*3) * 4\big) * (5 * \dots * 2010) = 4 * (\dots) = 4.$$

**Răspuns:** $4$. *Barem: 2p elementul absorbant, 3p calculul.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:\mathbb R^*\to\mathbb R$, $f(x) = x^2 + \dfrac2x$

#### a) $f'(x)$

$$f'(x) = 2x - \frac{2}{x^2}.$$

*Barem: 2p derivatele termenilor, 3p rezultatul.*

#### b) Tangenta în $A(2, 5)$

$f(2) = 4 + 1 = 5$, $f'(2) = 4 - \dfrac24 = \dfrac72$:

$$y - 5 = \frac72(x - 2) \iff y = \frac72x - 2.$$

**Răspuns:** $y = \dfrac72x - 2$. *Barem: 2p formula, 2p valorile, 1p ecuația.*

#### c) Asimptota verticală

$$\lim_{x\nearrow0}\left(x^2 + \frac2x\right) = -\infty, \qquad \lim_{x\searrow0}\left(x^2 + \frac2x\right) = +\infty.$$

**Răspuns:** dreapta $x = 0$. *Barem: 4p limitele, 1p concluzia.*

### 2. $f(x) = \dfrac{\ln x}{\sqrt x}$, $g(x) = 2\sqrt x(\ln x - 2)$, $x > 0$

#### a) $g$ este o primitivă a lui $f$

$g$ este derivabilă pe $(0, +\infty)$ și

$$g'(x) = \frac{2}{2\sqrt x}(\ln x - 2) + 2\sqrt x\cdot\frac1x = \frac{\ln x - 2}{\sqrt x} + \frac{2}{\sqrt x} = \frac{\ln x}{\sqrt x} = f(x).$$

*Barem: 1p derivabilitatea, 3p derivata, 1p concluzia.*

#### b) $\displaystyle\int_1^4 f(x)\,dx$

$$\int_1^4 f(x)\,dx = g(4) - g(1) = 4(\ln4 - 2) - 2(0 - 2) = 8\ln2 - 8 + 4 = 8\ln 2 - 4.$$

**Răspuns:** $8\ln2 - 4$. *Barem: 1p Leibniz–Newton, 2p înlocuirea, 2p rezultatul.*

#### c) $\displaystyle\int_1^{e^2}2^{g(x)}f(x)\,dx$

Cum $f = g'$, integrandul este $2^{g(x)}g'(x) = \left(\dfrac{2^{g(x)}}{\ln 2}\right)'$:

$$\int_1^{e^2}2^{g(x)}g'(x)\,dx = \frac{2^{g(x)}}{\ln2}\Big|_1^{e^2}.$$

$g(e^2) = 2e(2 - 2) = 0$, $g(1) = 2(0 - 2) = -4$, deci

$$\frac{2^0 - 2^{-4}}{\ln 2} = \frac{1 - \frac1{16}}{\ln2} = \frac{15}{16\ln 2}.$$

**Răspuns:** $\dfrac{15}{16\ln2}$. *Barem: 3p primitiva, 2p calculul.*

## Ce merită reținut din varianta 10

- **Progresii aritmetice**: din doi termeni afli $a_1$ și $r$, apoi $S_n = \frac{(a_1 + a_n)n}{2}$.
- **Coliniaritate**: scrie ecuația dreptei prin două puncte și impune ca al treilea să o verifice.
- **Element absorbant** ($x * 4 = 4$) într-un produs lung: rezultatul este chiar acel element.
- **$\int a^{g(x)}g'(x)\,dx = \frac{a^{g(x)}}{\ln a}$** — recunoaște derivata funcției compuse.
