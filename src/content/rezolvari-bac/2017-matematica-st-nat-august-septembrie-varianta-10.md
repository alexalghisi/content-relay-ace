## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_3 = 10$, $r = 3$; aflați $a_1$

$a_3 = a_1 + 2r$, deci $a_1 = a_3 - 2r = 10 - 6 = 4$.

**Răspuns:** $a_1 = 4$. *Barem: 3p formula, 2p rezultatul.*

### 2. $A(1,3)$ pe graficul lui $f(x) = x^2 - mx + 2m$

$f(1) = 3 \iff 1 - m + 2m = 3 \iff m = 2$.

**Răspuns:** $m = 2$. *Barem: 3p condiția, 2p valoarea.*

### 3. Ecuația $4^x + \frac14 = \frac12$

$$4^x = \frac12 - \frac14 = \frac14 = 4^{-1} \iff x = -1.$$

**Răspuns:** $x = -1$. *Barem: 3p $4^x = 4^{-1}$, 2p soluția.*

### 4. Numere pare de două cifre distincte cu cifre din $\{1,2,3,4\}$

Unitățile: cifră pară, $2$ sau $4$ — 2 moduri. Zecile: oricare din celelalte 3 cifre.

$$2\cdot3 = 6 \quad(12, 32, 42, 14, 24, 34).$$

**Răspuns:** 6. *Barem: 2p cifra unităților, 3p finalizarea.*

### 5. Mediatoarea segmentului $AB$, $A(4,2)$, $B(2,4)$

Mijlocul: $M(3, 3)$. Panta $AB$: $m_{AB} = \dfrac{4-2}{2-4} = -1$, deci mediatoarea (perpendiculară pe $AB$) are panta $1$:

$$y - 3 = 1\cdot(x - 3) \iff y = x.$$

**Răspuns:** $y = x$. *Barem: 2p mijlocul, 3p ecuația.*

### 6. Raza cercului circumscris, catete $AB = 8$, $AC = 6$

Ipotenuza: $BC = \sqrt{64 + 36} = 10$. Într-un triunghi dreptunghic ipotenuza este diametru:

$$R = \frac{BC}{2} = 5.$$

**Răspuns:** $R = 5$. *Barem: 2p ipotenuza, 3p raza.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(x) = \begin{pmatrix} 1 & 2x+5\\ 5 & 1\end{pmatrix}$

#### a) $\det(A(-2)) = -4$

$$\det\begin{pmatrix} 1 & 1\\ 5 & 1\end{pmatrix} = 1 - 5 = -4.$$

*Barem: 2p scrierea, 3p calculul.*

#### b) $A(x) + A(-x) = A(2017) + A(-2017)$

$$A(x) + A(-x) = \begin{pmatrix} 1 & 2x+5\\ 5 & 1\end{pmatrix} + \begin{pmatrix} 1 & -2x+5\\ 5 & 1\end{pmatrix} = \begin{pmatrix} 2 & 10\\ 10 & 2\end{pmatrix}.$$

Suma nu depinde de $x$, deci pentru $x = 2017$ obținem aceeași matrice. $\blacksquare$ *Barem: 3p suma, 2p finalizarea.*

#### c) $A(0)\begin{pmatrix} p\\ q\end{pmatrix} = \begin{pmatrix} 6\\ 6\end{pmatrix}$

$$\begin{pmatrix} 1 & 5\\ 5 & 1\end{pmatrix}\begin{pmatrix} p\\ q\end{pmatrix} = \begin{pmatrix} p + 5q\\ 5p + q\end{pmatrix} = \begin{pmatrix} 6\\ 6\end{pmatrix}.$$

Scăzând ecuațiile: $4q - 4p = 0 \Rightarrow p = q$, apoi $6p = 6$.

**Răspuns:** $p = q = 1$. *Barem: 3p produsul, 2p soluția.*

### 2. $x\circ y = xy + 6x + 6y + 30$

#### a) $x\circ y = (x+6)(y+6) - 6$

$$xy + 6x + 6y + 36 - 6 = x(y+6) + 6(y+6) - 6 = (x+6)(y+6) - 6.$$

*Barem: 2p + 3p.*

#### b) $e = -5$ este elementul neutru

$$x\circ(-5) = (x+6)\cdot1 - 6 = x, \qquad (-5)\circ x = 1\cdot(x+6) - 6 = x.$$

*Barem: 2p + 3p.*

#### c) $x\circ(-2017) = 2017\circ(-6)$

Membrul drept: $(2017 + 6)\cdot0 - 6 = -6$. Membrul stâng: $(x+6)(-2011) - 6$.

$$(x+6)(-2011) - 6 = -6 \iff x + 6 = 0 \iff x = -6.$$

**Răspuns:** $x = -6$. *Barem: 2p ecuația, 3p soluția.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:(0,+\infty)\to\mathbb R$, $f(x) = \dfrac2x + \ln x$

#### a) $f'(x) = \dfrac{x - 2}{x^2}$

$$f'(x) = -\frac{2}{x^2} + \frac1x = \frac{-2 + x}{x^2}.$$

*Barem: 2p derivarea, 3p forma finală.*

#### b) Tangenta în punctul de abscisă $1$

$f(1) = 2 + 0 = 2$, $f'(1) = \dfrac{1-2}{1} = -1$.

$$y - 2 = -1(x - 1) \iff y = -x + 3.$$

**Răspuns:** $y = -x + 3$. *Barem: 2p valorile, 3p ecuația.*

#### c) $\dfrac2x + \ln x \ge 1 + \ln 2$ pentru $x > 0$

$f'(x) = 0 \iff x = 2$; $f' \le 0$ pe $(0, 2]$ (descrescătoare), $f' \ge 0$ pe $[2, +\infty)$ (crescătoare). Deci $x = 2$ este punct de minim global:

$$f(x) \ge f(2) = 1 + \ln 2. \ \blacksquare$$

*Barem: 1p + 1p + 1p monotonia, 2p concluzia.*

### 2. $f:(0,+\infty)\to\mathbb R$, $f(x) = \dfrac{x^2 + 2}{2x}$

#### a) $\displaystyle\int_1^2 2xf(x)\,dx = \frac{13}{3}$

$2xf(x) = x^2 + 2$:

$$\int_1^2 (x^2 + 2)\,dx = \left(\frac{x^3}{3} + 2x\right)\Big|_1^2 = \left(\frac83 + 4\right) - \left(\frac13 + 2\right) = \frac73 + 2 = \frac{13}{3}.$$

*Barem: 3p primitiva, 2p calculul.*

#### b) Primitiva $F$ cu $F(1) = 1$

$f(x) = \dfrac x2 + \dfrac1x$, deci $F(x) = \dfrac{x^2}{4} + \ln x + c$. $F(1) = \dfrac14 + c = 1 \Rightarrow c = \dfrac34$.

**Răspuns:** $F(x) = \dfrac{x^2}{4} + \ln x + \dfrac34$. *Barem: 3p forma primitivelor, 2p constanta.*

#### c) $2\displaystyle\int_1^n \big(f(x) + xf'(x)\big)\,dx = n^2 - 1$

Integrandul este derivata unui produs: $f(x) + xf'(x) = \big(xf(x)\big)'$, iar $xf(x) = \dfrac{x^2 + 2}{2}$.

$$2\int_1^n \big(xf(x)\big)'\,dx = 2\cdot xf(x)\Big|_1^n = (x^2 + 2)\Big|_1^n = (n^2 + 2) - 3 = n^2 - 1. \ \blacksquare$$

*Barem: 3p recunoașterea derivatei produsului, 2p calculul.*
