## A. Mecanică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **d**, 2 – **d**, 3 – **b**, 4 – **a**, 5 – **c** (câte 3 puncte).

**1.** Dacă asupra corpului acționează numai greutatea (forță conservativă), energia mecanică se conservă → **d**.

**2.** Legea lui Hooke pentru un fir elastic: $F = \dfrac{ES}{\ell_0}\Delta\ell$, deci $k = S\cdot E\cdot \ell_0^{-1}$ → **d**.

**3.** $P\cdot\Delta t$ este lucrul mecanic (energia), măsurat în joule → **b**.

**4.** La echilibru $k\Delta\ell = mg$: $\Delta\ell = \dfrac{0{,}27\cdot 10}{30} = 0{,}09\ \text{m} = 9{,}0\ \text{cm}$ → **a**.

**5.** Între 3 s și 7 s viteza este constantă, $v = 6\ \text{m/s}$, deci $d = v\Delta t = 6\cdot 4 = 24\ \text{m}$ → **c**.

### Subiectul al II-lea — corp și găleată legate peste un scripete (15 puncte)

Date: $m_1 = 3\ \text{kg}$, $a = 2\ \text{m/s}^2$, $g = 10\ \text{m/s}^2$; $m_1$ coboară, găleata urcă.

**a.** Asupra corpului $m_1$ acționează **greutatea** $m_1\vec g$, vertical în jos, și **tensiunea din fir** $\vec T$, vertical în sus, cu $m_1 g > T$, pentru că acesta coboară accelerat. *Barem: 4p.*

**b.** $m_1 g - T = m_1 a \Rightarrow T = m_1(g - a) = 3\cdot 8 = 24\ \text{N}$. *Barem: 3p, 1p.*

**c.** Găleata urcă accelerat: $T - m_2 g = m_2 a \Rightarrow m_2 = \dfrac{T}{g + a} = \dfrac{24}{12} = 2\ \text{kg}$. *Barem: 3p, 1p.*

**d.** Ambele ramuri ale firului trag în jos de scripete: $F_{ax} = 2T = 48\ \text{N}$. *Barem: 2p, 1p.*

### Subiectul al III-lea — energie mecanică și frecare pe porțiunea BC (15 puncte)

Date: $m = 0{,}5\ \text{kg}$, $H = 1{,}8\ \text{m}$, $d = BC = 2{,}5\ \text{m}$, $v_C = 4\ \text{m/s}$; $E_p = 0$ la nivelul BC.

**a.** $E_A = E_{cA} + E_{pA}$, cu $E_{cA} = 0$ (repaus) și $E_{pA} = mgH$:

$$E_A = 0{,}5\cdot 10\cdot 1{,}8 = 9\ \text{J}.$$

*Barem: 1p + 1p + 1p + 1p.*

**b.** Pe AB nu există frecare, deci $E_B = E_A$, iar în B toată energia este cinetică:

$$\frac{mv_B^2}{2} = 9\ \text{J} \Rightarrow v_B = \sqrt{\frac{2\cdot 9}{0{,}5}} = 6\ \text{m/s}.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** Teorema variației energiei cinetice pe BC, unde lucrează doar frecarea:

$$\Delta E_c = \frac{mv_C^2}{2} - E_{cB} = 4 - 9 = -5\ \text{J}, \qquad L_f = -\mu mg\,d = -12{,}5\,\mu.$$

$$-12{,}5\,\mu = -5 \Rightarrow \mu = 0{,}4.$$

*Barem: 1p + 1p + 1p + 1p.*

**d.** Pe CD nu există frecare: $mgh = \dfrac{mv_C^2}{2} = 4\ \text{J}$. La urcare greutatea se opune deplasării:

$$L_G = -mgh = -4\ \text{J}.$$

*Barem: 1p + 1p + 1p.*

## B. Elemente de termodinamică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **a**, 2 – **d**, 3 – **d**, 4 – **b**, 5 – **c** (câte 3 puncte).

**1.** Principiul întâi: $\Delta U = Q - L$ → **a**.

**2.** Destindere adiabatică: $Q = 0$, $L > 0$, deci $\Delta U = -L < 0$ → **d**.

**3.** Căldura molară $C = \dfrac{Q}{\nu\Delta T}$ se măsoară în $\text{J}\cdot\text{mol}^{-1}\cdot\text{K}^{-1}$ → **d**.

**4.** Pentru o cantitate dată de gaz, $T$ este proporțională cu $pV$: $p_1V < p_3V < p_3V_3$, deci $T_3 > T_2 > T_1$ → **b**.

**5.** $Q = mc\Delta t = 2\cdot 4200\cdot 20 = 168\,000\ \text{J} = 168\ \text{kJ}$ → **c**.

### Subiectul al II-lea — oxigen într-un cilindru cu piston (15 puncte)

Date: $\nu = 0{,}2\ \text{mol}$, $\mu = 32\ \text{g/mol}$, $\ell = 20\ \text{cm}$, $T = 300\ \text{K}$, $p_0 = 10^5\ \text{Pa}$, $d = 5\ \text{cm}$.

**a.** $m = \nu\mu = 0{,}2\cdot 32 = 6{,}4\ \text{g}$. *Barem: 3p, 1p.*

**b.** $\rho = \dfrac{p_0\mu}{RT} = \dfrac{10^5\cdot 0{,}032}{8{,}31\cdot 300} \cong 1{,}28\ \text{kg/m}^3$. *Barem: 3p, 1p.*

**c.** Izoterm: $p_0V_0 = p_1V_1$, cu $V_0 = \ell S$ și $V_1 = (\ell + d)S$:

$$p_1 = p_0\frac{\ell}{\ell + d} = 10^5\cdot\frac{20}{25} = 0{,}8\cdot 10^5\ \text{Pa}.$$

*Barem: 1p + 1p + 1p + 1p.*

**d.** Încălzire izocoră. Eliberat, pistonul rămâne în repaus, deci $p_2 = p_0$:

$$\frac{p_1}{T} = \frac{p_2}{T_2} \Rightarrow T_2 = T\frac{p_0}{p_1} = \frac{300}{0{,}8} = 375\ \text{K}.$$

*Barem: 1p + 1p + 1p.*

### Subiectul al III-lea — ciclu izobar–izocor–izoterm (15 puncte)

Date: $\nu R = 0{,}24\cdot 8{,}31 \cong 2\ \text{J/K}$, $C_V = 2{,}5R$, $T_1 = 300\ \text{K}$, $\ln 2 = 0{,}7$. Ciclul: $1 \to 2$ izobar ($V_1 \to 2V_1$), $2 \to 3$ izocor, $3 \to 1$ izoterm.

**a.** $U_1 = \nu C_VT_1 = 2{,}5\cdot 2\cdot 300 = 1500\ \text{J} = 1{,}5\ \text{kJ}$. *Barem: 2p, 1p.*

**b.** $L_{12} = p_1(2V_1 - V_1) = p_1V_1 = \nu RT_1 = 600\ \text{J}$. *Barem: 2p, 1p, 1p.*

**c.** La presiune constantă volumul se dublează, deci $T_2 = 2T_1 = 600\ \text{K}$:

$$\Delta U_{12} = \nu C_V(T_2 - T_1) = 2{,}5\cdot 2\cdot 300 = 1{,}5\ \text{kJ}.$$

*Barem: 2p, 1p, 1p.*

**d.** Gazul cedează căldură pe $2 \to 3$ și pe $3 \to 1$:

$$Q_{23} = \nu C_V(T_1 - T_2) = -1500\ \text{J}, \qquad Q_{31} = \nu RT_1\ln\frac{V_1}{2V_1} = -600\cdot 0{,}7 = -420\ \text{J}.$$

$$Q_c = Q_{23} + Q_{31} = -1920\ \text{J} = -1{,}92\ \text{kJ}.$$

*Barem: 1p + 1p + 1p + 1p.*

## C. Producerea și utilizarea curentului continuu (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **b**, 2 – **a**, 3 – **d**, 4 – **c**, 5 – **d** (câte 3 puncte).

**1.** $\eta = \dfrac{P_{ext}}{P_{total}} = \dfrac{I^2R}{I^2(R + r)} = \dfrac{R}{R + r}$ → **b**.

**2.** Legea lui Ohm pentru întreg circuitul: $I = \dfrac{E}{R + r}$ → **a**.

**3.** Puterea înmulțită cu timpul este energia, măsurată în joule → **d**.

**4.** Când $I = 0$ (circuit deschis), tensiunea la borne este egală cu t.e.m.; din grafic $E = 12\ \text{V}$ → **c**.

**5.** $\alpha = \dfrac{R - R_0}{R_0 t} = \dfrac{150 - 120}{120\cdot 50} = 5\cdot 10^{-3}\ \text{K}^{-1}$ → **d**.

### Subiectul al II-lea — circuit cu două surse (15 puncte)

Date: $E_1 = E = 15\ \text{V}$, $r_1 = r = 5\ \Omega$, $R_1 = 10\ \Omega$, $R_2 = 6\ \Omega$, $R_3 = 9\ \Omega$, $I_1 = 0{,}2\ \text{A}$.

**a.** $R_2$ și $R_3$ sunt pe aceeași ramură, în serie: $R_{23} = R_2 + R_3 = 15\ \Omega$. *Barem: 3p, 1p.*

**b.** $U_{b1} = E_1 - I_1r_1 = 15 - 1 = 14\ \text{V}$. *Barem: 2p, 1p.*

**c.** Teorema a II-a a lui Kirchhoff pe ochiul celor două surse:

$$E_1 - E = I_1r_1 + I_1R_1 - Ir \Rightarrow 0 = 1 + 2 - 5I \Rightarrow I = 0{,}6\ \text{A}.$$

*Barem: 3p, 1p.*

**d.** Prin nod: $I_2 = I + I_1 = 0{,}8\ \text{A}$, deci $U_2 = I_2R_2 = 0{,}8\cdot 6 = 4{,}8\ \text{V}$. *Barem: 2p, 1p, 1p.*

### Subiectul al III-lea — bec și rezistor în paralel (15 puncte)

Date: $E = 16\ \text{V}$, $R_1 = 24\ \Omega$, $U_b = 12\ \text{V}$, $I_b = 0{,}5\ \text{A}$. Becul și $R_1$ sunt în paralel, deci au aceeași tensiune $U_b$.

**a.** $R_b = \dfrac{U_b}{I_b} = \dfrac{12}{0{,}5} = 24\ \Omega$. *Barem: 3p, 1p.*

**b.** $P_b = U_bI_b = 12\cdot 0{,}5 = 6\ \text{W}$. *Barem: 3p, 1p.*

**c.** $P_1 = \dfrac{U_b^2}{R_1} = \dfrac{144}{24} = 6\ \text{W}$, deci $P_{ext} = P_b + P_1 = 12\ \text{W}$. *Barem: 1p + 1p + 1p.*

**d.** $I_1 = \dfrac{U_b}{R_1} = 0{,}5\ \text{A}$, $I = I_b + I_1 = 1\ \text{A}$:

$$W_{total} = EI\Delta t = 16\cdot 1\cdot 300 = 4800\ \text{J} = 4{,}8\ \text{kJ}.$$

*Barem: 1p + 1p + 1p + 1p.*

## D. Optică (45 de puncte)

### Subiectul I — grilă (15 puncte)

**Răspunsuri:** 1 – **b**, 2 – **c**, 3 – **a**, 4 – **c**, 5 – **c** (câte 3 puncte).

**1.** Obiectul aflat între lentila convergentă și focar dă o imagine **virtuală, dreaptă** și mărită (lupa) → **b**.

**2.** Indicele de refracție nu are unitate, deci $[\nu\cdot n] = \text{s}^{-1}$ → **c**.

**3.** Raza reflectată în A face $50°$ cu verticala (normala oglinzii orizontale), deci $40°$ cu orizontala, care este normala oglinzii verticale. În B unghiul de incidență este $40°$, iar cel de reflexie tot $40°$. Unghiul dintre AB și BD este $\alpha = 40° + 40° = 80°$ → **a**.

**4.** Sistem afocal: $f_1 + f_2 = D$. Din $f_1 = \dfrac{1}{4}\ \text{m} = 25\ \text{cm}$ rezultă $f_2 = 33 - 25 = 8\ \text{cm}$, deci $C_2 = \dfrac{1}{0{,}08} = 12{,}5\ \text{m}^{-1}$ → **c**.

**5.** Din grafic, frecvența de prag (unde $E_c = 0$) este $\nu_0 = 5{,}5\cdot 10^{14}\ \text{Hz}$:

$$L = h\nu_0 = 6{,}6\cdot 10^{-34}\cdot 5{,}5\cdot 10^{14} = 3{,}63\cdot 10^{-19}\ \text{J}$$

Verificare: $h(6{,}8 - 5{,}5)\cdot 10^{14} \cong 0{,}86\cdot 10^{-19}\ \text{J}$, ca în grafic → **c**.

### Subiectul al II-lea — lentilă și imagine pe ecran (15 puncte)

Date: $h_1 = 10\ \text{mm}$, $h_2 = 5\ \text{mm}$, distanța obiect–ecran $d = 45\ \text{cm}$.

**a.** Imaginea de pe ecran este reală, deci răsturnată: $\beta = \dfrac{y_2}{y_1} = \dfrac{-h_2}{h_1} = -0{,}5$. *Barem: 2p, 1p, 1p.*

**b.** $-x_1 + x_2 = d$ și $x_2 = \beta x_1 = -0{,}5x_1$, deci $-1{,}5x_1 = 45\ \text{cm}$: $-x_1 = 30\ \text{cm}$ (iar $x_2 = 15\ \text{cm}$). *Barem: 1p + 1p + 1p.*

**c.** $\dfrac{1}{f} = \dfrac{1}{x_2} - \dfrac{1}{x_1} = \dfrac{1}{15} + \dfrac{1}{30} = \dfrac{1}{10\ \text{cm}}$, deci $C = \dfrac{1}{0{,}1\ \text{m}} = 10\ \text{m}^{-1}$. *Barem: 2p, 1p, 1p.*

**d.** Lentila este convergentă, cu $f = 10\ \text{cm}$. Obiectul se află la 30 cm, adică dincolo de $2f$. Pentru construcție se desenează din vârful obiectului:

- o rază **paralelă cu axa optică**, care după lentilă trece prin **focarul imagine** $F'$;
- o rază **prin centrul optic**, care trece nedeviată.

Razele se intersectează la 15 cm în spatele lentilei, între $F'$ și $2F'$. Imaginea este **reală, răsturnată și de două ori mai mică**, așa cum dau calculele. *Barem: 4p pentru construcția corectă.*

### Subiectul al III-lea — refracția luminii la suprafața apei (15 puncte)

Date: $n_{apă} = \dfrac43$, $n_{aer} = 1$, $MN = 12\ \text{cm}$, $SN = 18\ \text{cm}$, $AM = 8\ \text{cm}$.

**a.** $v = \dfrac{c}{n_{apă}} = \dfrac{3\cdot 10^8}{4/3} = 2{,}25\cdot 10^8\ \text{m/s}$. *Barem: 3p, 1p.*

**b.** Sursa se află deasupra apei, la $SM = SN - MN = 6\ \text{cm}$. În triunghiul dreptunghic SMA:

$$SA = \sqrt{SM^2 + AM^2} = \sqrt{36 + 64} = 10\ \text{cm}, \qquad \sin i = \frac{AM}{SA} = 0{,}8.$$

*Barem: 1p + 1p + 1p + 1p.*

**c.** Legea refracției: $n_{aer}\sin i = n_{apă}\sin r \Rightarrow \sin r = \dfrac{0{,}8}{4/3} = 0{,}6$. *Barem: 3p, 1p.*

**d.** $\cos r = \sqrt{1 - \sin^2 r} = 0{,}8$. Adâncimea apei este proiecția verticală a lui AB:

$$AB = \frac{MN}{\cos r} = \frac{12}{0{,}8} = 15\ \text{cm}.$$

*Barem: 1p + 1p + 1p.*
