## Subiectul I (30 de puncte)

### 1. Arătați că $3\cdot\left(\frac23 - \frac13\right) = 1$

$$\frac23 - \frac13 = \frac13, \qquad 3\cdot\frac13 = 1.$$

*Barem: 2p + 3p.*

### 2. $m$ cu $f(m) = 1$, $f(x) = x - 4$

$m - 4 = 1 \iff m = 5$. *Barem: 3p + 2p.*

### 3. Ecuația $\sqrt{2x^2 + 1} = 1$

$2x^2 + 1 = 1 \iff x^2 = 0 \iff x = 0$, care verifică ($\sqrt1 = 1$). *Barem: 3p + 2p.*

### 4. Profitul de 100000 lei reprezintă 4% din venituri

$$\frac{4}{100}\cdot x = 100000 \iff x = 2\,500\,000.$$

**Răspuns:** veniturile au fost 2 500 000 de lei. *Barem: 3p + 2p.*

### 5. Triunghiul $A(5,6)$, $B(2,6)$, $C(5,2)$ este dreptunghic

$AB = 5 - 2 = 3$, $AC = 6 - 2 = 4$, $BC = \sqrt{3^2 + 4^2} = 5$. Cum $AB^2 + AC^2 = 9 + 16 = 25 = BC^2$, triunghiul este dreptunghic în $A$ (reciproca teoremei lui Pitagora). *Barem: 3p + 2p.*

### 6. $\operatorname{tg}^2 60^\circ + \operatorname{tg}^2 45^\circ = 4$

$$(\sqrt3)^2 + 1^2 = 3 + 1 = 4.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 3 & 1\\ -5 & -2\end{pmatrix}$, $B = \begin{pmatrix} 2 & 1\\ -5 & -3\end{pmatrix}$

#### a) $\det A = -1$

$$\det A = 3\cdot(-2) - 1\cdot(-5) = -6 + 5 = -1.$$

*Barem: 2p + 3p.*

#### b) $2A\cdot B - B\cdot A = I_2$

$$A\cdot B = \begin{pmatrix} 6 - 5 & 3 - 3\\ -10 + 10 & -5 + 6\end{pmatrix} = I_2, \qquad B\cdot A = \begin{pmatrix} 6 - 5 & 2 - 2\\ -15 + 15 & -5 + 6\end{pmatrix} = I_2.$$

Deci $2A\cdot B - B\cdot A = 2I_2 - I_2 = I_2$. $\blacksquare$ *Barem: 2p + 3p.*

#### c) $x$ cu $A\cdot A - xA = I_2$

$$A\cdot A = \begin{pmatrix} 4 & 1\\ -5 & -1\end{pmatrix}, \qquad A\cdot A - xA = \begin{pmatrix} 4 - 3x & 1 - x\\ -5 + 5x & -1 + 2x\end{pmatrix}.$$

Egalitatea cu $I_2$: $1 - x = 0$, deci $x = 1$ (și atunci $4 - 3 = 1$, $-5 + 5 = 0$, $-1 + 2 = 1$ ✔).

**Răspuns:** $x = 1$. *Barem: 3p + 2p.*

### 2. $x * y = 2(x + y - 1) - xy$

#### a) $1 * 2 = 2$

$$2(1 + 2 - 1) - 2 = 4 - 2 = 2.$$

*Barem: 3p + 2p.*

#### b) $x * 2 = 2 * x = 2$

$$x * 2 = 2(x + 1) - 2x = 2, \qquad 2 * x = 2(1 + x) - 2x = 2.$$

*Barem: 2p + 3p.*

#### c) $x * x = x$

$$2(2x - 1) - x^2 = x \iff -x^2 + 3x - 2 = 0 \iff x^2 - 3x + 2 = 0 \iff (x-1)(x-2) = 0.$$

**Răspuns:** $x \in \{1, 2\}$. *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = (x-1)e^x$

#### a) $\lim\limits_{x\to0} f(x) = -1$

$f$ continuă: $\lim\limits_{x\to0} f(x) = f(0) = -1\cdot e^0 = -1$. *Barem: 2p + 3p.*

#### b) $f'(x) = e^x + f(x)$

$$f'(x) = 1\cdot e^x + (x-1)e^x = e^x + f(x).$$

*Barem: 3p + 2p.*

#### c) $\lim\limits_{x\to0}\dfrac{f(x) + 1}{x} = 0$

Cum $f(0) = -1$, limita este $\lim\limits_{x\to0}\dfrac{f(x) - f(0)}{x - 0} = f'(0) = e^0 + f(0) = 1 - 1 = 0$. *Barem: 2p + 3p.*

### 2. $f(x) = 3x^2 + 2x$

#### a) $\displaystyle\int_1^2 3x^2\,dx = 7$

$$x^3\Big|_1^2 = 8 - 1 = 7.$$

*Barem: 3p + 2p.*

#### b) Primitiva $F$ cu $F(1) = 2014$

$F(x) = x^3 + x^2 + c$; $F(1) = 2 + c = 2014 \Rightarrow c = 2012$.

**Răspuns:** $F(x) = x^3 + x^2 + 2012$. *Barem: 3p + 2p.*

#### c) $n \ge 2$ cu $\displaystyle\int_1^n\frac{f(x)}{x}\,dx = \frac{13}{2}$

$\dfrac{f(x)}{x} = 3x + 2$:

$$\int_1^n(3x + 2)\,dx = \left(\frac{3x^2}{2} + 2x\right)\Big|_1^n = \frac{3n^2}{2} + 2n - \frac72 = \frac{3n^2 + 4n - 7}{2}.$$

$\dfrac{3n^2 + 4n - 7}{2} = \dfrac{13}{2} \iff 3n^2 + 4n - 20 = 0 \iff (n - 2)(3n + 10) = 0$. Cum $n$ e natural: $n = 2$.

**Răspuns:** $n = 2$. *Barem: 3p + 2p.*

## Ce merită reținut din varianta 9

- **Procente inverse**: dacă $p\%$ din $x$ este $A$, atunci $x = \frac{100A}{p}$.
- **Legea $2(x + y - 1) - xy = -(x-2)(y-2) + 2$**: $2$ este element absorbant.
- **Dacă $AB = I_2$**, atunci și $BA = I_2$ ($B = A^{-1}$).
- **Limite $\frac{f(x) - f(a)}{x - a}$** = $f'(a)$.
