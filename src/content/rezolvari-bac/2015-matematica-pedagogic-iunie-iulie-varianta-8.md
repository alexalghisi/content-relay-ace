## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{32} - \sqrt{18} - \sqrt2 = 0$

$$\sqrt{32} = 4\sqrt2, \quad \sqrt{18} = 3\sqrt2 \Rightarrow 4\sqrt2 - 3\sqrt2 - \sqrt2 = 0.$$

*Barem: 2p, 3p.*

### 2. Intersecția graficelor $f(x) = x + 1$ și $g(x) = 4 - 2x$

$$x + 1 = 4 - 2x \iff 3x = 3 \iff x = 1, \quad y = 2.$$

**Răspuns:** $(1, 2)$. *Barem: 3p, 2p.*

### 3. Ecuația $5^{5 - 3x} = 25$

$$5 - 3x = 2 \iff x = 1.$$

**Răspuns:** $x = 1$. *Barem: 3p, 2p.*

### 4. Numere naturale pare de două cifre formate cu cifrele $1, 2, 3, 4, 5$

Cifra unităților trebuie să fie pară: $2$ sau $4$ — 2 moduri; cifra zecilor: oricare din cele 5 (cifrele se pot repeta) — 5 moduri.

$$2\cdot5 = 10.$$

**Răspuns:** $10$ numere. *Barem: 2p, 3p.*

### 5. $A(2,3)$, $B(5,3)$, $C(5,6)$: $AB = BC$

$$AB = \sqrt{3^2 + 0^2} = 3, \qquad BC = \sqrt{0^2 + 3^2} = 3.$$

*Barem: 2p, 3p.*

### 6. Arătați că $\sin30^\circ + \sin45^\circ\cdot\cos45^\circ = 1$

$$\frac12 + \frac{\sqrt2}{2}\cdot\frac{\sqrt2}{2} = \frac12 + \frac12 = 1.$$

*Barem: 3p valorile, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x\circ y = xy + x + y$.

### 1. $2015\circ(-1) = -1$

$$-2015 + 2015 - 1 = -1.$$

*Barem: 3p, 2p.*

### 2. Legea este asociativă

$$(x\circ y)\circ z = (xy + x + y)z + xy + x + y + z = xyz + xy + xz + yz + x + y + z,$$

$$x\circ(y\circ z) = x(yz + y + z) + x + yz + y + z = xyz + xy + xz + yz + x + y + z.$$

*Barem: 2p, 3p.*

### 3. $e = 0$ este element neutru

$x\circ0 = 0 + x + 0 = x$ și $0\circ x = x$. **Răspuns:** da. *Barem: 2p, 3p.*

### 4. $x\circ x = (x+1)^2 - 1$

$$x\circ x = x^2 + 2x = x^2 + 2x + 1 - 1 = (x+1)^2 - 1.$$

*Barem: 2p, 3p.*

### 5. Ecuația $x\circ x\circ x\circ x = 0$

Legea se scrie $x\circ y = (x+1)(y+1) - 1$, deci $x\circ x\circ x\circ x = (x+1)^4 - 1$.

$$(x+1)^4 = 1 \iff x + 1 = \pm1 \iff x \in \{-2, 0\}.$$

**Răspuns:** $x \in \{-2, 0\}$. *Barem: 2p expresia, 3p soluțiile.*

### 6. $x\circ(x + 1) \ge x$ pentru orice $x$

$$x\circ(x + 1) - x = x(x+1) + x + (x + 1) - x = x^2 + 2x + 1 = (x+1)^2 \ge 0. \ \blacksquare$$

*Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$A(a) = \begin{pmatrix}a & 2\\1 & a+1\end{pmatrix}$.

### 1. $\det(A(0)) = -2$

$$\det\begin{pmatrix}0&2\\1&1\end{pmatrix} = 0 - 2 = -2.$$

*Barem: 3p, 2p.*

### 2. $a$ cu $\det(A(a)) = 0$

$$\det A(a) = a(a+1) - 2 = a^2 + a - 2 = (a + 2)(a - 1).$$

**Răspuns:** $a \in \{-2, 1\}$. *Barem: 3p, 2p.*

### 3. Inecuația $\det(A(a) - I_2) < 0$

$$\det\begin{pmatrix}a - 1 & 2\\1 & a\end{pmatrix} = a^2 - a - 2 = (a - 2)(a + 1) < 0 \iff a \in (-1, 2).$$

**Răspuns:** $a \in (-1, 2)$. *Barem: 2p, 3p.*

### 4. $(2a + 1)A(a) - A(a)\cdot A(a) = (a^2 + a - 2)I_2$

$$(2a+1)A(a) = \begin{pmatrix}2a^2 + a & 4a + 2\\2a + 1 & 2a^2 + 3a + 1\end{pmatrix}, \qquad A(a)A(a) = \begin{pmatrix}a^2 + 2 & 4a + 2\\2a + 1 & a^2 + 2a + 3\end{pmatrix}.$$

Diferența: $\begin{pmatrix}a^2 + a - 2 & 0\\0 & a^2 + a - 2\end{pmatrix} = (a^2 + a - 2)I_2$. *Barem: 1p, 2p, 2p.*

### 5. Inversa matricei $A(2)$

$A(2) = \begin{pmatrix}2&2\\1&3\end{pmatrix}$, $\det = 4 \ne 0$:

$$\big(A(2)\big)^{-1} = \frac14\begin{pmatrix}3 & -2\\-1 & 2\end{pmatrix} = \begin{pmatrix}\frac34 & -\frac12\\-\frac14 & \frac12\end{pmatrix}.$$

*Barem: 2p determinantul, 3p inversa.*

### 6. Numerele naturale $m$ cu $\det(A(m)) \le 1$

$$m^2 + m - 2 \le 1 \iff m^2 + m - 3 \le 0 \iff m \in \left[\frac{-1 - \sqrt{13}}{2}, \frac{-1 + \sqrt{13}}{2}\right].$$

$\frac{-1 + \sqrt{13}}{2} \approx 1{,}3$, deci numerele naturale sunt $0$ și $1$ (verificare: $\det A(0) = -2$, $\det A(1) = 0$, $\det A(2) = 4$).

**Răspuns:** $m \in \{0, 1\}$. *Barem: 2p inecuația, 3p soluțiile.*

## Ce merită reținut din varianta 8

- **Legea $xy + x + y = (x+1)(y+1) - 1$**: compunerea a $n$ elemente egale dă $(x+1)^n - 1$.
- **Numere pare**: alegi întâi cifra unităților.
- **Inecuații de gradul 2 în parametru**: semnul trinomului între rădăcini.
