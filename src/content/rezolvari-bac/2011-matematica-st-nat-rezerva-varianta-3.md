## Subiectul I (30 de puncte)

### 1. $\log_6 3 + \log_6 12$

$$\log_6 3 + \log_6 12 = \log_6 36 = \log_6 6^2 = 2.$$

**Răspuns:** $2$. *Barem: 3p, 2p.*

### 2. Coordonatele vârfului parabolei asociate funcției $f(x) = 2x^2 - x + 3$

$$x_V = -\frac{b}{2a} = \frac14, \qquad \Delta = 1 - 24 = -23, \qquad y_V = -\frac{\Delta}{4a} = \frac{23}{8}.$$

**Răspuns:** $V\left(\dfrac14, \dfrac{23}{8}\right)$. *Barem: 2p, 1p, 2p.*

### 3. Ecuația $7^x + 7^{x+1} = 392$

$$7^x + 7\cdot 7^x = 392 \iff 8\cdot 7^x = 392 \iff 7^x = 49 \iff x = 2.$$

**Răspuns:** $x = 2$. *Barem: 1p, 2p, 2p.*

### 4. $n \ge 2$ cu $C_n^2 = 4A_n^1$

$$\frac{n(n-1)}{2} = 4n \iff \frac{n-1}{2} = 4 \iff n = 9$$

(am împărțit la $n \ne 0$).

**Răspuns:** $n = 9$. *Barem: 2p, 2p, 1p.*

### 5. $A(0, -2)$, $B(4, m)$; $m$ cu $AB = 5$

$$\sqrt{(4 - 0)^2 + (m + 2)^2} = 5 \iff 16 + (m+2)^2 = 25 \iff m^2 + 4m - 5 = 0 \iff (m + 5)(m - 1) = 0.$$

**Răspuns:** $m \in \{-5, 1\}$. *Barem: 1p, 2p, 2p.*

### 6. $\cos 40^\circ + \cos 140^\circ$

$\cos 140^\circ = \cos(180^\circ - 40^\circ) = -\cos 40^\circ$, deci suma este $0$.

**Răspuns:** $0$. *Barem: 3p, 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} m & -1 & 1\\ 1 & m & -1\\ 1 & -2 & 1\end{pmatrix}$ și sistemul $\begin{cases} mx - y + z = 0\\ x + my - z = 0\\ x - 2y + z = 0\end{cases}$

#### a) $\det A$

$$\det A = m^2 + 1 - 2 - (m + 2m - 1) = m^2 - 3m.$$

**Răspuns:** $\det A = m^2 - 3m$. *Barem: 3p, 2p.*

#### b) $m$ pentru care $(-1, 2, 5)$ este soluție

Înlocuim în cele trei ecuații:

$$\begin{cases} -m - 2 + 5 = 0\\ -1 + 2m - 5 = 0\\ -1 - 4 + 5 = 0\end{cases} \iff \begin{cases} m = 3\\ m = 3\\ 0 = 0\end{cases}$$

**Răspuns:** $m = 3$. *Barem: 3p, 2p.*

#### c) $m$ pentru care sistemul admite doar soluția $(0, 0, 0)$

Sistemul este omogen; are doar soluția nulă $\iff \det A \ne 0 \iff m(m - 3) \ne 0$.

**Răspuns:** $m \in \mathbb R\setminus\{0, 3\}$. *Barem: 2p, 3p.*

### 2. $x * y = xy + x + y$

#### a) Legea este asociativă

$$(x * y) * z = (xy + x + y)z + xy + x + y + z = xyz + xy + xz + yz + x + y + z,$$
$$x * (y * z) = x(yz + y + z) + x + yz + y + z = xyz + xy + xz + yz + x + y + z.$$

Expresiile coincid. (Observație: $x * y = (x+1)(y+1) - 1$.) *Barem: 2p, 2p, 1p.*

#### b) Elementul neutru

$x * e = xe + x + e = x \iff e(x + 1) = 0$ pentru orice $x$, deci $e = 0$ (și $0 * x = x$).

**Răspuns:** $e = 0$. *Barem: 2p, 1p, 2p.*

#### c) Ecuația $x^2 * 2 = x * 4$

$x^2 * 2 = 2x^2 + x^2 + 2 = 3x^2 + 2$, iar $x * 4 = 4x + x + 4 = 5x + 4$.

$$3x^2 + 2 = 5x + 4 \iff 3x^2 - 5x - 2 = 0 \iff (3x + 1)(x - 2) = 0.$$

**Răspuns:** $x \in \left\{-\dfrac13, 2\right\}$. *Barem: 1p, 1p, 1p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:\mathbb R\setminus\{1\} \to \mathbb R$, $f(x) = \dfrac{x + 2}{(x - 1)^2}$

#### a) $f'(x) = \dfrac{-x - 5}{(x - 1)^3}$

$$f'(x) = \frac{(x-1)^2 - (x+2)\cdot 2(x - 1)}{(x-1)^4} = \frac{(x - 1) - 2(x + 2)}{(x-1)^3} = \frac{-x - 5}{(x-1)^3}.$$

*Barem: 3p, 2p.*

#### b) Asimptota verticală

$f$ este continuă pe $\mathbb R\setminus\{1\}$ și $\lim\limits_{x\to 1}\dfrac{x + 2}{(x-1)^2} = \dfrac{3}{0^+} = +\infty$.

**Răspuns:** $x = 1$. *Barem: 3p, 2p.*

#### c) $f(x) + \dfrac{1}{12} \ge 0$ pentru $x \in (-\infty, 1)$

Pe $(-\infty, 1)$, $(x - 1)^3 < 0$, deci semnul lui $f'$ este opus semnului lui $-x - 5$:

- $x < -5$: $-x - 5 > 0$, $f' < 0$, $f$ descrescătoare;
- $-5 < x < 1$: $-x - 5 < 0$, $f' > 0$, $f$ crescătoare.

Deci $x = -5$ este punct de minim global pe $(-\infty, 1)$:

$$f(x) \ge f(-5) = \frac{-3}{36} = -\frac{1}{12} \Rightarrow f(x) + \frac{1}{12} \ge 0. \ \blacksquare$$

*Barem: 1p, 2p, 2p.*

### 2. $f(x) = \begin{cases} \dfrac{\ln x}{x}, & x > 1\\[2mm] \dfrac{x - 1}{x}, & 0 < x \le 1\end{cases}$

#### a) $\displaystyle\int_2^e\frac{f(x)}{\ln x}\,dx$

Pe $[2, e]$, $f(x) = \frac{\ln x}{x}$, deci $\frac{f(x)}{\ln x} = \frac1x$:

$$\int_2^e\frac1x\,dx = \ln x\Big|_2^e = 1 - \ln 2.$$

**Răspuns:** $1 - \ln 2$. *Barem: 3p, 2p.*

#### b) Primitiva lui $g = f|_{(0,1]}$ al cărei grafic conține $A(1, 5)$

$g(x) = \dfrac{x - 1}{x} = 1 - \dfrac1x$, deci primitivele sunt $G(x) = x - \ln x + c$.

$G(1) = 5 \iff 1 - 0 + c = 5 \iff c = 4$.

**Răspuns:** $G(x) = x - \ln x + 4$. *Barem: 1p, 1p, 1p, 1p, 1p.*

#### c) $\displaystyle\int_{1/2}^e f(x)\,dx$

Împărțim intervalul în punctul $1$:

$$\int_{1/2}^1\left(1 - \frac1x\right)dx = (x - \ln x)\Big|_{1/2}^1 = 1 - \left(\frac12 + \ln 2\right) = \frac12 - \ln 2,$$

$$\int_1^e\frac{\ln x}{x}\,dx = \frac{\ln^2 x}{2}\Big|_1^e = \frac12.$$

$$\int_{1/2}^e f(x)\,dx = \frac12 - \ln 2 + \frac12 = 1 - \ln 2.$$

**Răspuns:** $1 - \ln 2$. *Barem: 2p, 1p, 1p, 1p.*

## Ce merită reținut din varianta 3

- **Sistem omogen**: are doar soluția nulă exact când determinantul este nenul.
- **Verificarea unei soluții date** înseamnă înlocuire în toate ecuațiile — toate trebuie să dea aceeași valoare a parametrului.
- **Funcții definite pe ramuri**: integrala se împarte în punctul de racord.
- **Primitiva care trece printr-un punct**: găsești constanta $c$ din $G(x_0) = y_0$.
