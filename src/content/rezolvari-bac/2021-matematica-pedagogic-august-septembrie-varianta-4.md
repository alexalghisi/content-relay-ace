## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_1 = 2$, $a_3 = 14$; calculați $a_2$

Termenul din mijloc este media aritmetică a vecinilor:

$$a_2 = \frac{a_1 + a_3}{2} = \frac{2 + 14}{2} = 8.$$

*Barem: 3p + 2p.*

### 2. Intersecția graficului lui $f(x) = x^2 - 2x$ cu $Ox$

$f(x) = 0 \iff x(x - 2) = 0 \iff x \in \{0, 2\}$.

**Răspuns:** abscisele $0$ și $2$. *Barem: 3p + 2p.*

### 3. Ecuația $7^{3-x} = 49^x$

$49^x = 7^{2x}$, deci $3 - x = 2x \iff x = 1$.

*Barem: 3p + 2p.*

### 4. $A = \{1, 2, \dots, 9\}$; probabilitatea ca $n + 2$ să fie impar

9 cazuri posibile. $n + 2$ impar $\iff n$ impar: $1, 3, 5, 7, 9$ — 5 cazuri favorabile.

$$p = \frac59.$$

*Barem: 2p + 2p + 1p.*

### 5. $A(0,-3)$, $B(3,1)$, $C(a,0)$; $a$ cu $AB = AC$

$AB^2 = 9 + 16 = 25$, $AC^2 = a^2 + 9$. $a^2 + 9 = 25 \iff a^2 = 16$.

**Răspuns:** $a \in \{-4, 4\}$. *Barem: 2p + 3p.*

### 6. Arătați că $(1 + \sin30^\circ)\cos^245^\circ + \cos^260^\circ = 1$

$$\left(1 + \tfrac12\right)\cdot\tfrac12 + \tfrac14 = \tfrac34 + \tfrac14 = 1.$$

*Barem: 3p valorile, 2p calculul.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = 4x + 4y - 3$.

### 1. $0 * 3 = 9$

$$0 * 3 = 0 + 12 - 3 = 9.$$

*Barem: 3p + 2p.*

### 2. Legea este comutativă

$x * y = 4x + 4y - 3 = 4y + 4x - 3 = y * x$, pentru orice $x, y$ reali. $\blacksquare$ *Barem: 3p + 2p.*

### 3. $x$ cu $(-3) * x = 9$

$(-3) * x = -12 + 4x - 3 = 4x - 15 = 9 \iff x = 6$.

*Barem: 3p + 2p.*

### 4. $x$ cu $(-x) * (2x) = x^2$

$(-x) * (2x) = -4x + 8x - 3 = 4x - 3$. Atunci $4x - 3 = x^2 \iff x^2 - 4x + 3 = 0 \iff x \in \{1, 3\}$.

*Barem: 2p + 3p.*

### 5. $x$ cu $2^x * 2^x = 1$

$2^x * 2^x = 8\cdot2^x - 3 = 1 \iff 2^x = \frac12 \iff x = -1$.

*Barem: 2p + 3p.*

### 6. Scăzând $x$ din $x * \left(\frac x2 * \frac x4\right)$ se obține $x - 1$

$\frac x2 * \frac x4 = 2x + x - 3 = 3x - 3$; $x * (3x - 3) = 4x + 12x - 12 - 3 = 16x - 15$.

$$16x - 15 - x = x - 1 \iff 14x = 14 \iff x = 1.$$

**Răspuns:** $x = 1$. *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix}1&6\\-2&-7\end{pmatrix}$, $B(x) = \begin{pmatrix}2 & x + 2\\ x - 2 & -2\end{pmatrix}$.

### 1. $\det A = 5$

$$\det A = 1\cdot(-7) - 6\cdot(-2) = -7 + 12 = 5.$$

*Barem: 3p + 2p.*

### 2. $2B(1) - A = 3I_2$

$$B(1) = \begin{pmatrix}2&3\\-1&-2\end{pmatrix},\quad 2B(1) - A = \begin{pmatrix}4&6\\-2&-4\end{pmatrix} - \begin{pmatrix}1&6\\-2&-7\end{pmatrix} = \begin{pmatrix}3&0\\0&3\end{pmatrix} = 3I_2.$$

*Barem: 3p + 2p.*

### 3. $B(1)B(3) - 3I_2 = 2B(0)$

$$B(3) = \begin{pmatrix}2&5\\1&-2\end{pmatrix},\quad B(1)B(3) = \begin{pmatrix}4 + 3 & 10 - 6\\ -2 - 2 & -5 + 4\end{pmatrix} = \begin{pmatrix}7&4\\-4&-1\end{pmatrix},$$

$$B(1)B(3) - 3I_2 = \begin{pmatrix}4&4\\-4&-4\end{pmatrix} = 2\begin{pmatrix}2&2\\-2&-2\end{pmatrix} = 2B(0).$$

*Barem: 3p + 2p.*

### 4. $B(x)\cdot B(x) = x^2I_2$

$$B(x)^2 = \begin{pmatrix}4 + (x+2)(x-2) & 2(x+2) - 2(x+2)\\ 2(x-2) - 2(x-2) & (x+2)(x-2) + 4\end{pmatrix} = \begin{pmatrix}x^2&0\\0&x^2\end{pmatrix} = x^2I_2.$$

*Barem: 3p + 2p.*

### 5. $x$ cu $\det B(x) = \det B(x + 1)$

$\det B(x) = -4 - (x^2 - 4) = -x^2$, deci $\det B(x+1) = -(x + 1)^2$.

$$-x^2 = -(x+1)^2 \iff 2x + 1 = 0 \iff x = -\frac12.$$

*Barem: 3p + 2p.*

### 6. $n$ natural cu $B(3)B(3) + B(4)B(4) = B(n)B(n)$

Din punctul 4: $9I_2 + 16I_2 = n^2I_2 \iff n^2 = 25$, și cum $n \in \mathbb N$, $n = 5$.

*Barem: 3p + 2p.*
