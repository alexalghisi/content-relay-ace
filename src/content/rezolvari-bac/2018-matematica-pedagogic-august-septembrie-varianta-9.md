## Subiectul I (30 de puncte)

### 1. $(\sqrt3 + 1)(\sqrt3 - 1) - (\sqrt2 + 1)(\sqrt2 - 1) = 1$

Folosim $(a+b)(a-b) = a^2 - b^2$:

$$(3 - 1) - (2 - 1) = 2 - 1 = 1.$$

*Barem: 3p produsele, 2p finalizarea.*

### 2. $f(x) = 3x - 2$; inecuația $f(x) < 4$

$$3x - 2 < 4 \iff 3x < 6 \iff x < 2.$$

**Răspuns:** $x \in (-\infty, 2)$. *Barem: 3p $3x < 6$, 2p mulțimea soluțiilor.*

### 3. $\log_2(x^3 + 3) = \log_2 30$

Logaritmul este injectiv: $x^3 + 3 = 30 \iff x^3 = 27 \iff x = 3$. Verificare: $27 + 3 = 30 > 0$ ✔.

**Răspuns:** $x = 3$. *Barem: 3p $x^3 - 27 = 0$, 2p soluția.*

### 4. Câte numere de trei cifre distincte se formează cu cifrele $1, 2, 3, 4, 5$

Alegem cifrele pe rând: cifra unităților — 5 moduri, cifra zecilor (distinctă) — 4 moduri, cifra sutelor — 3 moduri (0 nu e printre cifre, deci nu apar restricții suplimentare):

$$5\cdot 4\cdot 3 = 60 = A_5^3.$$

**Răspuns:** 60 de numere. *Barem: 2p prima alegere, 3p numărul total.*

### 5. $P$, simetricul lui $N(-1, 4)$ față de $M(2, 3)$

$M$ este mijlocul lui $NP$:

$$2 = \frac{-1 + x_P}{2} \Rightarrow x_P = 5, \qquad 3 = \frac{4 + y_P}{2} \Rightarrow y_P = 2.$$

**Răspuns:** $P(5, 2)$. *Barem: 3p $x_P$, 2p $y_P$.*

### 6. $BC$ în triunghiul dreptunghic în $A$, $AB = 8$, $m(\angle C) = 30^\circ$

$BC$ este ipotenuza, iar $AB$ este cateta opusă unghiului $C$:

$$\sin C = \frac{AB}{BC} \iff \frac12 = \frac{8}{BC} \iff BC = 16.$$

(Teorema unghiului de $30^\circ$: cateta opusă este jumătate din ipotenuză.)

**Răspuns:** $BC = 16$. *Barem: 3p relația, 2p rezultatul.*

## Subiectul al II-lea (30 de puncte)

Legea: $x * y = xy - 2(x + y) + 6$.

### 1. $1 * 2 = 2$

$$1 * 2 = 1\cdot 2 - 2(1 + 2) + 6 = 2 - 6 + 6 = 2.$$

*Barem: 3p înlocuirea, 2p finalizarea.*

### 2. $x * y = (x-2)(y-2) + 2$

$$x * y = xy - 2x - 2y + 4 + 2 = x(y - 2) - 2(y - 2) + 2 = (x-2)(y-2) + 2.$$

*Barem: 2p scrierea, 3p factorizarea.*

### 3. $e = 3$ este elementul neutru

$$x * 3 = (x-2)\cdot 1 + 2 = x, \qquad 3 * x = 1\cdot(x - 2) + 2 = x,$$

pentru orice $x$ real, deci $e = 3$ este element neutru. *Barem: 2p $x * 3 = x$, 3p $3 * x = x$ și concluzia.*

### 4. Numerele naturale $n$ cu $n * n \le n$

$$(n-2)^2 + 2 \le n \iff n^2 - 5n + 6 \le 0 \iff (n-2)(n-3) \le 0 \iff n \in [2, 3].$$

**Răspuns:** $n \in \{2, 3\}$. *Barem: 3p inecuația, 2p soluțiile naturale.*

### 5. $(2^x * 2^x) * 2^x = 10$

Din 2: $2^x * 2^x = (2^x - 2)^2 + 2$, iar apoi $(2^x * 2^x) * 2^x = (2^x - 2)^2\cdot(2^x - 2) + 2 = (2^x - 2)^3 + 2$.

$$(2^x - 2)^3 + 2 = 10 \iff (2^x - 2)^3 = 8 \iff 2^x - 2 = 2 \iff 2^x = 4 \iff x = 2.$$

**Răspuns:** $x = 2$. *Barem: 3p forma compunerii, 2p soluția.*

### 6. $\dfrac{2}{\sqrt3 - 1} * \dfrac{2}{\sqrt3 - 1} = p + q\sqrt3$, $p, q \in \mathbb Q$

Raționalizăm: $\dfrac{2}{\sqrt3 - 1} = \dfrac{2(\sqrt3 + 1)}{3 - 1} = \sqrt3 + 1$, deci $\dfrac{2}{\sqrt3-1} - 2 = \sqrt3 - 1$.

$$(\sqrt3 - 1)^2 + 2 = 3 - 2\sqrt3 + 1 + 2 = 6 - 2\sqrt3.$$

Cum $p, q$ raționale și $\sqrt3$ irațional, identificăm $p = 6$, $q = -2$.

**Răspuns:** $p = 6$, $q = -2$. *Barem: 3p calculul, 2p identificarea.*

## Subiectul al III-lea (30 de puncte)

$A = \begin{pmatrix} -2 & 4\\ -1 & 2\end{pmatrix}$, $M(a) = I_2 + aA$.

### 1. $\det A = 0$

$$\det A = (-2)\cdot 2 - (-1)\cdot 4 = -4 + 4 = 0.$$

*Barem: 3p formula, 2p calculul.*

### 2. $A\cdot A = O_2$

$$A\cdot A = \begin{pmatrix} 4 - 4 & -8 + 8\\ 2 - 2 & -4 + 4\end{pmatrix} = \begin{pmatrix} 0 & 0\\ 0 & 0\end{pmatrix} = O_2.$$

*Barem: 3p înmulțirea, 2p rezultatul.*

### 3. $M(a)\cdot M(b) = M(a + b)$

$$M(a)M(b) = (I_2 + aA)(I_2 + bA) = I_2 + aA + bA + abA^2 = I_2 + (a+b)A = M(a+b),$$

deoarece $A^2 = O_2$. *Barem: 3p dezvoltarea, 2p finalizarea.*

### 4. $M(t)\cdot M(t^2) = M(90)$

Din 3: $M(t)M(t^2) = M(t + t^2)$. Cum $A \ne O_2$, $M(x) = M(y) \iff x = y$, deci

$$t^2 + t - 90 = 0 \iff (t + 10)(t - 9) = 0.$$

**Răspuns:** $t \in \{-10, 9\}$. *Barem: 2p $M(t + t^2)$, 3p ecuația și soluțiile.*

### 5. Inversa lui $I_2 + A$ este $I_2 - A$

$$(I_2 + A)(I_2 - A) = I_2 - A + A - A^2 = I_2, \qquad (I_2 - A)(I_2 + A) = I_2 + A - A - A^2 = I_2.$$

*Barem: 2p primul produs, 3p al doilea și concluzia.*

### 6. Ecuația $(I_2 + A)\cdot X = A - I_2$

Înmulțim la stânga cu $(I_2 + A)^{-1} = I_2 - A$:

$$X = (I_2 - A)(A - I_2) = A - I_2 - A^2 + A = 2A - I_2 = \begin{pmatrix} -5 & 8\\ -2 & 3\end{pmatrix}.$$

**Răspuns:** $X = \begin{pmatrix} -5 & 8\\ -2 & 3\end{pmatrix}$. *Barem: 2p $X = (I_2+A)^{-1}(A - I_2)$, 3p matricea.*
