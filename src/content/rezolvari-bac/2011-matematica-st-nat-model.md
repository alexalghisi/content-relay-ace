## Subiectul I (30 de puncte)

### 1. Numerele întregi $x$ cu $-1 \le \dfrac{x+1}{3} < 1$

$$-3 \le x + 1 < 3 \iff -4 \le x < 2.$$

**Răspuns:** $x \in \{-4, -3, -2, -1, 0, 1\}$. *Barem: 2p, 2p, 1p.*

### 2. Intersecția graficelor lui $f(x) = 2x - 1$ și $g(x) = x^2 - 2x + 3$

$$2x - 1 = x^2 - 2x + 3 \iff x^2 - 4x + 4 = 0 \iff (x - 2)^2 = 0 \iff x = 2,$$

iar $f(2) = 3$.

**Răspuns:** $A(2, 3)$ (dreapta este tangentă parabolei). *Barem: 1p, 2p, 2p.*

### 3. $2 - \sqrt{2 - x} = x$

Rescriem: $\sqrt{2 - x} = 2 - x$. Condiție $x \le 2$. Notând $t = \sqrt{2 - x} \ge 0$: $t = t^2 \iff t \in \{0, 1\}$, adică $2 - x \in \{0, 1\}$.

(Echivalent, ridicând la pătrat: $2 - x = 4 - 4x + x^2 \iff x^2 - 3x + 2 = 0$.)

**Răspuns:** $x \in \{1, 2\}$. *Barem: 1p, 1p, 2p, 1p.*

### 4. $\dfrac{P_5}{C_5^2 + A_6^2}$

$P_5 = 120$, $C_5^2 = 10$, $A_6^2 = 30$:

$$\frac{120}{10 + 30} = 3.$$

**Răspuns:** $3$. *Barem: 3p, 2p.*

### 5. Ecuația dreptei $AB$, $A(2,3)$, $B(-1,0)$

$$\frac{y - 3}{0 - 3} = \frac{x - 2}{-1 - 2} \iff y - 3 = x - 2 \iff y = x + 1.$$

**Răspuns:** $y = x + 1$. *Barem: 3p, 2p.*

### 6. Perimetrul triunghiului $MNP$, $MN = 2$, $MP = 3$, $m(\angle NMP) = 120^\circ$

Teorema cosinusului, cu $\cos120^\circ = -\dfrac12$:

$$NP^2 = 4 + 9 - 2\cdot 2\cdot 3\cdot\left(-\tfrac12\right) = 19 \Rightarrow NP = \sqrt{19}.$$

**Răspuns:** perimetrul este $5 + \sqrt{19}$. *Barem: 2p, 2p, 1p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 2\\ 0 & 1\end{pmatrix}$

#### a) $\det A$

$1\cdot 1 - 2\cdot 0 = 1$. *Barem: 2p, 3p.*

#### b) $A^2 - 2A + I_2$

$$A^2 = \begin{pmatrix} 1 & 4\\ 0 & 1\end{pmatrix}, \quad A^2 - 2A + I_2 = \begin{pmatrix} 1 - 2 + 1 & 4 - 4 + 0\\ 0 & 1 - 2 + 1\end{pmatrix} = O_2.$$

**Răspuns:** $O_2$. *Barem: 2p, 2p, 1p.*

#### c) Matricele $X$ cu $X^2 = A$

Fie $X = \begin{pmatrix} a & b\\ c & d\end{pmatrix}$; $X^2 = \begin{pmatrix} a^2 + bc & b(a + d)\\ c(a + d) & d^2 + bc\end{pmatrix}$. Egalând cu $A$:

$$a^2 + bc = 1,\quad b(a + d) = 2,\quad c(a + d) = 0,\quad d^2 + bc = 1.$$

Din a doua, $a + d \ne 0$, deci din a treia $c = 0$. Atunci $a^2 = d^2 = 1$ și, cum $a + d \ne 0$, $a = d$. Apoi $2ab = 2$, adică $b = \dfrac1a = a$.

**Răspuns:** $X = \begin{pmatrix} 1 & 1\\ 0 & 1\end{pmatrix}$ sau $X = \begin{pmatrix} -1 & -1\\ 0 & -1\end{pmatrix}$. *Barem: 1p, 3p, 1p.*

### 2. Legea $x * y = xy - 3x - 3y + 12$

#### a) $x * y = (x - 3)(y - 3) + 3$

$(x - 3)(y - 3) + 3 = xy - 3x - 3y + 9 + 3 = x * y$. *Barem: 3p, 2p.*

#### b) $x * x = 19$

$$(x - 3)^2 + 3 = 19 \iff (x - 3)^2 = 16 \iff x - 3 = \pm4.$$

**Răspuns:** $x \in \{-1, 7\}$. *Barem: 2p, 3p.*

#### c) $\sqrt[3]1 * \sqrt[3]2 * \ldots * \sqrt[3]{2011}$

$x * 3 = 3 * x = 3$ pentru orice $x$, iar printre factori se află $\sqrt[3]{27} = 3$. Folosind asociativitatea:

$$\left(\sqrt[3]1 * \ldots * \sqrt[3]{26}\right) * 3 * \left(\sqrt[3]{28} * \ldots * \sqrt[3]{2011}\right) = 3.$$

**Răspuns:** $3$. *Barem: 2p, 2p, 1p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = e^x - x$

#### a) $f'(x) - f(x) = x - 1$

$f'(x) = e^x - 1$, deci $f'(x) - f(x) = e^x - 1 - e^x + x = x - 1$. *Barem: 3p, 2p.*

#### b) Tangenta în $x = 0$

$f(0) = 1$, $f'(0) = 0$: $y - 1 = 0$.

**Răspuns:** $y = 1$. *Barem: 2p, 2p, 1p.*

#### c) Asimptota oblică spre $-\infty$

$$m = \lim_{x\to-\infty}\frac{e^x - x}{x} = \lim_{x\to-\infty}\left(\frac{e^x}{x} - 1\right) = -1, \qquad n = \lim_{x\to-\infty}(f(x) + x) = \lim_{x\to-\infty}e^x = 0.$$

**Răspuns:** $y = -x$. *Barem: 2p, 2p, 1p.*

### 2. $f:(0, +\infty) \to \mathbb R$, $f(x) = \dfrac1x + \dfrac{1}{x + 1}$

#### a) $\displaystyle\int_1^e\left(f(x) - \frac{1}{x+1}\right)dx$

$$\int_1^e\frac1x\,dx = \ln x\Big|_1^e = 1.$$

**Răspuns:** $1$. *Barem: 2p, 2p, 1p.*

#### b) Aria între grafic, $Ox$, $x = 1$, $x = 2$

$f > 0$ pe $[1, 2]$, deci

$$\mathcal A = \int_1^2 f(x)\,dx = \big(\ln x + \ln(x + 1)\big)\Big|_1^2 = \ln 2 + \ln 3 - \ln 2 = \ln 3.$$

**Răspuns:** $\ln 3$. *Barem: 2p, 2p, 1p.*

#### c) Volumul pentru $g = f|_{[1,2]}$

$$g^2(x) = \frac{1}{x^2} + \frac{1}{(x+1)^2} + \frac{2}{x(x+1)}, \qquad \frac{2}{x(x+1)} = 2\left(\frac1x - \frac{1}{x+1}\right).$$

$$V = \pi\left(-\frac1x - \frac{1}{x+1} + 2\ln\frac{x}{x+1}\right)\Big|_1^2 = \pi\left(\frac12 + \frac16 + 2\ln\frac23 - 2\ln\frac12\right) = \pi\left(\frac23 + 2\ln\frac43\right).$$

**Răspuns:** $V = \pi\left(\dfrac23 + 2\ln\dfrac43\right)$. *Barem: 1p, 1p, 2p, 1p.*

## Ce merită reținut din model

- **Element absorbant ascuns**: la $(x-3)(y-3)+3$ caută termenul egal cu $3$ ($\sqrt[3]{27}$).
- **Rădăcina pătrată a unei matrice**: scrie $X$ generic și exploatează ecuația care forțează $c = 0$.
