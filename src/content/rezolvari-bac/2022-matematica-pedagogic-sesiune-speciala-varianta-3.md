## Subiectul I (30 de puncte)

### 1. Arătați că $(\sqrt3 + 1)^2 - (\sqrt3 - 1)^2 = \sqrt{48}$

$(\sqrt3 + 1)^2 = 4 + 2\sqrt3$, $(\sqrt3 - 1)^2 = 4 - 2\sqrt3$, deci diferența este $4\sqrt3 = \sqrt{16\cdot 3} = \sqrt{48}$. $\blacksquare$

*Barem: 3p pătratele, 2p finalizarea.*

### 2. Intersecția graficelor lui $f(x) = 2x + 1$ și $g(x) = -2x + 5$

$$f(x) = g(x) \iff 2x + 1 = -2x + 5 \iff x = 1,\qquad f(1) = 3.$$

**Răspuns:** punctul $(1, 3)$. *Barem: 2p abscisa, 3p punctul.*

### 3. Ecuația $3^{x-2} = \left(\frac13\right)^{-2x}$

$\left(\frac13\right)^{-2x} = 3^{2x}$, deci $x - 2 = 2x \iff x = -2$.

**Răspuns:** $x = -2$. *Barem: 3p + 2p.*

### 4. Câte numere impare de două cifre se pot forma cu cifrele $1, 2, \dots, 8$?

Cifra unităților trebuie să fie impară: $1, 3, 5, 7$ — **4 moduri**. Cifra zecilor poate fi oricare dintre cele 8 cifre — **8 moduri**. Regula produsului: $4\cdot 8 = 32$.

**Răspuns:** $32$ de numere. *Barem: 2p + 3p.*

### 5. Distanța de la $B(5,2)$ la mijlocul lui $AC$, $A(0,2)$, $C(6,6)$

$M\left(\frac{0+6}{2}, \frac{2+6}{2}\right) = M(3, 4)$.

$$BM = \sqrt{(3-5)^2 + (4-2)^2} = \sqrt{8} = 2\sqrt2.$$

**Răspuns:** $2\sqrt2$. *Barem: 3p mijlocul, 2p distanța.*

### 6. $AB = 9$, $AC = 12$, $BC = 15$: arătați că $\sin B + \sin C = \frac75$

$AB^2 + AC^2 = 81 + 144 = 225 = BC^2$, deci triunghiul este dreptunghic în $A$ (reciproca lui Pitagora).

$$\sin B = \frac{AC}{BC} = \frac{12}{15} = \frac45,\quad \sin C = \frac{AB}{BC} = \frac{9}{15} = \frac35,\quad \sin B + \sin C = \frac75.$$

*Barem: 3p unghiul drept, 2p finalizarea.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x * y = -\dfrac13xy + \dfrac13(x + y) + \dfrac23$.

### 1. $4 * 2 = 0$

$$4 * 2 = -\frac83 + \frac63 + \frac23 = 0.$$

*Barem: 3p + 2p.*

### 2. $x * y = -\frac13(x - 1)(y - 1) + 1$

$$-\tfrac13(x-1)(y-1) + 1 = -\tfrac13(xy - x - y + 1) + 1 = -\tfrac13xy + \tfrac13(x+y) - \tfrac13 + 1 = x * y.$$

*Barem: 3p + 2p.*

### 3. $x$ real cu $4 * x = x$

$4 * x = -\tfrac13\cdot 3(x - 1) + 1 = -x + 2$. Atunci $-x + 2 = x \iff x = 1$.

**Răspuns:** $x = 1$. *Barem: 2p + 3p.*

### 4. $e = -2$ este elementul neutru

$$(-2) * x = -\tfrac13(-3)(x - 1) + 1 = x - 1 + 1 = x,$$

iar $x * (-2) = x$ analog (legea este comutativă). $\blacksquare$ *Barem: 2p + 3p.*

### 5. $x$ real cu $x * x = -2$

$$-\tfrac13(x-1)^2 + 1 = -2 \iff (x - 1)^2 = 9 \iff x - 1 = \pm 3.$$

**Răspuns:** $x \in \{-2, 4\}$. *Barem: 2p + 3p.*

### 6. $\frac1x * \frac1x \le 1$ pentru orice $x \ne 0$

$$\tfrac1x * \tfrac1x = -\tfrac13\left(\tfrac1x - 1\right)^2 + 1 \le 1 \iff -\tfrac13\left(\tfrac1x - 1\right)^2 \le 0,$$

adevărat, deoarece un pătrat este nenegativ. $\blacksquare$ *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

$A(x,y) = \begin{pmatrix}x&y\\1&2\end{pmatrix}$, $B = \begin{pmatrix}1&2\\-1&0\end{pmatrix}$, $I_2$.

### 1. $\det B = 2$

$$\det B = 1\cdot 0 - 2\cdot(-1) = 2.$$

*Barem: 3p + 2p.*

### 2. $\det A(2n, 2n+1)$ este număr natural impar, $n \ge 1$

$$\det A(2n, 2n+1) = \begin{vmatrix}2n & 2n+1\\1 & 2\end{vmatrix} = 4n - 2n - 1 = 2n - 1,$$

care pentru $n \ge 1$ este natural și impar. *Barem: 3p + 2p.*

### 3. $A(2x, 0) + A(0, 2x) = 2A(x,x)$

$$\begin{pmatrix}2x&0\\1&2\end{pmatrix} + \begin{pmatrix}0&2x\\1&2\end{pmatrix} = \begin{pmatrix}2x&2x\\2&4\end{pmatrix} = 2\begin{pmatrix}x&x\\1&2\end{pmatrix} = 2A(x,x).$$

*Barem: 3p + 2p.*

### 4. $x, y$ cu $A(x,y)\cdot B = B\cdot A(x,y)$

$$A(x,y)B = \begin{pmatrix}x - y & 2x\\ -1 & 2\end{pmatrix},\qquad BA(x,y) = \begin{pmatrix}x + 2 & y + 4\\ -x & -y\end{pmatrix}.$$

Egalând: $x - y = x + 2 \Rightarrow y = -2$; $-1 = -x \Rightarrow x = 1$; verificăm $2x = 2 = y + 4$ și $2 = -y$ ✔.

**Răspuns:** $x = 1$, $y = -2$. *Barem: 3p + 2p.*

### 5. $x > 0$ cu suma elementelor lui $A(\log_3 x, 1)$ egală cu 5

Suma elementelor: $\log_3 x + 1 + 1 + 2 = 4 + \log_3 x = 5 \iff \log_3 x = 1 \iff x = 3$.

**Răspuns:** $x = 3$. *Barem: 3p + 2p.*

### 6. $x, y$ cu $A(x,y)\cdot A(x,y) = 2I_2$

$$A(x,y)^2 = \begin{pmatrix}x^2 + y & xy + 2y\\ x + 2 & y + 4\end{pmatrix} = \begin{pmatrix}2&0\\0&2\end{pmatrix}.$$

Din $x + 2 = 0$ și $y + 4 = 2$: $x = -2$, $y = -2$. Verificare: $x^2 + y = 2$ ✔, $xy + 2y = 4 - 4 = 0$ ✔.

**Răspuns:** $x = y = -2$. *Barem: 2p + 3p.*
