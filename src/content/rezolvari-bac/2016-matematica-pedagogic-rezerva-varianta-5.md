## Subiectul I (30 de puncte)

### 1. Arătați că $2\left(1 + \frac12\right)\left(1 + \frac13\right)\left(1 + \frac14\right) = 5$

$$2\cdot\frac32\cdot\frac43\cdot\frac54 = 5$$

(produs telescopic: fiecare numărător se simplifică cu numitorul următor). *Barem: 3p, 2p.*

### 2. $x$ cu $f(x) \ge g(x)$, $f(x) = 3x - 2$, $g(x) = x + 4$

$3x - 2 \ge x + 4 \iff x \ge 3$. **Răspuns:** $[3, +\infty)$. *Barem: 2p, 3p.*

### 3. Ecuația $7^{x^2+3} = 7^{4x}$

$x^2 - 4x + 3 = 0 \iff x \in \{1, 3\}$. *Barem: 3p, 2p.*

### 4. Profitul anual, știind că $5\%$ din el înseamnă $6000$ lei

$\dfrac{x}{20} = 6000 \iff x = 120\,000$. **Răspuns:** $120\,000$ de lei. *Barem: 3p, 2p.*

### 5. Perimetrul triunghiului $A(3,0)$, $B(6,4)$, $C(0,4)$

$$AB = \sqrt{9 + 16} = 5, \quad AC = \sqrt{9 + 16} = 5, \quad BC = 6.$$

$P = 5 + 5 + 6 = 16$. *Barem: 2p, 3p.*

### 6. Arătați că $\sin^2 30^\circ + \cos^2 60^\circ = \frac12$

$$\frac14 + \frac14 = \frac12.$$

*Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

Legea pe $\mathbb R$: $x\circ y = x + y + 5$.

### 1. $(-1)\circ1 = 5$

$-1 + 1 + 5 = 5$. *Barem: 3p, 2p.*

### 2. Legea este asociativă

$(x\circ y)\circ z = x + y + z + 10 = x\circ(y\circ z)$. *Barem: 2p, 3p.*

### 3. $e = -5$ este element neutru

$x\circ(-5) = x - 5 + 5 = x$ și $(-5)\circ x = x$. **Răspuns:** da. *Barem: 2p, 3p.*

### 4. $x^2\circ x = 7$

$x^2 + x + 5 = 7 \iff x^2 + x - 2 = 0 \iff x \in \{-2, 1\}$. *Barem: 3p, 2p.*

### 5. $(x^2 - y - 5)\circ(x - y^2) = (x - y)(x + y + 1)$

$$(x^2 - y - 5) + (x - y^2) + 5 = x^2 - y^2 + x - y = (x-y)(x+y) + (x - y) = (x - y)(x + y + 1).$$

*Barem: 2p, 3p.*

### 6. Numerele naturale $m, n$ cu $m\circ n = 6$

$m + n + 5 = 6 \iff m + n = 1$.

**Răspuns:** $(m,n) \in \{(0,1), (1,0)\}$. *Barem: 2p, 3p.*

## Subiectul al III-lea (30 de puncte)

$A(a) = \begin{pmatrix}1&a\\a&1\end{pmatrix}$.

### 1. $\det(A(0)) = 1$

$A(0) = I_2$. *Barem: 3p, 2p.*

### 2. $a$ cu $\det(A(a)) = 0$

$\det A(a) = 1 - a^2 = 0 \iff a = \pm1$. *Barem: 2p, 3p.*

### 3. $A(1)\cdot A(1) - 2A(1) = O_2$

$$A(1)^2 = \begin{pmatrix}2&2\\2&2\end{pmatrix} = 2A(1).$$

*Barem: 3p, 2p.*

### 4. $a$ cu $A(2)\cdot A(a) = 3A(1)$

$$A(2)A(a) = \begin{pmatrix}1 + 2a & a + 2\\2 + a & 2a + 1\end{pmatrix} = \begin{pmatrix}3&3\\3&3\end{pmatrix} \iff a = 1.$$

*Barem: 3p, 2p.*

### 5. $\det(A(a) - A(0)) \le 0$

$$A(a) - A(0) = \begin{pmatrix}0 & a\\a & 0\end{pmatrix}, \qquad \det = -a^2 \le 0. \ \blacksquare$$

*Barem: 3p, 2p.*

### 6. $a, b$ cu $A(a)\cdot A(b) = O_2$

$$A(a)A(b) = \begin{pmatrix}1 + ab & a + b\\a + b & 1 + ab\end{pmatrix} = O_2 \iff a + b = 0,\ ab = -1.$$

Cu $b = -a$: $-a^2 = -1 \Rightarrow a = \pm1$.

**Răspuns:** $(a, b) \in \{(1, -1), (-1, 1)\}$. *Barem: 2p, 3p.*

## Ce merită reținut din varianta 5

- **Produse telescopice** $\left(1 + \frac1k\right) = \frac{k+1}{k}$.
- **Legea $x + y + c$**: neutrul este $-c$.
- **Matricele $\begin{pmatrix}1&a\\a&1\end{pmatrix}$**: $\det = 1 - a^2$, produsul are forma $\begin{pmatrix}1 + ab & a + b\\a + b & 1 + ab\end{pmatrix}$.
- **Distanța între puncte** pe orizontală/verticală se citește direct.
