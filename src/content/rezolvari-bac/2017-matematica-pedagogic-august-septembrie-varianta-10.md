## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt{\frac{9}{25}} - \frac{33}{55} = 0$

$\sqrt{\dfrac{9}{25}} = \dfrac35$, iar $\dfrac{33}{55} = \dfrac{3\cdot11}{5\cdot11} = \dfrac35$. Diferența este $\dfrac35 - \dfrac35 = 0$.

*Barem: 2p radicalul, 3p finalizarea.*

### 2. Inecuația $3(x-1) < 6$ în $\mathbb N^*$

$$x - 1 < 2 \iff x < 3.$$

**Răspuns:** $x \in \{1, 2\}$. *Barem: 2p inecuația, 3p soluțiile naturale nenule.*

### 3. Ecuația $\log_4(x^2 + 4x + 6) = \log_4 2$

Logaritmul este injectiv: $x^2 + 4x + 6 = 2 \iff x^2 + 4x + 4 = 0 \iff (x+2)^2 = 0 \iff x = -2$.

**Verificare:** $4 - 8 + 6 = 2 > 0$ ✔. **Răspuns:** $x = -2$. *Barem: 3p ecuația, 2p soluția.*

### 4. Numere impare de două cifre formate cu cifrele $1, 2, 3, 4, 5$

Cifrele se pot repeta (enunțul nu cere cifre distincte). Unitățile trebuie să fie impare: $1, 3, 5$ — 3 moduri. Zecile: oricare din cele 5 cifre.

$$3\cdot5 = 15.$$

**Răspuns:** 15. *Barem: 2p cifra unităților, 3p finalizarea.*

### 5. $M(1,1)$, $N(4,1)$, $P(4,4)$: triunghiul $MNP$ este isoscel

$$MN = \sqrt{(4-1)^2 + (1-1)^2} = 3, \qquad NP = \sqrt{(4-4)^2 + (4-1)^2} = 3.$$

$MN = NP$, deci triunghiul este isoscel (chiar dreptunghic isoscel în $N$). *Barem: 2p $MN$, 3p $NP$ și concluzia.*

### 6. Triunghi dreptunghic în $A$, $AB = 6$, $BC = 12$: $\angle C = 30^\circ$

$$\sin C = \frac{AB}{BC} = \frac{6}{12} = \frac12.$$

$C$ este unghi ascuțit (triunghiul e dreptunghic în $A$), deci $m(\angle C) = 30^\circ$. *Barem: 2p $\sin C$, 3p concluzia.*

## Subiectul al II-lea (30 de puncte)

Legea: $x * y = xy + 7(x + y) + 42$.

### 1. $\sqrt2 * (-\sqrt2) = 40$

$$\sqrt2\cdot(-\sqrt2) + 7\big(\sqrt2 - \sqrt2\big) + 42 = -2 + 0 + 42 = 40.$$

*Barem: 3p înlocuirea, 2p calculul.*

### 2. $x * y = (x+7)(y+7) - 7$

$$xy + 7x + 7y + 49 - 7 = x(y+7) + 7(y+7) - 7 = (x+7)(y+7) - 7.$$

*Barem: 2p scrierea $42 = 49 - 7$, 3p factorizarea.*

### 3. $e = -6$ este element neutru

$$x * (-6) = (x+7)(-6+7) - 7 = x + 7 - 7 = x, \qquad (-6) * x = 1\cdot(x+7) - 7 = x.$$

Pentru orice $x$ real, deci $e = -6$ este elementul neutru. *Barem: 2p + 3p.*

### 4. $2 * a = 65$

$$2 * a = 9(a+7) - 7 = 9a + 56 = 65 \iff 9a = 9 \iff a = 1.$$

**Răspuns:** $a = 1$. *Barem: 3p expresia, 2p soluția.*

### 5. $(\log_2 x) * (\log_2 x) = 42$, $x > 0$

$$(\log_2 x + 7)^2 - 7 = 42 \iff (\log_2 x + 7)^2 = 49 \iff \log_2 x + 7 = \pm7.$$

- $\log_2 x = 0 \Rightarrow x = 1$;
- $\log_2 x = -14 \Rightarrow x = 2^{-14}$.

**Răspuns:** $x \in \{2^{-14}, 1\}$. *Barem: 3p ecuația, 2p soluțiile.*

### 6. Numerele întregi $m$ cu $m * (2 - m) \ge 57$

$$m * (2-m) = (m+7)(9-m) - 7 = -m^2 + 2m + 63 - 7 = -m^2 + 2m + 56.$$

$$-m^2 + 2m + 56 \ge 57 \iff -m^2 + 2m - 1 \ge 0 \iff -(m-1)^2 \ge 0 \iff m = 1.$$

**Răspuns:** $m = 1$. *Barem: 2p expresia, 3p soluția.*

## Subiectul al III-lea (30 de puncte)

Matricele: $A = \begin{pmatrix} 6 & -5\\ -1 & 1\end{pmatrix}$, $B = \begin{pmatrix} 1 & 5\\ 1 & 6\end{pmatrix}$.

### 1. $\det A = 1$

$$\det A = 6\cdot1 - (-1)(-5) = 6 - 5 = 1.$$

*Barem: 3p scrierea, 2p calculul.*

### 2. $A\cdot B - B\cdot A = O_2$

$$A\cdot B = \begin{pmatrix} 6 - 5 & 30 - 30\\ -1 + 1 & -5 + 6\end{pmatrix} = I_2, \qquad B\cdot A = \begin{pmatrix} 6 - 5 & -5 + 5\\ 6 - 6 & -5 + 6\end{pmatrix} = I_2.$$

Diferența este $I_2 - I_2 = O_2$. (Deci $B = A^{-1}$!) *Barem: 3p produsele, 2p finalizarea.*

### 3. $\det(A + xB) = 1 - 3x$

$$A + xB = \begin{pmatrix} 6 + x & -5 + 5x\\ -1 + x & 1 + 6x\end{pmatrix},$$

$$\det(A + xB) = (6+x)(1+6x) - 5(x-1)(x-1) = 6x^2 + 37x + 6 - 5x^2 + 10x - 5 = x^2 + 47x + 1.$$

$x^2 + 47x + 1 = 1 - 3x \iff x^2 + 50x = 0 \iff x(x + 50) = 0$.

**Răspuns:** $x \in \{-50, 0\}$. *Barem: 2p determinantul, 3p soluțiile.*

### 4. $A\cdot\begin{pmatrix} x\\ y\end{pmatrix} = \begin{pmatrix} 7\\ -1\end{pmatrix}$

$$\begin{cases} 6x - 5y = 7\\ -x + y = -1\end{cases}$$

Din a doua: $y = x - 1$; înlocuind: $6x - 5x + 5 = 7 \Rightarrow x = 2$, $y = 1$.

**Răspuns:** $x = 2$, $y = 1$. *Barem: 3p sistemul, 2p soluția.*

### 5. $\det(A + B) + \det(A - B) = 2(\det A + \det B)$

$A + B = \begin{pmatrix} 7 & 0\\ 0 & 7\end{pmatrix}$, $A - B = \begin{pmatrix} 5 & -10\\ -2 & -5\end{pmatrix}$.

$$\det(A+B) + \det(A-B) = 49 + (-25 - 20) = 49 - 45 = 4.$$

$\det B = 6 - 5 = 1$, deci $2(\det A + \det B) = 2\cdot2 = 4$. Egalitatea are loc. $\blacksquare$ *Barem: 2p matricele, 2p determinanții, 1p finalizarea.*

### 6. $X$ cu $A\cdot X - B = I_2$

$A\cdot X = I_2 + B$, iar din punctul 2, $A^{-1} = B$. Deci

$$X = A^{-1}(I_2 + B) = B\begin{pmatrix} 2 & 5\\ 1 & 7\end{pmatrix} = \begin{pmatrix} 1 & 5\\ 1 & 6\end{pmatrix}\begin{pmatrix} 2 & 5\\ 1 & 7\end{pmatrix} = \begin{pmatrix} 7 & 40\\ 8 & 47\end{pmatrix}.$$

**Răspuns:** $X = \begin{pmatrix} 7 & 40\\ 8 & 47\end{pmatrix}$. *Barem: 2p inversa, 3p matricea $X$.*

- **Când $AB = I_2$**, $B$ este chiar inversa lui $A$ — folosește-o direct în ecuațiile matriceale.
