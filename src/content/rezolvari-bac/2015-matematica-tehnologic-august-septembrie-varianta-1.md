## Subiectul I (30 de puncte)

### 1. Arătați că $\frac12 : 0{,}5 - 1 = 0$

$0{,}5 = \frac12$, deci $\frac12 : \frac12 - 1 = 1 - 1 = 0$. *Barem: 2p + 3p.*

### 2. $f(x) = x^2 + x$; $f(-1) + f(0) + f(1)$

$f(-1) = 0$, $f(0) = 0$, $f(1) = 2$; suma este $2$. *Barem: 3p + 2p.*

### 3. Ecuația $\sqrt{3x + 1} = 5$

$3x + 1 = 25 \iff x = 8$, care verifică ($\sqrt{25} = 5$). *Barem: 3p + 2p.*

### 4. Prețul de 150 lei după o scumpire cu 30%

$\frac{30}{100}\cdot150 = 45$ lei, deci prețul nou este $195$ lei. *Barem: 3p + 2p.*

### 5. Distanța dintre $A(1,5)$ și $B(3,5)$

$$AB = \sqrt{(3-1)^2 + 0^2} = 2.$$

*Barem: 3p + 2p.*

### 6. Triunghi dreptunghic în $A$, $AC = 5$, $B = 45^\circ$; aflați $AB$

$C = 90^\circ - 45^\circ = 45^\circ = B$, deci triunghiul este dreptunghic isoscel și $AB = AC = 5$. *Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $M = \begin{pmatrix} -2 & 2\\ -1 & -1\end{pmatrix}$

#### a) $\det M = 4$

$$\det M = (-2)(-1) - 2\cdot(-1) = 2 + 2 = 4.$$

*Barem: 3p + 2p.*

#### b) $M\cdot M + 3M + 4I_2 = O_2$

$$M\cdot M = \begin{pmatrix} 4 - 2 & -4 - 2\\ 2 + 1 & -2 + 1\end{pmatrix} = \begin{pmatrix} 2 & -6\\ 3 & -1\end{pmatrix}, \quad 3M = \begin{pmatrix} -6 & 6\\ -3 & -3\end{pmatrix}, \quad 4I_2 = \begin{pmatrix} 4 & 0\\ 0 & 4\end{pmatrix}.$$

Suma: $\begin{pmatrix} 2 - 6 + 4 & -6 + 6\\ 3 - 3 & -1 - 3 + 4\end{pmatrix} = O_2$. $\blacksquare$ *Barem: 3p + 2p.*

#### c) $a, b$ cu $M\cdot M\cdot M = aM + bI_2$

Din b), $M^2 = -3M - 4I_2$. Înmulțind cu $M$:

$$M^3 = -3M^2 - 4M = -3(-3M - 4I_2) - 4M = 5M + 12I_2.$$

Verificare directă: $M^3 = \begin{pmatrix} 2 & 10\\ -5 & 7\end{pmatrix}$ și $5M + 12I_2 = \begin{pmatrix} -10 + 12 & 10\\ -5 & -5 + 12\end{pmatrix}$ ✔.

**Răspuns:** $a = 5$, $b = 12$. *Barem: 3p + 2p.*

### 2. $f = X^3 - 5X^2 + 5X - 1$

#### a) $f(1) = 0$

$$f(1) = 1 - 5 + 5 - 1 = 0.$$

*Barem: 3p + 2p.*

#### b) $f(a) + f(-a) + 2 \le 0$

$f(a) = a^3 - 5a^2 + 5a - 1$, $f(-a) = -a^3 - 5a^2 - 5a - 1$. Adunând (termenii impari se reduc):

$$f(a) + f(-a) + 2 = -10a^2 - 2 + 2 = -10a^2 \le 0. \ \blacksquare$$

*Barem: 2p + 3p.*

#### c) $x_1^2 + x_2^2 + x_3^2 = 15x_1x_2x_3$

Viète: $\sum x_i = 5$, $\sum x_ix_j = 5$, $x_1x_2x_3 = 1$.

$$x_1^2 + x_2^2 + x_3^2 = 25 - 10 = 15 = 15\cdot1 = 15x_1x_2x_3. \ \blacksquare$$

*Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = 2x^3 - 6x + 1$

#### a) $f'(x) = 6(x-1)(x+1)$

$$f'(x) = 6x^2 - 6 = 6(x^2 - 1) = 6(x-1)(x+1).$$

*Barem: 3p + 2p.*

#### b) Tangenta în $x = 1$

$f(1) = 2 - 6 + 1 = -3$, $f'(1) = 0$, deci tangenta este $y = -3$. *Barem: 2p + 3p.*

#### c) $f(2012) + f(2014) \le f(2013) + f(2015)$

Pe $[1, +\infty)$, $f'(x) \ge 0$, deci $f$ este crescătoare. Atunci $f(2012) \le f(2013)$ și $f(2014) \le f(2015)$; adunând, obținem inegalitatea. $\blacksquare$ *Barem: 3p + 2p.*

### 2. $f(x) = x^2 - 4$

#### a) $\displaystyle\int_0^1(f(x) + 4)\,dx = \frac13$

$$\int_0^1 x^2\,dx = \frac13.$$

*Barem: 2p + 3p.*

#### b) Aria sub $g(x) = \dfrac{1}{f(x) + 5} = \dfrac{1}{x^2 + 1}$ pe $[0,1]$

$$\mathcal A = \int_0^1\frac{1}{x^2 + 1}\,dx = \operatorname{arctg} x\Big|_0^1 = \frac\pi4.$$

*Barem: 3p + 2p.*

#### c) $a > 1$ cu $\displaystyle\int_1^a\frac{f(x) + 4}{x}\,dx = 12$

$\dfrac{x^2}{x} = x$:

$$\int_1^a x\,dx = \frac{a^2 - 1}{2} = 12 \iff a^2 = 25,$$

iar $a > 1$, deci $a = 5$. *Barem: 3p + 2p.*
