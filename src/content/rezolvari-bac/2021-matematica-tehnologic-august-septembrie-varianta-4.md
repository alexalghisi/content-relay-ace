## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_1 = 4$, $r = 5$; termenul $a_3$

$$a_3 = a_1 + 2r = 4 + 10 = 14.$$

*Barem: 3p + 2p.*

### 2. $f(x) = x^2 - x - 1$; arătați că $f(0) = f(1)$

$f(0) = -1$, $f(1) = 1 - 1 - 1 = -1$, deci $f(0) = f(1)$. $\blacksquare$

*Barem: 2p + 3p.*

### 3. Ecuația $\log_4(3x + 4) = \log_416$

$3x + 4 = 16 \iff x = 4$ (convine).

*Barem: 3p + 2p.*

### 4. După o scumpire cu 25%, produsul costă 350 de lei. Prețul inițial?

$$x + \frac{25}{100}x = 350 \iff \frac54x = 350 \iff x = 280.$$

**Răspuns:** $280$ de lei. *Barem: 3p + 2p.*

### 5. $A(-4,1)$, $B(a,b)$; $O$ este mijlocul lui $AB$

$$\frac{-4 + a}{2} = 0 \Rightarrow a = 4,\qquad \frac{1 + b}{2} = 0 \Rightarrow b = -1.$$

*Barem: 3p + 2p.*

### 6. $\triangle ABC$ isoscel dreptunghic în $A$, cu aria 8; lungimea lui $AB$

$AB = AC$, deci $\mathcal A = \frac{AB^2}{2} = 8 \iff AB^2 = 16 \iff AB = 4$.

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}5&-2\\-1&1\end{pmatrix}$, $B(x) = \begin{pmatrix}x & -2x\\ 1 & -1\end{pmatrix}$

#### a) $\det A = 3$

$$\det A = 5\cdot1 - (-2)(-1) = 3.$$

*Barem: 3p + 2p.*

#### b) $3B(2) + B(6) = 4B(3)$

$$3\begin{pmatrix}2&-4\\1&-1\end{pmatrix} + \begin{pmatrix}6&-12\\1&-1\end{pmatrix} = \begin{pmatrix}12&-24\\4&-4\end{pmatrix} = 4\begin{pmatrix}3&-6\\1&-1\end{pmatrix} = 4B(3).$$

*Barem: 3p + 2p.*

#### c) $x$ cu $\big(B(-x) - B(x)\big)\big(B(-x) + B(x)\big) = A + B(3)$

$$B(-x) - B(x) = \begin{pmatrix}-2x & 4x\\0&0\end{pmatrix},\quad B(-x) + B(x) = \begin{pmatrix}0&0\\2&-2\end{pmatrix},$$

$$\text{produsul} = \begin{pmatrix}8x & -8x\\0&0\end{pmatrix},\qquad A + B(3) = \begin{pmatrix}8&-8\\0&0\end{pmatrix}.$$

**Răspuns:** $x = 1$. *Barem: 3p + 2p.*

### 2. Legea $x\circ y = 3x + 4y - 25$

#### a) $3\circ4 = 0$

$$3\circ4 = 9 + 16 - 25 = 0.$$

*Barem: 3p + 2p.*

#### b) $x$ cu $(2x)\circ x = 5$

$(2x)\circ x = 6x + 4x - 25 = 10x - 25 = 5 \iff x = 3$.

*Barem: 3p + 2p.*

#### c) $m$ întreg cu $m^2\circ1 \ge 1\circ m^2$

$m^2\circ1 = 3m^2 - 21$, $1\circ m^2 = 4m^2 - 22$.

$$3m^2 - 21 \ge 4m^2 - 22 \iff m^2 \le 1 \iff m \in [-1, 1].$$

**Răspuns:** $m \in \{-1, 0, 1\}$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:\left(-\frac13,\infty\right)\to\mathbb R$, $f(x) = \dfrac{2x}{3x + 1}$

#### a) $f'(x) = \dfrac{2}{(3x+1)^2}$

$$f'(x) = \frac{2(3x + 1) - 2x\cdot3}{(3x+1)^2} = \frac2{(3x+1)^2}.$$

*Barem: 3p + 2p.*

#### b) Asimptota orizontală spre $+\infty$

$$\lim_{x\to\infty}\frac{2x}{3x + 1} = \lim_{x\to\infty}\frac2{3 + \frac1x} = \frac23.$$

**Răspuns:** $y = \frac23$. *Barem: 3p + 2p.*

#### c) $f$ este concavă

$$f''(x) = \left(2(3x+1)^{-2}\right)' = -4\cdot3(3x+1)^{-3} = -\frac{12}{(3x+1)^3}.$$

Pe $\left(-\frac13,\infty\right)$, $3x + 1 > 0$, deci $f''(x) < 0$: $f$ e concavă. $\blacksquare$ *Barem: 3p + 2p.*

### 2. $f:(0,\infty)\to\mathbb R$, $f(x) = x^2 + \ln x - 1$

#### a) $\displaystyle\int_1^4\left(f(x) - \ln x + 1\right)dx = 21$

$$\int_1^4x^2dx = \frac{x^3}3\Big|_1^4 = \frac{64 - 1}3 = 21.$$

*Barem: 3p + 2p.*

#### b) $\displaystyle\int_2^4\frac{x}{f(x) - \ln x}dx = \frac12\ln5$

$$\int_2^4\frac{x}{x^2 - 1}dx = \frac12\ln(x^2 - 1)\Big|_2^4 = \frac12(\ln15 - \ln3) = \frac12\ln5.$$

*Barem: 3p + 2p.*

#### c) $a > 1$ cu $\displaystyle\int_1^a\frac{f(x)}{x^2}dx = \frac{a - \ln a}a$

$\dfrac{f(x)}{x^2} = 1 + \dfrac{\ln x}{x^2} - \dfrac1{x^2}$. Prin părți: $\displaystyle\int_1^a\frac{\ln x}{x^2}dx = -\frac{\ln x}{x}\Big|_1^a + \int_1^a\frac1{x^2}dx$, deci

$$\int_1^a\frac{f(x)}{x^2}dx = (a - 1) - \frac{\ln a}a.$$

$a - 1 - \dfrac{\ln a}a = 1 - \dfrac{\ln a}a \iff a = 2$ (convine, $a > 1$).

**Răspuns:** $a = 2$. *Barem: 3p + 2p.*
