## Subiectul I (30 de puncte)

### 1. Progresia aritmetică cu $a_1 = 3$, $a_3 = 7$: suma primilor 10 termeni

$a_3 = a_1 + 2r \Rightarrow 7 = 3 + 2r \Rightarrow r = 2$. Atunci $a_{10} = a_1 + 9r = 21$ și

$$S_{10} = \frac{(a_1 + a_{10})\cdot 10}{2} = \frac{24\cdot 10}{2} = 120.$$

**Răspuns:** $S_{10} = 120$. *Barem: 2p rația, 1p $a_{10}$, 2p suma.*

### 2. $A(m, -1)$ pe graficul lui $f(x) = x^2 - 3x + 1$

$$m^2 - 3m + 1 = -1 \iff m^2 - 3m + 2 = 0 \iff (m - 1)(m - 2) = 0.$$

**Răspuns:** $m \in \{1, 2\}$. *Barem: 3p, 2p.*

### 3. $\log_5(2x + 3) = 2$

Condiție: $x > -\dfrac32$. $2x + 3 = 5^2 = 25 \iff x = 11$, care convine.

**Răspuns:** $x = 11$. *Barem: 1p, 4p.*

### 4. Numărul submulțimilor cu 3 elemente ale unei mulțimi cu 5 elemente

$$C_5^3 = \frac{5!}{3!\,2!} = 10.$$

**Răspuns:** 10. *Barem: 3p, 2p.*

### 5. Distanța de la $C(2,-1)$ la mijlocul lui $AB$, $A(-1,-2)$, $B(1,2)$

$M\left(\dfrac{-1+1}{2}, \dfrac{-2+2}{2}\right) = M(0, 0)$, deci

$$CM = \sqrt{(2 - 0)^2 + (-1 - 0)^2} = \sqrt5.$$

**Răspuns:** $CM = \sqrt5$. *Barem: 2p, 1p, 2p.*

### 6. Aria triunghiului cu $AB = AC = 8$, $m(\angle BAC) = 30^\circ$

$$\mathcal A = \frac{AB\cdot AC\cdot\sin A}{2} = \frac{8\cdot 8\cdot\frac12}{2} = 16.$$

**Răspuns:** $16$. *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 3 & 1 & 1\\ 0 & 3 & 1\\ 0 & 0 & 3\end{pmatrix}$, $B = \begin{pmatrix} 0 & 3 & 4\\ 0 & 0 & 3\\ 0 & 0 & 0\end{pmatrix}$, $f(X) = X^2 - 3X + I_3$

#### a) $\det(I_3 + B)$

$I_3 + B = \begin{pmatrix} 1 & 3 & 4\\ 0 & 1 & 3\\ 0 & 0 & 1\end{pmatrix}$ este superior triunghiulară, deci $\det = 1$. *Barem: 2p, 3p.*

#### b) $f(A) = I_3 + B$

$$A^2 = \begin{pmatrix} 9 & 6 & 7\\ 0 & 9 & 6\\ 0 & 0 & 9\end{pmatrix}, \qquad A^2 - 3A + I_3 = \begin{pmatrix} 9 - 9 + 1 & 6 - 3 & 7 - 3\\ 0 & 1 & 6 - 3\\ 0 & 0 & 1\end{pmatrix} = \begin{pmatrix} 1 & 3 & 4\\ 0 & 1 & 3\\ 0 & 0 & 1\end{pmatrix} = I_3 + B.$$

*Barem: 2p, 1p, 2p.*

#### c) $(f(A))^3 = I_3 + 3B + 3B^2$

$I_3$ comută cu $B$, deci se aplică binomul:

$$(I_3 + B)^3 = I_3 + 3B + 3B^2 + B^3.$$

$B^2 = \begin{pmatrix} 0 & 0 & 9\\ 0 & 0 & 0\\ 0 & 0 & 0\end{pmatrix}$, iar $B^3 = B^2\cdot B = O_3$. Rezultă $(f(A))^3 = I_3 + 3B + 3B^2$. $\blacksquare$ *Barem: 2p, 2p, 1p.*

### 2. Pe $\mathbb Z$: $x * y = x + y - 3$, $x\circ y = (x - 3)(y - 3) + 3$

#### a) $x\circ x = x * x$

$$(x - 3)^2 + 3 = 2x - 3 \iff (x - 3)^2 - 2(x - 3) = 0 \iff (x - 3)(x - 5) = 0.$$

**Răspuns:** $x \in \{3, 5\}$. *Barem: 2p, 1p, 2p.*

#### b) $a$ întreg cu $x\circ a = 3$ pentru orice $x$

$(x - 3)(a - 3) + 3 = 3 \iff (x - 3)(a - 3) = 0$ pentru orice $x$, deci $a = 3$.

**Răspuns:** $a = 3$. *Barem: 2p, 3p.*

#### c) Sistemul $x * (y + 1) = 4$, $(x - y)\circ 1 = 5$

- $x + y + 1 - 3 = 4 \iff x + y = 6$;
- $(x - y - 3)(1 - 3) + 3 = 5 \iff -2(x - y - 3) = 2 \iff x - y = 2$.

**Răspuns:** $x = 4$, $y = 2$. *Barem: 3p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f:\mathbb R^* \to \mathbb R$, $f(x) = x^3 + \dfrac3x$

#### a) $f'(x)$

$$f'(x) = 3x^2 - \frac{3}{x^2} = \frac{3(x^4 - 1)}{x^2}.$$

*Barem: 2p, 2p, 1p.*

#### b) $\lim\limits_{x\to1}\dfrac{f(x) - f(1)}{x - 1}$

Este $f'(1) = 3 - 3 = 0$. *Barem: 3p, 2p.*

#### c) Intervalele de monotonie

$f'(x) = \dfrac{3(x^2 - 1)(x^2 + 1)}{x^2}$ are semnul lui $x^2 - 1$; $f'(x) = 0 \iff x = \pm1$.

**Răspuns:** $f$ crescătoare pe $(-\infty, -1]$ și pe $[1, +\infty)$; descrescătoare pe $[-1, 0)$ și pe $(0, 1]$. *Barem: 1p, 2p, 2p.*

### 2. $f:[0,1] \to \mathbb R$, $f(x) = x\sqrt{2 - x^2}$

#### a) Volumul corpului de rotație

$$V = \pi\int_0^1 x^2(2 - x^2)\,dx = \pi\left(\frac{2x^3}{3} - \frac{x^5}{5}\right)\Big|_0^1 = \pi\left(\frac23 - \frac15\right) = \frac{7\pi}{15}.$$

**Răspuns:** $\dfrac{7\pi}{15}$. *Barem: 1p, 2p, 2p.*

#### b) $\displaystyle\int_0^1 f(x)\,dx$

Substituim $t = 2 - x^2$, $dt = -2x\,dx$; $x = 0 \to t = 2$, $x = 1 \to t = 1$:

$$\int_0^1 x\sqrt{2 - x^2}\,dx = \frac12\int_1^2\sqrt t\,dt = \frac12\cdot\frac23t\sqrt t\Big|_1^2 = \frac{2\sqrt2 - 1}{3}.$$

**Răspuns:** $\dfrac{2\sqrt2 - 1}{3}$. *Barem: 3p, 2p.*

#### c) $\lim\limits_{x\to0}\dfrac{\int_0^x f(t)\,dt}{x^2}$

Cazul $\frac00$; funcția $F(x) = \int_0^x f(t)\,dt$ are $F' = f$. Cu l'Hospital:

$$\lim_{x\to0}\frac{x\sqrt{2 - x^2}}{2x} = \lim_{x\to0}\frac{\sqrt{2 - x^2}}{2} = \frac{\sqrt2}{2}.$$

(Baremul calculează explicit $\int_0^x f = \frac{2\sqrt2 - (2 - x^2)\sqrt{2 - x^2}}{3}$ și apoi aplică l'Hospital — același rezultat.)

**Răspuns:** $\dfrac{\sqrt2}{2}$. *Barem: 3p, 2p.*

## Ce merită reținut din model

- **Matrice nilpotentă**: dacă $B^3 = O_3$, binomul lui Newton pentru $(I_3 + B)^n$ se oprește după trei termeni.
- **Element absorbant**: la $x\circ y = (x-3)(y-3) + 3$, $a = 3$ dă mereu $3$.
- **Limite cu integrală variabilă**: l'Hospital + $\left(\int_0^x f\right)' = f(x)$.
