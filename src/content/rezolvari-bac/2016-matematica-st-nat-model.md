## Subiectul I (30 de puncte)

### 1. Primul termen al progresiei geometrice cu $b_5 = 48$ și $b_8 = 384$

$b_1q^4 = 48$, $b_1q^7 = 384$; împărțind: $q^3 = 8 \Rightarrow q = 2$. Apoi $b_1 = \dfrac{48}{16} = 3$.

**Răspuns:** $b_1 = 3$. *Barem: 3p, 2p.*

### 2. Distanța dintre punctele de intersecție ale graficului lui $f(x) = x^2 - 7x + 6$ cu $Ox$

$x^2 - 7x + 6 = 0 \iff x \in \{1, 6\}$: punctele $(1, 0)$ și $(6, 0)$, la distanța $6 - 1 = 5$.

**Răspuns:** $5$. *Barem: 3p, 2p.*

### 3. Ecuația $32^x = 16\cdot 2^x$

$$2^{5x} = 2^{4 + x} \iff 5x = 4 + x \iff x = 1.$$

**Răspuns:** $x = 1$. *Barem: 3p, 2p.*

### 4. Probabilitatea ca $n \in \{1, 2, 3, 4, 5\}$ să verifice $n^2 - 5n + 6 = 0$

$n^2 - 5n + 6 = (n - 2)(n - 3) = 0 \iff n \in \{2, 3\}$: 2 cazuri favorabile din 5.

$$p = \frac25.$$

*Barem: 1p, 2p, 2p.*

### 5. $a$ pentru care $\vec u = (a + 1)\vec i + (a - 1)\vec j$ și $\vec v = 6\vec i + 2\vec j$ sunt coliniari

$$\frac{a + 1}{6} = \frac{a - 1}{2} \iff 2a + 2 = 6a - 6 \iff a = 2.$$

**Răspuns:** $a = 2$. *Barem: 3p, 2p.*

### 6. $(2\sin x + \cos x)^2 + (\sin x + 2\cos x)^2 - 4\sin 2x = 5$

$$(2\sin x + \cos x)^2 = 4\sin^2 x + 4\sin x\cos x + \cos^2 x,$$
$$(\sin x + 2\cos x)^2 = \sin^2 x + 4\sin x\cos x + 4\cos^2 x.$$

Suma: $5(\sin^2 x + \cos^2 x) + 8\sin x\cos x = 5 + 4\sin 2x$. Scăzând $4\sin 2x$ obținem $5$. *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 2\\ 4 & 1\end{pmatrix}$, $B = \begin{pmatrix} 0 & x\\ y & 0\end{pmatrix}$

#### a) $\det(2A) = -28$

$$2A = \begin{pmatrix} 2 & 4\\ 8 & 2\end{pmatrix}, \quad \det(2A) = 4 - 32 = -28.$$

*Barem: 3p, 2p.*

#### b) $x, y$ cu $A + 2B = I_2$

$$A + 2B = \begin{pmatrix} 1 & 2 + 2x\\ 4 + 2y & 1\end{pmatrix} = \begin{pmatrix} 1 & 0\\ 0 & 1\end{pmatrix} \iff x = -1,\ y = -2.$$

**Răspuns:** $x = -1$, $y = -2$. *Barem: 2p, 3p.*

#### c) Dacă $AB = BA$, atunci $\det B \le 0$

$$AB = \begin{pmatrix} 2y & x\\ y & 4x\end{pmatrix}, \qquad BA = \begin{pmatrix} 4x & x\\ y & 2y\end{pmatrix}.$$

$AB = BA \iff 2y = 4x \iff y = 2x$. Atunci

$$\det B = -xy = -2x^2 \le 0. \ \blacksquare$$

*Barem: 2p, 3p.*

### 2. $x \circ y = 3xy + 3x + 3y + 2$

#### a) $(-1)\circ 1 = -1$

$$(-1)\circ 1 = -3 - 3 + 3 + 2 = -1.$$

*Barem: 3p, 2p.*

#### b) Ecuația $x \circ x = x$

$$3x^2 + 6x + 2 = x \iff 3x^2 + 5x + 2 = 0 \iff (3x + 2)(x + 1) = 0.$$

**Răspuns:** $x \in \left\{-1, -\dfrac23\right\}$. *Barem: 3p, 2p.*

#### c) Perechile de numere întregi $(a, b)$ cu $a \circ b = 8$

$a \circ b = 3(a + 1)(b + 1) - 1$, deci

$$3(a + 1)(b + 1) - 1 = 8 \iff (a + 1)(b + 1) = 3.$$

Descompunerile lui 3 în $\mathbb Z$: $1\cdot 3$, $3\cdot 1$, $(-1)(-3)$, $(-3)(-1)$.

**Răspuns:** $(a, b) \in \{(0, 2), (2, 0), (-2, -4), (-4, -2)\}$. *Barem: 3p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = (x - 2)e^x$

#### a) $f'(x) = (x - 1)e^x$

$$f'(x) = e^x + (x - 2)e^x = (x - 1)e^x.$$

*Barem: 2p, 3p.*

#### b) Asimptota orizontală spre $-\infty$

$$\lim_{x\to-\infty}(x - 2)e^x = \lim_{x\to-\infty}\frac{x - 2}{e^{-x}} \overset{\text{l'H}}{=} \lim_{x\to-\infty}\frac{1}{-e^{-x}} = 0.$$

**Răspuns:** $y = 0$. *Barem: 3p, 2p.*

#### c) $f'(x) \ge -1$ pentru orice $x$ real

$f''(x) = e^x + (x - 1)e^x = xe^x$, nul în $x = 0$; $f'' \le 0$ pe $(-\infty, 0]$ și $f'' \ge 0$ pe $[0, +\infty)$. Deci $f'$ are minimul în $0$:

$$f'(x) \ge f'(0) = -1. \ \blacksquare$$

*Barem: 2p, 1p, 2p.*

### 2. $f:(0, +\infty) \to \mathbb R$, $f(x) = \dfrac{2x^2 + 1}{x}$

#### a) $\displaystyle\int_1^2\left(f(x) - \frac1x\right)dx = 3$

$f(x) - \frac1x = 2x$:

$$\int_1^2 2x\,dx = x^2\Big|_1^2 = 3.$$

*Barem: 3p, 2p.*

#### b) $F(x) = x^2 + \ln x + 2016$ este o primitivă a lui $f$

$$F'(x) = 2x + \frac1x = \frac{2x^2 + 1}{x} = f(x).$$

*Barem: 2p, 3p.*

#### c) Volumul corpului obținut prin rotația graficului lui $g = f|_{[1,2]}$ este mai mic decât $14\pi$

$$g^2(x) = \left(2x + \frac1x\right)^2 = 4x^2 + 4 + \frac{1}{x^2}.$$

$$V = \pi\int_1^2\left(4x^2 + 4 + \frac{1}{x^2}\right)dx = \pi\left(\frac{4x^3}{3} + 4x - \frac1x\right)\Big|_1^2 = \pi\left(\frac{28}{3} + 4 + \frac12\right) = \frac{83\pi}{6}.$$

Cum $\frac{83}{6} < \frac{84}{6} = 14$, $V < 14\pi$. $\blacksquare$ *Barem: 2p, 3p.*
