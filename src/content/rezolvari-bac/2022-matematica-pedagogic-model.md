> **Cum să folosești rezolvarea:** lucrează întâi singur subiectul (deschide PDF-ul de mai sus), apoi compară fiecare pas. Dacă ai ajuns la alt drum corect, primești tot punctajul — baremul acceptă orice soluție corectă.

## Subiectul I (30 de puncte)

### 1. Arătați că $\sqrt3\,(2 - \sqrt3) + 3 = \sqrt{12}$

$$\sqrt3(2 - \sqrt3) + 3 = 2\sqrt3 - 3 + 3 = 2\sqrt3, \qquad \sqrt{12} = \sqrt{4\cdot3} = 2\sqrt3.$$

Cei doi membri sunt egali. *Barem: 3p calculul, 2p $\sqrt{12} = 2\sqrt3$.*

### 2. $f(x) = x + 1$, $g(x) = 2x - 1$; numerele naturale $a$ cu $f(a) > g(a)$

$$a + 1 > 2a - 1 \iff a < 2.$$

Cum $a \in \mathbb N$, obținem $a \in \{0, 1\}$. *Barem: 2p inecuația, 3p soluțiile.*

### 3. Ecuația $3^{x+2}\cdot 2^{x+1} + 2\cdot 6^x = 120$

$3^{x+2}\cdot2^{x+1} = 9\cdot 2\cdot 3^x 2^x = 18\cdot 6^x$, deci

$$18\cdot6^x + 2\cdot 6^x = 120 \iff 20\cdot 6^x = 120 \iff 6^x = 6 \iff x = 1.$$

**Răspuns:** $x = 1$. *Barem: 3p, 2p.*

### 4. Probabilitatea ca $n \in \{1, 2, \dots, 113\}$ să fie divizibil cu 4

Numerele naturale nenule mai mici decât $114$ sunt $1, \dots, 113$: **113 cazuri posibile**. Multiplii lui 4: $4, 8, \dots, 112 = 4\cdot 28$: **28 de cazuri favorabile**.

$$p = \frac{28}{113}.$$

*Barem: 2p + 2p + 1p.*

### 5. $a$ real cu $M(a, 15) \in d: y = 3x + 2a$

$$15 = 3a + 2a = 5a \iff a = 3.$$

**Răspuns:** $a = 3$. *Barem: 3p condiția, 2p rezultatul.*

### 6. $\triangle ABC$ dreptunghic în $A$, $AB = 3$, $AC = 4$, înălțimea $AD$. Arătați că $\sin\angle BAD = \frac35$

$BC = \sqrt{9 + 16} = 5$. Teorema catetei: $AB^2 = BD\cdot BC \Rightarrow BD = \dfrac{9}{5}$.

În $\triangle ABD$ (dreptunghic în $D$): $\sin\angle BAD = \dfrac{BD}{AB} = \dfrac{9/5}{3} = \dfrac35.$ $\blacksquare$

(Altfel: $\angle BAD = \angle C$, iar $\sin C = \frac{AB}{BC} = \frac35$.) *Barem: 3p $BD$, 2p sinusul.*

## Subiectul al II-lea (30 de puncte)

Legea asociativă pe $\mathbb R$: $x \circ y = 2xy - x - y + 1$.

### 1. $(-1)\circ(-1) = 5$

$$(-1)\circ(-1) = 2\cdot1 + 1 + 1 + 1 = 5.$$

*Barem: 2p + 3p.*

### 2. $x \circ y = 2\left(x - \frac12\right)\left(y - \frac12\right) + \frac12$

$$2\left(x - \tfrac12\right)\left(y - \tfrac12\right) + \tfrac12 = 2\left(xy - \tfrac x2 - \tfrac y2 + \tfrac14\right) + \tfrac12 = 2xy - x - y + 1 = x\circ y.$$

*Barem: 3p + 2p.*

### 3. $e = 1$ este elementul neutru

$$x\circ 1 = 2\left(x - \tfrac12\right)\cdot\tfrac12 + \tfrac12 = x - \tfrac12 + \tfrac12 = x,$$

și analog $1\circ x = x$, pentru orice $x$ real. $\blacksquare$ *Barem: 2p + 3p.*

### 4. $x \circ \frac12 = \frac12 \circ x = \frac12$

$$x\circ\tfrac12 = 2\left(x - \tfrac12\right)\cdot 0 + \tfrac12 = \tfrac12,$$

la fel $\tfrac12\circ x = \tfrac12$. *Barem: 2p + 3p.*

### 5. Calculați $\frac13\circ\frac24\circ\frac35\circ\dots\circ\frac{2020}{2022}$

Termenul $\frac{k}{k+2}$ pentru $k = 1$ este $\frac13$, pentru $k = 2$ este $\frac24 = \frac12$. Folosind asociativitatea și punctul 4:

$$\tfrac13\circ\left(\tfrac12\circ\tfrac35\circ\dots\circ\tfrac{2020}{2022}\right) = \tfrac13\circ\tfrac12 = \tfrac12.$$

**Răspuns:** $\frac12$. *Barem: 2p + 3p.*

### 6. $x > 0$ cu $\left(\log_2 x + \frac12\right)\circ\left(\log_3 x + \frac12\right) = \frac12$

Cu forma de la 2:

$$2\log_2 x\cdot\log_3 x + \tfrac12 = \tfrac12 \iff \log_2 x\cdot\log_3 x = 0 \iff x = 1.$$

**Răspuns:** $x = 1$ (convine, $x > 0$). *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

$I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$, $A = \begin{pmatrix}0&2\\2&0\end{pmatrix}$, $M(a) = \begin{pmatrix}a&2\\2&a\end{pmatrix}$.

### 1. $A\cdot A = 4I_2$

$$A\cdot A = \begin{pmatrix}0\cdot0 + 2\cdot2 & 0\\ 0 & 2\cdot 2\end{pmatrix} = \begin{pmatrix}4&0\\0&4\end{pmatrix} = 4I_2.$$

*Barem: 3p + 2p.*

### 2. $aI_2 + A = M(a)$

$$aI_2 + A = \begin{pmatrix}a&0\\0&a\end{pmatrix} + \begin{pmatrix}0&2\\2&0\end{pmatrix} = \begin{pmatrix}a&2\\2&a\end{pmatrix} = M(a).$$

*Barem: 3p + 2p.*

### 3. $M(2)\cdot M(4) = 6M(2)$

$$M(2)M(4) = (2I_2 + A)(4I_2 + A) = 8I_2 + 6A + A^2 = 12I_2 + 6A = 6(2I_2 + A) = 6M(2).$$

*Barem: 3p + 2p.*

### 4. Perechi $(a,b)$ de numere naturale cu $M(a)M(b) = 7I_2 + 4A$

$$M(a)M(b) = (aI_2 + A)(bI_2 + A) = abI_2 + (a+b)A + 4I_2 = (ab + 4)I_2 + (a + b)A.$$

Identificând: $ab + 4 = 7$ și $a + b = 4$, adică $ab = 3$, $a + b = 4$, deci $\{a, b\} = \{1, 3\}$.

**Răspuns:** $(1,3)$ și $(3,1)$. *Barem: 3p + 2p.*

### 5. $k$ natural cu $\det M(k+2) \le 0$

$$\det M(k+2) = (k+2)^2 - 4 = k^2 + 4k = k(k+4) \le 0.$$

Pentru $k \ge 0$, $k + 4 > 0$, deci $k \le 0$, adică $k = 0$. *Barem: 3p + 2p.*

### 6. $a < -2$ cu $M(a)^{-1} = M(a) - 2A$

$M(a) - 2A = \begin{pmatrix}a & -2\\ -2 & a\end{pmatrix}$, iar

$$M(a)\big(M(a) - 2A\big) = \begin{pmatrix}a^2 - 4 & 0\\ 0 & a^2 - 4\end{pmatrix} = I_2 \iff a^2 = 5.$$

Cum $a < -2$, rezultă $a = -\sqrt5$ (și $M(a)$ este inversabilă, $\det = a^2 - 4 = 1 \neq 0$).

**Răspuns:** $a = -\sqrt5$. *Barem: 2p + 3p.*

## Ce merită reținut din model

- **Scrierea $M(a) = aI_2 + A$** cu $A^2 = 4I_2$ transformă produsele de matrice în calcule cu „polinoame”.
- **Elementul absorbant** ($\frac12$ aici) rezolvă instant compunerile lungi.
- **Teorema catetei** $AB^2 = BD\cdot BC$ în triunghiul dreptunghic cu înălțime.
