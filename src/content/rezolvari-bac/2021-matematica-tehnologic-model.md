## Subiectul I (30 de puncte)

### 1. Arătați că $\left(0{,}25\cdot10 - \frac12\right)\left(0{,}25\cdot10 + \frac12\right) = 6$

$0{,}25\cdot10 = 2{,}5$, deci produsul este $(2{,}5 - 0{,}5)(2{,}5 + 0{,}5) = 2\cdot3 = 6$.

*Barem: 2p + 3p.*

### 2. $f(x) = x^2 - ax + 1$; $a$ cu $A(2,1) \in G_f$

$f(2) = 1 \iff 4 - 2a + 1 = 1 \iff a = 2$.

*Barem: 3p + 2p.*

### 3. Ecuația $3^{x+2} + 3^x = 30$

$3^x(9 + 1) = 30 \iff 3^x = 3 \iff x = 1$.

*Barem: 3p + 2p.*

### 4. Un obiect costă 500 de lei; prețul după o scumpire cu 20%

Scumpirea: $\frac{20}{100}\cdot500 = 100$ lei; prețul nou: $600$ de lei.

*Barem: 3p + 2p.*

### 5. $A(0,3)$, $B(8,3)$, $M$ mijlocul lui $AB$; distanța $OM$

$M(4, 3)$, deci $OM = \sqrt{4^2 + 3^2} = 5$.

*Barem: 2p + 3p.*

### 6. $\triangle ABC$ dreptunghic în $A$, $AB = 5$, $AC = 10$; aria

$$\mathcal A = \frac{AB\cdot AC}2 = \frac{5\cdot10}2 = 25.$$

*Barem: 2p + 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix}1&3\\1&2\end{pmatrix}$

#### a) $\det A = -1$

$$\det A = 1\cdot2 - 3\cdot1 = -1.$$

*Barem: 3p + 2p.*

#### b) $A\cdot A - 3A = I_2$

$$A\cdot A = \begin{pmatrix}4&9\\3&7\end{pmatrix},\quad A\cdot A - 3A = \begin{pmatrix}4 - 3 & 9 - 9\\ 3 - 3 & 7 - 6\end{pmatrix} = I_2.$$

*Barem: 3p + 2p.*

#### c) $X = \begin{pmatrix}1&x\\y&1\end{pmatrix}$ cu $AX - XA = \begin{pmatrix}-2&1\\-1&2\end{pmatrix}$

$$AX = \begin{pmatrix}1 + 3y & x + 3\\ 1 + 2y & x + 2\end{pmatrix},\quad XA = \begin{pmatrix}1 + x & 3 + 2x\\ 1 + y & 3y + 2\end{pmatrix},\quad AX - XA = \begin{pmatrix}3y - x & -x\\ y & x - 3y\end{pmatrix}.$$

Egalând: $-x = 1 \Rightarrow x = -1$; $y = -1$; verificare $3y - x = -2$ ✔, $x - 3y = 2$ ✔.

**Răspuns:** $x = y = -1$. *Barem: 2p + 3p.*

### 2. Legea $x\circ y = 4xy + x + y$

#### a) $3\circ2 = 29$

$$3\circ2 = 24 + 3 + 2 = 29.$$

*Barem: 3p + 2p.*

#### b) $x\circ y = \dfrac{(4x+1)(4y+1) - 1}{4}$

$$\frac{(4x+1)(4y+1) - 1}4 = \frac{16xy + 4x + 4y + 1 - 1}4 = 4xy + x + y = x\circ y.$$

*Barem: 3p + 2p.*

#### c) $x$ cu $x\circ x \le 2$

$$\frac{(4x+1)^2 - 1}4 \le 2 \iff (4x + 1)^2 \le 9 \iff -3 \le 4x + 1 \le 3 \iff -1 \le x \le \frac12.$$

**Răspuns:** $x \in \left[-1, \frac12\right]$. *Barem: 2p + 3p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = e^x + \dfrac{x}{x^2 + 1}$

#### a) $f'(x) = e^x + \dfrac{1 - x^2}{(x^2+1)^2}$

$$f'(x) = e^x + \frac{(x^2 + 1) - x\cdot2x}{(x^2+1)^2} = e^x + \frac{1 - x^2}{(x^2+1)^2}.$$

*Barem: 3p + 2p.*

#### b) Asimptota orizontală spre $-\infty$

$$\lim_{x\to-\infty}f(x) = \lim_{x\to-\infty}e^x + \lim_{x\to-\infty}\frac{x}{x^2+1} = 0 + 0 = 0.$$

**Răspuns:** $y = 0$. *Barem: 3p + 2p.*

#### c) $\dfrac{2 - e}{2e} \le f(x) \le \dfrac{2e + 1}2$ pe $[-1, 1]$

Pe $[-1,1]$: $1 - x^2 \ge 0$ și $e^x > 0$, deci $f'(x) > 0$: $f$ crescătoare. Prin urmare $f(-1) \le f(x) \le f(1)$, cu

$$f(-1) = \frac1e - \frac12 = \frac{2 - e}{2e},\qquad f(1) = e + \frac12 = \frac{2e + 1}2.\ \blacksquare$$

*Barem: 3p + 2p.*

### 2. $f:[0,\infty)\to\mathbb R$, $f(x) = (x + 1)\sqrt x$

#### a) $\displaystyle\int_1^2\frac{f(x)}{\sqrt x}dx = \frac52$

$$\int_1^2(x + 1)dx = \left(\frac{x^2}2 + x\right)\Big|_1^2 = 4 - \frac32 = \frac52.$$

*Barem: 3p + 2p.*

#### b) Volumul corpului de rotație al lui $g = f|_{[0,1]}$ este $\frac{17\pi}{12}$

$$V = \pi\int_0^1g^2(x)dx = \pi\int_0^1(x+1)^2x\,dx = \pi\int_0^1(x^3 + 2x^2 + x)dx = \pi\left(\frac14 + \frac23 + \frac12\right) = \frac{17\pi}{12}.$$

*Barem: 3p + 2p.*

#### c) $a$ cu $\displaystyle\int_1^e\frac{f(x)\sqrt x\ln x}{x + 1}dx = \frac{e^2 + a}4$

Integrandul se simplifică la $x\ln x$. Prin părți:

$$\int_1^ex\ln x\,dx = \frac{x^2}2\ln x\Big|_1^e - \int_1^e\frac x2dx = \frac{e^2}2 - \frac{e^2 - 1}4 = \frac{e^2 + 1}4.$$

**Răspuns:** $a = 1$. *Barem: 3p + 2p.*
