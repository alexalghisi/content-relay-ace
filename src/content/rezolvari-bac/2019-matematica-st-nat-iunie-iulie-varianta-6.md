## Subiectul I (30 de puncte)

### 1. Termenul $b_3$ al progresiei geometrice cu $b_1 = 1$, $q = 5$

$b_3 = b_1q^2 = 25$. *Barem: 3p, 2p.*

### 2. Intersecția graficelor lui $f(x) = x^2 - x + 1$ și $g(x) = 4x - 5$

$x^2 - x + 1 = 4x - 5 \iff x^2 - 5x + 6 = 0 \iff x \in \{2, 3\}$. *Barem: 2p, 3p.*

### 3. Ecuația $\sqrt{2x} + x = 4$

$\sqrt{2x} = 4 - x \Rightarrow 2x = 16 - 8x + x^2 \iff x^2 - 10x + 16 = 0 \iff x \in \{2, 8\}$.

Trebuie $4 - x \ge 0$: $x = 8$ nu convine; $x = 2$: $\sqrt4 + 2 = 4$ ✔.

**Răspuns:** $x = 2$. *Barem: 3p, 2p.*

### 4. $A = \{\sqrt1, \sqrt2, \dots, \sqrt{49}\}$: probabilitatea ca elementul ales să fie natural

49 de cazuri posibile; $\sqrt k \in \mathbb N \iff k$ pătrat perfect: $1, 4, 9, \dots, 49$ — 7 cazuri.

$$p = \frac{7}{49} = \frac17.$$

*Barem: 2p, 2p, 1p.*

### 5. Mediana din $A$ în $\triangle ABC$, $A(2,3)$, $B(-3,0)$, $C(-3,6)$

Mijlocul lui $BC$: $M(-3, 3)$. $A$ și $M$ au aceeași ordonată, deci mediana este $y = 3$.

**Răspuns:** $y = 3$. *Barem: 2p, 3p.*

### 6. $\sin x(3\sin x - \cos x) + \cos x(\sin x + 3\cos x) = 3$

$3\sin^2x - \sin x\cos x + \sin x\cos x + 3\cos^2x = 3(\sin^2 x + \cos^2x) = 3$. $\blacksquare$ *Barem: 2p, 3p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A(a) = \begin{pmatrix}a & 4\\ -4 & a\end{pmatrix}$

**a)** $\det A(-1) = 1 + 16 = 17$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** $$A(2019 - a) + A(2019 + a) = \begin{pmatrix}4038 & 8\\ -8 & 4038\end{pmatrix} = 2\begin{pmatrix}2019 & 4\\ -4 & 2019\end{pmatrix} = 2A(2019).\ \blacksquare$$

*Barem: 3p, 2p.*

**c)** $$A(x)A(y) = \begin{pmatrix}xy - 16 & 4x + 4y\\ -4x - 4y & xy - 16\end{pmatrix},\qquad 2A(-8) = \begin{pmatrix}-16 & 8\\ -8 & -16\end{pmatrix}.$$

$xy - 16 = -16 \Rightarrow xy = 0$; $4(x + y) = 8 \Rightarrow x + y = 2$.

**Răspuns:** $(x, y) \in \{(0, 2), (2, 0)\}$. *Barem: 3p, 2p.*

### 2. Pe $G = (-2, 2)$: $x * y = \dfrac{4x + 4y}{4 + xy}$

**a)** $x * 0 = \frac{4x}{4} = x$ și $0 * x = x$, deci $0$ este element neutru. $\blacksquare$ *Barem: 2p, 3p.*

**b)** $x * x = \dfrac{8x}{4 + x^2} = \dfrac85 \iff 5x = 4 + x^2 \iff x^2 - 5x + 4 = 0 \iff x \in \{1, 4\}$; $4 \notin G$.

**Răspuns:** $x = 1$. *Barem: 3p, 2p.*

**c)** $$f(x) * f(y) = \frac{4\left(\frac{2(x-1)}{x+1} + \frac{2(y-1)}{y+1}\right)}{4 + \frac{4(x-1)(y-1)}{(x+1)(y+1)}} = \frac{2\big[(x-1)(y+1) + (y-1)(x+1)\big]}{(x+1)(y+1) + (x-1)(y-1)}.$$

Numărătorul: $2(2xy - 2) = 4(xy - 1)$; numitorul: $2xy + 2 = 2(xy + 1)$. Deci

$$f(x) * f(y) = \frac{2(xy - 1)}{xy + 1} = f(xy).\ \blacksquare$$

*Barem: 3p, 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = 1 - 2x + 2\ln(x + 1)$, $x > -1$

**a)** $f'(x) = -2 + \dfrac{2}{x + 1} = \dfrac{-2x - 2 + 2}{x + 1} = \dfrac{-2x}{x+1}$. $\blacksquare$ *Barem: 3p, 2p.*

**b)** $f(0) = 1$, $f'(0) = 0$, deci tangenta este $y = 1$. *Barem: 2p, 3p.*

**c)** $f' \ge 0$ pe $(-1, 0]$, $f' \le 0$ pe $[0, +\infty)$, deci $f(x) \le f(0) = 1$, adică $1 - 2x + 2\ln(x+1) \le 1 \iff \ln(x + 1) \le x$ pentru orice $x > -1$.

Pentru $x \in (0, \pi)$, $\cos x > -1$, deci putem lua $\cos x$ în locul lui $x$: $\ln(1 + \cos x) \le \cos x$. $\blacksquare$

*Barem: 3p, 2p.*

### 2. $f(x) = \dfrac{x + 3}{e^x}$

**a)** $$\int_{-1}^1 f(x)e^xdx = \int_{-1}^1(x + 3)\,dx = \left(\frac{x^2}{2} + 3x\right)\Big|_{-1}^1 = \left(\frac12 + 3\right) - \left(\frac12 - 3\right) = 6.\ \blacksquare$$

*Barem: 3p, 2p.*

**b)** Pentru orice primitivă $F$: $F'(x) = f(x) = \frac{x + 3}{e^x} \ge 0$ pe $[-3, +\infty)$, deci $F$ este crescătoare acolo. $\blacksquare$ *Barem: 2p, 3p.*

**c)** Pe $[0, n]$, $f > 0$. O primitivă a lui $(x + 3)e^{-x}$ este $-(x + 4)e^{-x}$ (verificare prin derivare: $-e^{-x} + (x+4)e^{-x} = (x + 3)e^{-x}$):

$$\mathcal A = -(x + 4)e^{-x}\Big|_0^n = 4 - (n + 4)e^{-n}.$$

$4 - (n + 4)e^{-n} = 4 - 6e^{-n} \iff n + 4 = 6 \iff n = 2$.

**Răspuns:** $n = 2$. *Barem: 3p, 2p.*

## Ce merită reținut din varianta 6

- **Inegalitatea $\ln(1 + t) \le t$** se obține din maximul unei funcții și se aplică apoi pentru $t = \cos x$.
- **Izomorfisme:** pentru $f(xy) = f(x) * f(y)$ calculează direct membrul drept și simplifică.
- **Primitiva lui $(ax + b)e^{-x}$** are forma $(cx + d)e^{-x}$ — găsește coeficienții prin derivare.
