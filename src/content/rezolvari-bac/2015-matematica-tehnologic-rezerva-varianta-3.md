## Subiectul I (30 de puncte)

### 1. Media geometrică a numerelor $16$ și $9$ este $12$

$$m_g = \sqrt{16\cdot9} = 4\cdot3 = 12.$$

*Barem: 3p + 2p.*

### 2. $m$ cu $f(2) = 0$, $f(x) = x + m$

$2 + m = 0 \iff m = -2$. *Barem: 2p + 3p.*

### 3. Ecuația $3^{2x+1} = 3^5$

$2x + 1 = 5 \iff x = 2$. *Barem: 3p + 2p.*

### 4. Probabilitatea ca un număr din $\{1, \dots, 9\}$ să fie multiplu de 2

Favorabile: $2, 4, 6, 8$ — 4 din 9.

$$p = \frac49.$$

*Barem: 1p + 2p + 2p.*

### 5. Mijlocul segmentului $AB$, $A(-1,3)$, $B(5,3)$

$x_M = \frac{-1 + 5}{2} = 2$, $y_M = 3$. **Răspuns:** $M(2, 3)$. *Barem: 3p + 2p.*

### 6. $\sin x = \frac12$, știind $x \in \left(0, \frac\pi2\right)$ și $\cos x = \frac{\sqrt3}{2}$

$$\sin^2 x = 1 - \frac34 = \frac14,$$

iar în cadranul I $\sin x > 0$, deci $\sin x = \frac12$. *Barem: 3p + 2p.*

## Subiectul al II-lea (30 de puncte)

### 1. $A = \begin{pmatrix} 1 & 3\\ 2 & 1\end{pmatrix}$, $B = \begin{pmatrix} -4 & 0\\ 0 & 4\end{pmatrix}$, $C(x) = \begin{pmatrix} x & 1\\ 2 & 3\end{pmatrix}$

#### a) $\det A = -5$

$$\det A = 1 - 6 = -5.$$

*Barem: 3p + 2p.*

#### b) $\det(A + C(-1)) = \det B$

$$A + C(-1) = \begin{pmatrix} 0 & 4\\ 4 & 4\end{pmatrix}, \quad \det = 0 - 16 = -16; \qquad \det B = -16.$$

*Barem: 3p + 2p.*

#### c) $x$ cu $C(x)\cdot A - A\cdot C(x) = B$

$$C(x)\cdot A = \begin{pmatrix} x + 2 & 3x + 1\\ 8 & 9\end{pmatrix}, \qquad A\cdot C(x) = \begin{pmatrix} x + 6 & 10\\ 2x + 2 & 5\end{pmatrix},$$

$$C(x)A - AC(x) = \begin{pmatrix} -4 & 3x - 9\\ 6 - 2x & 4\end{pmatrix}.$$

Egalitatea cu $B$ cere $3x - 9 = 0$ și $6 - 2x = 0$, deci $x = 3$.

**Răspuns:** $x = 3$. *Barem: 3p + 2p.*

### 2. $f = X^3 + 2X^2 - 6X + 3$

#### a) $f(1) = 0$

$$1 + 2 - 6 + 3 = 0.$$

*Barem: 3p + 2p.*

#### b) Câtul și restul împărțirii la $X^2 + 3X - 3$

$(X - 1)(X^2 + 3X - 3) = X^3 + 3X^2 - 3X - X^2 - 3X + 3 = X^3 + 2X^2 - 6X + 3 = f$.

**Răspuns:** câtul $X - 1$, restul $0$. *Barem: 3p + 2p.*

#### c) $x_1 + x_2 + x_3 + \frac{1}{x_1} + \frac{1}{x_2} + \frac{1}{x_3} = 0$

Viète: $\sum x_i = -2$, $\sum x_ix_j = -6$, $x_1x_2x_3 = -3$.

$$\sum\frac{1}{x_i} = \frac{\sum x_ix_j}{x_1x_2x_3} = \frac{-6}{-3} = 2,$$

deci suma cerută este $-2 + 2 = 0$. $\blacksquare$ *Barem: 3p + 2p.*

## Subiectul al III-lea (30 de puncte)

### 1. $f(x) = x^3 - 3x + 1$

#### a) $f'(x) = 3(x-1)(x+1)$

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1).$$

*Barem: 3p + 2p.*

#### b) $\lim\limits_{x\to+\infty}\dfrac{f(x) - x^3}{x}$

$$\lim_{x\to+\infty}\frac{-3x + 1}{x} = -3.$$

*Barem: 2p + 3p.*

#### c) $-1 \le f(x) \le 3$ pentru $x \in [-1, 1]$

Pe $[-1, 1]$, $f'(x) \le 0$, deci $f$ este descrescătoare: $f(1) \le f(x) \le f(-1)$.

$f(1) = 1 - 3 + 1 = -1$, $f(-1) = -1 + 3 + 1 = 3$. $\blacksquare$ *Barem: 2p + 3p.*

### 2. $f:(0,+\infty)\to\mathbb R$, $f(x) = 2x + \frac1x$

#### a) $\displaystyle\int_2^3\left(f(x) - \frac1x\right)dx = 5$

$$\int_2^3 2x\,dx = x^2\Big|_2^3 = 9 - 4 = 5.$$

*Barem: 3p + 2p.*

#### b) $F(x) = x^2 + \ln x + 2015$ este primitivă a lui $f$

$$F'(x) = 2x + \frac1x = f(x).$$

*Barem: 2p + 3p.*

#### c) Volumul pentru $g(x) = f(x) - 2x = \frac1x$ pe $[1,2]$

$$V = \pi\int_1^2\frac{1}{x^2}\,dx = \pi\left(-\frac1x\right)\Big|_1^2 = \pi\left(-\frac12 + 1\right) = \frac\pi2.$$

*Barem: 3p + 2p.*
